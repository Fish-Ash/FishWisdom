JavaScript变量

  • 数组

JavaScript提供以下三种声明变量的方法：


            var x;
            let y;
            const z;

其中，var变量与let变量均为常规变量，可以是整型、浮点型、字符串或null值，但是let变量更安全.

const声明的是常量.

数据类型

  • String：字符串
  • Number：浮点数
  • BigInt：整数
  • Boolean：true或false
  • null：空值
  • undefined：未定义

类型转换

转换为浮点数 

                parseFloat(value)
字符串拼接 

            "String" + Variable +"String";
模板字符串 

            `String ${Variable} String`;
字符串字数 

            S.length;
字符串全大写 

            S.toUpperCase();
字符串全小写 

            S.toLowerCase();
字符串切片 

            S.substring(start, end);
字符串分割 

            S.split("");

数组

定义数组 

                let array = [];
                let array = new Array();
索引 

                Array[index];
数组头部增加元素 

                array.unshift(element);
数组尾部增加元素 

                array.push();
删除数组末尾元素 

                array.pop();
判断变量是否为数组 

                Array.isArray(Variable);
获取特定元素的索引 

                array.indexOf(element);
