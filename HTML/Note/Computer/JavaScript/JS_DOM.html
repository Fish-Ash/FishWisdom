DOM

获取元素

通过id获取某个元素 

            const element = document.getElementById("id")
通过class获取元素 

            const element = document.getElementByClassName("class");

[注]即使只有一个该class的元素，使用这种方法返回的也是一个数组.

获取元素 

            const element = document.querySelector("Tag")
            const element = document.querySelector(".class")
            const element = document.querySelector("#id")
            const element = document.querySelector("Tag.class")

            const element = document.querySelectorAll("Tag")
            # 返回所有符合条件的元素为NodeList数据

forEach()是数组或类数组（如NodeList）的方法，会对集合中的每一个元素调用回调函数.


            element.forEach(item => {})
            # item：数组或非数组中当前遍历到的元素
            # {}中的内容为回调函数
