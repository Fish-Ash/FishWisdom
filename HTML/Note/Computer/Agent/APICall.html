大模型API调用——最简单的对话尝试

环境搭建

openai库 
pip install openai

openai库是用于调用api的，哪怕不适用chatgpt的api也可以使用这个库.

from openai import OpenAI

配置客户端


            client = OpenAI(
                api_key = ... # 可用的API Key
                base_url = ... # 所用模型的url
            )

发起一次最简单的对话


            response = client.chat.completions.create(
                model = ... # 所使用的模型
                message = [
                    {"role": ..., "content": ...}
                ]
            )
            """
            .chat：调用聊天功能
            客户端的功能包括：
            - .chat：聊天
            - .image：图像生成
            - .audio：语音转文字
            - .embedding：嵌入向量
            - .fine_tuning：模型微调
            """

            """
            .completions.create：发起一次对话请求
            [注]completions其实另有含义，但是不纠结
            """

            """
            "role"：用户身份，包括：
                - system：系统指令（开发者）
                - user：用户消息（用户）
                - assistant：助手消息（模型）
            """

            """
            "content"：内容
            """

获取模型回复


            print(response.choices[0].message.content)

            """
            .choices[0]
            模型回复时会生成很多候选回复，[0]表示取第一个            
            """

            """
            .message.content：内容
            """

完整代码示例


            from openai import OpenAI

            # 1. 配置客户端（指向智谱，这就叫协议兼容）
            client = OpenAI(
                api_key="2e677758637d4c2f93f7ac92e34a3c78.b1r8aLUJSPX1d4fY",  # 替换为你刚才复制的Key
                base_url="https://open.bigmodel.cn/api/paas/v4"  # 关键：把请求发送到智谱
            )

            # 2. 发起一次最简单的对话
            response = client.chat.completions.create(
                model="glm-4.7-flash",  # 智谱的模型名
                messages=[
                    {"role": "user", "content": "你好，请用一句话介绍你自己"}
                ]
            )

            # 3. 打印模型的回复
            print(response.choices[0].message.content)
