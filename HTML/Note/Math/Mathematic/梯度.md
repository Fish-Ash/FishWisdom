# 梯度

求出$r = \sqrt{x^2 + y^2 + z^2}$（位置矢量大小）的梯度

**解答**
$$\begin{align}\nabla r &= \frac{\partial r}{\partial x}\hat{\mathbf{x}} + \frac{\partial r}{\partial y}\hat{\mathbf{y}} + \frac{\partial r}{\partial z}\hat{\mathbf{z}}\\&=\frac{2x}{2\sqrt{x^2 + y^2 + z^2}}\hat{\mathbf{x}} + \frac{2y}{2\sqrt{x^2 + y^2 + z^2}}\hat{\mathbf{y}} + \frac{2z}{2\sqrt{x^2 + y^2 + z^2}}\hat{\mathbf{z}}\\&=\frac{x\hat{\mathbf{x}} + y\hat{\mathbf{y}} + z\hat{\mathbf{z}}}{\sqrt{x^2 + y^2 + z^2}}\\&=\frac{\mathbf{r}}{r}\\&=\hat{\mathbf{r}}\end{align}$$
