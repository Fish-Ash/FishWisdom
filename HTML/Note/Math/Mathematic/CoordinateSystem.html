坐标系

球坐标系

点P的球坐标为：\((r,\theta,\phi)\).

  • \(r\)：到原点的距离（位置矢量的大小）
  • \(\theta\)：极角，位置矢量与z轴的夹角
  • \(\phi\)：方位角，位置矢量在xy平面投影与x轴的夹角

球坐标\((r,\theta,\phi)\)与直角坐标\((x,y,z)\)的关系为：

$$x = r\sin\theta\cos\phi$$ $$y = r\sin\theta\sin\phi$$ $$z = r\cos\theta$$

柱坐标系

柱坐标\(r,\phi,z\)与直角坐标\(x,y,z\)的关系为：

$$x = r\cos\phi$$ $$y = r\sin\phi$$ $$z = z$$
$$r = \sqrt{x^2 + y^2}$$ $$\phi = \arctan\frac{y}{x}$$ $$z = z$$

直角坐标系与柱坐标系的转化

$$r$$ $$\phi$$
$$x$$
$$\frac{\partial r}{\partial x} = \cos\phi$$
$$\because r = \sqrt{x^2 + y^2}$$ $$\therefore \frac{\partial r}{\partial x} = \frac{1}{2\sqrt{x^2 + y^2}}\cdot 2x = \frac{x}{r}$$ $$\because x = r\cos\phi$$ $$\therefore \frac{\partial r}{\partial x} = \cos\phi$$
$$\frac{\partial\phi}{\partial x} = -\frac{\sin\phi}{r}$$
$$\because \phi = \arctan\frac{y}{x}$$ $$\therefore \frac{\partial\phi}{\partial x} = \frac{1}{1 + \left(\frac{y}{x}\right)^2}\cdot -\frac{y}{x^2} = -\frac{y}{x^2 + y^2}$$ $$\because y = r\sin\phi,\quad r = \sqrt{x^2 + y^2}$$ $$\therefore \frac{\partial\phi}{\partial x} = -\frac{\sin\phi}{r}$$
$$y$$
$$\frac{\partial r}{\partial y} = \sin\phi$$
$$\because r = \sqrt{x^2 + y^2}$$ $$\therefore\frac{\partial r}{\partial y} = \frac{1}{2\sqrt{x^2 + y^2}}\cdot 2y = \frac{y}{r}$$ $$\because y = r\sin\phi$$ $$\therefore\frac{\partial r}{\partial y} = \sin\phi$$
$$\frac{\partial\phi}{\partial y} = \frac{\cos\phi}{r}$$
$$\because \phi = \arctan\frac{y}{x}$$ $$\frac{\partial\phi}{\partial y} = \frac{1}{1 + \left(\frac{y}{x}\right)^2}\cdot \frac{1}{x} = \frac{x}{x^2 + y^2}$$ $$\because x = r\cos\phi,\quad r = \sqrt{x^2 + y^2}$$ $$\therefore\frac{\partial\phi}{\partial y} = \frac{\cos\phi}{r}$$
$$\frac{\partial}{\partial x} = \cos\phi\frac{\partial}{\partial r} - \frac{\sin\phi}{r}\frac{\partial}{\partial\phi}$$
$$\because\frac{\partial}{\partial x} = \frac{\partial}{\partial r}\frac{\partial r}{\partial x} + \frac{\partial}{\partial\phi}\frac{\partial\phi}{\partial x}$$ $$\therefore \frac{\partial}{\partial x} = \cos\phi\frac{\partial}{\partial r} - \frac{\sin\phi}{r}\frac{\partial}{\partial\phi}$$
$$\frac{\partial}{\partial y} = \sin\phi\frac{\partial}{\partial r} + \frac{\cos\phi}{r}\frac{\partial}{\partial\phi}$$
$$\because\frac{\partial}{\partial y} = \frac{\partial}{\partial r}\frac{\partial r}{\partial y} + \frac{\partial}{\partial\phi}\frac{\partial\phi}{\partial y}$$ $$\therefore\frac{\partial}{\partial y} = \sin\phi\frac{\partial}{\partial r} + \frac{\cos\phi}{r}\frac{\partial}{\partial\phi}$$
$$\begin{align} \frac{\partial^2}{\partial x^2} =& \cos^2\phi\frac{\partial^2}{\partial r^2} + \frac{\sin^2\phi}{r}\frac{\partial}{\partial r} - \frac{\sin\phi\cos\phi}{r}\frac{\partial^2}{\partial r\partial\phi}\\ & -\frac{\sin\phi\cos\phi}{r}\frac{\partial^2}{\partial\phi\partial r} + \frac{2\sin\phi\cos\phi}{r^2}\frac{\partial}{\partial\phi} + \frac{\sin^2\phi}{r^2}\frac{\partial^2}{\partial\phi^2} \end{align}$$
$$\begin{align} \frac{\partial^2}{\partial x^2} =& \frac{\partial}{\partial x}\left(\frac{\partial}{\partial x}\right)\\ =& \left(\cos\phi\frac{\partial}{\partial r} - \frac{\sin\phi}{r}\frac{\partial}{\partial\phi}\right)\left(\cos\phi\frac{\partial}{\partial r} - \frac{\sin\phi}{r}\frac{\partial}{\partial\phi}\right)\\ =& \cos\phi\frac{\partial}{\partial r}\left(\cos\phi\frac{\partial}{\partial r}\right) - \cos\phi\frac{\partial}{\partial r}\left(\frac{\sin\phi}{r}\frac{\partial}{\partial\phi}\right)\\ & -\frac{\sin\phi}{r}\frac{\partial}{\partial\phi}\left(\cos\phi\frac{\partial}{\partial r}\right) + \frac{\sin\phi}{r}\frac{\partial}{\partial\phi}\left(\frac{\sin\phi}{r}\frac{\partial}{\partial\phi}\right)\\ =& \cos^2\phi\frac{\partial^2}{\partial r^2} - \sin\phi\cos\phi\left(-\frac{1}{r^2}\frac{\partial}{\partial\phi} + \frac{1}{r}\frac{\partial^2}{\partial r\partial\phi}\right)\\ & -\frac{\sin\phi}{r}\left(-\sin\phi\frac{\partial}{\partial r} + \cos\phi\frac{\partial^2}{\partial\phi\partial r}\right) + \frac{\sin\phi}{r^2}\left(\cos\phi\frac{\partial}{\partial\phi} + \sin\phi\frac{\partial^2}{\partial\phi^2}\right)\\ =& \cos^2\phi\frac{\partial^2}{\partial r^2} + \frac{\sin\phi\cos\phi}{r^2}\frac{\partial}{\partial\phi} - \frac{\sin\phi\cos\phi}{r}\frac{\partial^2}{\partial r\partial\phi} + \frac{\sin^2\phi}{r}\frac{\partial}{\partial r}\\ & -\frac{\sin\phi\cos\phi}{r}\frac{\partial^2}{\partial\phi\partial r} + \frac{\sin\phi\cos\phi}{r^2}\frac{\partial}{\partial\phi} + \frac{\sin^2\phi}{r^2}\frac{\partial^2}{\partial\phi^2}\\ =& \cos^2\phi\frac{\partial^2}{\partial r^2} + \frac{\sin^2\phi}{r}\frac{\partial}{\partial r} - \frac{\sin\phi\cos\phi}{r}\frac{\partial^2}{\partial r\partial\phi}\\ & -\frac{\sin\phi\cos\phi}{r}\frac{\partial^2}{\partial\phi\partial r} + \frac{2\sin\phi\cos\phi}{r^2}\frac{\partial}{\partial\phi} + \frac{\sin^2\phi}{r^2}\frac{\partial^2}{\partial\phi^2} \end{align}$$
$$\begin{align} \frac{\partial^2}{\partial y^2} =& \sin^2\phi\frac{\partial^2}{\partial r^2} + \frac{\cos^2\phi}{r}\frac{\partial}{\partial r} + \frac{\sin\phi\cos\phi}{r}\frac{\partial^2}{\partial r\partial\phi}\\ & +\frac{\sin\phi\cos\phi}{r}\frac{\partial^2}{\partial\phi\partial r} - \frac{2\sin\phi\cos\phi}{r^2}\frac{\partial}{\partial\phi} + \frac{\cos^2\phi}{r^2}\frac{\partial^2}{\partial\phi^2} \end{align}$$
