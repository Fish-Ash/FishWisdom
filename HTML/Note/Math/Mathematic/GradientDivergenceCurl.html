梯度、散度、旋度

\(\nabla\)算子

$$\nabla = \frac{\partial}{\partial x}\hat{\boldsymbol{x}} + \frac{\partial y}{\partial y}\hat{\boldsymbol{y}} + \frac{\partial}{\partial z}\hat{\boldsymbol{z}}$$
\(\nabla\)的三种作用方式
梯度 作用在一个标量函数\(F\)上 $$\nabla F$$
散度 通过点积作用在一个矢量函数\(\boldsymbol{v}\)上 $$\nabla\cdot\boldsymbol{v}$$
旋度 通过叉积作用在一个矢量函数\(\boldsymbol{v}\)上 $$\nabla\times\boldsymbol{v}$$

梯度

$$\begin{align} \mathrm{d}F &= \left(\frac{\partial F}{\partial x}\right)\mathrm{d}x + \left(\frac{\partial F}{\partial y}\right)\mathrm{d}y + \left(\frac{\partial F}{\partial z}\right)\mathrm{d}z\\ &= \left(\frac{\partial F}{\partial x}\hat{\boldsymbol{x}} + \frac{\partial F}{\partial y}\hat{\boldsymbol{y}} + \frac{\partial F}{\partial z}\hat{\boldsymbol{z}}\right)\cdot(\mathrm{d}x\hat{\boldsymbol{x}} + \mathrm{d}y\hat{\boldsymbol{y}} + \mathrm{d}z\hat{\boldsymbol{z}})\\ &= \nabla F\cdot \mathrm{d}\boldsymbol{l} \end{align}$$

其中：

$$\nabla F = \left(\frac{\partial F}{\partial x}\hat{\boldsymbol{x}} + \frac{\partial F}{\partial y}\hat{\boldsymbol{y}} + \frac{\partial F}{\partial z}\hat{\boldsymbol{z}}\right)$$

称为F的梯度.

散度

$$\begin{align} \nabla\cdot \boldsymbol{v} &= \left(\frac{\partial}{\partial x}\hat{\boldsymbol{x}} + \frac{\partial}{\partial y}\hat{\boldsymbol{y}} + \frac{\partial}{\partial z}\hat{\boldsymbol{z}}\right)\cdot (v_x\hat{\boldsymbol{x}} + v_y\hat{\boldsymbol{y}} + v_z\hat{\boldsymbol{z}})\\ &= \frac{\partial v_x}{\partial x} + \frac{\partial v_y}{\partial y} + \frac{\partial v_z}{\partial z} \end{align}$$

旋度

$$\begin{align} \nabla\times\boldsymbol{v} &= \left|\begin{matrix}\hat{\boldsymbol{x}}&\hat{\boldsymbol{y}}&\hat{\boldsymbol{z}}\\\partial/\partial x& \partial/\partial y&\partial/\partial z\\v_x&v_y&v_z\end{matrix}\right|\\ &= \left(\frac{\partial v_z}{\partial y}-\frac{\partial v_y}{\partial v_z}\right)\hat{\boldsymbol{x}} + \left(\frac{\partial v_x}{\partial z} - \frac{\partial v_z}{\partial v_x}\right)\hat{\boldsymbol{y}} + \left(\frac{\partial v_y}{\partial x} - \frac{\partial v_x}{\partial y}\right)\hat{\boldsymbol{z}} \end{align}$$
$$\nabla\times \frac{\partial \boldsymbol{Y}}{\partial t} = \frac{\partial}{\partial t}(\nabla\times\boldsymbol{Y})$$

一般运算规则

$$\nabla(f+g) = \nabla f + \nabla g$$ $$\nabla\cdot(\boldsymbol{A}+\boldsymbol{B}) = (\nabla\cdot\boldsymbol{A}) + (\nabla\cdot\boldsymbol{B})$$ $$\nabla\times(\boldsymbol{A}+\boldsymbol{B}) = (\nabla\times\boldsymbol{A}) + (\nabla\times\boldsymbol{B})$$ $$\nabla(kf) = k(\nabla f)$$ $$\nabla\cdot(k\boldsymbol{A}) = k(\nabla\cdot\boldsymbol{A})$$ $$\nabla\times(k\boldsymbol{A}) = k(\nabla\times\boldsymbol{A})$$

积规则

用两个矢量或标量去构造一个标量有两种方式：

  • 两个标量函数的乘积：\(fg\)
  • 两个矢量函数的点积：\(\boldsymbol{A}\cdot\boldsymbol{B}\)

对应地，梯度有两个积规则：

$$\nabla(fg) = f\nabla g + g\nabla f$$ $$\nabla(\boldsymbol{A}\cdot\boldsymbol{B}) = \boldsymbol{A}\times(\nabla\times\boldsymbol{B}) + \boldsymbol{B}\times(\nabla\times\boldsymbol{A}) + (\boldsymbol{A}\cdot\nabla)\boldsymbol{B} + (\boldsymbol{B}\cdot\nabla)\boldsymbol{A}$$

用两个矢量或标量去构造一个矢量有两种方式：

  • 标量函数与矢量函数的乘积：\(f\boldsymbol{A}\)
  • 两个矢量函数的叉积：\(\boldsymbol{A}\times\boldsymbol{B}\)

对应地，散度有两个积规则：

$$\nabla\cdot(f\boldsymbol{A}) = f(\nabla\cdot\boldsymbol{A}) + \boldsymbol{A}\cdot(\nabla f)$$ $$\nabla\cdot(\boldsymbol{A}\times\boldsymbol{B}) = \boldsymbol{B}\cdot(\nabla\times\boldsymbol{A}) - \boldsymbol{A}\cdot(\nabla\times\boldsymbol{B})$$

旋度有两个积规则：

$$\nabla\times(f\boldsymbol{A}) = f(\nabla\times\boldsymbol{A}) - \boldsymbol{A}\times(\nabla f)$$ $$\nabla\times(\boldsymbol{A}\times\boldsymbol{B}) = (\boldsymbol{B}\cdot\nabla)\boldsymbol{A} - (\boldsymbol{A}\cdot\nabla)\boldsymbol{B} + \boldsymbol{A}(\nabla\cdot\boldsymbol{B}) - \boldsymbol{B}(\nabla\cdot\boldsymbol{A})$$

二阶微分

梯度\(\nabla F\)为矢量，因此可以对其求散度与旋度.

梯度的散度\(\nabla\cdot(\nabla F)\)

$$\begin{align} \nabla\cdot(\nabla F) &= (\frac{\partial}{\partial x}\hat{\boldsymbol{x}} + \frac{\partial}{\partial y}\hat{\boldsymbol{y}} + \frac{\partial}{\partial z}\hat{\boldsymbol{z}})\cdot\left(\frac{\partial F}{\partial x}\hat{\boldsymbol{x}} + \frac{\partial F}{\partial y}\hat{\boldsymbol{y}} + \frac{\partial F}{\partial z}\hat{\boldsymbol{z}}\right)\\ &= \frac{\partial^2 F}{\partial x^2} + \frac{\partial^2 F}{\partial y^2} + \frac{\partial^2 F}{\partial z^2}\\ &= \nabla^2 F \end{align}$$

\(\nabla^2 F\)称为\(F\)的拉普拉斯.

一个标量的拉普拉斯仍为标量.

梯度的旋度\(\nabla\times(\nabla F)\)

$$\nabla\times(\nabla F) = 0$$

散度\(\nabla\cdot\boldsymbol{v}\)为标量，因此可以对其求梯度.

散度的梯度\(\nabla(\nabla\cdot\boldsymbol{v})\)

旋度\(\nabla\times\boldsymbol{v}\)为矢量，因此可以对其求散度与旋度

旋度的散度\(\nabla\cdot(\nabla\times\boldsymbol{v})\)

$$\nabla\cdot(\nabla\times\boldsymbol{v}) = 0$$

旋度的旋度\(\nabla\times(\nabla\times\boldsymbol{v})\)

$$\nabla\times(\nabla\times\boldsymbol{v}) = \nabla(\nabla\cdot\boldsymbol{v}) - \nabla^2\boldsymbol{v}$$

其他性质

$$\boldsymbol{\nabla}\times\frac{\partial\boldsymbol{E}}{\partial t} = \frac{\partial\nabla\times\boldsymbol{E}}{\partial t}$$

矢量导数在球坐标系中的表示

梯度 $$\nabla F = \frac{\partial F}{\partial r}\hat{\boldsymbol{r}} + \frac{1}{r}\frac{\partial F}{\partial\theta}\hat{\boldsymbol{\theta}} + \frac{1}{r\sin\theta}\frac{\partial F}{\partial \phi}\hat{\boldsymbol{\phi}}$$
散度 $$\nabla\cdot\boldsymbol{v} = \frac{1}{r^2}\frac{\partial}{\partial r}(r^2 v_r)+\frac{1}{r\sin\theta}\frac{\partial}{\partial\theta}(\sin\theta v_\theta) + \frac{1}{r\sin\theta}\frac{\partial v_\phi}{\partial\phi}$$
旋度 $$\nabla\times\mathbf{v} = \frac{1}{r\sin\theta}\left[\frac{\partial}{\partial\theta}(\sin\theta v_\phi) - \frac{\partial v_\theta}{\partial\phi}\right]\hat{\boldsymbol{r}} + \frac{1}{r}\left[\frac{1}{\sin\theta}\frac{\partial v_r}{\partial\phi} - \frac{\partial}{\partial r}(rv_\phi)\right]\hat{\boldsymbol{\theta}}+\frac{1}{r}\left[\frac{\partial}{\partial r}(rv_\theta)-\frac{\partial v_r}{\partial\theta}\right]\hat{\boldsymbol{\phi}}$$
