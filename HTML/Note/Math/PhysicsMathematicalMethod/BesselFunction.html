Bessel方程

正则奇点邻域上的Bessel方程级数解

\(\nu\)阶Bessel方程

在\(x_0 = 0\)的邻域上求解\(\nu\)阶Bessel方程：

$$x^2\frac{\mathrm{d}^2y}{\mathrm{d}x^2} + x\frac{\mathrm{d}y}{\mathrm{d}x} + (x^2 - \nu^2)y = 0$$
  • \(\nu\)：阶数，不为整数或半整数
$$y'' + \frac{1}{x}y' + \left(1 - \frac{\nu^2}{x^2}\right)y = 0$$

点\(x_0 = 0\)为\(p(x) = \frac{1}{x}\)的一阶极点，又是\(q(x) = 1 - \frac{\nu^2}{x^2}\)的二阶极点，因此\(x_0 = 0\)为Bessel方程的正则奇点.

判定方程为：

$$s(s-1) + s - \nu^2 = 0$$

即

$$s^2 - \nu^2 = 0$$ $$s_1 = \nu,\quad s_2 = -\nu$$

\(s_1 - s_2 = 2\nu\neq\mathbb{Z}\)，因此线性独立解的形式为：

$$\omega_1(z) = \sum_{k=0}^\infty a_k (z-z_0)^{s_1 +k}$$ $$\omega_2(z) = \sum_{k=0}^\infty b_k (z-z_0)^{s_2 +k}$$

半奇数\(l+1/2\)阶Bessel方程

在\(x_0 = 0\)的邻域上求解\(l+1/2\)阶Bessel方程：

$$x^2y'' + xy' + \left[x^2 - (l + 1/2)^2\right]y = 0,\quad l=0,1,2,\cdots$$

\(x_0 = 0\)为方程的正则奇点.

\(l\)阶球Bessel方程

$$r^2\frac{\mathrm{d}^2R}{\mathrm{d}r^2} + 2r\frac{\mathrm{d}R}{\mathrm{d}r} + \left[k^2r^2 - l(l+1)\right]R = 0$$

\(k=0\)时，方程退化为：

$$r^2\frac{\mathrm{d}^2R}{\mathrm{d}r^2} + 2r\frac{\mathrm{d}R}{\mathrm{d}r} - l(l+1)R = 0$$

[令]

$$x = kr,\quad R(r) = \sqrt{\frac{\pi}{2x}}y(x)$$

则方程化为\(l + 1/2\)阶Bessel方程：

$$x^2\frac{\mathrm{d}^2y}{\mathrm{d}x^2} + x\frac{\mathrm{d}y}{\mathrm{d}x} + \left[x^2 - \left(l + \frac{1}{2}\right)^2\right]y = 0$$

线性独立解

\(l + 1/2\)阶Bessel方程有如下几种解：

$$J_{l + 1/2}(x),\quad J_{-(l + 1/2)},\quad N_{l + 1/2}(x),\quad H_{l + 1/2}^{(1)}(x),\quad H_{l + 1/2}^{(2)}(x)$$

其中，任取两个就组成\(l+1/2\)阶Bessel方程的线性独立解.

这样，\(l\)阶Bessel方程的线性独立解就是下列五种中的任选两种：

球Bessel函数： $$j_l(x) = \sqrt{\frac{\pi}{2x}}J_{l + 1/2}(x)$$ $$j_{-l}(x) = \sqrt{\frac{\pi}{2x}}J_{-l + 1/2}(x)$$ 球Neumann函数： $$n_l(x) = \sqrt{\frac{\pi}{2x}}N_{l + 1/2}(x)$$ 球Hankel函数： $$h_l^{(1)}(x) = \sqrt{\frac{\pi}{2x}}H_{l + 1/2}^{(1)}(x)$$ $$h_l^{(2)}(x) = \sqrt{\frac{\pi}{2x}}H_{l + 1/2}^{(2)}(x)$$

递推公式

用\(z_l(x)\)表示球Bessel函数中球Neumann函数或球Hankel函数：

$$z_l(x) = \sqrt{\frac{\pi}{2x}}Z_{l + 1/2}(x)$$ $$\because Z_{\nu+1}(x) - 2\nu Z_{\nu}(x)/x + Z_{\nu-1}(x) = 0$$

[令]\(\nu = l + 1/2\)

$$Z_{l + 3/2}(x) = (2l + 1)Z_{l + 1/2}(x)/x + Z_{l - 1/2}(x) = 0$$ $$z_{l+1}(x) = \frac{(2l + 1)}{x}z_l(x) + z_{l-1}(x)$$

初等函数表示式

$$J_{1/2}(x) = \sqrt{\frac{2}{\pi x}}\sin x,\quad J_{-1/2}(x) = \sqrt{\frac{2}{\pi x}}\cos x$$
$$j_0(x) = \frac{\sin x}{x},\quad j_{-1}(x) = \frac{\cos x}{x}$$
$$\because j_l(x) = \sqrt{\frac{\pi}{2x}}J_{l + 1/2}(x)$$
$$\begin{align}\therefore j_0(x) &= \sqrt{\frac{\pi}{2x}}J_{1/2}(x)\\ &= \frac{\sin x}{x} \end{align}$$
$$\begin{align}\therefore j_{-1}(x) &= \sqrt{\frac{\pi}{2x}}J_{-1/2}(x)\\ &= \frac{\cos x}{x} \end{align}$$

缺少关于\(x\geq 0\)的证明.

应用递推公式，可以得到所有\(j_l(x)\)的初等函数表达式.
