球函数

Laplace方程

$$\nabla^2u = 0$$

将球坐标系下的拉普拉斯算符代入，得：

$$\frac{1}{r^2}\frac{\partial}{\partial r}\left(r^2\frac{\partial u}{\partial r}\right) + \frac{1}{r^2\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial u}{\partial\theta}\right) + \frac{1}{r^2\sin^2\theta}\frac{\partial^2 u}{\partial\phi^2} = 0$$

Laplace方程的变量分离

[令]

$$u(r,\theta,\phi) = R(r)Y(\theta,\phi)$$

Laplace方程可以分离为：

$$\frac{1}{R}\frac{\mathrm{d}}{\mathrm{d}r}\left(r^2\frac{\mathrm{d}R}{\mathrm{d}r}\right) = l(l+1)$$
$$-\frac{1}{Y}\left[\frac{1}{\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial Y}{\partial\theta}\right) + \frac{1}{\sin^2\theta}\frac{\partial^2Y}{\partial\phi^2}\right] = l(l+1)$$
$$\because u(r,\theta,\phi) = R(r)Y(\theta,\phi)$$ $$\therefore \frac{Y}{r^2}\frac{\mathrm{d}}{\mathrm{d}r}\left(r^2\frac{\mathrm{d}R}{\mathrm{d}r}\right) + \frac{R}{r^2\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial Y}{\partial\theta}\right) + \frac{R}{r^2\sin^2\theta}\frac{\partial^2Y}{\partial\phi^2}= 0$$ $$\therefore \frac{1}{R}\frac{\mathrm{d}}{\mathrm{d}r}\left(r^2\frac{\mathrm{d}R}{\mathrm{d}r}\right) = -\frac{1}{Y}\left[\frac{1}{\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial Y}{\partial\theta}\right) + \frac{1}{\sin^2\theta}\frac{\partial^2Y}{\partial\phi^2}\right]$$

左式仅为\(r\)的函数，而右式仅为\(\theta,\phi\)的函数，两边相等的情况仅可能是同时恒为常数.

[令]

$$\frac{1}{R}\frac{\mathrm{d}}{\mathrm{d}r}\left(r^2\frac{\mathrm{d}R}{\mathrm{d}r}\right) = l(l+1)$$ $$-\frac{1}{Y}\left[\frac{1}{\sin\theta}\frac{\partial}{\partial\theta}\left(\sin\theta\frac{\partial Y}{\partial\theta}\right) + \frac{1}{\sin^2\theta}\frac{\partial^2Y}{\partial\phi^2}\right] = l(l+1)$$

[令]

$$Y(\theta,\phi) = \Theta(\theta)\Phi(\phi)$$

球函数方程可以分离为：

$$\frac{\sin\theta}{\Theta}\frac{\mathrm{d}}{\mathrm{d}\theta}\left(\sin\theta\frac{\mathrm{d}\Theta}{\partial\theta}\right) + l(l+1)\sin^2\theta = m^2$$ $$-\frac{1}{\Phi}\frac{\mathrm{d}^2\Phi}{\mathrm{d}\phi^2} = m^2$$
$$\because Y(\theta,\phi) = \Theta(\theta)\Phi(\phi)$$ $$\therefore\Phi\sin\theta\frac{\mathrm{d}}{\mathrm{d}\theta}\left(\sin\theta\frac{\mathrm{d}\Theta}{\partial\theta}\right) + \Theta\frac{\mathrm{d}^2\Phi}{\mathrm{d}\phi^2} = -l(l+1)\Theta\Phi\sin^2\theta$$ $$\therefore\frac{\sin\theta}{\Theta}\frac{\mathrm{d}}{\mathrm{d}\theta}\left(\sin\theta\frac{\mathrm{d}\Theta}{\partial\theta}\right) + \frac{1}{\Phi}\frac{\mathrm{d}^2\Phi}{\mathrm{d}\phi^2} = -l(l+1)\sin^2\theta$$ $$\therefore\frac{\sin\theta}{\Theta}\frac{\mathrm{d}}{\mathrm{d}\theta}\left(\sin\theta\frac{\mathrm{d}\Theta}{\partial\theta}\right) + l(l+1)\sin^2\theta = -\frac{1}{\Phi}\frac{\mathrm{d}^2\Phi}{\mathrm{d}\phi^2}$$

左式仅为\(\theta\)的函数，而右式仅为\(\phi\)的函数，两边相等的情况仅可能是同时恒为常数.

[令]

$$\frac{\sin\theta}{\Theta}\frac{\mathrm{d}}{\mathrm{d}\theta}\left(\sin\theta\frac{\mathrm{d}\Theta}{\partial\theta}\right) + l(l+1)\sin^2\theta = m^2$$ $$-\frac{1}{\Phi}\frac{\mathrm{d}^2\Phi}{\mathrm{d}\phi^2} = m^2$$

方程求解

\(R(r)\)微分方程的解为：

$$R(r) = C_1r^l + C_2r^{-(l+1)}$$
$$\frac{1}{R}\frac{\mathrm{d}}{\mathrm{d}r}\left(r^2\frac{\mathrm{d}R}{\mathrm{d}r}\right) = \lambda,\quad \lambda\in\mathbb{C}$$ $$r^2\frac{\mathrm{d}^2R}{\mathrm{d}r^2} + 2r\frac{\mathrm{d}R}{\mathrm{d}r} - \lambda R = 0$$

该式为欧拉常微分方程.

[令]\(r = e^t\)

$$\therefore \frac{\mathrm{d}R}{\mathrm{d}r} = \frac{\mathrm{d}R}{\mathrm{d}t}\frac{\mathrm{d}t}{\mathrm{d}r} = \frac{\mathrm{d}R}{\mathrm{d}t}\cdot\frac{1}{r} = e^{-t}\frac{\mathrm{d}R}{\mathrm{d}t}$$ $$\begin{align}\therefore \frac{\mathrm{d}^2R}{\mathrm{d}r^2} &= \frac{\mathrm{d}t}{\mathrm{d}r}\frac{\mathrm{d}}{\mathrm{d}t}\left(e^{-t}\frac{\mathrm{d}R}{\mathrm{d}t}\right)\\ &= e^{-t}\left(e^{-t}\frac{\mathrm{d}^2R}{\mathrm{d}t^2} - e^{-t}\frac{\mathrm{d}R}{\mathrm{d}t}\right)\\ &= e^{-2t}\left(\frac{\mathrm{d}^2R}{\mathrm{d}t^2} - \frac{\mathrm{d}R}{\mathrm{d}t}\right) \end{align}$$ $$\therefore e^{2t}\cdot e^{-2t}\left(\frac{\mathrm{d}^2R}{\mathrm{d}t^2} - \frac{\mathrm{d}R}{\mathrm{d}t}\right) + 2e^t\cdot e^{-t}\frac{\mathrm{d}R}{\mathrm{d}t} - \lambda R = 0$$ $$\frac{\mathrm{d}^2 R}{\mathrm{d}t^2} + \frac{\mathrm{d}R}{\mathrm{d}t} - \lambda R = 0$$

这就转化成了二阶齐次微分方程的形式，其特征方程为：

$$s^2 + s - \lambda = 0$$

[令]\(\lambda = l(l+1)\)

$$s(s+1) = l(l+1)$$ $$\therefore s = l \quad or\quad s = -(l+1)$$

这里缺少一段\(\lambda\geq 0\)的证明，先假设两个根都是实数.

$$\therefore R(r) = C_1r^l + C_2r^{-(l+1)}$$

[注]求解过程中解释了使用\(l(l+1)\)的原因.
