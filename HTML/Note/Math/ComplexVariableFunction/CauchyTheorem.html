Cauchy定理

若复变函数\(f(z)\)在有界闭区域\(\overline{G}\)中解析，则沿\(\overline{G}\)的边界\(C\)，有：

$$\oint_C f(z)\mathrm{d}z = 0$$

对于单连通区域：

设\(f'(z)\)在\(\overline{G}\)中连续，则：

$$\oint_Cf(z)\mathrm{d}z = \oint_C(u\mathrm{d}x - v\mathrm{d}y) + i\oint_C(v\mathrm{d}x + v\mathrm{d}y)$$

应用Green公式：

$$\oint_C\left[P(x,y)\mathrm{d}x + Q(x,y)\mathrm{d}y\right] = \iint_S\left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y}\right)\mathrm{d}x\mathrm{d}y$$

从而将闭合围道积分化为面积分：

$$\oint_C(u\mathrm{d}x - v\mathrm{d}y) = -\iint_S\left(\frac{\partial v}{\partial x} + \frac{\partial u}{\partial y}\right)$$ $$\oint_C(v\mathrm{d}x + u\mathrm{d}y) = \iint_S\left(\frac{\partial u}{\partial x} - \frac{\partial v}{\partial y}\right)$$

由Cauchy-Riemann方程，右端两个积分中的被积函数均为0，故：

$$\oint_Cf(z)\mathrm{d}z = 0$$
