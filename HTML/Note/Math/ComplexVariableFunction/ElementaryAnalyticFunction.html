初等函数

幂函数\(z^n\)

\(n = 0,1,2,\cdots\)时，\(z^n\)在\(\mathbb{C}\)内解析；且当\(n=1,2,\cdots\)时，\(z^n\)在\(z=\infty\)不解析.

\(n = -1,-2,\cdots\)时，\(z^n\)在\(z=0\)处不解析，在\(\infty\)处与\(\mathbb{C}\)内除\(0\)外的其他点均解析.

导数 $$(z^n)' = nz^{n-1}$$
\(n\)次多项式 $$P_n(z) = a_n z^n + a_{n-1}z^{n-1} + \cdots + a_1z + a_0,~a_n\neq 0$$
有理函数 $$R(z) = \frac{P_n(z)}{Q_m(z)},~ Q_m(z) \neq 0$$
