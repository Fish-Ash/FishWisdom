复数运算

复数的乘法

$$z_1z_2 = r_1e^{i\theta_1}r_2e^{i\theta_2} = r_1r_2e^{i(\theta_1 + \theta_2)}$$

从几何的角度上看，两个复数相乘的结果为：模相乘，辐角相加.

复数的除法

$$\frac{z_1}{z_2} = \frac{r_1e^{i\theta_1}}{r_2e^{i\theta_2}} = \frac{r_1}{r_2}e^{i(\theta_1-\theta_2)}$$

从几何的角度上看，两个复数相除的结果为：模相除，辐角相减.

其他公式

$$|z_1z_2| = |z_1||z_2|$$
$$\begin{align} |z_1z_2| &= |(x_1 + iy_1)(x_2 + iy_2)|\\ &= |x_1x_2 + i(x_1y_2 + x_2y_1) - y_1y_2|\\ &= \sqrt{(x_1x_2 - y_1y_2)^2 + (x_1y_2 + x_2y_1)^2}\\ &= \sqrt{x_1^2x_2^2 - 2x_1x_2y_1y_2 + y_1^2y_2^2 + x_1^2y_2^2 + 2x_1x_2y_1y_2 + x_2^2y_1^2}\\ &= \sqrt{x_1^2x_2^2 + x_1^2y_2^2 + x_2^2y_1^2 + y_1^2y_2^2}\\ &= \sqrt{x_1^2(x_2^2 + y_2^2) + y_1^2(x_2^2 + y_2^2)}\\ &= \sqrt{(x_1^2 + y_1^2)(x_2^2 + y_2^2)}\\ &= |z_1||z_2| \end{align}$$
