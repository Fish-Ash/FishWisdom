二阶线性常微分方程的级数解法

级数解法

对于带初始条件的二阶线性常微分方程：

$$\omega'' + p(z)\omega' + q(z)\omega = 0$$ $$\omega(z_0) = C_0, \quad \omega'(z_0) = C_1$$
  • \(z_0\)：任意指定点
  • \(C_0, C_1\in\mathbb{C}\)

这种方程常常无法用常规方法解出，但可用级数解法解出.

级数解法，就是在某个任选点\(z_0\)的邻域上，将待求的解表示为系数待定的系数，代入方程以逐个确定系数.

方程的常点

若\(p(z)\)与\(q(z)\)在\(z_0\)的邻域中是解析的，则\(z_0\)称为方程的常点.

方程的奇点

若\(z_0\)为\(p(z)\)或\(q(z)\)的奇点，则\(z_0\)称为方程的奇点.

常点邻域上的级数解法

二阶线性常微分方程在常点邻域上的级数解，有如下定理：

若\(p(z), q(z)\)为点\(z_0\)邻域\(|z-z_0|\lt R\)中的解析函数，则方程在此邻域内存在唯一的解析解\(\omega(z)\)，且满足：

$$\omega(z_0) = C_0, \quad \omega'(z_0) = C_1$$
  • \(z_0\)：任意指定点
  • \(C_0, C_1\in\mathbb{C}\)

可以将\(\omega(z)\)表示为此邻域上Taylor级数的形式：

$$\omega(z) = \sum_{k=0}^{\infty} a_k (z-z_0)^k$$

为了确定级数解中的系数，具体做法是将其代入原方程，合并同幂项，令合并后的各系数分别为0，找出系数间的递推关系，最后用给定的初值\(C_0, C_1\)来确定系数，从而求得确定的级数解.

正则奇点邻域上的级数解法

奇点邻域上的级数解

对于二阶线性常微分方程：

$$\omega'' + p(z)\omega' + q(z)\omega = 0$$

若选定的点\(z_0\)为方程的奇点，则一般情况下，解也以\(z_0\)为奇点，在\(z_0\)点邻域上的展开式不是Taylor级数而含有负幂项.

关于奇点邻域上的级数解，有如下定理：

若\(z_0\)为方程奇点，则在\(z_0\)的邻域\(0\lt|z-z_0|\lt R\)上，方程存在两个线性独立解，其形式为为：

$$\omega_1(z) = \sum_{k=-\infty}^{\infty} a_k (z-z_0)^{s_1 +k}$$ $$\omega_2(z) = \sum_{k=-\infty}^{\infty} b_k (z-z_0)^{s_2 +k}$$

或

$$\omega_2(z) = A\omega_1(z)\ln(z-z_0) + \sum_{k=-\infty}^{\infty} b_k (z-z_0)^{s_2 +k}$$
  • \(s_1, s_2, a_k, b_k, A(k=0,\pm1, \pm2)\in\mathbb{C}\)

一般情况下，很难确定\(s_1, s_2, a_k, b_k, A\)的值.

正则奇点邻域上的级数解

方程的正则奇点

若在方程的奇点\(z_0\)的邻域\(0\lt |z-z_0\lt R|\)上，方程的两个线性独立解全部具有有限个负幂项，则\(z_0\)称为方程的正则奇点.

若\(p(z)\)以\(z_0\)为不高于一阶的极点，且\(q(z)\)以\(z_0\)为不高于二阶的极点，即：

$$p(z) = \sum_{k=-1}^\infty p_k(z-z_0)^k,\quad q(z) = \sum_{k=-2}^\infty q_k(z-z_0)^k$$

则\(z_0\)为方程的正则奇点.

也就是说，在\(z_0\)的邻域\(0\lt|z-z_0|\lt R\)上，方程的两个线性独立解的级数表达式仅有有限个负幂项：

$$\omega_1(z) = \sum_{k=0}^\infty a_k (z-z_0)^{s_1 +k}$$ $$\omega_2(z) = \sum_{k=0}^\infty b_k (z-z_0)^{s_2 +k},\quad s_1-s_2\notin\mathbb{Z}$$

或

$$\omega_2(z) = A\omega_1(z)\ln(z-z_0) + \sum_{k=0}^\infty b_k (z-z_0)^{s_2 +k},\quad s_1-s_2\in\mathbb{Z}$$
判定方程 $$s(s-1) + sp_{-1} + q_{-2} = 0$$

\(s_1\gt s_2\)为判定方程的两个根，\(a_k, b_k, A\in\mathbb{C}\).
