1. 证明：
(1) $(A \setminus B) \setminus C = A\setminus (B\cup C)$

证：
$$(A\setminus B)\setminus C = \{x: x\in A~and~x\notin B~and~x\notin C\}$$
$$\begin{align}A\setminus (B\cup C) &= \{x:x\in A~and~x\notin B\cup C\}\\&= \{x: x\in a~and~x\notin B~and~x\notin C\}\end{align}$$
$$\therefore (A \setminus B) \setminus C = A\setminus (B\cup C)$$

(2) $(A\cup B)\setminus C = (A\setminus C)\cup(B\setminus C)$（原题有误）
证：
$$(A\cup B)\setminus C = \{x: x\in A~or~x\in B~and~x\notin C\}$$
$$\begin{align}(A\setminus C)\cup(B\setminus C) &= \{x: x\in A~and~x\notin C\}\cup\{x:x\in B~and~x\notin C\}\\&= \{x: x\in A~or~x\in B~and~x\notin C\}\end{align}$$
$$\therefore (A\cup B)\setminus C = (A\setminus C)\cup(A\setminus B)$$
