内积空间

复欧式空间中，向量除了有长度的概念，还定义了两个向量的内积运算.

内积

[设]\(\alpha = (a_1, a_2, \cdots, a_n), \beta = (b_1, b_2, \cdots, b_n),~a_i,b_i\in\mathbb{C}\).

\(\alpha\)与\(\beta\)的内积定义为：

$$\left\langle\alpha,\beta\right\rangle = a_1b_1^* + a_2b_2^* + \cdots + a_nb_n^*$$
  • \(b_i^*\)：\(b_i\)的复共轭

内积与向量的长度存在如下关系：

$$||\alpha|| = \sqrt{\left\langle\alpha,\alpha\right\rangle}$$

\(\alpha\)与\(\beta\)正交\(\Leftrightarrow \left\langle\alpha, \beta\right\rangle = 0\)

有限维复欧式空间\(\mathbb{E}^n\)中，内积具有以下性质：

  • \(\left\langle\alpha, \alpha\right\rangle\geq 0\)，当且仅当\(\alpha = 0\)时取等号.
  • \(\left\langle m\alpha + n\beta, \gamma\right\rangle = m\langle\alpha, \gamma\rangle + n\langle\beta,\gamma\rangle,~\alpha,\beta,\gamma\in\mathbb{E}^n,~m,n\in\mathbb{C}\)
  • \(\langle\alpha,\beta\rangle = \overline{\langle\beta,\alpha\rangle},~\alpha,\beta\in\mathbb{E}^n\)

在一般的线性空间中引入内积的概念.

一般线性空间中的内积

[设]\(X\)为复线性空间.

若\(\forall\)向量\(x,y\in X\)，有一复数\(\left\langle x,y\right\rangle\)与之对应，且满足以下条件：

  • \(\left\langle x, x\right\rangle\geq 0,~x\in X\)，当且仅当\(x = 0\)时取等号.
  • \(\left\langle mx + ny, z\right\rangle = m\langle x, z\rangle + n\langle y, z\rangle,~x,y,z\in X,~m,n\in\mathbb{C}\)
  • \(\langle x,y\rangle = \overline{\langle y,x\rangle},~x,y\in\mathbb{E}^n\)

称\(\langle x,y\rangle\)为\(x\)与\(y\)的内积，\(X\)为内积空间.
