集合

一定范围内的个体事物的全体，将它们看作一个整体时，称此整体为集合.

集合中每个个体事物称为该集合的元素.

一个集合中的各个元素必须是互异的.

一个集合中的各个元素必须是明确的.

集合的表示

通过列举其元素\(a,b,c,\cdots\)来表示：

$$A = \{a, b, c, \cdots\}$$

通过该集合中必须且只需满足的条件\(p\)来表示：

$$A = \{x:x满足p\}$$
元素与集合的关系

[设]\(A\)为一个集合

若\(x\)为\(A\)的元素，称\(x\)属于A，记作：

$$x\in A$$

若\(x\)不为\(A\)的元素，称\(x\)不属于\(A\)，记作：

$$x\notin A$$

交集

[设]A、B为任意两集合.

由一切既属于A又属于B的元素组成的集合C，称为A和B的交集（积集），简称交（积），记作\(C = A\cap B\).

可以表示为：

$$C = A\cap B = \left\{x:x\in A~and~x\in B\right\}$$

映射

设\(A,B\)为两个非空集合，如存在一法则\(\phi\)，使得每一个\(x\in A\)都有唯一确定的\(y\in B\)与之对应，称\(\phi\)为\(A\)到\(B\)内的映射，记作：

$$\phi:A\rightarrow B$$

当映射\(\phi\)使\(y\)与\(x\)对应时，称\(y\)为\(x\)在映射\(\phi\)下的像，记作：

$$y = \phi(x)$$

\(\forall E\subset A\)，称\(\phi(E) = \{y:y=f(x),~x\in E\}\)为\(A\)在\(\phi\)下的像集.

这里称为\(E\)的像集是否更妥当？

若\(F\subset B\)，称\(\phi^{-1}(F) = \{x: \phi(x)\in F\}\)为\(F\)关于\(\phi\)的原像.

单射、满射、双射

[设]\(\phi:A\rightarrow B\).

称\(\phi\)为：

  • 单射：\(\forall x,y\in A, \phi(x)=\phi(y)\Rightarrow x=y\)（每个x都有不同的y与之对应）
  • 满射：\(\forall y=B, \exists x\in A\Rightarrow \phi(x) = y\)（每个\(y\)至少对应一个\(x\)）
  • 双射：既是单射也是满射

若\(A,B\)为非空集合，且存在双射\(\phi:A\rightarrow B\)，则称\(A\)与\(B\)对等，记作\(A\sim B\).

规定：\(\emptyset\sim\emptyset\)

对等关系的性质
自反性 $$A\sim A$$

Bernstein定理

[设]\(A,B\)为两个非空集合.

若\(A\)对等于\(B\)的一个子集，且\(B\)对等于\(A\)的一个子集，则\(A\sim B\).

基数形式为：\(\overline{\overline{A}}\leq\overline{\overline{B}}, \overline{\overline{B}}\leq\overline{\overline{A}}\Rightarrow \overline{\overline{A}} = \overline{\overline{B}}\)

可数集合

可数集合

凡与\(\mathbb{Z}^+\)对等的集合都可以称为可数集合或可列集合.

设\(A\)为一个集合，\(A\)为可数集合的充分必要条件为\(A\)可以排成一个无穷序列：

$$a_1, a_2, \cdots, a_n, \cdots$$

任何无限集合都至少包含一个可数集合.

该定理说明了可数集的一个特征：它在所有无限集中有最小的基数.

所有的可数集都拥有相同的基数吗？都是无限集为什么基数会不同？

可数集合的任何无限子集必为可数集合

不可数集合

不可数集合

不是可数集合的无限集合.

\(\mathbb{R}\)为不可数集合.

[推论]若用\(c\)表示\(\mathbb{R}\)的基数，用\(a\)表示\(\mathbb{Z}^+\)的空间，则\(c\gt a\).

称\(c\)为连续基数.

对于\(a\lt b\)，任意区间\((a,b), [a,b), (a,b], (0,\infty), [0,\infty)\)均具有连续基数\(c\).

欧式空间（\(n\)维欧几里得空间）

[设]\(n\in \mathbb{Z}^+\)，将由\(n\)个实数\(x_1, x_2, \cdots, x_n\)按确定的次序排成的数组\((x_1, x_2, \cdots x_n)\)全体称为\(n\)维欧几里得空间，记作\(\mathbb{R}^n\).

每个组\((x_1, x_2, \cdots, x_n)\)称为欧几里得空间的点.

称\(x_i\)为点\((x_1,x_2,\cdots,x_n)\)的第\(i\)个坐标.

记：

$$\mathbb{R}^\infty = \left\{(x_1, x_2, \cdots):x_i\in\mathbb{R},~i=1,2,\cdots\right\}$$

\(n\)维欧几里得空间\(\mathbb{R}^n\)的基数为\(c\).
