线性空间

设\(X\)为一非空集合，在\(X\)中定义了元素的加法运算与实数（或复数）同\(X\)中元素的乘法运算，满足下列条件：

1、关于加法成为交换群，即\(\forall x,y\in X, \exists u\in X\)与之对应，记作\(u = x+y\)，称为\(x\)与\(y\)的和，满足：

  • \(x+y = y+x\)
  • \((x+y)+z = x+(y+z),~z\in X\)
  • 在\(X\)中存在唯一元素\(\theta\)，使\(\forall x\in X\)，有\(x+\theta = x\)，称\(\theta\)为\(X\)中零元素.
  • \(\forall x \in X\)，存在唯一元素\(x'\in X\)，使\(x + x' = \theta\)，称\(x'\)为\(x\)的负元素，记作\(-x\).

2、\(\forall x\in X\)，及任意实数（或复数）\(a\)，存在元素\(u\in X\)与之对应，及\(u = ax\)，称为\(a\)与\(x\)的数积，满足：

  • \(1x = x\)
  • \(a(bx) = (ab)x\)对任意实数（或复数）\(a\)和\(b\)成立.
  • \((a+b)x = ax+bx, a(x+y) = ax + ay\)

称\(X\)按上述加法和数乘运算成为线性空间或向量空间.

其中的元素成为向量.

若数积运算仅对实数（或复数）有意义，称\(X\)为实（复）线性空间.

当取值既包含实数也包含复数时，由于实数属于复数，因此也称为复数线性空间.

\(l^p\)空间（\(p\gt 0\)）

设复数列\(x = (\xi_1, \xi_2, \cdots)\)，若\(\sum_\limits{i=1}^\infty|\xi_i|^p\lt \infty\)，称数列\((\xi_1, \xi_2, \cdots)\)为\(p\)次收敛数列.

记\(p\)次收敛数列全体为\(l^p\).

x为无穷数列是吗？

\(\forall x = (\xi_i,\xi_2,\cdots),~y = (\eta_1, \eta_2, \cdots)\in l^p\)及\(a\in\mathbb{C}\)，定义：

$$x + y = (\xi_1+\eta_1, \xi_2+\eta_2 + \cdots)$$ $$ax = (a\xi_1, a\xi_2, a\xi_3, \cdots)$$ $$x + y\in l^p,\quad ax\in l^p$$
