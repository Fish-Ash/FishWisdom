正交矢量空间与正交函数系

正交矢量空间

正交函数系

正交矢量空间的概念可以推广到正交函数系.

正交函数系

若定义在\((x_1,x_2)\)区间上的复函数系\(\left\{\phi_n(x)\right\}\)中的每个函数绝对平方可积，且满足：

$$\int_{x_1}^{x_2}\phi_n(x)\phi_m^*(x)\mathrm{d}x = \begin{cases}0,\quad n\neq m\\\mu_m,\quad n=m\end{cases}$$
  • \(\mu_m\in\mathbb{R}\)

称\(\{\phi_n(x)\}\)为区间\((x_1, x_2)\)上的正交函数系.

标准正交函数系

若\(\forall m, \mu_m = 1\)，则称\(\{\phi_n(x)\}\)为区间\((x_1, x_2)\)上的标准正交函数系.

完备正交函数系

若在\(\{\phi_n(x)\}\)外再也找不到一个平方可积函数\(g(x)\)（\(g(x)\)在\((x_1, x_2)\)上不恒为零）能和函数系中的所有函数正交，则称\(\{\phi_n(x)\}\)为\((x_1, x_2)\)上的完备正交函数系.

可以用正交函数系中的个函数（基元函数）的线性组合表示任一位于区间\((x_1, x_2)\)的复函数\(f(x)\)：

$$\begin{align} f(x) &= c_1\phi_1(x) + c_2\phi_2(x) + \cdots c_3\phi_3(x) + \cdots\\ &= \sum_i^{\infty}c_n\phi_n(x) \end{align}$$
  • \(c_n\)：复值系数，作为级数每一项的权重因子

[注]展开式可能包含有限项或无限项数，视具体情况而定.

\(c_i\)的确定
$$c_i = \frac{1}{\mu_i}\int_{x_1}^{x_2}f(x)\phi_i^*(x)\mathrm{d}x$$
$$\begin{align} \int_{x_1}^{x_2}f(x)\phi_i^*(x)\mathrm{d}x &= \int_{x_1}^{x_2}c_1\phi_1(x)\phi_i^*(x) + c_2\phi_2(x)\phi_i^*(x) + \cdots + c_i\phi_i(x)\phi_i^*(x) + \cdots\mathrm{d}x\\ &= c_i\mu_i \end{align}$$ $$\therefore c_i = \frac{1}{\mu_i}\int_{x_1}^{x_2}f(x)\phi_i^*(x)\mathrm{d}x$$

满足正交性的函数系很多，但对线性系统而言，最重要的是正、余弦函数系与复指数函数系.

正弦函数系 $$\phi_n(x) = \sin2\pi nf_0x,~n=0,1,2\cdots$$
余弦函数系 $$\phi_n(x) = \cos2\pi nf_0x,~n=0,1,2\cdots$$
复指数函数系 $$\phi_n(x) = \exp(i2\pi nf_0x), n=0,\pm 1, \pm2, \cdots$$

这些函数系都在等于周期\(\frac{1}{f_0}\)的整数倍的区间上正交，即：

$$x_1 - x_2 = k\left(\frac{1}{f_0}\right),\quad k=1,2,3,\cdots$$
