叉乘

叉乘（叉积、矢积、外积） $$\begin{align} \boldsymbol{w} &= \boldsymbol{u}\times\boldsymbol{v} \\ &= \left|\begin{matrix}\boldsymbol{i}&\boldsymbol{j}&\boldsymbol{k}\\u_x&u_y&u_z\\v_x&v_y&v_z\end{matrix}\right| \end{align}$$

向量运算

$$\vec\alpha = (a_1, a_2, \cdots, a_n)^T$$ $$\vec\beta = (b_1, b_2, \cdots, b_n)^T$$
运算 公式 运算规律
向量加法 $$\vec\alpha + \vec\beta = (a_1 + b_1, a_2 + b_2, \cdots, a_n + b_n)^T$$ 交换律 $$\alpha + \beta = \beta + \alpha$$
结合律 $$\alpha + (\beta + \gamma) = (\alpha + \beta) + \gamma$$
$$\alpha + \boldsymbol{0} = \boldsymbol{0} + \alpha = \alpha$$

\(\alpha + (-\alpha) = 0\)
向量数乘 $$k\alpha = (ka_1, ka_2, \cdots, ka_n)^T$$ $$k(l\alpha) = (kl)\alpha$$
$$k(\alpha + \beta) = k\alpha + k\beta$$
$$(k+l)\alpha = k\alpha + l\alpha$$
点乘
（标量）		 $$\vec\alpha\cdot\vec\beta = \sum\limits_{i=1}^n a_ib_i = |\vec a||\vec b|\cos\theta$$
叉乘
（矢量）		 方向 由右手法则决定，右手四指指向\(\vec\alpha\)，向\(\vec\beta\)弯曲，拇指所指方向即为结果方向。
大小 $$\vec\alpha \times \vec \beta = |\vec a||\vec b|\sin\theta$$
