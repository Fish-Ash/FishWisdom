坐标变换

引言

描述同一空间的物理问题，可以根据需要选择不同的坐标系.

同一物理量在不同坐标系中往往以不同的分量加以定量描述.

基矢量的转换关系

本节给出了新老坐标系下，协变、逆变基矢量的转换式.

新老坐标系各自有协变基矢量与逆变基矢量，它们各自分别满足对偶条件.

新坐标系的基矢量对老坐标系的基矢量分解

$$\boldsymbol{g}_{i'} = \beta_{i'}^j\boldsymbol{g}_j,\quad i'=1,2,3$$ $$\boldsymbol{g}^{i'} = \beta_j^{i'}\boldsymbol{g}^j,\quad i'=1,2,3$$
  • \(\beta_{i'}^j\)：协变转换系数
  • \(\beta_j^{i'}\)：逆变转换系数

协变转换系数与逆变转换系数各有\(9\)个，可各自排列成\(3\times 3\)矩阵.

协变转换系数与逆变转换系数并不独立，因为它们之间必须满足对偶关系：

$$\delta_{i'}^{j'} = \boldsymbol{g}_{i'}\cdot\boldsymbol{g}^{j'} = \beta_{i'}^k\boldsymbol{g}_k\cdot\beta_l^{j'}\boldsymbol{g}^l = \beta_{i'}^k\beta_l^{j'}\delta_k^l = \beta_{i'}^k\beta_k^{j'}\quad i',j' = 1,2,3$$

上式表示协变转换系数与逆变转换系数组成的矩阵互逆，即：

$$\begin{bmatrix}\beta_{1'}^1&\beta_{1'}^2&\beta_{1'}^3\\\beta_{2'}^1&\beta_{2'}^2&\beta_{2'}^3\\\beta_{3'}^1&\beta_{3'}^2&\beta_{3'}^3\end{bmatrix} \begin{bmatrix} \beta_1^{1'}&\beta_1^{2'}&\beta_1^{3'} \\ \beta_2^{1'}&\beta_2^{2'}&\beta_2^{3'} \\ \beta_3^{1'}&\beta_3^{2'}&\beta_3^{3'} \end{bmatrix} = \begin{bmatrix} 1&0&0\\0&1&0\\0&0&1 \end{bmatrix}$$

老坐标协变基矢量对新坐标协变基矢量分解

$$\boldsymbol{g}_j = a_j^{i'}\boldsymbol{g}_{i'},\quad j=1,2,3$$

转换系数\(a_j^{i'}\)同样有\(9\)个.

$$\boldsymbol{g}_j\cdot\boldsymbol{g}^{i'} = a_j^{k'}\boldsymbol{g}_{k'}\cdot\boldsymbol{g}^{i'} = a_j^{k'}\delta_{k'}^{i'} = a_j^{i'},\quad j,i'=1,2,3$$ $$\boldsymbol{g}_j\cdot\boldsymbol{g}^{i'} = \boldsymbol{g}_j\cdot\beta_k^{i'}\boldsymbol{g}^k = \beta_k^{i'}\delta_j^k = \beta_j^{i'},\quad j,i'=1,2,3$$ $$\therefore a_j^{i'} = \beta_j^{i'}$$ $$\therefore \boldsymbol{g}_j = \beta_j^{i'}\boldsymbol{g}_{i'}\quad j = 1,2,3$$ $$\beta_{j}^{i'} = \boldsymbol{g}^{i'}\cdot\boldsymbol{g}_j\quad i',j = 1,2,3$$

同理：

$$\boldsymbol{g}^j = \beta_{i'}^j\boldsymbol{g}^{i'}\quad j=1,2,3$$ $$\beta_{i'}^j = \boldsymbol{g}^j\cdot\boldsymbol{g}_{i'}\quad i',j = 1,2,3$$

上式表示协变转换系数与逆变转换系数的另一种矩阵关系：

$$\begin{bmatrix} \beta_1^{1'}&\beta_1^{2'}&\beta_1^{3'} \\ \beta_2^{1'}&\beta_2^{2'}&\beta_2^{3'} \\ \beta_3^{1'}&\beta_3^{2'}&\beta_3^{3'} \end{bmatrix}\begin{bmatrix}\beta_{1'}^1&\beta_{1'}^2&\beta_{1'}^3\\\beta_{2'}^1&\beta_{2'}^2&\beta_{2'}^3\\\beta_{3'}^1&\beta_{3'}^2&\beta_{3'}^3\end{bmatrix} = \begin{bmatrix} 1&0&0\\0&1&0\\0&0&1 \end{bmatrix}$$
老坐标系基矢量\(\to\)新坐标系基矢量 $$\boldsymbol{g}_{i'} = \beta_{i'}^j\boldsymbol{g}_j,\quad \boldsymbol{g}^{i'} = \beta_j^{i'}\boldsymbol{g}^j\quad i' = 1,2,3$$
新坐标系基矢量\(to\)老坐标系基矢量 $$\boldsymbol{g}_j = \beta_j^{i'}\boldsymbol{g}_{i'},\quad \boldsymbol{g}^j = \beta_{i'}^j\boldsymbol{g}^{i'},\quad j = 1,2,3$$

协变与逆变转换系数

协变转换系数 $$\beta_{i'}^j = \frac{\partial x^j}{\partial x^{i'}}\quad i',j = 1,2,3$$
逆变转换系数 $$\beta_j^{i'} = \frac{\partial x^{i'}}{\partial x^j}\quad i',j = 1,2,3$$

矢量分量的坐标转换关系

矢量\(\boldsymbol{v}\)可以在不同的坐标系中对不同的基矢量分解.

在新、老坐标系中，对逆变基分解，得到同一矢量不同协变分量；对协变基分解，得到同一矢量的不同逆变分量.

这些分量虽不相同，但分矢量的矢量和不应随坐标不同而变化，即：

$$\boldsymbol{v} = v_{i'}\boldsymbol{g}^{i'} = v_j\boldsymbol{g}^j\quad\text{or}\quad \boldsymbol{v} = v^{i'}\boldsymbol{g}_{i'} = v^j\boldsymbol{g}_j$$

四个式子都是相等的.

不同坐标系中矢量分量之间满足的关系可由基矢量的转换关系确定：

$$\because \boldsymbol{g}^{j} = \beta_{i'}^{j}\boldsymbol{g}^{i'}$$ $$\therefore v_{i'}\boldsymbol{g}^{i'} = v_j\boldsymbol{g}^j = v_j\beta_{i'}^j\boldsymbol{g}^{i'}$$

同理：

$$v^{i'} = \beta_{j}^{i'}v^j\quad i'=1,2,3$$
