Fourier变换的定义

\(f(x)\)的Fourier变换式

设函数\(f(t)\)满足Fourier积分定理条件，则表达式：

$$\begin{align} F(\omega) &= \mathcal{F}[f(t)]\\ &= \int_{-\infty}^{+\infty}f(t)e^{-i\omega t}\mathrm{d}t \end{align}$$

为\(f(t)\)的Fourier变换式，称函数\(F(\omega)\)为\(f(t)\)的Fourier变换.

\(F(\omega)\)的Fourier逆变换式 $$\begin{align} f(t) &= \mathcal{F}^{-1}[F(\omega)]\\ &= \frac{1}{2\pi}\int_{-\infty}^{+\infty}F(\omega)e^{i\omega t}\mathrm{d}\omega \end{align}$$

该表达式为\(F(\omega)\)的Fourier逆变换式，称函数\(f(t)\)为\(F(\omega)\)的Fourier逆变换.

二维Fourier变换

$$\begin{align} G(f_x,f_y) &= \mathcal{F}[g(x,y)]\\ &= \iint_{-\infty}^{+\infty}g(x,y)e^{-i2\pi(f_xx + f_yy)}\mathrm{d}x\mathrm{d}y \end{align}$$ $$\begin{align} g(x,y) &= \mathcal{F}^{-1}[G(f_x,f_y)]\\ &= \iint_{-\infty}^{+\infty}G(f_x,f_y)e^{i2\pi(f_xx + f_yy)}\mathrm{d}f_x\mathrm{d}f_y \end{align}$$

Fourier变换的性质

线性性质

$$F[k_1f_1(t) + k_2f_2(t)] = k_1F[f_1(t)] + k_2F[f_2(t)]$$ $$F^{-1}[k_1F_1(\omega) + k_2F_2(\omega)] = k_1F^{-1}[F_1(\omega)] + k_2F^{-1}[F_2(\omega)]$$

对称性质

$$F(\omega) = F[f(t)]\Rightarrow F[F(t)] = 2\pi f(-\omega)$$
$$\because F[f(t)] = \int_{-\infty}^{+\infty}f(t)e^{-i\omega t}\mathrm{d}t$$ $$\therefore F[F(t)] = \int_{-\infty}^{+\infty}F(t)e^{i\omega t}\mathrm{d}t$$ $$\because f(t) = \int_{-\infty}^{+\infty}F(\omega)e^{i\omega t}\mathrm{d}\omega$$ $$\begin{align} \therefore f(-\omega) &= \frac{1}{2\pi}\int_{-\infty}^{+\infty}F(x)e^{ix(-\omega)}\mathrm{d}x\\ &= \frac{1}{2\pi}\int_{-\infty}^{+\infty}F(t)e^{-i\omega t}\mathrm{d}t\\ &= \frac{1}{2\pi}F[F(t)] \end{align}$$ $$\therefore F[F(t)] = 2\pi f(-\omega)$$

卷积与Fourier变换

前置知识
  • 卷积
卷积定理

[设]\(F(\omega) = \mathcal F[f(t)],~G(\omega) = \mathcal F[g(t)]\)

$$\mathcal F[f(t)*g(t)] = F(\omega)\cdot G(\omega)$$ $$\begin{align} \mathcal F[f(t)*g(t)] &= \int_{-\infty}^{+\infty}\left[\int_{-\infty}^{+\infty}f(\tau)g(t-\tau)\mathrm{d}\tau\right]e^{-i\omega t}\mathrm{d}t\\ &= \int_{-\infty}^{+\infty}f(\tau)\left[\int_{-\infty}^{+\infty}g(t-\tau)e^{-i\omega(t-\tau)}\mathrm{d}(t-\tau)\right]e^{-i\omega\tau}\mathrm{d}\tau\\ &= F(\omega)\cdot G(\omega) \end{align}$$ $$\mathcal F[f_1(t)\cdot f_2(t)] = \frac{1}{2\pi}F_1(\omega)*F_2(\omega)$$
Fourier变换的物理意义

\(f(t)\)：信号如何随时间变化，即时域表示.

\(F(\omega)\)：信号由哪些频率组成，即频域表示

广义Fourier变换

若只考虑经典意义（狭义）的Fourier变换，那么对一些很有用的函数，都无法确定其Fourier变换，这给Fourier变换带来很大的局限性.

Fourier变换之所以获得如此广泛的应用，很大程度上与引入广义Fourier变换有关.

广义Fourier变换：
  • 极限意义下的Fourier变换
  • \(\delta\)函数的Fourier变换

极限意义下的Fourier变换

[设]\(\boldsymbol{f}(x)\)是一个无法确定狭义Fourier变换的函数.

若\(\boldsymbol{f}(x)\)与一个函数序列\(\boldsymbol{f}_n(x)\)（\(n = 1,2,\cdots\)）具有如下关系：

$$\boldsymbol{f}(x) = \lim_{n\to\infty}\boldsymbol{f}_n(x)$$

且对函数序列中的每个函数\(\boldsymbol{f}_n(x)\)来说，其狭义Fourier变换：

$$\boldsymbol{F}_n(\xi) = F\{\boldsymbol{f}_n(x)\}$$

都存在.

且当\(n\to\infty\)时，函数序列\(\boldsymbol{F}(\xi)\)也具有确定的极限，则称该极限为函数在极限意义下的Fourier变换.

\(\delta\)函数的Fourier变换

\(\delta\)函数是一个广义函数，狭义Fourier变换的概念不再适用.

然而，根据\(\delta\)函数的定义式，可以直接求得其Fourier变换.

$$\boldsymbol{F}\{\delta(x)\} = \int_{-\infty}^{+\infty}\delta(x)e^{-i2\pi\xi x}\mathrm{d}x = 1$$

即\(\delta\)函数的Fourier变换为常数1.

Fourier变换的基本性质

线性性质

[设]

$$F(\xi, \eta) = \mathcal{F}\{f(x,y)\}$$ $$G(\xi, \eta) = \mathcal{F}\{g(x,y)\}$$ $$a,b\in\mathbb{C}$$ $$\therefore \mathcal{F}\{af(x,y) + bg(x,y)\} = aF(\xi, \eta) + bG(\xi, \eta)$$

即：函数线性组合的傅里叶变换等于各函数傅里叶变换的相应组合，这是由积分运算的线性性质决定的.

对称性

[设]

$$F(\xi, \eta) = \mathcal{F}\{f(x,y)\}$$ $$\therefore \mathcal{F}\{F(x, y)\} = f(-\xi, -\eta)$$

迭次Fourier变换

以连续两次Fourier变换为例，有：

$$\mathcal{F}\{\mathcal{F}\{f(x,y)\}\} = f(-x, -y)$$

即对二元函数\(f(x,y)\)连续作两次Fourier变换，得其倒立像.

坐标缩放性质

[设]

$$a,b\in\mathbb{R}\quad \text{and}\quad a,b\neq 0$$ $$\mathcal{F}\{f(x,y)\} = F(\xi, \eta)$$ $$\therefore \mathcal{F}\{f(ax, by)\} = \frac{1}{|ab|}F\left(\frac{\xi}{a}, \frac{\eta}{b}\right)$$

这一性质表明，若\(f(x,y)\)的图像变窄，则其Fourier变换\(F(\xi, \eta)\)的图像将变宽变矮；若\(f(x, y)\)变宽，则\(F(\xi, \eta)\)变高变窄.

平移性

空间域平移，频率域多一个相位因子；反之亦然，但相位因子不同.

[设]

$$\mathcal{F}\{f(x,y)\} = F(\xi, \eta)$$ $$x_0, y_0\in \mathbb{R}$$ $$\therefore \mathcal{F}\{f(x-x_0, y-y_0)\} = e^{-i2\pi(\xi x_0 + \eta y_0)}F(\xi, \eta)$$

Fourier变换的基本定理

卷积定理

[设]

$$\mathcal{F}\{f(x,y)\} = F(\xi, \eta)$$ $$\mathcal{F}\{g(x,y)\} = G(\xi, \eta)$$ $$\therefore \mathcal{F}\{f(x,y)*g(x,y)\} = F(\xi, \eta)G(\xi, \eta)$$ $$\mathcal{F}\{f(x,y)g(x,y)\} = F(\xi,\eta)*G(\xi,\eta)$$

相关定理（维纳-辛钦定理）

互相关定理

[设]

$$F(\xi, \eta) = \mathcal{F}\{f(x,y)\}$$ $$G(\xi, \eta) = \mathcal{F}\{g(x,y)\}$$ $$\therefore \mathcal{F}(f(x,y))$$

称\(F^*(\xi, \eta)\)与\(G(\xi, \eta)\)为函数\(f(x, y)\)与\(g(x, y)\)的互谱能量密度或简称互谱密度.

因此，互相关定理表明，两个函数的互相关与其互谱密度构成Fourier变换对.

自相关定理

[设]

$$F(\xi, \eta) = \mathcal{F}\{f(x,y)\}$$ $$\therefore F()$$

称\(|F(\xi, \eta)|^2\)为\(f(x,y)\)的能谱密度.

因此，自相关定理表明，一个函数的自相关函数与其能谱密度构成Fourier变换对.
