三角Fourier级数

考察三角函数系：

$$1,\quad \cos2\pi f_0x,\quad\sin2\pi f_0x,\quad\cdots,\quad\cos2\pi nf_0x,\quad\sin2\pi nf_0x,\cdots$$

在区间

$$x_2 - x_1 = k\left(\frac{1}{f_0}\right),\quad k=1,2,3,\cdots$$

上的正交性，有：

$$\int_{x_1}^{x_2}\cos2\pi nf_0x\mathrm{d}x = \int_{x_1}^{x_2}\sin 2\pi nf_0x\mathrm{d}x = 0, \quad n\neq 0$$ $$\int_{x_1}^{x_2}\cos2\pi mf_0x\cdot \sin2\pi nf_0x\mathrm{d}x = 0, \quad m,n\in \mathbb{Z}$$ $$\int_{x_1}^{x_2}\cos2\pi mf_0x\cdot \cos 2\pi nf_0x\mathrm{d}x = \begin{cases}0, \quad m\neq n,\\ \frac{k}{2}\frac{1}{f_0}, \quad m = n\end{cases}$$ $$\int_{x_1}^{x_2}\sin2\pi mf_0x\cdot \sin 2\pi nf_0x\mathrm{d}x = \begin{cases}0, \quad m\neq n,\\ \frac{k}{2}\frac{1}{f_0}, \quad m = n\end{cases}$$ $$\int_{x_1}^{x_2}1^2\mathrm{d}x = k\left(\frac{1}{f_0}\right)$$

由于函数系中任意两个不同函数的乘积在区间\((x_1, x_2)\)上的积分为0，且每个函数（除1外）自乘的积分为\(\frac{k}{2}\left(\frac{1}{f_0}\right)\)，因此在该区间三角函数系构成正交函数系.

在这一区间内的任意函数\(g(x)\)可以由这些函数的线性组合表示.

若\(g(x)\)是周期为\(\tau = 1/f_0\)的周期函数，则在整个区间\((-\infty, +\infty)\)内都可以由三角Fourier级数表示：

$$g(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}(a_n\cos2\pi nf_0x + b_n\sin2\pi nf_0x)$$
$$a_n = \frac{1}{\pi} \int_{-\pi}^\pi g(x) \cos nx \mathrm{d}x, n=0,1,2,\cdots$$ $$b_n = \frac{1}{\pi} \int_{-\pi}^\pi g(x) \sin nx \mathrm{d}x, n=1,2,\cdots$$

Fourier级数在\((0,\tau)\)区间上一致收敛于\(g(x)\)，因此可逐项积分：

为什么收敛？为什么可以逐项积分？

$$\int_0^\tau g(x)\mathrm{d}x = \int_0^\tau\frac{a_0}{2}\mathrm{d}x + \sum_{n=1}^{\infty}\left(a_n\int_0^\tau \cos2\pi nf_0x\mathrm{d}x + b_n\int_0^\tau \sin2\pi nf_0x\mathrm{d}x\right)$$

由于三角函数的正交性，上式右端除第一项外均为0，因此：

$$\int_0^\tau g(x)\mathrm{d}x = \frac{a_0}{2}\tau$$

Fourier级数两端同时乘\(\cos2\pi mf_0x\)或\(\sin2\pi mf_0x\)，然后逐项积分，因函数的正交性，右侧仅剩\(m=n\)的项，其他各项为0，因此：

$$\int_0^\tau g(x)\cos2\pi mf_0x\mathrm{d}x = \frac{a_0}{2}\tau$$ $$\int_0^\tau g(x)\sin2\pi mf_0x\mathrm{d}x = \frac{b_0}{2}\tau$$

因此Fourier系数为：

$$a_0 = \frac{2}{\tau}\int_0^\tau g(x)\mathrm{d}x$$ $$a_n = \frac{2}{\tau}\int_0^\tau g(x)\cos2\pi nf_0x\mathrm{d}x, n=1,2,\cdots$$ $$b_n = \frac{2}{\tau}\int_0^\tau g(x)\sin2\pi nf_0x\mathrm{d}x, n=1,2,\cdots$$

称为\(g(x)\)的傅里叶系数，表示相应频率\(nf_0, n=0,1,2,\cdots\)的余弦波分量与正弦波分量的振幅大小.

利用三角关系式：

$$B_n\cos(2\pi n f_0 x + \phi_n) = B_n\cos\phi_n \cos2\pi nf_0 x - B_n\sin\phi_n\sin2\pi nf_0x$$

[令]

$$a_n = B_n\cos\phi_n,\quad b_n = -B_n\sin\phi_n$$

Fourier级数可以改写为：

$$g(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}B_n\cos(2\pi nf_0x + \phi_n)$$
  • \(B_n = \sqrt{a_n^2 + b_n^2}\)
  • \(\phi_n = \arctan\left(-\frac{b_n}{a_n}\right)\)

公式表明，周期函数\(g(x)\)可以表示为无穷多不同频率余弦波分量的线性组合，每一频率余弦波分量的振幅\(B_n\)于初相位\(\Phi_n\)由上式决定.

指数Fourier级数

考虑复指数函数系：

$$\left\{e^{i2\pi nf_0x}\right\},\quad n\in\mathbb{Z}$$

在区间

$$x_2 - x_1 = k\left(\frac{1}{f_0}\right),\quad k\in\mathbb{N}_+$$

上正交，因为它满足以下条件：

$$\int_{x_1}^{x_2}e^{i2\pi mf_0x}(e^{i2\pi nf_0x})^*\mathrm{d}x = \int_{x_1}^{x_2}e^{i2\pi(m-n)f_0x}\mathrm{d}x = \begin{cases}0,\quad m\neq n\\k\left(\frac{1}{f_0}\right),\quad m=n\end{cases}$$

满足狄利克雷条件的周期为\(\tau = \frac{1}{f_0}\)的函数\(g(x)\)，可以表示为无限多不同频率的复指数函数的线性组合，即指数傅里叶级数形式：

$$g(x) = \sum_{n=-\infty}^{+\infty}c_ne^{i2\pi nf_0x},\quad n\in\mathbb{Z}$$

为了确定系数\(c_n\)，用\((e^{i2\pi mf_0x})^*\)乘上式两端，然后在\((0,\tau)\)区间积分，得到：

$$\int_0^\tau g(x)e^{-i2\pi (n-m)f_0x}\mathrm{d}x = \sum_{n=-\infty}^{+\infty}\int_0^\tau c_n e^{i2\pi(n-m)f_0x}\mathrm{d}x$$

由函数的正交性可知，上式右端仅\(m=n\)项积分不为0.

$$\int_0^\tau g(x)e^{-i2\pi nf_0x}\mathrm{d}x = c_n\tau$$ $$c_n = \frac{1}{\tau}\int_0^\tau g(x)e^{-i2\pi nf_0x}\mathrm{d}x$$
频谱（频谱函数）

Fourier系数\(c_n\)为频率\(nf_0\)的函数，称为频谱函数.

定义在空间域的函数\(g(x)\)，也可以从频率域研究，即将函数看作不同频率的复指数分量的线性组合，研究系数\(c_n\)与频率\(nf_0\)的关系，也就是研究频谱.

\(c_n\)为复函数时，可以表示为：

$$c_n = A_n e^{i\phi_n}$$
  • \(A_n = |c_n|\)：振幅频谱
  • \(\phi_n\)：相位频谱

三角Fourier级数与指数Fourier级数的关系

三角Fourier级数与指数Fourier级数只是同一种级数的两种表示方式，一种系数可以由另一种系数导出.

利用欧拉公式，可以找到\(c_n\)与三角Fourier级数系数\(a_n,b_n\)间的关系，三角Fourier级数可以改写为：

$$\begin{align} g(x) &= \frac{a_0}{2} + \sum_{n=1}^{+\infty}\left[a_n\left(\frac{e^{i2\pi nf_0x} + e^{-i2\pi nf_0x}}{2}\right) + b_n\left(\frac{e^{i2\pi nf_0x} + e^{-i2\pi nf_0x}}{2i}\right)\right]\\ &= \frac{a_0}{2} + \sum_{n=1}^{+\infty}\left[\left(\frac{a_n-ib_n}{2}\right)e^{i2\pi nf_0x} + \left(\frac{a_n + ib_n}{2}e^{-i2\pi nf_0x}\right)\right] \end{align}$$

[令]

$$c_0 = \frac{a_0}{2}$$ $$c_n = \frac{1}{2}(a_n - ib_n),\quad n\in\mathbb{N}_+$$ $$c_{-n} = \frac{1}{2}(a_n + ib_n),\quad n\in\mathbb{N}_+$$

则有：

$$\begin{align} g(x) &= c_0 + \sum_{n=1}^{+\infty}(c_ne^{i2\pi nf_0x} + c_{-n}e^{-i2\pi nf_0x})\\ &= \sum_{n=-\infty}^{+\infty}c_n e^{i2\pi nf_0 x}, \quad n\in\mathbb{Z} \end{align}$$

收敛定理（狄利克雷条件）

函数\(g(x)\)应满足狄利克雷条件，即在一个周期内仅有有限个极值点与第一类不连续点.

设\(f(x)\)为周期函数，若其满足：

  • 在一个周期内连续或只有有限个第一类间断点
  • 在一个周期内至多只有有限个极值点

则\(f(x)\)的傅里叶级数收敛，且：

  • \(x_0\)为\(f(x)\)连续点\(\Rightarrow\)级数收敛于\(f(x_0)\)
  • \(x_0\)为\(f(x)\)间断点\(\Rightarrow\)级数收敛于\(\frac{1}{2}[f(x_0^-) + f(x_0^+)]\)
常用结论 $$\sin n\pi = 0$$ $$\cos n\pi = (-1)^n$$

[注]\(\sin[(n+k)x], \cos[(n+k)x]\)直接展开.

将\(f(x)\)展开为傅里叶级数的基本步骤

(1)列出\(a_n\)表达式，将\(n=0\)代入求得\(a_0\).

(2)求出\(n=1,2,\cdots\)时的\(a_n\)与\(b_n\).

(3)判断\(f(x)\)在一个区间内的连续性，以及\(f(-l)\)是否等于\(f(l)\)，得出收敛区间.

[注]：若\(f(x)\)在\(x_0\)出间断，则\(x\neq (2k + 1)x_0, k\in \mathbb{Z}\)

周期为\(2\pi\)函数\(f(x)\)的展开

奇函数在\([-\pi, \pi\)上的傅里叶级数 $$a_n = 0, n = 0,1,2, \cdots$$ $$b_n = \frac{2}{\pi}\int_0^\pi f(x)\sin nx \mathrm{d}x, n=1,2,\cdots$$ \(f(x)\)为偶函数 $$a_n = \frac{2}{\pi}\int_0^\pi f(x)\cos nx \mathrm{d}x, n=0,1,2\cdots$$ $$b_n = 0, n=1,2,\cdots$$ 在\([0,\pi]\)上函数\(f(x)\)的正弦级数和余弦级数

（1）将\(f(x)\)延拓成\([-\pi, \pi]\)上的奇函数，则

$$a_0, n=0,1,2\cdots$$ $$b_n = \frac{2}{\pi}\int_0^\pi f(x)\sin nx \mathrm{d}x, n=1,2,\cdots$$

\(f(x)\)的正弦级数为：

$$f(x) \sim \sum\limits_{n=1}^\infty b_n\sin nx$$

（2）将\(f(x)\)延拓成\([-\pi, \pi]\)上的偶函数，则

$$a_n = \frac{2}{\pi}\int_0^\pi f(x)\cos nx \mathrm{d}x, n=0,1,2\cdots$$ $$b_n = 0, n=1,2,\cdots$$

\(f(x)\)的余弦级数为：

$$f(x)\sim \frac{a_0}{2} + \sum\limits_{n=1}^\infty a_n\cos nx$$ 周期为\(2l\)的函数的展开

在\([-l,l]\)上函数\(f(x)\)的傅里叶级数为

$$f(x)\sim \frac{a_0}{2} + \sum\limits_{n=1}^\infty(a_n\cos \frac{n\pi}{l}x + b_n\sin\frac{n\pi}{l}x)$$ $$a_n = \frac{1}{l}\int_{-l}^{l}f(x)\cos\frac{n\pi}{l}x\mathrm{d}x, n=0,1,2,\cdots$$ $$b_n = \frac{1}{l}\int_{-l}^lf(x)\sin\frac{n\pi}{l}x\mathrm{d}x, n=1,2,\cdots$$ 在\([-l,l]\)上奇偶函数的傅里叶级数展开

\(f(x)\)为奇函数

$$a_n = 0, n=0,1,2,\cdots$$ $$b_n = \frac{2}{l}\int_0^lf(x)\sin\frac{n\pi}{l}x\mathrm{d}x, n=1,2,\cdots$$ $$f(x)\sim \sum\limits_{n=1}^\infty b_n\sin\frac{n\pi}{l}x$$

\(f(x)\)为偶函数

$$a_n = \frac{2}{l}\int_0^{l}f(x)\cos\frac{n\pi}{l}x\mathrm{d}x, n=0,1,2,\cdots$$ $$b_n = 0, n=1,2,\cdots$$ $$f(x)\sim \frac{a_0}{2} + \sum\limits_{n=1}^\infty a_n\cos \frac{n\pi}{l}x$$ 在\([0,l]\)上\(f(x)\)的正弦级数和余弦级数

（1）将\(f(x)\)延拓成\([-l,l]\)上的奇函数，则

$$a_n = 0, n=0,1,2,\cdots$$ $$b_n = \frac{2}{l}\int_0^lf(x)\sin\frac{n\pi}{l}x\mathrm{d}x, n=1,2,\cdots$$ $$f(x)\sim \sum\limits_{n=1}^\infty b_n\sin\frac{n\pi}{l}x$$

（1）将\(f(x)\)延拓成\([-l,l]\)上的偶函数，则

$$a_n = \frac{2}{l}\int_0^{l}f(x)\cos\frac{n\pi}{l}x\mathrm{d}x, n=0,1,2,\cdots$$ $$b_n = 0, n=1,2,\cdots$$ $$f(x)\sim \frac{a_0}{2} + \sum\limits_{n=1}^\infty a_n\cos \frac{n\pi}{l}x$$
