卷积

给定定义在\((-\infty, +\infty)\)上的函数\(f(t)\)与\(g(t)\)，两个函数的卷积定义为：

$$f(t)*g(t) = \int_{-\infty}^{+\infty}f(\tau)g(t-\tau)\mathrm{d}\tau$$

其中，\(*\)表示卷积运算.

二维卷积

两个复值函数\(f(x,y)\)与\(g(x,y)\)的卷积定义为：

$$f(x,y)*g(x,y) = \iint f(\xi,\eta)h(x-\xi,y-\eta)\mathrm{d}\xi\mathrm{d}\eta$$
卷积的运算定律
交换律 $$f(t)*g(t) = g(t)*f(t)$$
$$f(x,y)*g(x,y) = g(x,y)*f(x,y)$$
结合律 $$f(t)*[g(t)*h(t)] = [f(t)*fg(t)]*h(t)$$
$$[f(x,y)*g(x,y)]*h(x,y) = f(x,y)*[g(x,y)*h(x,y)]$$
分配律 $$[f(x,y) + g(x,y)]*h(x,y) = f(x,y)*h(x,y) + g(x,y)*h(x,y)$$
线性性质 $$[k_1f_1(t) + k_2f_2(t)]*g(t) = k_1f_1(t)g(t) + k_2f_2(t)g(t),~k_1,k_2\in \mathbb{C}$$
平移不变性 $$f_1(t)*f_2(t) = g(t) \Rightarrow f_1(t-\alpha)*f_2(t-\beta) = g(t-\alpha-\beta)$$
坐标缩放性质 $$f_1(t)*f_2(t) = g(t) \Rightarrow f_1(at)*f_2(at) = \frac{1}{|a|}g(at),~a\neq 0$$
