项目环境配置

1、创建一个文件夹，用VSCode打开，在Terminal中运行：

npm init

此时会生成一个package.json文件

2、安装electron——在Terminal中运行：

npm install -g cnpm --registry=https://registry.npmmirror.com

cnpm install --save-dev electron

3、补充package.json中的author与description，并将main改为main.js

4、在"scripts"中添加：

"start": "electron ."

5、创建main.js文件

6、在终端运行：

npm start
