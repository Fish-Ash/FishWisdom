光波导的一般理论

光频的Maxwell方程组

对于线性、各向同性、时不变的光波导，通常有：

$$\boldsymbol{D} = \epsilon_0\boldsymbol{E} + \boldsymbol{P}$$ $$\boldsymbol{B} = \mu_0(\boldsymbol{H} + \boldsymbol{M})$$

光频下，介质都是无磁性介质，即：

$$\boldsymbol{M} = 0$$ $$\therefore \boldsymbol{B} = \mu_0\boldsymbol{H}$$

但\(\boldsymbol{P}\)与\(\boldsymbol{E}\)的关系却是很复杂的，\(\boldsymbol{P}\)与\(\boldsymbol{E}\)关系的一个微小变化，都将导致波导新的物理现象.

对于线性、各向同性的时不变光波导，有：

$$\boldsymbol{\boldsymbol{D}} = \epsilon(\omega)\boldsymbol{E}$$
$$\because \boldsymbol{P}(\boldsymbol r, t) = \epsilon_0\boldsymbol R(t)*\boldsymbol E(\boldsymbol r, t)$$ $$\begin{align} \therefore \boldsymbol D(\boldsymbol r, t) &= \epsilon_0\boldsymbol{E}(\boldsymbol r, t) + \boldsymbol{P}(\boldsymbol r, t)\\ &= \epsilon_0\boldsymbol{E}(\boldsymbol r, t) + \epsilon_0\boldsymbol R(t)*\boldsymbol E(\boldsymbol r, t)\\ \end{align}$$ $$\because\mathcal F[f(t)*g(t)] = F(\omega)\cdot G(\omega)$$ $$\mathcal{F}[\boldsymbol{R}(t)] = \chi^{(1)}(\omega)$$ $$\begin{align} \therefore \boldsymbol{D}(\boldsymbol{r}, \omega) &= \mathcal{F}[\boldsymbol{D}(\boldsymbol{r}, t)]\\ &= \epsilon_0\boldsymbol{E}(\boldsymbol{r}, \omega) + \epsilon_0\chi^{(1)}(\omega)\boldsymbol{E}(\boldsymbol{r}, \omega)\\ &= \epsilon_0[1 + \chi^{(1)}(\omega)]\boldsymbol{E}(\boldsymbol{r}, \omega) \end{align}$$

[令]

$$\epsilon(\omega) = \epsilon_0[1 + \chi^{(1)}(\omega)]$$ $$\therefore \boldsymbol{D}(\boldsymbol{r}, \omega) = \epsilon(\omega)\boldsymbol{E}(\boldsymbol{r}, \omega)$$

可见，以往常用的\(\boldsymbol{D} = \epsilon\boldsymbol{E}\)，实际是一个频域表达式（而非时域），\(\boldsymbol{D}, \boldsymbol{E}, \epsilon\)三个量均为频率（光频）的函数，都有大小、相位等.

为便于分析我们首先考虑单一光频的情形，此时光场可以表示为：

$$\left[\begin{matrix}\boldsymbol{E}(x,y,z,t)\\\boldsymbol{H}(x,y,z,t)\end{matrix}\right] = \left[\begin{matrix}\boldsymbol{E}(x,y,z)\\\boldsymbol{H}(x,y,z)\end{matrix}\right]e^{-i\omega t} + c.c.$$
  • \(c.c.\)：共轭

[注]\(\left[\begin{matrix}\boldsymbol{E}(x,y,z)\\\boldsymbol{H}(x,y,z)\end{matrix}\right]\)为一个复矢量，包括方向、幅度、相位.

单色平面电磁波

由单色电磁波的基本方程，根据激发形式的不同与传播介质及其边界条件的限制，电磁波的场强\(\boldsymbol{E}(\boldsymbol{r})\)和\(\boldsymbol{H}(\boldsymbol{r})\)可以有不同的形式.

单色平面电磁波是电磁波最单纯、最基本的理想形式，其特征是等相位面为平面，电磁波有确定的传播方向，场量可表示为：

$$\boldsymbol{E}(\boldsymbol{r}, t) = \boldsymbol{E}_0e^{-i(\omega t - \boldsymbol{k}\cdot\boldsymbol{r})},\quad\boldsymbol{H}(\boldsymbol{r}, t) = \boldsymbol{H}_0e^{-i(\omega t - \boldsymbol{k}\cdot\boldsymbol{r})}$$

光场纵向分量与横向分量的关系

纵向（传输方向）与横向的取向区分是光波导基本特征.

规定哪个方向为纵向或横向，具有很大的任意性，但一旦规定好了纵向与横向，则场的分布、方程的形式等随之确定，不再具有任意性.

此时光波导中的光场可以分解为纵向分量与横向分量之和：

$$\boldsymbol{E} = \boldsymbol{E}_t + \boldsymbol{E}_z$$ $$\boldsymbol{H} = \boldsymbol{H}_t + \boldsymbol{H}_z$$
  • 下标\(z\)方向：纵向
  • 下表\(t\)方向：垂直于\(z\)方向的横向

矢量微分算子可以表示为纵向与横向两个方向的叠加：

$$\nabla = \nabla_t + \frac{\partial}{\partial z}\hat{\boldsymbol{z}}$$
  • \(\hat{\boldsymbol{z}}\)：\(z\)方向单位矢量

全反射相移

全反射条件下，菲涅尔公式不成立，透射角失去实数意义，因此反射光束与入射光束间的关系也需要重新确定.

采用如图所示的坐标系，设入射面为\(xOz\)平面，分别讨论TE与TM两种偏振状态.

TE偏振

TE偏振下，电磁波的场分量只有\(E_y, H_x, H_z\)，其他分量都为\(0\).

根据切向分量连续的边界条件，有：

$$E_{1y} + E_{2y} = E_{3y}$$ $$H_{1z} + H_{2z} = H_{3z}$$ $$\Phi_{\text{TE}} = \arctan\frac{\delta}{n_1\cos\alpha} = \arctan\frac{\sqrt{\sin^2\alpha - n_2^2/n_1^2}}{\cos\alpha}$$

TE偏振下的全反射相移为：

$$\Gamma = 2\Phi_{\text{TE}}$$

TM偏振

TM偏振下，电磁波的场分量只有\(H_y, E_x, E_z\)，其他分量均为\(0\).

根据切向分量连续的边界条件：

$$H_{1y} + H_{2y} = H_{3y}$$ $$E_{1z} + E_{2z} = E_{3z}$$ $$\Phi{\text{TM}} = \arctan\frac{n_1^2}{n_2^2}\frac{\delta}{n_1\cos\alpha} = \arctan\left(\frac{n_1^2}{n_2^2}\frac{\sqrt{\sin^2\alpha - n_2^2/n_1^2}}{\cos\alpha}\right)$$

TM偏振下的全反射相移为：

$$\Gamma = 2\Phi_{\text{TM}}$$

Goos-Hänchen位移

前面的分析都是认为光束的反射点与入射点在同一位置，然而Goos与Hänchen通过实验精确测出了全反射光线的位置，发现并不像通常认为的那样，而是沿表面产生了一个位移\(\Delta z\)，从而使反射光线产生一侧向位移\(D\).

这一位移称为Goos-Hänchen位移，位移的大小与入射角和偏振状态有关，是波长的量级.

上面已经给出全反射相移\(\Gamma\)，进一步应用电磁波理论可以证明：

$$\Delta z = \frac{\partial\Gamma}{\partial\beta}$$
  • \(\beta = n_1k_0\sin\alpha\)

TE与TM偏振的Goos-Hänchen位移分别为：

$$D_{\text{TE}} = \frac{\lambda_1}{\pi}\frac{\sin\theta_1}{\sqrt{\sin^2\theta_1 - n^2}}$$ $$D_{\text{TM}} = \frac{n^2}{(1 + n^2)\sin^2\theta_1 - n^2}$$
  • \(n = n_2/n_1\)

入射角接近全反射临界角时，Goos-Hänchen位移最大，随入射角增大快速减小.
