导模特性

导模截止与辐射模式

从TE模和TM模的特征方程与场分布，可以看出导模具有两个重要的特点：

1、由于\(m\)只能取非负整数，特征方程的解必然是分立的，因此导模的特征值\(\beta\)与\(\kappa\)也只能取分立值.

2、导模场在衬底与覆盖层都是呈指数衰减的，这就等效于壁垒作用，使导模场被限制在芯层内.

波导条件下\(\kappa\)的取值范围

$$0\lt\kappa\lt \kappa_c$$
  • \(\kappa_c = k_0\sqrt{n_1^2 - n_2^2}\)

由导波条件：

$$n_2k_0\lt\beta\lt n_1k_0$$ $$\because \kappa = \sqrt{n_1^2k_0^2 - \beta^2}$$ $$\therefore 0\lt \kappa\lt k_0\sqrt{n_1^2 - n_2^2}$$

[令]

$$\kappa_c = k_0\sqrt{n_1^2 - n_2^2}$$ $$\therefore 0\lt \kappa\lt \kappa_c$$

导模截止

电磁场方程不可能仅仅存在波导解，当参数发生变化时，解的性质也会改变.

若\(\beta\)逐渐减小并趋于\(n_2k_0\)，则\(\kappa\rightarrow \kappa_c\)，而衬底区的衰减参数\(p\rightarrow 0\)，结果时衬底区模场逐渐增强，穿透深度逐渐增大.

\(\beta = n_2k_0\)时，随着光波的传输，芯层电磁场能量会外泄而衰减，这种情况称为导模截止.

\(\kappa_c\)称为参数\(\kappa\)的截止上限，其仅与波导的物理参数与光波长有关.

辐射模式

若\(\beta\)进一步减小，使\(\beta\lt n_2k_0\)，亦即\(\kappa\gt\kappa_c\)，则\(p\)成为虚数，甚至\(p, q\)都成为虚数.

此时\(e^{px}\)与\(e^{-qx}\)成为振荡因子，倏逝波成为辐射波，电磁波不仅向\(z\)轴方向传播，同时又在衬底与覆盖层沿\(x\)轴方向传播.

这种场模式就是辐射模式.

对于辐射模，\(\beta\)可在\([0, n_2k_0]\)区间连续取值，即辐射模谱是连续的.

导模定则

已有的分析都是针对\(\beta, \kappa, p, q\)四个模参数进行的，这些参数必须通过数值计算才能确定.

但是实际工作中，需要在已知波导结构参数\(d,n_1,n_2,n_3\)与入射光波长的基础上，在未经数值计算的条件下，对波导模式、导模数量及导模与波长关系等特性，做出简单而可信的判断和预测.

为了探求一种简便的预测方式，有必要对导模的特征方程进行更细致的分析.

TE模的特征方程为：

$$\kappa d = m\pi + \arctan\frac{\sqrt{(n_1^2 - n_2^2)k_0^2 - \kappa^2}}{\kappa} + \arctan\frac{\sqrt{(n_1^2 - n_3^2)k_0^2 - \kappa^2}}{\kappa}$$

[令]

$$f_m(\kappa) = m\pi + \arctan\frac{\sqrt{(n_1^2 - n_2^2)k_0^2 - \kappa^2}}{\kappa} + \arctan\frac{\sqrt{(n_1^2 - n_3^2)k_0^2 - \kappa^2}}{\kappa}$$

\(m\)给定时，\(f_m(\kappa)\)随\(\kappa\)增大而单调下降，\(f_m(\kappa)\)是以\(m\)为序号的等间距的下降曲线族.

导模范围内，\(0\lt\kappa\lt\kappa_c\)，因此：

$$f_m(0)\geq f_m(\kappa)\geq f_m(\kappa_c)$$

其中

$$f_m(0) = (m+1)\pi$$ $$f_m(\kappa_c) = m\pi + \phi_c$$
  • \(\phi_c = \arctan\frac{\sqrt{n_2^2 - n_3^2}}{\sqrt{n_1^2 - n_2^2}}\)

\(\kappa d\)是以\(\kappa\)为变量的线性递增函数，在\((0,\kappa_c)\)范围内有：

$$0\lt \kappa d\lt\kappa_c d$$

因此，TE模的特征方程表示为：

$$\kappa d = f_m(\kappa)$$

直线\(\kappa d\)与曲线族\(f_m(\kappa)\)的交点就代表特征方程的解.

基于上述分析，可以建立导模定则，表示如下：

若\(\kappa_c d\gt f_m(\kappa_c)\):

则在\((0,\kappa_c)\)范围内，特征方程有\(m+1\)个解，\(m\)阶导模存在，且\(m\)阶以下各阶导模也一定存在.

若\(\kappa_c d = f_{\kappa_c}\)：

\(\kappa_c\)为特征方程的解，\(m\)阶导模处于临界截止状态，\(m\)以下各阶导模存在.

若\(\kappa_c d\lt f_m(\kappa_c)\)：

则在\((0,\kappa_c)\)范围内，\(m\)及\(m\)以上各阶导模均不存在.

对TM模的特征方程作同样分析，只需修改\(\phi_c\)为：

$$\phi_c' = \arctan\frac{n_1^2}{n_2^2}\frac{\sqrt{(n_2^2 - n_3^2)}}{\sqrt{(n_1^2 - n_2^2)}}$$

以上讨论依然适用.

因此，TM_m模存在的条件为：

$$\kappa_c d \gt m\pi + \phi_c'$$

导模数量

当\(m\)增加时会导致方程的根增大，并逐渐趋近截止限\(\kappa_c\).

因此相对而言，高阶模接近截止区，低阶模远离截止区，可以预料导模阶数\(m\)必然存在一个上限.

TE偏振态下导模定则的具体形式为：

$$\frac{2\pi d}{\lambda}\sqrt{n_1^2 - n_2^2}\gt m\pi + \phi_c$$ $$\therefore m\lt \frac{2d}{\lambda}\sqrt{n_1^2 - n_2^2} + \frac{\phi_c}{\pi}$$

由于\(m\)仅能取整数，因此TE模导模的最高限为：

$$m_c = \text{int}[\frac{2d}{\lambda}\sqrt{n_1^2 - n_2^2} + \frac{\phi_c}{\pi}]$$
  • int：取整

同样的，TM模的导模最高限为：

$$m_c' = \text{int}[\frac{2d}{\lambda}\sqrt{n_1^2 - n_2^2} + \frac{\phi_c'}{\pi}]$$

式中\(\phi_c\)与\(\phi_c'\)均为仅与折射率有关的常数，取值均小于\(\pi/2\).

传播的TE与TM导模总数\(M\)为：

$$M = m_c + m_c' + 2$$ $$M\approx \frac{4d}{\lambda}\sqrt{n_1^2 - n_2^2}$$

单模传输

单模传输

对于确定频率的光波，适当选择波导尺寸，使高阶模截止而只传输主模.

多模传输

允许主模与高阶模同时传输.

为使TE0模单模运行，必须同时满足TE0模的导模条件与TE1模的截止条件：

$$\phi_c\lt \frac{2\pi d}{\lambda}\sqrt{n_1^2 - n_2^2}\lt \pi + \phi_c\quad(TE_0)$$

同样，对于TM模式，单模传输时只能是TM0模，单模条件为：

$$\phi_c'\lt \frac{2\pi d}{\lambda}\sqrt{n_1^2 - n_2^2}\lt \pi + \phi_c'\quad(TM_0)$$

导模光强

光波传输过程中必然伴随着能量的传输，因而每一导波模式都携带有一定的能量.

为了研究导模的能量传输特性，有必要首先分析波导横截面上的光强分布.

Poyting矢量为：

$$\boldsymbol{S} = \boldsymbol{E}\times\boldsymbol{H}$$

它代表电磁场的瞬态能流密度，为了得到实际光强，需要进行适当的时间平均.

另一方面，现有电磁理论中的\(\boldsymbol{E}\)和\(\boldsymbol{H}\)都以复数形式表示，特别是还包含经常被省略的\(e^{i\omega t}\)因子，因此对它们的二次形式的运算必须进行实数化处理：

$$\boldsymbol{S} = \text{Re}(\boldsymbol{E})\times\text{Re}(\boldsymbol{H}) = \frac{1}{2}(\boldsymbol{E} + \boldsymbol{E}^*) + \frac{1}{2}(\boldsymbol{H} + \boldsymbol{H}^*)$$
