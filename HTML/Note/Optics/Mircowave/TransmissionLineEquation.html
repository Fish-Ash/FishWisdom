传输线方程

一般传输线方程

一般传输线方程 $$\frac{\partial v(z,t)}{\partial z} = -R_1i(z, t) - L_1\frac{\partial i(z, t)}{\partial t}$$ $$\frac{\partial i(z,t)}{\partial z} = -G_1v(z, t) - C_1\frac{\partial v(z, t)}{\partial t}$$

一般传输线方程又称电报方程（telegraph equation），是一对偏微分方程.

其解析解的严格求解不可能，一般只能作数值计算；作各种假定后，可求其解析解.

时谐均匀传输线方程

时谐传输线方程

对于常用的均匀传输线稳态情况，一般传输线方程可以简化.

此时电压\(v\)与电流\(i\)可用角频率\(\omega\)的复数交流形式表示为：

$$v(z,t) = \mathrm{Re}\{V(z)e^{i\omega t}\}$$ $$i(z,t) = \mathrm{Re}\{I(z)e^{i\omega t}\}$$

为什么？

代入一般传输线方程后，得时谐传输线方程：

$$\frac{\mathrm{d}V(z)}{\mathrm{d}z} = -(R_1 + i\omega L_1)I(z) = -Z_1I(z)$$
  • \(Z_1 = R_1 + i\omega L_1\)：传输线单位长度的串联阻抗
$$\frac{\mathrm{d}I(z)}{\mathrm{d}z} = -(G_1 + i\omega C_1)V(z) = -Y_1V(z)$$
  • \(Y_1 = G_1 + i\omega C_1\)：传输线单位长度的并联导纳

这里代入的似乎是整个复数，而非实数部分，至于原因，尚未弄清.

电压、电流的通解

时谐传输线方程可以进一步写作：

$$\frac{\mathrm{d}^2 V(z)}{\mathrm{d}z^2} = Z_1Y_1V(z)$$
$$\because \frac{\mathrm{d}V(z)}{\mathrm{d}z} = -Z_1I(z)$$ $$\therefore \frac{\mathrm{d}^2 V(z)}{\mathrm{d}z^2} = -Z_1\frac{\mathrm{d}I(z)}{\mathrm{d}z}$$ $$\because \frac{\mathrm{d}I(z)}{\mathrm{d}z} = -Y_1V(z)$$ $$\therefore \frac{\mathrm{d}^2 V(z)}{\mathrm{d}z^2} = Z_1Y_1V(z)$$
$$\frac{\mathrm{d}^2 I(z)}{\mathrm{d}z^2} = Z_1Y_1I(z)$$
$$\because \frac{\mathrm{d}I(z)}{\mathrm{d}z} = -Y_1V(z)$$ $$\therefore \frac{\mathrm{d}^2 I(z)}{\mathrm{d}z^2} = -Y_1\frac{\mathrm{d}V(z)}{\mathrm{d}z}$$ $$\because \frac{\mathrm{d}V(z)}{\mathrm{d}z} = -Z_1I(z)$$ $$\therefore \frac{\mathrm{d}^2 I(z)}{\mathrm{d}z^2} = Z_1Y_1I(z)$$

定义电压传播常数：

电压传播常数\(\gamma\) $$\gamma = \sqrt{Z_1Y_1} = \sqrt{(R_1 + i\omega L_1)(G_1 + i\omega C_1)}$$

则：

$$\frac{\mathrm{d}^2 V(z)}{\mathrm{d}z^2} - \gamma^2V(z) = 0$$ $$\frac{\mathrm{d}^2 I(z)}{\mathrm{d}z^2} - \gamma^2I(z) = 0$$

电压解为：

$$V(z) = A_1e^{-\gamma z} + A_2e^{\gamma z}$$ $$\because \frac{\mathrm{d}V(z)}{\mathrm{d}z} = -Z_1I(z)$$

故电流解为：

$$I(z) = \frac{1}{Z_0}(A_1e^{-\gamma z} - A_2e^{\gamma z})$$
  • \(Z_0 = \sqrt{\frac{G_1 + i\omega C_1}{R_1 + i\omega L_1}}\)
$$\because \frac{\mathrm{d}V(z)}{\mathrm{d}z} = -Z_1I(z)$$ $$\therefore I(z) = -\frac{1}{Z_1}(-\gamma A_1e^{-\gamma z} + \gamma A_2e^{\gamma z})$$ $$\because \gamma = \sqrt{(R_1 + i\omega L_1)(G_1 + i\omega C_1)}$$ $$Z_1 = R_1 + i\omega L_1$$ $$\therefore I(z) = \sqrt{\frac{G_1 + i\omega C_1}{R_1 + i\omega L_1}}(A_1e^{-\gamma z} - A_2e^{\gamma z})$$

[令]

$$Z_0 = \sqrt{\frac{G_1 + i\omega C_1}{R_1 + i\omega L_1}}$$ $$\therefore I(z) = \frac{1}{Z_0}(A_1e^{-\gamma z} - A_2e^{\gamma z})$$

终端条件解

已知终端的电压\(V_L\)与电流\(I_L\)，代入电压、电流的通解，得：

$$V(l) = V_L = A_1e^{-\gamma l} + A_2e^{\gamma l}$$ $$I(l) = I_L = \frac{1}{Z_0}(Ae^{-\gamma l} - A_2e^{\gamma l})$$ $$V(d) = \frac{V_L + I_LZ_0}{2}e^{\gamma d} + \frac{V_L- I_LZ_0}{2}e^{-\gamma d}$$
  • \(V^-(d) = \frac{V_L - I_LZ_0}{2}e^{-\gamma d}\)：反射波电压
  • \(V^+(d) = \frac{V_L + I_LZ_0}{2}e^{\gamma d}\)：入射波电压
$$I(d) = \frac{V_L + I_LZ_0}{2Z_0}e^{\gamma d} - \frac{V_L - I_LZ_0}{2Z_0}e^{-\gamma d}$$
  • \(I^-(d) = \frac{V_L - I_LZ_0}{2Z_0}e^{-\gamma d}\)：反射波电流
  • \(I^+(d) = - \frac{V_L + I_LZ_0}{2Z_0}e^{\gamma d}\)：入射波电流
双曲函数表示
$$V(d) = V_L\cosh(\gamma d) + I_LZ_0\sinh(\gamma d)$$
$$\begin{align} V(d) &= \frac{V_L + I_LZ_0}{2}e^{\gamma d} + \frac{V_L- I_LZ_0}{2}e^{-\gamma d}\\ &= V_L\frac{e^{\gamma d} + e^{-\gamma d}}{2} + I_LZ_0\frac{e^{\gamma d} - e^{-\gamma d}}{2}\\ &= V_L\cosh(\gamma d) + I_LZ_0\sinh(\gamma d) \end{align}$$
$$I(d) = \frac{V_L}{Z_0}\sinh(\gamma d) + I_L\cosh(\gamma d)$$
$$\begin{align} I(d) &= \frac{V_L + I_LZ_0}{2Z_0}e^{\gamma d} - \frac{V_L - I_LZ_0}{2Z_0}e^{-\gamma d}\\ &= \frac{V_L}{Z_0}\frac{e^{\gamma d} - e^{-\gamma d}}{2} + I_L\frac{e^{\gamma d} + e^{-\gamma d}}{2}\\ &= \frac{V_L}{Z_0}\sinh(\gamma d) + I_L\cosh(\gamma d) \end{align}$$
矩阵形式 $$\left[\begin{matrix}V(d)\\I(d)\end{matrix}\right] = \left[\begin{matrix}\cosh(\gamma d) & Z_0\sinh(\gamma d)\\\frac{\sinh(\gamma d)}{Z_0} & \cosh(\gamma d)\end{matrix}\right]\left[\begin{matrix}V_L\\I_L\end{matrix}\right]$$

始端条件解

已知始端的电压\(V_0\)与电流\(I_0\)，解为：

$$V(z) = \frac{V_0 + I_0Z_0}{2}e^{-\gamma z} + \frac{V_0 - I_0Z_0}{2}e^{\gamma z}$$ $$I(z) = \frac{V_0 - I_0Z_0}{2Z_0}e^{-\gamma z} - \frac{V_0 - I_0Z_0}{2Z_0}e^{\gamma z}$$

信号源与负载条件解

已知信号源电动势\(E_G\)，内阻抗\(Z_G\)与负载阻抗\(Z_L\)，由信源端条件与负载端条件导出的代数方程确定\(A_1\)与\(A_2\)，代入电压、电流通解得：

$$V(d) = \frac{E_GZ_0}{Z_G + Z_0}\frac{e^{\gamma d} + e^{-\gamma d}}{1 - \Gamma_L\Gamma_Ge^{-2\gamma d}}(e^{\gamma d} + \Gamma_Le^{-\gamma d})$$ $$I(d) = \frac{E_G}{Z_G + Z_0}\frac{e^{-\gamma d}}{1 - \Gamma_L\Gamma_Ge^{-2\gamma d}}(e^{\gamma d} - \Gamma_Le^{-\gamma d})$$
  • \(\Gamma_L = \frac{Z_L - Z_0}{Z_L + Z_0}\)
  • \(\Gamma_G = \frac{Z_G - Z_0}{Z_G + Z_0}\)

上述三种解形均说明，一般情况下，传输线上的电压与电流是由从信号源向负载传播的入射波和从负载向信号源传播的反射波的叠加，呈行驻波混合分布.
