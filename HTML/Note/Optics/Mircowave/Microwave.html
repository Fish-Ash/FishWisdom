微波理论

导行波及其一般传输特性

微波电路是一种由各种导行系统构成的导行电磁波电路，其设计的理论基础之一是导行波基本理论.

导行波基本理论

  • 导行波理论的横向问题：导行波的模式及其在导行系统横截面内的场结构分析，与导行系统的具体截面形状尺寸有关
  • 导行波理论的纵向问题：导行波沿导行系统轴向的传输特性分析，对于规则导行系统，纵向问题具有一些通性

本节在讲解导行波基本概念的基础上，论述导行波的一般传输特性.

导行波概念

导行系统（guided system）

用以约束或引导电磁波能量定向传输的结构.

导行系统的主要功能
  • 无辐射损耗地引导电磁波沿其轴向行进，而将能量从一处传输至另一处，称之为馈线.
  • 设计构成各种微波电路元件，如滤波器、阻抗变换器、定向耦合器等.

导行系统的种类可按其上的导行波分为三类：

  • TEM或准TEM传输线
  • 封闭金属波导
  • 表面波波导（开波导）
导行波（guided wave）

能量的全部或大部分受导行系统的导体或介质的边界约束，在有限横截面内沿确定方向（一般为轴向）传输的电磁波.

简单说就是沿导行系统定向传输的电磁波，简称为导波.

各种传输线使电能波能量约束或限制在导体之间空间沿其轴向传播，其导行波是横电磁波（TEM）或准TEM波.

封闭金属波导使电磁波能量完全限制在金属管内沿轴向传播，其导行波使横电波（TE）或横磁波（TM）.

开波导使电磁波能量约束在波导结构的周围（波导内和波导表面附近）沿轴向传播，其导行波是表面波.

导模（guided mode）

导行波的模式，是能够沿导行系统独立存在的场型.

又称传输模、正规模.

导模的特点
  • 在导行系统横截面上的电磁场呈驻波分布，且是完全确定的；这一分布与频率无关，并于横截面在导行系统上的位置无关.
  • 导模是离散的，具有离散谱；当工作频率一定时，每个导模具有唯一的传播常数.
  • 导模之间相互正交、彼此独立，互不耦合.
  • 具有截止特性，截止条件与截止波长因导行系统和模式而异.
规则导行系统（regular guided system）

无限长的笔直导行系统，其截面形状与尺寸、媒质分布情况、结构材料及边界条件沿轴向均不变化.

传输线理论

传输线理论又称一维分布参数电路理论，是微波电路设计和计算的理论基础.

传输线理论在电路理论与场的理论之间起着桥梁作用，在微波网络分析中也相当重要.

本章从路的观点，研究传输线在微波运用下的传输特性，讨论用史密斯圆图进行阻抗计算与阻抗匹配的方法.

本章分析得到的一个结论为：传输线段具有阻抗变换作用，微波电路的阻抗将因附加一小段传输线而显著改变.

本章所得到的一些基本概念与公式，不仅适用于TEM传输线，而且可以引用于天线与波导传输中.

传输线方程

传输线方程是传输线理论的基本方程，是描述传输线上电压、电流变化规律及其相互关系的微分方程.

传输线的电路模型

传输线（transmission line）

以TEM导模的方式传送电磁波能量或信号的导行系统.

其横向尺寸远小于其上工作波长.

横向尺寸就是指截面积.

长线（long line）

几何长度\(l\)与工作波长\(\lambda\)可相比拟的传输线，需用分布参数电路描述.

短线（short line）

几何长度\(l\)与工作波长\(\lambda\)相比可以忽略不计的线，采用集总参数电路表示.

电路理论与传输线之间的关键不同处在于电尺寸.

电路分析假设一个网络的实际尺寸远小于工作波长，而传输线的长度则可与工作波长相比拟或为数个波长.

因此，一段传输线是一个分布参数网络，电压与电流在其上的振幅和相位都可能变化.

集总参数电路与分布参数电路的分界线可认为是：\(l/\lambda\geq 0.05\).

分布参数电路与集总参数电路的区别就在于\(l\)与\(\lambda\)的相对尺度.

以微波工作的传输线，其长度可与工作波长相比拟或更长.

根据电磁场理论知道，此时传输线的导体上存在有：

  • 损耗电阻\(R_1\)
  • 电感\(L_1\)

导体间存在：

  • 电容\(C_1\)
  • 漏电导\(G_1\)

这些参数虽然看不见，但当频率高时便会呈现出其对能量或信号传输的影响.

它们是沿线分布着的，其影响分布在传输线的没一点，故称之为分布参数（distributed parameter）.

\(R_1,~L_1,~C_1,~G_1\)分别称为传输线单位长度的分布电阻、分布电感、分布电容与分布电导.

均匀传输线

\(R_1,~L_1,~C_1,~G_1\)沿线均匀分布，即与距离无关的传输线.

非均匀传输线

\(R_1,~L_1,~C_1,~G_1\)沿线非均匀分布，即与距离有关的传输线.

传输线的特性参数

特性阻抗\(Z_0\)（characteristic impedance）

传输线上行波电压与电流之比.

特性阻抗的一般表示式为：

$$Z_0 = \sqrt{\frac{R_1 + i\omega L_1}{G_1 + i\omega C_1}}$$

可见特性阻抗通常为复数，且与工作频率有关.

这个一般表示式的来历.

如下两种特殊情况，特性阻抗与频率无关，仅由传输线本身的分布参数决定，且为纯电阻：

无耗线

此时\(R_1 = G_1 = 0\)，则：

$$Z_0 = \sqrt{\frac{L_1}{C_1}}$$ 微波低耗线

此时\(R_1\ll \omega L_1,~ G_1\ll \omega C_1\)，则：

$$\begin{align} Z_0 &= \sqrt{\frac{R_1 + i\omega L_1}{G_1 + i\omega C_1}}\\ &= \sqrt{\frac{i\omega L_1}{i\omega C_1}}\sqrt{\frac{R_1/(i\omega L_1) + 1}{G_1/(i\omega C_1) + 1}}\\ &= \sqrt{\frac{L_1}{C_1}}\left(1 + \frac{R_1}{i\omega L_1}\right)^{1/2}\left(1 + \frac{G_1}{i\omega C_1}\right)^{-1/2}\\ &\approx \sqrt{\frac{L_1}{C_1}}\left(1 + \frac{1}{2}\frac{R_1}{i\omega L_1}\right)\left(1 - \frac{1}{2}\frac{G_1}{i\omega C_1}\right)\\ &= \sqrt{\frac{L_1}{C_1}}\left(1 + \frac{1}{2}\frac{R_1}{i\omega L_1} - \frac{1}{2}\frac{G_1}{i\omega C_1} - \frac{1}{4}\frac{R_1}{i\omega L_1}\frac{G_1}{i\omega C_1}\right)\\ &\approx \sqrt{\frac{L_1}{C_1}}\\ \end{align}$$

双导线特性阻抗为：

$$Z_0 = 120\ln\left[\frac{D}{d} + \sqrt{\left(\frac{D}{d}\right)^2 - 1}\right]\approx 120\ln\frac{2D}{d}$$

同轴线特性阻抗为：

$$Z_0 = \frac{60}{\varepsilon_r}\ln\frac{b}{a}$$

平行板传输线特性阻抗为：

$$Z_0 = \frac{d}{W}\eta$$
特性导纳\(Y_0\)（characteristic admittance）

特性阻抗的倒数.

$$Y_0 = \frac{1}{Z_0}$$
传播常数\(\gamma\)（propagation constant）

描述导行波沿导行系统传播过程中的衰减与相位变化的参数，通常为复数.

$$\gamma = \sqrt{(R_1 + i\omega L_1)(G_1 + i\omega C_1)} = \alpha + i\beta$$
  • \(\alpha\)：衰减常数（attenuation constant），单位为：\(\text{Np/m}\)或\(\text{dB/m}\)（\(1~\text{Np} = 8.686~\text{dB}\)）
  • \(\beta\)：相位常数（phase constant），单位为：\(\text{rad/m}\)

\(\gamma\)一般是频率的复杂函数，对于无耗和微波低耗的情况，其表达式十分简单：

无耗线 $$\because R_1 = G_1 = 0$$ $$\therefore \gamma = i\omega\sqrt{L_1C_1}$$ $$\therefore \alpha = 0,\quad \beta = \omega\sqrt{L_1C_1}$$ 微波低耗线 $$\because R_1\ll \omega L_1,\quad G_1 = \omega C_1$$ $$\begin{align}\therefore \gamma &= \sqrt{(R_1 + i\omega L_1)(G_1 + i\omega C_1)}\\ &= i\omega\sqrt{L_1C_1}\left(1 + \frac{R_1}{i\omega L_1}\right)^{1/2}\left(1 + \frac{G_1}{i\omega C_1}\right)^{1/2}\\ &\approx i\omega\sqrt{L_1C_1}\left(1 + \frac{1}{2}\frac{R_1}{i\omega L_1}\right)\left(1 + \frac{1}{2}\frac{G_1}{i\omega C_1}\right)\\ &= i\omega\sqrt{L_1C_1}\left(1 + \frac{1}{2}\frac{R_1}{i\omega L_1}+ \frac{1}{2}\frac{G_1}{i\omega C_1} + \frac{1}{4}\frac{R_1}{i\omega L_1}\frac{G_1}{i\omega C_1}\right)\\ &\approx i\omega\sqrt{L_1C_1}\left[1 + \frac{1}{2}\frac{1}{i\omega}\left(\frac{R_1}{L_1}+\frac{G_1}{C_1}\right)\right]\\ &= \frac{1}{2}\left(R_1\sqrt{\frac{C_1}{L_1}} + G_1\sqrt{\frac{L_1}{C_1}}\right) + i\omega\sqrt{L_1C_1}\\ &= \frac{R_1}{2Z_0} + \frac{G_1Z_0}{2} + i\omega\sqrt{L_1C_1} \end{align}$$ $$\therefore \alpha = \frac{R_1}{2Z_0} + \frac{G_1Z_0}{2} = \alpha_c + \alpha_d,\quad \beta = \omega\sqrt{L_1C_1}$$
  • \(\alpha_c = \frac{R_1}{2Z_0}\)：由单位长度分布电阻决定的导体衰减常数
  • \(\alpha_d = \frac{G_1Z_0}{2}\)：由单位长度漏电导决定的介质衰减常数

此外，传输线上导行波的波长与相速度都与传播常数\(\beta\)有关.

分布参数阻抗

前置知识
  • 双曲函数
分布参数阻抗（distributed impedance）

由传输线上电压与电流决定的传输线阻抗.

微波阻抗是分布参数阻抗，低频阻抗是集总参数阻抗.

传输线上任一点的阻抗\(Z_{in}(d)\)

该点的电压与电流之比.

$$Z_{in}(d) = Z_0\frac{Z_L + Z_0\tanh\gamma d}{Z_0 + Z_L\tanh\gamma d}$$
$$\begin{align} Z_{in}(d) &= \frac{V(d)}{I(d)}\\ &= \frac{V_L\cosh\gamma d + I_LZ_0\sinh\gamma d}{\frac{V_L}{Z_0}\sinh\gamma d + I_L\cosh\gamma d}\\ &= Z_0\frac{V_L + I_LZ_0\tanh\gamma d}{V_L\tanh\gamma d + I_LZ_0}\\ &= Z_0\frac{Z_L + Z_0\tanh\gamma d}{Z_0 + Z_L\tanh\gamma d} \end{align}$$

对于无耗线，\(\alpha = 0,~\gamma = i\beta\).

$$\therefore \tanh(\gamma d) = \tanh(i\beta d) = i\tan(\beta d)$$
$$\therefore Z_{in}(d) = Z_0\frac{Z_L + iZ_0\tan\beta d}{Z_0 + iZ_L\tan\beta d}$$

这表明，传输线上任一点\(d\)的阻抗与该点的位置\(d\)和负载阻抗\(Z_L\)有关，\(d\)点的阻抗可看作由\(d\)处向负载看去的输入阻抗（input impedance）（或称视在阻抗）.

由上式可见：

  • 传输线阻抗随位置\(d\)变化，分布于沿线各点，且与负载有关，是一种分布参数阻抗.
  • 传输线段具有阻抗变换作用，\(Z_L\)通过线段\(d\)变为\(Z_{in}(d)\)，或相反.
  • 无耗线的阻抗呈周期性变化，具有\(\lambda/4\)变换性与\(\lambda/2\)重复性，即：若\(d = n\lambda/2\)，则\(Z_{in} = Z_L\)；若\(d = \lambda/4 + n\lambda/2\)，则\(Z_{in} = Z_0^2/Z_L\).

反射参量

由于微波频率下，电压与电流缺乏明确的物理意义，不能直接测量，因此传输线阻抗也不能直接测量，解决的办法是引入可以直接测量的反射参量与驻波参量.

反射系数\(\Gamma\)（reflection coefficient）

传输线上某点的反射系数定义为：该点的反射波电压（或电流）与该点的入射波电压（或电流）之比.

$$\Gamma_V(d) = \frac{V^-(d)}{V^+(d)}$$
  • \(V^-(d)\)：反射波电压
  • \(V^+(d)\)：入射波电压
$$\Gamma_I(d) = \frac{I^-(d)}{I^+(d)}$$
  • \(I^-(d)\)：反射波电流
  • \(I^+(d)\)：入射波电流

由终端条件解：

$$\Gamma_I(d) = -\Gamma_V(d)$$
$$\begin{align} \Gamma_I(d) &= \frac{I^-(d)}{I^+(d)}\\ &= -\frac{V_L - I_LZ_0}{V_L + I_LZ_0}e^{-2\gamma d} \end{align}$$ $$\begin{align} \Gamma_V(d) &= \frac{V^-(d)}{V^+(d)}\\ &= \frac{V_L - I_LZ_0}{V_L + I_LZ_0}e^{-2\gamma d} \end{align}$$ $$\therefore \Gamma_I(d) = -\Gamma_V(d)$$

通常采用便于测量的电压反射系数，用\(\Gamma(d)\)表示之，由终端条件解，得到：

$$\begin{align} \Gamma(d) &= \frac{V_L - I_LZ_0}{V_L + I_LZ_0}e^{-2\gamma d}\\ &= \frac{Z_L - Z_0}{Z_L + Z_0}e^{-2\gamma d}\\ &= \Gamma_Le^{-2\gamma d}\\ &= |\Gamma_L|e^{i\phi_L}e^{-2\gamma d}\\ &= |\Gamma_L|e^{-2\alpha d}e^{i(\phi_L - 2\beta d)} \end{align}$$
  • \(\Gamma_L = \frac{Z_L - Z_0}{Z_L + Z_0} = |\Gamma_L|e^{\gamma\phi_L}\)：终端反射系数

上式说明：\(\Gamma(d)\)的大小与相位均在单位圆内的向内螺旋轨道上变化.

对于无耗线，\(\alpha = 0\)，则：

$$\Gamma(d) = |\Gamma_L|e^{i(\phi_L - 2\beta d)}$$

其大小保持不变，仅其相位以\(-2\beta d\)的角度沿等圆周向信号源端顺时针方向变化.

阻抗与反射系数的关系

引入反射系数后，传输线上\(d\)处的电压与电流可表示为：

$$V(d) = V^+(d) + V^-(d) = V^+(d)[1 + \Gamma(d)]$$ $$I(d) = I^+(d) + I^-(d) = I^+(d)[1 - \Gamma(d)]$$ $$\therefore Z_{\text{in}}(d) = \frac{V^+(d)[1 + \Gamma(d)]}{I^+(d)[1 - \Gamma(d)]} = Z_0\frac{1 + \Gamma(d)}{1 - \Gamma(d)}$$ $$\Gamma(d) = \frac{Z_{\text{in}(d)} - Z_0}{Z_{\text{in}}(d) + Z_0}$$

上式表明：传输线的特性阻抗\(Z_0\)一定时，传输线上任一点\(d\)处的阻抗\(Z_{in}(d)\)与该点的反射系数\(\Gamma(d)\)一一对应；\(Z_{\text{in}}(d)\)可以通过测量\(\Gamma(d)\)来确定.

为了通用起见，引入归一化阻抗：

\(Z_0\)的归一化阻抗\(z_{\text{in}}(d)\) $$z_{\text{in}(d)} = \frac{Z_{\text{in}}(d)}{Z_0} = \frac{1 + \Gamma(d)}{1 - \Gamma(d)}$$

\(z_{\text{in}}\)与\(\Gamma(d)\)一一对应.

为了描述传输线上的功率传输关系，引入传输系数.

传输系数\(T\)

通过传输线上某处的传输电压或电流与该处的入射电压或电流之比.

$$T = \frac{V^t}{V^+} = \frac{I^t}{I^+}$$

驻波参量

上述反射系数为复数，且不便测量；为了间接测量微波阻抗，还可引入驻波参量.

电压驻波比VSWR

传输线上各点的电压与电流一般由入射波与反射波叠加，结果在线上形成驻波，沿各点的电压与电流的振幅不同，以\(\lambda/2\)周期变化.

称电压（或电流）振幅具有最大值的点为电压（或电流）驻波的波腹点.

称电压（或电流）振幅具有最小值的店为电压（或电流）驻波的波谷点.

振幅为0的点称为驻波的波节点.

电压驻波比VSWR（voltage standingwave ratio）

传输线上相邻波腹点与波谷点的电压振幅之比.

简称驻波比SWR，或称电压驻波系数\(\rho\)（voltage standingwave coefficient）.

$$\text{VSWR} = \frac{|V|_{\max}}{|V|_{\min}}$$
行波系数\(K\)（traveling wave coefficient） $$K = \frac{1}{VSWR} = \frac{|V|_{\min}}{|V|_{\max}}$$
$$V(d) = V^+(d) + V^-(d) = V^+(d)[1 + \Gamma(d)] = V^+(d)[1 + |\Gamma_L|e^{i(\phi_L - 2\beta d)}]$$
$$|V(d)| = |V^+(d)|[1 + |\Gamma_L|^2 + 2|\Gamma_L|\cos(\phi_L - 2\beta d)]^{1/2}$$
$$\because |z_1z_2| = |z_1||z_2|$$ $$\begin{align}\therefore |V(d)| &= |V^+(d)||1 + |\Gamma_L|\cos(\phi_L - 2\beta d) + i|\Gamma_L|\sin(\phi_L - 2\beta d)|\\ &= |V^+(d)|\sqrt{1 + 2|\Gamma_L|\cos(\phi_L - 2\beta d) + |\Gamma_L|^2\cos^2(\phi_L - 2\beta d) + |\Gamma_L|^2\sin^2(\phi_L - 2\beta d)}\\ &= |V^+(d)|\sqrt{1 + 2|\Gamma_L|\cos(\phi_L - 2\beta d) + |\Gamma_L|^2} \end{align}$$
$$\therefore |V(d)|_{\max} = |V^+(d)|[1 + |\Gamma_L|]$$ $$\therefore |V(d)|_{\min} = |V^+(d)|[1 - |\Gamma_L|]$$ $$I(d) = I^+(d) + I^-(d) = I^+(d)[1 - \Gamma(d)] = I^+(d)[1 - |\Gamma_L|e^{i(\phi_L - 2\beta d)}]$$ $$|I(d)| = |I^+(d)|[1 + |\Gamma_L|^2 - 2|\Gamma_L|\cos(\phi_L - 2\beta d)]^{1/2}$$ $$\therefore |I(d)|_{\max} = |I^+(d)|[1 + |\Gamma_L|]$$ $$\therefore |I(d)|_{\min} = |I^+(d)|[1 - |\Gamma_L|]$$ $$\therefore Z_0 = \frac{|V(d)|_{\max}}{|I(d)|_{\max}} = \frac{|V(d)|_{\min}}{|I(d)|_{\min}}$$ $$\text{VSWR} = \frac{1 + |\Gamma_L|}{1 - |\Gamma_L|}\Leftrightarrow |\Gamma_L| = \frac{\text{VSWR} - 1}{\text{VSWR} + 1}$$
  • \(|\Gamma_L| = 0\)时：\(\text{VSWR} = 1\)
  • \(|\Gamma_L| = 1\)时，\(\text{VSWR} = \infty\)

电压驻波比与反射系数一样，可用来描述传输线的工作状态.

阻抗与驻波参量的关系

对于无耗线：

$$\because Z_{\text{in}}(d) = Z_0\frac{Z_L + iZ_0\tan\beta d}{Z_0 + iZ_L\tan\beta d}$$
$$\therefore Z_L = Z_0\frac{Z_{\text{in}}(d) - iZ_0\tan\beta d}{Z_0 - iZ_{\text{in}}(d)\tan\beta d}$$
$$Z_0Z_{\text{in}}(d) + iZ_LZ_{\text{in}}(d)\tan\beta d = Z_0Z_L + iZ_0^2\tan\beta d$$ $$Z_L[Z_0 - iZ_{\text{in}}(d)\tan\beta d] = Z_0[Z_{\text{in}}(d) - iZ_0\tan\beta d]$$ $$\therefore Z_L = Z_0\frac{Z_{\text{in}}(d) - iZ_0\tan\beta d}{Z_0 - iZ_{\text{in}}(d)\tan\beta d}$$

无耗线工作状态分析

传输线终端接不同负载阻抗时，有三种不同的工作状态：

  • 行波状态
  • 驻波状态
  • 行驻波状态

分析这三种状态时，忽略线上的损耗，作为无耗线分析.

本节分析得到的无耗线不同工作状态的特性对微波电路的分析与设计极为有用.

书上这些推导都是基于公式：

$$\Gamma_L = \frac{Z_L - Z_0}{Z_L + Z_0}$$

展开的，个人理解三种情况分别对应于\(\Gamma_L = 0, \Gamma_L = 1, 0\lt\Gamma_L\lt 1\)

但是为什么对应于行波和驻波？不理解

行波状态：无反射情况

条件

终端无反射，线上载行波的实际条件是：\(Z_L = Z_0\).

$$\Gamma_L = \frac{Z_L - Z_0}{Z_L + Z_0}= 0$$ $$\therefore Z_L = Z_0$$

此时：

  • \(\Gamma_L = 0\)
  • \(\text{VSWR} = 1\)
  • \(K = 1\)

特性分析

行波状态的特点是：

  • 沿线电压与电流的振幅不变
  • 电压与电流沿线各点同相，电压或电流的相位随\(z\)增加连续滞后
  • 沿线各点的阻抗均等于传输线的特性阻抗

驻波条件：全反射情况

条件

终端全反射，线上形成驻波的条件为终端短路（\(Z_L = 0\)）、开路（\(Z_L = \infty\)）和接纯电抗负载\(Z_L = \pm iX_L\).

$$|\Gamma_L| = \left|\frac{Z_L - Z_0}{Z_L + Z_0}\right| = 1$$ case1 $$\frac{Z_L - Z_0}{Z_L + Z_0} = 1$$ $$\therefore Z_L = \infty$$ case2 $$\frac{Z_L - Z_0}{Z_L + Z_0} = -1$$ $$\therefore Z_L = 0$$ case3 $$\frac{Z_L - Z_0}{Z_L + Z_0} = \pm i$$ $$Z_L - Z_0 = \pm i(Z_L + Z_0)$$ $$Z_L(1 \mp i) = Z_0(1 \pm i)$$ $$Z_L = Z_0\frac{1 \pm i}{1 \mp i}$$ $$\therefore Z_L = \pm iZ_0$$

无耗线中，\(Z_0\in\mathbb{R}\).

$$\therefore Z_L = \pm iX_L$$

\(X_L\)为\(Z_L\)的虚部，说明\(Z_L\)为纯虚数.

上述条件下，线上的驻波特点是一样的，只是驻波在线上的分布情况不同，下面分别加以讨论.

1、终端短路线
  • \(Z_L = 0\)
  • \(\Gamma_L = -1\)
  • \(\text{VSWR} = \infty\)

线上电压和电流为：

$$V(d) = i2V_L^+\sin(\beta d)$$ $$I(d) = \frac{2V_L^+}{Z_0}\cos(\beta d) = 2I_L^+\cos(\beta d)$$

可见：负载处电压为\(V_L = 0\)，而电流有最大值\(I_L = 2V_L^+/Z_0\).

即终端为电压波节点，电流波腹点.

沿线的输入阻抗为：

$$Z_{\text{in}}^\infty(d) = iZ_0\tan(\beta d)$$

可见任意长度\(d\)的终端段线路的输入阻抗都是纯电抗，可取\((-i\infty, +i\infty)\)间的所有值.

2、终端开路线
  • \(Z_L = \infty\)
  • \(\Gamma_L = 1\)
  • \(\text{VSWR} = \infty\)

线上电压与电流为：

$$V(d) = 2V_L^+\cos(\beta d)$$ $$I(d) = i\frac{2V_L^+}{Z_0}\sin(\beta d) = i2I_L^+\sin(\beta d)$$
