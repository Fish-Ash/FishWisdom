并矢Green函数

Green函数的数学表达式

Green函数表示点源产生的场，是场论中的一个重要概念.

并矢Green函数\(\overleftrightarrow{\boldsymbol{G}}\)本质上由以下关系定义：

位于源点\(\boldsymbol{r}'\)的电偶极子\(\boldsymbol{p}\)，在场点\(\boldsymbol{r}\)处产生电场\(\boldsymbol{E}\).

数学形式表示为：

$$\boldsymbol{E}(\boldsymbol{r}) = \omega^2\mu_0\mu\overleftrightarrow{\boldsymbol{G}}(\boldsymbol{r}, \boldsymbol{r}')\boldsymbol{p}$$

考虑一个一般的非齐次方程：

$$\mathcal{L}\boldsymbol{A}(\boldsymbol{r}) = \boldsymbol{B}(\boldsymbol{r})$$
非齐次方程

方程右边存在一个不为零的、独立于未知函数的“源项”或“驱动项”.

这里其实指的是一个非齐次线性微分方程.

线性算符\(\mathcal{L}\)作用于矢量场\(\boldsymbol{A}\)，而\(\boldsymbol{A}\)表示系统的未知响应（亦即算符\(\mathcal{L}\)对源\(\boldsymbol{B}\)）的响应.

响应

源\(B\)是客观存在的，它经过法则\(\mathcal{L}\)，会引起\(A\).

比如胡克定律：

$$f = kx$$

其中\(f\)就是源，在算符\(k\)作用下，它引起了弹簧移动\(x\).

矢量场\(\boldsymbol{B}\)是已知的源函数，它使该微分方程成为非齐次方程.

线性微分方程的定理指出：通解等于齐次方程（\(\boldsymbol{B} = 0\)）的完整解与某个非齐次特解之和.

[设]齐次解\(\boldsymbol{A}_0\)已知.

因此，我们需要解出任意一个特解.

通常，直接求解上式非常困难，简单起见，考虑形式为\(\delta(\boldsymbol{r} - \boldsymbol{r'})\)的点源，该电源在除\(\boldsymbol{r} = \boldsymbol{r}'\)处外，处处为0.

这样，方程可以写作：

$$\mathcal{L}\boldsymbol{G}_i(\boldsymbol{r}, \boldsymbol{r}') = \boldsymbol{n}_i\delta(\boldsymbol{r} - \boldsymbol{r}'),\quad i=x,y,z$$
  • \(\boldsymbol{n}_i\)：\(i\)方向上的单位矢量
  • \(\boldsymbol{G}_i\)：\(\mathcal{L}\)对源\(\boldsymbol{n}_i\delta(\boldsymbol{r}-\boldsymbol{r}')\)的响应

写成矩阵形式为：

$$\mathcal{L}\boldsymbol{G}(\boldsymbol{r}, \boldsymbol{r}') = \overleftrightarrow{\boldsymbol{I}}\delta(\boldsymbol{r} - \boldsymbol{r}')$$
  • \(\overleftrightarrow{\boldsymbol{I}}\)：单位矩阵

其中\(\mathcal{L}\)作用于\(\overleftrightarrow{\boldsymbol{G}}\)的每一列.

满足上式的\(\overleftrightarrow{\boldsymbol{G}}\)称为并矢Green函数.

均匀介质的Green函数

考虑由常数\(\epsilon\)与\(\mu\)表征的无限均匀介质.

在这种介质中，Green函数最方便的推导方法是采用时谐矢势（time-harmonic vector potential）\(\boldsymbol{A}\)与标势（scalar potential）\(\phi\)，它们与电场和磁场的关系为：

$$\boldsymbol{E}(\boldsymbol{r}) = i\omega\boldsymbol{A}(\boldsymbol{r}) - \nabla\phi(\boldsymbol{r})$$ $$\boldsymbol{H}(\boldsymbol{r}) = \frac{1}{\mu_0\mu}\nabla\times\boldsymbol{A}(\boldsymbol{r})$$ $$\nabla\times\nabla\times\boldsymbol{A}(\boldsymbol{r}) = \mu_0\mu\boldsymbol{j}(\boldsymbol{r}) - i\omega\mu_0\mu\epsilon_0\epsilon[i\omega\boldsymbol{A}(\boldsymbol{r}) - \nabla\phi(\boldsymbol{r})]$$
