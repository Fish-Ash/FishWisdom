第四章 光在各向异性介质中的传播特性

  • 波片
  • 晶体的双折射

光在各向同性介质中的传播特性是光在各向异性介质中传播特性的特殊情况.

晶体是典型的光学各向异性介质.

介电张量的主轴变换

各向异性介质中，总存在三个一般情况下正交的方向，具有如下性质：

朝这三个方向的某个方向施加电场时，电位移矢量与电场矢量同方向.

反之，若沿其他方向\(\mathbf{r}\)施加电场，电位移矢量总沿另外的\(\mathbf{r}'\)方向.

这样三个方向称为各向异性介质的主轴（介电轴）.

由光的电磁理论，晶体的介电张量\(\mathbf{\epsilon}\)为一个对称矩阵.

晶体的介电张量为对称张量，经主轴变换后的介电张量为对角张量.

$$\boldsymbol{\epsilon} = \epsilon_0\left[\begin{matrix}\epsilon_{xx}&0&0\\0&\epsilon_{yy}&0\\0&0&\epsilon_{zz}\end{matrix}\right]$$

\(\epsilon_{xx},\epsilon_{yy},\epsilon_{zz}\)常称为主相对介电常数.

主轴坐标系中，有：

$$D_i = \epsilon_0\epsilon_{ii}E_i,\quad i=x,y,z$$

由Maxwell关系式：

$$n = \sqrt{\epsilon_r}$$

可相应定义主折射率：\(n_x,n_y,n_z\).

光在晶体中传播特性的解析法描述

光在晶体中的传播特性由Maxwell方程组描述.

在均匀、不导电、非磁性的各向异性介质中，若无自由电荷存在，Maxwell方程组表示为：

$$\begin{cases} \nabla\times\mathbf{H} = \frac{\partial\mathbf{D}}{\partial t}\\ \nabla\times\mathbf{E} = -\mu_0\frac{\partial\mathbf{H}}{\partial t}\\ \nabla\cdot\mathbf{B} = 0\\ \nabla\cdot\mathbf{D} = 0 \end{cases}$$

物质方程为：

$$\begin{cases} \mathbf{B} = \mu_0\mathbf{H}\\ \mathbf{D} = \boldsymbol{\epsilon}\cdot\mathbf{E} \end{cases}$$

这里只讨论单色平面光波在晶体中的传播特性，这样可以不考虑介质的色散特性.

同时，对于任意复杂的光波，因光场可以通过傅里叶变换分解为不同频率的单色平面光波叠加，因此也不失普遍性.

$$\begin{cases} \mathbf{D}\perp\mathbf{H}\\ \mathbf{D}\perp\mathbf{k}\\ \mathbf{H}\perp\mathbf{E}\\ \mathbf{H}\perp\mathbf{k} \end{cases}\Rightarrow \mathbf{H}\perp\mathbf{D},\mathbf{E},\mathbf{k} $$

故\(\mathbf{E},\mathbf{D},\mathbf{k}\)在垂直于\(\mathbf{H}\)的同一平面内.

且\(\mathbf{E}\)与\(\mathbf{D}\)通常不在同一方向上.

各向异性介质中，光的能量传播方向通常与光波法线方向不同.

一般情况下，光在晶体中的相速度和光线速度的大小和方向均不相同.

相速度：

$$\mathbf{v}_p = v_p\mathbf{k}$$
光线速度\(\mathbf{v}_r\)

单色光波能量的传播速度

$$\mathbf{v}_r = v_r\mathbf{S}$$

晶体中，有：

$$v_p = v_r\cos\alpha$$

一般情况下，对应于晶体中每一给定的波法线方向\(\mathbf{k}\)，只允许有两个特定振动方向的线偏振光传播，它们的\(\mathbf{D}\)矢量相互垂直（因而振动面相互垂直），具有不同的折射率和相速度.

光在晶体中传播特性的几何描述

折射率椭球

主轴坐标系中，晶体的电场储能密度为：

$$\omega_e = \frac{1}{2}\mathbf{E}\cdot\mathbf{D} = \frac{1}{2\epsilon_0}\left(\frac{D_1^2}{\epsilon_1} + \frac{D_2^2}{\epsilon_2} + \frac{D_3^2}{\epsilon_3}\right)$$ $$\therefore \frac{D_1^2}{\epsilon_1} + \frac{D_2^2}{\epsilon_2} + \frac{D_3^2}{\epsilon_3} = 2\epsilon_0\omega_e$$

令

$$x_1 = \frac{D_1}{\sqrt{2\epsilon_0\omega_e}},~x_2 = \frac{D_2}{\sqrt{2\epsilon_0\omega_e}},~x_3 = \frac{D_3}{\sqrt{2\epsilon_0\omega_e}}$$

则有

$$\frac{x_1^2}{\epsilon_1} + \frac{x_2^2}{\epsilon_2} + \frac{x_3^2}{\epsilon^3} = 1$$

或

$$\frac{x_1^2}{n_1^2} + \frac{x_2^2}{n_2^2} + \frac{x_3^2}{n_3^2} = 1$$

也就是说，椭球的三个轴的半轴长分别是\(n_1\)、\(n_2\)与\(n_3\).

单轴晶体折射率椭球方程为： $$\frac{x_1^2}{n_o^2} + \frac{x_2^2}{n_o^2} + \frac{x_3^2}{n_e^2} = 1$$

波片

波片

波片是一种对二垂直振动分量（光波场的两个独立振动方向）提供固定相位差的元件.

通常是从单轴晶体上按一定方式切割的、有一定厚度的平行平面薄片.

  • 全波片
  • 半波片
  • 1/4波片

当一线偏振光垂直射入波片时，在入射表面产生的o光与e光分量同相位，振幅分别为\(A_o\)与\(A_e\)

$$\mathbf{E_o} = \mathbf{A_o}\cos(\phi_0)$$ $$\mathbf{E_e} = \mathbf{A_e}\cos(\phi_0)$$

当二光穿过波片射出时，附加了一个相位延迟差，即：

$$\phi_o - \phi_e = \phi$$

故合成光矢量端点的轨迹方程为：

$$(\frac{E_o}{A_o})^2 + (\frac{E_e}{A_e})^2 - 2(\frac{E_o}{A_o})(\frac{E_e}{A_e})\cos \phi = \sin^2 \phi$$

全波片

全波片的附加相位差为：

$$\phi = \frac{2\pi}{\lambda}(n_o-n_e)d = 2m\pi\quad m = \pm1,\pm2,\cdots$$

因此：

$$\frac{E_o}{A_o} = \frac{E_e}{A_e}$$

即：线偏振光通过全波片后，其偏振状态不变.

全波片的厚度为：

$$d = |\frac{m}{n_o-n_e}|\lambda$$

半波片

半波片的附加相位差为：

$$\phi = \frac{2\pi}{\lambda}(n_o-n_e)d = (2m+1)\pi\quad m = 0,\pm1,\pm2,\cdots$$

出射光仍为线偏振光，但振动面的方位较入射光转过了\(2\theta\)角.

半波片的厚度为：

$$d = |\frac{2m+1}{n_o-n_e}|\frac{\lambda}{2}$$

\(\lambda/4\)波片

\(\lambda/4\)波片产生的相位延迟\(\delta\)与相应的波片厚度\(d\)为：

$$\delta = (2m+1)\pi/2$$ $$d = \frac{(2m+1)}{|n_o - n_e|}\frac{\lambda}{4}$$

\(\lambda/4\)波片产生\(\pi/2\)奇数倍的相位延迟，能使入射线偏振光变为椭圆偏振光.

若入射线偏振光的光矢量与波片快（慢）轴成\(\pm\frac{\pi}{4}\)，将得到圆偏振光.

相位差与光程差的关系为：

$$\Delta \phi = \frac{2\pi}{\lambda}\times \Delta L$$

一束线偏振光入射向波片时，会被分解为两个相互垂直的分量，分别沿快轴与慢轴，因此两束光在波片中传播速度不一样，从而产生光程差，进而产生相位差.

光在晶体界面上的双折射与双反射现象

当一束单色平面光从空气入射到晶体界面时，会产生两束频率相同的折射光，发生双折射现象.

当一束单色平面光从晶体内部射向晶体-空气界面上时，会产生两束频率相同的反射光，发生双反射现象.

在界面上产生的两束折射光或两束反射光都是线偏振光，它们的振动方向相互垂直.

双折射和双反射现象都是晶体中光学各向异性的结果.

光在晶体界面上的双反射和双折射特性可以用解析法和几何作图法描述.

解析法描述

假设一束单色平面光波自空气射向晶体，\(\mathbf{k}_i, \mathbf{k}_r, \mathbf{k}_t\)分别为入射光、反射光、折射光的波矢，则由光的电磁场理论可得：

$$(\mathbf{k}_r - \mathbf{k}_i)\cdot\mathbf{r} = 0$$ $$(\mathbf{k}_t - \mathbf{k}_i)\cdot\mathbf{r} = 0$$
$$\begin{cases} \mathbf{E}_i = \mathbf{E}_{i0}e^{i(\mathbf{k}_i\cdot\mathbf{r} - \omega t)}\\ \mathbf{E}_r = \mathbf{E}_{r0}e^{i(\mathbf{k}_r\cdot\mathbf{r} - \omega t)}\\ \mathbf{E}_t = \mathbf{E}_{t0}e^{i(\mathbf{k}_t\cdot\mathbf{r} - \omega t)} \end{cases}$$

[注]此处的\(\mathbf{E}_0\)实指\(\mathbf{E}_0e^{i\phi_0}\).

在晶体-空气分界面上，应用边界条件，有：

$$\mathbf{E}_{i0,\tan}e^{i(\mathbf{k}_i\cdot\mathbf{r} - \omega t)} + \mathbf{E}_{r0,\tan}e^{i(\mathbf{k}_r\cdot\mathbf{r} - \omega t)} = \mathbf{E}_{t0,\tan}e^{i(\mathbf{k}_t\cdot\mathbf{r} - \omega t)}$$

[注]\(\mathbf{E}_{\tan}\)为\(\mathbf{E}\)的切向分量，由于\(\mathbf{E}\)的方向仅由\(\mathbf{E}_0\)决定而与\(\mathbf{r}\)的方向无关，此处仍需标明分量.

由于上式对任意时刻分界面上的任意向量均成立，故：

$$\mathbf{k}_i\cdot\mathbf{r} - \omega t = \mathbf{k}_r\cdot\mathbf{r} - \omega t = \mathbf{k}_t\cdot\mathbf{r} - \omega t$$ $$\therefore\mathbf{k}_i\cdot\mathbf{r} = \mathbf{k}_r\cdot\mathbf{r} = \mathbf{k}_t\cdot\mathbf{r}$$ $$\therefore\begin{cases} (\mathbf{k}_r - \mathbf{k}_i)\cdot\mathbf{r} = 0\\ (\mathbf{k}_t - \mathbf{k}_i)\cdot\mathbf{r} = 0 \end{cases}$$

1式是反射定律的矢量形式，可表述为：反射光和入射光的波矢差与界面垂直.

2式是折射定律的矢量形式，可表述为：折射光和入射光的波矢差与界面垂直.

由两式可知，\(\mathbf{k}_i, \mathbf{k}_r, \mathbf{k}_t\)与界面法线共面，或者说：反射光与折射光的波矢均在入射面内.

Q：为什么双折射与双反射只定义一个k？

A：上述不是定义，而是假设；双折射、双反射的两个光波，都需满足上式.


Q：什么叫切向分量？

A：垂直于平面的叫法向分量，平行于平面的叫切向分量.


电磁场的边界条件：电场与磁场的切向分量连续（大小相等、方向相同）.

界面一侧的电场切向分量总和等于另一侧的电场切向分量总和.

设\(\theta_i, \theta_r, \theta_t\)分别为入射角、反射角、折射角，则：

$$k_i\sin\theta_i = k_r\sin\theta_r = k_t\sin\theta_t$$
$$\because \mathbf{k}_i\cdot\mathbf{r} = \mathbf{k}_r\cdot\mathbf{r} = \mathbf{k}_t\cdot\mathbf{r}$$ $$\therefore |k_i||r|\cos(\frac{\pi}{2} - \theta_i) = |k_r||r|\cos(\frac{\pi}{2} - \theta_r) = |k_t||r|\cos(\frac{\pi}{2} - \theta_t)$$ $$\therefore k_i\sin\theta_i = k_r\sin\theta_r = k_t\sin\theta_t$$

亦即：

$$n_i\sin\theta_i = n_r\sin\theta_r$$ $$n_i\sin\theta_i = n_t\sin\theta_t$$
$$\because k = \frac{\omega n}{c}$$

1式为光在晶体界面上的反射定律.

2式为光在晶体界面上的折射定律.

从形式上看，光在晶体界面上的反射定律和折射定律与光在各向同性介质界面上的反射定律和折射定律相同.

但是，由于晶体中的光学各向异性，晶体内存在两个特许的线偏振光（本征模式）.

什么叫“特许的偏振光（本征模式）”？

所以，相应于一个入射光，在晶体界面内可能产生两个反射光或两个折射光，

当一束单色平面光从空气垂直入射到方解石单轴警惕上时，晶体中将产生两束折射光，分别为o光和e光，根据折射定律，两折射光的折射角\(\theta_{to} = \theta_{te} = 0\)，即晶体中二折射光的波矢方向相同、均垂直入射界面.

但是，由于单轴晶体中o光波矢方向与光线方向相同，e光波矢方向与光线方向离散，所以在晶体内可观测到两条离散方向传播的光线，分别为o光和e光的能流方向.
