单色波

一般单色波

任意满足适当数学条件的复色矢量场，都可以表示为单色矢量场的傅里叶积分或傅里叶级数.

确定频率的电磁波，电磁场对时间的依赖关系为\(e^{i\omega t}\)，因此单色电磁波的基本表达式为：

$$\boldsymbol{E}(\boldsymbol{r}, t) = \tilde{\boldsymbol{E}}(\boldsymbol{r})e^{-i\omega t},\quad\boldsymbol{H}(\boldsymbol{r}, t) = \tilde{\boldsymbol{H}}(\boldsymbol{r})e^{-i\omega t}$$

因此：

$$\frac{\partial}{\partial t}\boldsymbol{E} = -i\omega\boldsymbol{E},\quad\frac{\partial}{\partial t}\boldsymbol{H} = -i\omega\boldsymbol{H}$$

单色电磁波的基本方程

[设]对于各向同性的线性非磁性光学介质（通常为非导体），\(\rho = 0, \boldsymbol{j} = 0, \boldsymbol{D} = \epsilon\boldsymbol{E}, \boldsymbol{B} = \mu\boldsymbol{H}\).

因此，单色波下Maxwell方程组可简化为不含时间因子的形式，即：

$$\nabla\times\boldsymbol{E} = i\omega\mu\boldsymbol{H}$$
$$\begin{align} \nabla\times\boldsymbol{E} &= -\frac{\partial\boldsymbol{B}}{\partial t}\\ &= -\mu\frac{\partial\boldsymbol{H}}{\partial t}\\ \end{align}$$ $$\because \frac{\partial}{\partial t}\boldsymbol{H} = -i\omega\boldsymbol{H}$$ $$\therefore \nabla\times\boldsymbol{E} = i\omega\mu\boldsymbol{H}$$
$$\nabla\times\boldsymbol{H} = -i\omega\epsilon\boldsymbol{E}$$
$$\begin{align} \nabla\times\boldsymbol{H} &= \frac{\partial\boldsymbol{D}}{\partial t}\\ &= \epsilon\frac{\partial\boldsymbol{E}}{\partial t}\\ \end{align}$$ $$\because \frac{\partial}{\partial t}\boldsymbol{E} = -i\omega\boldsymbol{E}$$ $$\therefore \nabla\times\boldsymbol{H} = -i\omega\epsilon\boldsymbol{E}$$
$$\nabla\cdot\boldsymbol{D} = 0$$ $$\nabla\cdot\boldsymbol{B} = 0$$

这组方程只有前两式是独立的，后两式可以由前两式取散度运算导出.

单色光波的分量形式

利用单色电磁波的基本方程，直角坐标系下，可以写出如下单色光波的分量形式：

$$\nabla\times\boldsymbol{E} = i\omega\mu\boldsymbol{H}$$ $$\nabla\times\boldsymbol{H} = -i\omega\epsilon\boldsymbol{E}$$
直角坐标系下 $$\frac{\partial}{\partial y}E_z - \frac{\partial}{\partial z}E_y = i\omega\mu H_x$$ $$\frac{\partial}{\partial z}E_x - \frac{\partial}{\partial x}E_z = i\omega\mu H_y$$ $$\frac{\partial}{\partial x}E_y - \frac{\partial}{\partial y}E_x = i\omega\mu H_z$$ $$\frac{\partial}{\partial y}H_z - \frac{\partial}{\partial z}H_y = -i\omega\epsilon E_x$$ $$\frac{\partial}{\partial z}H_x - \frac{\partial}{\partial x}H_z = -i\omega\epsilon E_y$$ $$\frac{\partial}{\partial x}H_y - \frac{\partial}{\partial y}H_x = -i\omega\epsilon E_z$$
柱坐标系下
$$\frac{1}{r}\frac{\partial}{\partial\phi}E_z - \frac{\partial}{\partial z}E_\phi = i\omega\mu H_r$$ $$\frac{\partial}{\partial z}E_r - \frac{\partial}{\partial r}E_z = i\omega\mu H_\phi$$ $$\frac{\partial}{\partial r}E_\phi - \frac{1}{r}\frac{\partial}{\partial\phi}E_r = i\omega\mu H_z$$
$$\nabla\times\boldsymbol{E} = \left\lvert\begin{matrix}\hat{\boldsymbol{r}}&\hat{\boldsymbol{\phi}}&\hat{\boldsymbol{z}}\\\frac{\partial}{\partial r}&\frac{1}{r}\frac{\partial}{\partial \phi}&\frac{\partial}{\partial z}\\E_r&E_\phi&E_z\end{matrix}\right\rvert$$
$$\frac{1}{r}\frac{\partial}{\partial\phi}H_z - \frac{\partial}{\partial z}H_\phi = -i\omega\epsilon E_r$$ $$\frac{\partial}{\partial z}H_r - \frac{\partial}{\partial r}H_z = -i\omega\epsilon E_\phi$$ $$\frac{\partial}{\partial r}H_\phi - \frac{1}{r}\frac{\partial}{\partial\phi}H_r = -i\omega\epsilon E_z$$

单色球面波

单色球面波是最简单的简谐球面光波.

当然还有非简谐的光波，但是单色且简谐通常是矛盾的.

发散球面波

$$E = \frac{E_0}{|\boldsymbol{r}|}\cos(\omega t - \boldsymbol{k}\cdot\boldsymbol{r} + \phi_0) = \frac{E_0}{r}e^{-i(\omega t - \boldsymbol{k}\cdot\boldsymbol{r})}$$
  • \(E_0\)：距点源单位距离处的振幅值
  • \(|\boldsymbol{r}|\)：观察点到点源的距离

等相面是\(|\boldsymbol{r}| \in \mathbb{C}\)的球面.

复振幅为：

$$\tilde{E}(\boldsymbol{r}) = \frac{E_0}{|\boldsymbol{r}|}e^{i\boldsymbol{k}\cdot\boldsymbol{r}}$$ 光波在某特定平面上产生的复振幅分布的数学描述

点光源\(S(x_0, y_0, 0)\)位于\(x_0y_0\)平面内，考察与其相距\(z>0\)的\(xy\)平面上的光场分布.

$$|\boldsymbol{r}| = \sqrt{(x-x_0)^2 + (y-y_0)^2 + z^2}$$

[近似]当xy平面上只考虑一个对S张角不大的范围（傍轴近似）：

$$\frac{(x-x_0)^2 + (y-y_0)^2}{z^2} \ll 1$$

麦克劳林展开（或二项式展开）后，约去高阶项，近似为：

$$\begin{align} |\boldsymbol{r}| &= z\left[\frac{(x-x_0)^2 + (y-y_0)^2}{z^2} + 1\right]^{1/2}\\ &\approx z\left[1 + \frac{(x-x_0)^2 + (y-y_0)^2}{2z^2}\right]\\ &\approx z + \frac{(x-x_0)^2 + (y-y_0)^2}{2z} \end{align}$$

单色平面波

$$\boldsymbol{E} = \boldsymbol{A}e^{-i(\omega t - \boldsymbol{k}\cdot\boldsymbol{r})}$$

一些结论

$$\nabla\times\boldsymbol{E} = i\boldsymbol{k}\times\boldsymbol{E}$$
$$\begin{align} \nabla\times\boldsymbol{E} &= \left\lvert\begin{matrix}\hat{\boldsymbol{x}}&\hat{\boldsymbol{y}}&\hat{\boldsymbol{z}}\\\frac{\partial}{\partial x}&\frac{\partial}{\partial y}&\frac{\partial}{\partial z}\\E_x&E_y&E_z\end{matrix}\right\rvert\\ &= \left(\frac{\partial E_z}{\partial y} - \frac{\partial E_y}{\partial z}\right)\hat{\boldsymbol{x}} + \left(\frac{\partial E_x}{\partial z} - \frac{\partial E_z}{\partial x}\right)\hat{\boldsymbol{y}} + \left(\frac{\partial E_y}{\partial x} - \frac{\partial E_x}{\partial y}\right)\hat{\boldsymbol{z}} \end{align}$$ $$\because\boldsymbol{E} = \boldsymbol{A}e^{-i[\omega t - (k_xx + k_yy + k_zz)]}$$ $$\therefore\frac{\partial\boldsymbol{E}}{\partial r} = ik_r\boldsymbol{A}e^{-i[\omega t - (k_xx + k_yy + k_zz)]} = ik_r\boldsymbol{E},\quad r=x,y,z$$ $$\begin{align}\therefore \nabla\times\boldsymbol{E} &= i(k_yE_z - k_zE_y)\hat{\boldsymbol{x}} + i(k_zE_x - k_xE_z)\hat{\boldsymbol{y}} + i(k_yE_x - k_xE_y)\hat{\boldsymbol{z}}\\ &= i\left\lvert\begin{matrix}\hat{\boldsymbol{x}}&\hat{\boldsymbol{y}}&\hat{\boldsymbol{z}}\\k_x&k_y&k_z\\E_x&E_y&E_z\end{matrix}\right\rvert\\ &= i\boldsymbol{k}\times\boldsymbol{E} \end{align}$$
