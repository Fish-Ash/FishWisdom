光波的叠加

波的叠加原理

两个或多个波在相遇点产生的合振动是各个波单独在该点产生的振动的矢量和.

波的叠加原理是波动光学的基本原理.

两个频率相同、振动方向相同的单色光波叠加

设两个频率相同、振动方向相同的单色光波分别发自光源S1与S2.

它们在空间某点P相遇，P到S1与S2的距离分别为\(r_1\)与\(r_2\).

点光源\(\Rightarrow\)球面波：

$$E = \frac{A_1}{r}\cos(\omega t - kr)$$

频率相同：

$$\omega_1 = \omega_2 = \omega$$ $$k_1 = k_2 = \frac{\omega}{cn}$$

振动方向相同\(\Rightarrow\)可线性叠加

$$E_1 = E_{01}\cos(\omega t - kr_1)$$ $$E_2 = E_{02}\cos(\omega t - kr_2)$$

其中，\(E_{01}\)和\(E_{02}\)分别为两个光波在P点处的振幅.

令

$$\alpha_1 = kr_1$$ $$\alpha_2 = kr_2$$ $$\begin{align} \therefore E &= E_1 + E_2\\ &= E_{01}\cos(\omega t - \alpha_1) + E_{02}\cos(\omega t - \alpha_2)\\ &= E_0\cos(\omega t - \alpha) \end{align}$$

其中：

$$E_0^2 = E_{01}^2 + E_{02}^2 + 2E_{01}E_{02}\cos(\alpha_1 - \alpha_2)$$ $$\tan \alpha = \frac{E_{01}\sin\alpha_1 + E_{02}\sin\alpha_2}{E_{01}\cos(\alpha_1) + E_{02}\cos(\alpha_2)}$$

可见，P点的合振动也是一个简谐运动，其振动频率于振动方向与两单色波相同.

驻波

两个频率相同，振动方向相同而传播方向相反的单色光波叠加形成驻波.

e.g.垂直入射到两种介质分界面的单色光波和反射波的叠加.

设界面反射比很高，即入射波与出射波振幅相等.

入射波：

$$E_1 = E_0\cos(\omega t - kr + \phi_{1})$$

出射波：

$$E_2 = E_0\cos(\omega t + kr + \phi_{2})$$

由和差化积公式，有：

$$\begin{align} E &= E_1 + E_2\\ &= 2E_0\cos\left(\omega t + \frac{\phi_1 + \phi_2}{2}\right)\cos\left(-kr + \frac{\phi_1 - \phi_2}{2}\right)\\ &= 2E_0\cos\left(kr + \frac{\phi_2 - \phi_1}{2}\right)\cos\left(\omega t + \frac{\phi_1 + \phi_2}{2}\right) \end{align}$$

同一位置\(r\)下，驻波振幅能达到的最大值为：

$$|E|_r = \left|2E_0\cos\left(kr + \frac{\phi_2 - \phi_1}{2}\right)\right|$$

时间\(t\)一定时，驻波振幅的最大值为：

$$|E|_t = \left|2E_0\cos\left(\omega t + \frac{\phi_1 + \phi_2}{2}\right)\right|$$

不同的\(r\)处有不同的振幅，但极大值与极小值的位置不随时间改变.

波腹

振幅最大的位置.

$$kr + \frac{\Delta\phi}{2} = n\pi,~n = 1,2,\cdots$$ $$|E|_{\max} = 2E_0$$
波节

振幅最小的位置.

$$kr + \frac{\Delta\phi}{2} = \left(n - \frac{1}{2}\right)\pi,~n = 1,2,\cdots$$ $$|E|_{\min} = 0$$

驻波是干涉相长与干涉相消叠加的结果.

相邻波腹或波节间的距离为：

$$\Delta r = \lambda/2$$

相邻波腹与波节间的距离为：

$$\Delta r = \lambda/4$$

若参与合成驻波的两个波振幅不相等，除合成驻波外还会产生一个行波，因此波节处振幅不为0，且由于行波的存在，通常伴随能量的传播.

两个不同频率的单色波叠加

两个振幅相同、振动方向相同、传播方向相同、频率相近的单色波的叠加，将产生光学上有意义的拍现象.

光学拍

$$E_1 = E_0\cos(\omega_1 t - k_1r)$$ $$E_2 = E_0\cos(\omega_2 t - k_2r)$$

由和差化积公式：

$$\begin{align} E &= E_1 + E_2\\ &= E_0\cos(\omega_1 t - k_1r) + E_0\cos(\omega_2 t - k_2r)\\ &= 2E_0\cos\left(\omega_mt - k_mr\right)\cos\left(\bar{\omega}t - \bar{k}r\right) \end{align}$$

其中

$$\omega_m = (\omega_1 - \omega_2)/2$$ $$k_m = (k_1 - k_2)/2$$ $$\bar{\omega} = (\omega_1 + \omega_2)/2$$ $$\bar{k} = (k_1 + k_2)/2$$
