光波的叠加

波的叠加原理

两个或多个波在相遇点产生的合振动是各个波单独在该点产生的振动的矢量和.

驻波

两个频率相同，振动方向相同而传播方向相反的单色光波叠加形成驻波.

e.g.垂直入射到两种介质分界面的单色光波和反射波的叠加.

设界面反射比很高，即入射波与出射波振幅相等.

入射波：

$$E_1 = E_0\cos(\omega t - kr + \phi_{1})$$

出射波：

$$E_2 = E_0\cos(\omega t + kr + \phi_{2})$$

由和差化积公式，有：

$$\begin{align} E &= E_1 + E_2\\ &= 2E_0\cos\left(\omega t + \frac{\phi_1 + \phi_2}{2}\right)\cos\left(-kr + \frac{\phi_1 - \phi_2}{2}\right)\\ &= 2E_0\cos\left(kr + \frac{\phi_2 - \phi_1}{2}\right)\cos\left(\omega t + \frac{\phi_1 + \phi_2}{2}\right) \end{align}$$ $$\therefore |E| = \left|2E_0\cos\left(kr + \frac{\phi_2 - \phi_1}{2}\right)\right|$$
波腹

振幅最大的位置.

$$kr + \frac{\Delta\phi}{2} = n\pi,~n = 1,2,\cdots$$ $$|E|_{\max} = 2E_0$$
波节

振幅最小的位置.

$$kr + \frac{\Delta\phi}{2} = \left(n - \frac{1}{2}\right)\pi,~n = 1,2,\cdots$$ $$|E|_{\min} = 0$$

驻波是干涉相长与干涉相消叠加的结果.
