波动方程的解

球面波、平面波都是波动方程的基本解.

由波动方程的线性性质，任何复杂的波都能用球面波或平面波的线性组合表示.

球面波、平面波并非波动方程唯一的基本解.

球面波解与平面波解具有完备性.

单色电磁波

单色平面电磁波

表达式

$$\boldsymbol{E} = \boldsymbol{E_0}\exp[i\omega(t - \frac{r}{v})] = \boldsymbol{E_0}\exp[i(\omega t + \alpha)]$$ 其中，\(\alpha\)可以看作是\(\boldsymbol{E}\)的初相。

[注]光波中包含电场矢量\(\boldsymbol{E}\)与磁场矢量\(\boldsymbol{H}\)，从波的传播特性来看，其具有相同的地位；但从光与介质的相互作用来看，磁场的作用远比电场弱，甚至不起作用.因此，在讨论光的波动特性时，常常只考虑电场矢量\(\boldsymbol{E}\).通常称\(\boldsymbol{E}\)为光矢量，\(\boldsymbol{E}\)的振动称为光振动.

三角函数表示
$$\boldsymbol{E} = \boldsymbol{E}_0\cos(\omega t - kr) = \boldsymbol{E}_0\cos[\omega(t - \frac{r}{v})] = \boldsymbol{E}_0\cos[2\pi(\frac{t}{T} - \frac{r}{\lambda})]$$
$$ \begin{align} \boldsymbol{E} &= \boldsymbol{E}_0\cos(\omega t - kr)\\ &= \boldsymbol{E}_0\cos[\omega(t - \frac{k}{w}r)]\\ &\because k = \omega/v\\ \therefore \boldsymbol{E} &= \boldsymbol{E}_0\cos[\omega(t-\frac{r}{v})]\\\\ \boldsymbol{E} &= \boldsymbol{E}_0\cos(\omega t - kr)\\ &= \boldsymbol{E}_0\cos[2\pi(\frac{\omega}{2\pi}t - \frac{k}{2\pi}r)]\\ &\because k=2\pi/\lambda,~\omega = 2\pi/T\\ \therefore \boldsymbol{E} &= \boldsymbol{E}_0\cos[2\pi(\frac{t}{T} - \frac{r}{\lambda})] \end{align} $$

多个平面波的线性叠加不是平面波.

复数形式

复数的虚部无物理意义，为了便于计算，引入单色平面波的复数形式.

$$\boldsymbol{E} = \boldsymbol{E}_0 e^{-i(\omega t - kz)}$$

由欧拉方程

$$\begin{align} \boldsymbol{E} &= \boldsymbol{E}_0 e^{-i(\omega t - kz)}\\ &= \boldsymbol{E}_0 [\cos(\omega t - kz) - i\sin(\omega t - kz)] \end{align}$$

由于虚部无物理意义，故

$$\boldsymbol{E} = \boldsymbol{E}_0 \cos(\omega t - kz)$$
时间相位因子 $$e^{-i\omega t}$$ 空间相位因子 $$e^{i\boldsymbol{k}\cdot\boldsymbol{r}}$$
复振幅

复振幅反映了光场振动的振幅和相位随空间的变化.

$$\boldsymbol{E} = \boldsymbol{E}_0 e^{-i(\omega t - \boldsymbol{k}\cdot\boldsymbol{r} + \phi_0)} = \boldsymbol{E}_0 e^{i(\boldsymbol{k}\cdot\boldsymbol{r} - \phi_0)}e^{-i\omega t}$$

\(\tilde{E} = \boldsymbol{E}_0 e^{i(\boldsymbol{k}\cdot\boldsymbol{r} - \phi_0)}\)称为复振幅.

沿任意波矢量\(\boldsymbol{k}\)方向传播的平面简谐波

实际光电场： $$\boldsymbol{E} = \boldsymbol{E}_0\cos(\omega t - \boldsymbol{k}\cdot \boldsymbol{r} + \phi_0)$$

为便于计算，常取复数形式：

$$\boldsymbol{E}' = \boldsymbol{E}_0' e^{-i(\omega t - \boldsymbol{k}\cdot \boldsymbol{r} + \phi_0)} = \boldsymbol{E}_0' e^{-i\phi}$$

复振幅为

$$\tilde{\boldsymbol{E}} =\boldsymbol{E}_0' e^{i(\boldsymbol{k}\cdot \boldsymbol{r} - \phi_0)}$$
描述方式 \(\boldsymbol{E}_0'\)
$$\boldsymbol{E} = \text{Re}\{\boldsymbol{E}'\}$$ $$\boldsymbol{E}_0' = \boldsymbol{E}_0$$
$$\boldsymbol{E} = \boldsymbol{E'} + c.c.$$ $$\boldsymbol{E}_0' = \frac{1}{2}\boldsymbol{E}_0$$

平面电磁波的性质

平面电磁波是横波

$$\boldsymbol{k}\boldsymbol{E} = 0$$ $$\boldsymbol{k}\boldsymbol{B} = 0$$

电矢量与磁矢量方向均垂直于波传播方向，平面电磁波为横波

\(\boldsymbol{E}, \boldsymbol{B}, \boldsymbol{k}_0\)互成右手螺旋系

$$\boldsymbol{B} = \frac{1}{v}(\boldsymbol{k}_0\times\boldsymbol{E})$$

\(\boldsymbol{E}, \boldsymbol{B}\)同相位

单色平面电磁波的一般方程

三角函数形式 $$\boldsymbol{E} = \boldsymbol{E}_0\cos(\omega t - \boldsymbol{k}\boldsymbol{r} + \phi_0)$$ 复数形式 $$\boldsymbol{E} = \boldsymbol{E}_0e^{-i(\omega t - \boldsymbol{k}\boldsymbol{r}+ + \phi_0)}$$
  • 振动方向：\(\boldsymbol{E}_0\)的方向
  • 传播方向：\(\boldsymbol{k}_0\)的方向
  • 相位速度：\(v = \frac{\omega}{k}\)，单位为\(m/s\)，方向沿\(\boldsymbol{k}_0\)
  • 振幅：\(E_0\)，单位为\(V/m\)
  • 频率：\(\nu = \omega/2\pi\)，单位为\(Hz\)
  • 波长：\(\lambda = 2\pi/k\)，单位为\(m\)

[注]复数形式是为了简便计算而取的，虚部无物理意义.此处取\(\boldsymbol{E} = \boldsymbol{E}_0e^{-i(\omega t - kr + \phi_0)}\)与\(\boldsymbol{E} = \boldsymbol{E}_0e^{i(\omega t - kr + \phi_0)}\)都是可行的，取其实部均为\(\boldsymbol{E}_0\cos(\omega t - kr + \phi_0)\)，约定取\(-i\)形式.

球面波

球面波

将一个点光源放置于各向同性介质中，从点光源发出的光波以相同的速度沿径向传播，某一时刻电磁波所到达的各点将构成一个以点光源为中心的球面，其等相面也为球面，这种光波称为球面波.

光波的速度

相速度

光波等相位面的传播速度.

群速度（包络速度）

等振幅面的传播速度.

单色光波的速度

单色光波的能量传播速度（能流速度） $$v = \omega/k = c/n$$ 单色光波的相速度

单色光波的相速度等于单色光波的能量传播速度.

复色光波的速度

简单起见，以二色光波为例：

$$E = E_{01}\cos(\omega_1t - k_1z) + E_{02}\cos(\omega_2t - k_2z)$$

设\(E_{0} = E_{01} = E_{02}\)，由和差化积公式

$$\begin{align} E &= E_0[\cos(\omega_1t - k_1z) + \cos(\omega_2t - k_2z)]\\ &= 2E_0\cos\frac{\omega_1t-k_1z + \omega_2t - k_2z}{2}\cos\frac{\omega_1t-k_1z - \omega_2t + k_2z}{2}\\ &= 2E_0\cos(\frac{\omega_1 + \omega_2}{2}t - \frac{k_1+k_2}{2}z)\cos(\frac{\omega_1 - \omega_2}{2}t - \frac{k_1 - k_2}{2}z)\\ &= 2E_0\cos(\omega_mt - k_mz)\cos(\bar{\omega}t - \bar{k}z) \end{align}$$ $$\begin{align} &\omega_m = \frac{1}{2}(\omega_1 - \omega_2) = \frac{1}{2}\Delta\omega\\\\ &k_m = \frac{1}{2}(k_1 - k_2) = \frac{1}{2}\Delta k\\\\ &\bar{\omega} = \frac{1}{2}(\omega_1 + \omega_2)\\\\ &\bar{k} = \frac{1}{2}(k_1 + k_2) \end{align}$$ 复色光波的相速度 $$v = \frac{\bar{\omega}}{\bar{k}}$$ 复色光波的群速度 $$v_g = \frac{\omega_m}{k_m} = \frac{\Delta \omega}{\Delta k}$$

当\(\Delta \omega\)很小时

$$v_g = \frac{\mathrm{d}\omega}{\mathrm{d}k} = = v(1 + \frac{\lambda}{n}\frac{\mathrm{d}n}{\mathrm{d}\lambda})$$
$$\because \omega = kv$$ $$v_g = \frac{\mathrm{d}\omega}{\mathrm{d}k} = \frac{\mathrm{d}(kv)}{\mathrm{d}k} = \frac{k\mathrm{d}v + v\mathrm{d}k}{\mathrm{d}k} = v + k\frac{\mathrm{d}v}{\mathrm{d}k}$$ $$\because v = c/n, k = 2\pi/\lambda$$ $$\therefore \mathrm{d}v = -\frac{c}{n^2}\mathrm{d}n, \mathrm{d}k = -\frac{2\pi}{\lambda^2}\mathrm{d}\lambda$$ $$v_g = v + \frac{2\pi}{\lambda}\frac{-\frac{c}{n^2}\mathrm{d}n}{-\frac{2\pi}{\lambda^2}\mathrm{d}\lambda} = v + v\frac{\lambda}{n}\frac{\mathrm{d}n}{\mathrm{d}\lambda} = v(1 + \frac{\lambda}{n}\frac{\mathrm{d}n}{\mathrm{d}\lambda})$$

在折射率\(n\)随波长\(\lambda\)变化的色散介质中，复色光波的相速度不等于群速度：

  • 正常色散介质（\(\mathrm{d}n/\mathrm{d}\lambda \lt 0\)）：\(v \gt v_g\)
  • 反常色散介质（\(\mathrm{d}n/\mathrm{d}\lambda \gt 0\)）：\(v \lt v_g\)

无色散介质（\(\mathrm{d}n/\mathrm{d}\lambda = 0\)）中，复色光波的群速度等于相速度，实际上只有真空才属于这种情况.
