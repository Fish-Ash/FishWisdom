光子

光的量子学说（光子说）认为，光是一种以光速\(c\)运动的光子流.

光子的粒子属性

光子的能量\(\epsilon\) $$\epsilon = h\nu$$
  • \(h = 6.626\times 10^{-34}\mathrm{J}\cdot \mathrm{s}\)：普朗克常数
  • \(\nu\)：光波频率

    • 光的能量就是所有光子的能量的总和.

光子的运动质量\(m\) $$m = \frac{\epsilon}{c^2} = \frac{h\nu}{c^2}$$

光子的静止质量为\(0\).

光子的动量\(\boldsymbol{P}\)

光子运动方向即平面光波传播方向.

$$\boldsymbol{P} = mc\boldsymbol{k}_0 = \hbar \boldsymbol{k}$$
$$\boldsymbol{P} = mc\boldsymbol{k}_0$$ $$\because m = \frac{h\nu}{c^2}$$ $$\boldsymbol{P} = \frac{h\nu}{c}\boldsymbol{k}_0$$ $$\because \begin{cases} \nu = \frac{1}{T}\\ c = \frac{\lambda}{T} \end{cases}$$ $$\begin{align} \boldsymbol{P} &= \frac{h}{\lambda}\boldsymbol{k}_0\\ &= \frac{h}{2\pi}\frac{2\pi}{\lambda}\boldsymbol{k}_0\\ &= \hbar\boldsymbol{k} \end{align}$$
  • \(\hbar = \frac{h}{2\pi}\)：约化普朗克常数
  • \(\boldsymbol{k}\)为波矢量
光子的偏振

光子具有两种可能的独立偏振状态，对应于光波场的两个独立偏振方向。

光子属于玻色子，处于同一状态的光子数目是没有限制的。

粒子属性 表达公式 波动属性
能量 $$\epsilon = h \nu$$ 频率
动量 $$\boldsymbol{P} = \hbar \boldsymbol{k}$$ 波矢

量子电动力学从理论上将光的电磁（波动）理论和光子（微粒）理论在电磁场量子化描述的基础上统一起来，在理论上阐明了光的波粒二象性。
