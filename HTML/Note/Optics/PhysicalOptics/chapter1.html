光的电磁理论基础

光波电磁场的波动方程 $$\begin{cases} \nabla^2\boldsymbol{E} - \frac{1}{v^2}\frac{\partial^2 \boldsymbol{E}}{\partial t^2} = 0\\ \nabla^2\boldsymbol{H} - \frac{1}{v^2}\frac{\partial^2 \boldsymbol{H}}{\partial t^2} = 0 \end{cases}$$
等相面（等相位面，波面）

某一时刻相位相同的点的空间位置.

等相面的法线方向即为波的传播方向.

相邻等相面间的相位差为\(2\pi\).

波矢量\(\boldsymbol{k}\) $$\boldsymbol{k} = k\hat{\boldsymbol{k}}$$

\(\hat{\boldsymbol{k}}\)为单位矢量，沿波的传播方向.

\(k = 2\pi/\lambda = \sqrt{k_x^2 + k_y^2 + k_z^2}\)为空间角频率或波数，表示光在单位长度上产生的相位变化.

\(k_r = 0 \Leftrightarrow\)沿\(r\)方向相位不发生改变.

[推论]

$$\boldsymbol{k} = n\boldsymbol{k}_0$$ $$k = \frac{2\pi}{\lambda} \Rightarrow \lambda = \frac{2\pi}{k}$$
基本公式 $$c = 1/\sqrt{\mu_0\epsilon_0}\approx2.9979\times 10^8m/s$$ $$n = c/v$$ $$\mu_r = \mu/\mu_0$$ $$\epsilon_r = \epsilon/\epsilon_0$$ $$\omega = 2\pi\nu = 2\pi/T$$ $$\lambda = vT$$ $$f = \frac{1}{\lambda}$$ 衍生公式 $$\nu = 1/T$$
$$n = \frac{\sqrt{\mu\epsilon}}{\sqrt{\mu_0\epsilon_0}} = \sqrt{\mu_r\epsilon_r}$$
$$n = \frac{c}{v} = \frac{\sqrt{\mu\epsilon}}{\sqrt{\mu_0\epsilon_0}} = \sqrt{\mu_r\epsilon_r}$$
$$k = \frac{2\pi}{\lambda} = \frac{2\pi}{vT} = \frac{2\pi\nu}{v} = \frac{\omega}{v}$$
$$\lambda = \lambda_0/n$$
$$\lambda = vT = cT/n = \lambda_0/n$$
$$f = \frac{k}{2\pi}$$
$$f = \frac{1}{\lambda}$$ $$f = \frac{k}{2\pi}$$
