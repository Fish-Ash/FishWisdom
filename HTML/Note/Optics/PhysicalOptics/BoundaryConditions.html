电磁场的边界条件

在利用Maxwell方程组解决有限空间的电磁场问题，或涉及两种及两种以上介质内的电磁场问题时，除了考虑物质方程外，还须考虑介电常数不连续处的边界条件.

由于物理量在界面上发生跃变，因此微分形式的Maxwell方程不再适用，须利用Maxwell方程组的积分形式.

电磁场的连续条件

在没有传导电流和自由电荷的介质中，磁感强度\(\boldsymbol{B}\)与电位移矢量\(\boldsymbol{D}\)的法向分量在界面上连续；电场强度\(\boldsymbol{E}\)和磁场强度\(\boldsymbol{H}\)的切向分量在界面上连续.

$$\begin{cases} B_{1n} = B_{2n}\\ D_{1n} = D_{2n}\\ H_{1t} = H_{2t}\\ E_{1t} = E_{2t} \end{cases}$$

对于各向同性介质，\(D_{1n} = D_{2n}\)也可写作\(n_1^2E_{1n} = n_2^2E_{2n}\).

证明过程见《光波导理论基础》Page2，需一定的电磁学基础.

其他形式的边界条件

$$\boldsymbol{n}\times(\boldsymbol{E}_2 - \boldsymbol{E}_1) = 0$$ $$\boldsymbol{n}\times(\boldsymbol{H}_2 - \boldsymbol{H}_1) = \boldsymbol{J}_S$$
  • \(\boldsymbol{J}_s\)：面电流密度
$$\boldsymbol{n}\cdot(\boldsymbol{D}_2 - \boldsymbol{D}_1) = \sigma_s$$ $$\boldsymbol{n}\cdot(\boldsymbol{B}_2 - \boldsymbol{B}_1) = 0$$
  • \(\sigma_S\)：电荷面密度

对于非导电介质，有：

$$\sigma_S = 0,\quad J_S = 0$$

四个电磁场矢量的边界条件可以简化为：

$$\boldsymbol{n}\times(\boldsymbol{E}_2 - \boldsymbol{E}_1) = 0$$ $$\boldsymbol{n}\times(\boldsymbol{H}_2 - \boldsymbol{H}_1) = \boldsymbol{J}_S$$ $$\boldsymbol{n}\cdot(\boldsymbol{D}_2 - \boldsymbol{D}_1) = \sigma_s$$ $$\boldsymbol{n}\cdot(\boldsymbol{B}_2 - \boldsymbol{B}_1) = 0$$
