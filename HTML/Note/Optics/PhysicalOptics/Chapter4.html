第四章 光在各向异性介质中的传播特性

  • 波片

光在各向同性介质中的传播特性是光在各向异性介质中传播特性的特殊情况.

晶体是典型的光学各向异性介质.

各向异性介质中：

$$\mathbf{D} = \epsilon_0\boldsymbol{\epsilon}_r\mathbf{E}$$

介电张量\(\boldsymbol{\epsilon} = \epsilon_0\boldsymbol{\epsilon}_r\)为二阶张量，\(\epsilon_0\)为标量.

由光的电磁理论，晶体的介电张量\(\mathbf{\epsilon}\)为一个对称矩阵.

晶体的介电张量为对称张量，经主轴变换后的介电张量为对角张量.

$$\epsilon_0\left[\begin{matrix}\epsilon_{11}&0&0\\0&\epsilon_{22}&0\\0&0&\epsilon_{33}\end{matrix}\right]$$

\(\epsilon_{11},\epsilon_{22},\epsilon_{33}\)常表示为\(\epsilon_1,\epsilon_2,\epsilon_3\)，称为主相对介电常数.

由Maxwell关系式：

$$n = \sqrt{\epsilon_r}$$

可相应定义主折射率：\(n_1,n_2,n_3\).

光在晶体中传播特性的解析法描述

光在晶体中的传播特性由Maxwell方程组描述.

在均匀、不导电、非磁性的各向异性介质中，若无自由电荷存在，Maxwell方程组表示为：

$$\begin{cases} \nabla\times\mathbf{H} = \frac{\partial\mathbf{D}}{\partial t}\\ \nabla\times\mathbf{E} = -\mu_0\frac{\partial\mathbf{H}}{\partial t}\\ \nabla\cdot\mathbf{B} = 0\\ \nabla\cdot\mathbf{D} = 0 \end{cases}$$

物质方程为：

$$\begin{cases} \mathbf{B} = \mu_0\mathbf{H}\\ \mathbf{D} = \boldsymbol{\epsilon}\cdot\mathbf{E} \end{cases}$$

这里只讨论单色平面光波在晶体中的传播特性，这样可以不考虑介质的色散特性.

同时，对于任意复杂的光波，因光场可以通过傅里叶变换分解为不同频率的单色平面光波叠加，因此也不失普遍性.

$$\begin{cases} \mathbf{D}\perp\mathbf{H}\\ \mathbf{D}\perp\mathbf{k}\\ \mathbf{H}\perp\mathbf{E}\\ \mathbf{H}\perp\mathbf{k} \end{cases}\Rightarrow \mathbf{H}\perp\mathbf{D},\mathbf{E},\mathbf{k} $$

故\(\mathbf{E},\mathbf{D},\mathbf{k}\)在垂直于\(\mathbf{H}\)的同一平面内.

且\(\mathbf{E}\)与\(\mathbf{D}\)通常不在同一方向上.

各向异性介质中，光的能量传播方向通常与光波法线方向不同.

一般情况下，光在晶体中的相速度和光线速度的大小和方向均不相同.

相速度：

$$\mathbf{v}_p = v_p\mathbf{k}$$
光线速度\(\mathbf{v}_r\)

单色光波能量的传播速度

$$\mathbf{v}_r = v_r\mathbf{S}$$

晶体中，有：

$$v_p = v_r\cos\alpha$$

一般情况下，对应于晶体中每一给定的波法线方向\(\mathbf{k}\)，只允许有两个特定振动方向的线偏振光传播，它们的\(\mathbf{D}\)矢量相互垂直（因而振动面相互垂直），具有不同的折射率和相速度.

光波在具体晶体中的光学性质

各向同性介质（立方晶体）

单轴晶体

单轴晶体的主相对介电常数为：

$$\begin{cases} \epsilon_1=\epsilon_2=n_o^2\\ \epsilon_3=n_e^2\neq n_o^2 \end{cases}$$

\(n_e\gt n_o\)的晶体，称为正单轴晶体.

\(n_e\lt n_o\)的晶体，称为负单轴晶体.

光在晶体中传播特性的几何描述

折射率椭球

主轴坐标系中，晶体的电场储能密度为：

$$\omega_e = \frac{1}{2}\mathbf{E}\cdot\mathbf{D} = \frac{1}{2\epsilon_0}\left(\frac{D_1^2}{\epsilon_1} + \frac{D_2^2}{\epsilon_2} + \frac{D_3^2}{\epsilon_3}\right)$$ $$\therefore \frac{D_1^2}{\epsilon_1} + \frac{D_2^2}{\epsilon_2} + \frac{D_3^2}{\epsilon_3} = 2\epsilon_0\omega_e$$

令

$$x_1 = \frac{D_1}{\sqrt{2\epsilon_0\omega_e}},~x_2 = \frac{D_2}{\sqrt{2\epsilon_0\omega_e}},~x_3 = \frac{D_3}{\sqrt{2\epsilon_0\omega_e}}$$

则有

$$\frac{x_1^2}{\epsilon_1} + \frac{x_2^2}{\epsilon_2} + \frac{x_3^2}{\epsilon^3} = 1$$

或

$$\frac{x_1^2}{n_1^2} + \frac{x_2^2}{n_2^2} + \frac{x_3^2}{n_3^2} = 1$$ 单轴晶体折射率椭球方程为： $$\frac{x_1^2}{n_o^2} + \frac{x_2^2}{n_o^2} + \frac{x_3^2}{n_e^2} = 1$$
