Fresnel衍射与Fraunhofer衍射

Fresnel衍射

Fresnel衍射成立的充分条件的导出

$$\begin{align} r &= \sqrt{(x-x_0)^2 + (y-y_0)^2 + z^2}\\ &= z\left[1 + \left(\frac{x-x_0}{z}\right)^2 + \left(\frac{y-y_0}{z}\right)^2\right]^{1/2} \end{align}$$

Taylor展开，得：

$$r = z\left\{1 + \frac{(x-x_0)^2 + (y-y_0)^2}{2z^2} - \frac{[(x-x_0^2) + (y-y_0)]^2}{8z^4} + \cdots\right\}$$

上式第三项引起的相位差为：

$$\begin{align} \Delta\varphi &= kr\\ &= \frac{2\pi}{\lambda}\frac{[(x-x_0)^2 + (y-y_0)^2]}{8z^3} \end{align}$$

为使Fresnel近似成立，必须使\([(x-x_0)^2-(y-y_0)^2]^2\)取最大值时，\(\Delta\varphi\ll 2\pi\)，即：

$$\frac{2\pi}{\lambda}\frac{[(x-x_0)^2 + (y-y_0)^2]}{8z^3}\ll 2\pi$$ $$z^3\gg \frac{1}{8\lambda}[(x-x_0)^2 + (y-y_0)^2]^2_{\max}$$

也可以从衍射的角谱理论出发，对描述光波传播的传递函数\(H\)作出近似，导出Fresnel衍射公式：

观察面上光扰动的角谱与孔平面上光扰动的角谱的关系为：

$$A(f_x, f_y) = A_0(f_x, f_y)H(f_x, f_y)$$

\(H\)为描述传播现象频率效应的传递函数，其值为：

$$H(f_x, f_y) = e^{ikz\sqrt{1-\cos^2\alpha-\cos^2\beta}}$$

\(\cos^2\alpha + \beta^2\lt 1\)时，对相位因子中的根式作Taylor展开，得：

$$[1 - (\cos^2\alpha + \cos^2\beta)]^{1/2} = 1 - \frac{1}{2}(\cos^2\alpha + \cos^2\beta) - \frac{1}{8}(\cos^2\alpha + \cos^2\beta)^2 + \cdots$$

若展开式中第三项所贡献的相位远小于\(2\pi\)，则从上式中第三想起均可忽略不计，即：

$$\frac{2\pi}{\lambda}z\frac{1}{8}(\cos^2\alpha + \cos^2\beta)^2\ll 2\pi$$

平面波传播方向与孔径平面和观察平面坐标间的关系为：

$$\cos\alpha\approx \frac{x-x_0}{z},\quad \cos\beta\approx\frac{y-y_0}{z}$$ $$\therefore \frac{z}{8\lambda}\left[\frac{(x-x_0)^2 + (y-y_0)^2}{z^2}\right]^2\ll 1$$ $$z^3\gg \frac{1}{8}[(x-x_0)^2 + (y-y_0)^2]^2_{\max}$$

与之前的讨论一致.

衍射角谱理论下的进一步分析

Fresnel衍射区内：

$$\sqrt{1 - \cos^2\alpha - \cos^2\beta} \approx 1 - \frac{1}{2}(\cos^2\alpha + \cos^2\beta)$$ $$\therefore H(\frac{\cos\alpha}{\lambda}, \frac{\cos\beta}{\lambda}) = e^{ikz[1-\frac{1}{2}(\cos^2\alpha+\cos^2\beta)]}$$ $$\because f_x = \frac{\cos\alpha}{\lambda},\quad f_y = \frac{\cos\beta}{\lambda}$$ $$\begin{align}\therefore H(f_x, f_y) &= e^{ikz}e^{-i\frac{2\pi}{\lambda}\frac{1}{2}\lambda^2(f_x^2+f_y^2)}\\ &= e^{ikz}e^{-i\pi\lambda z(f_x^2+f_y^2)} \end{align}$$ $$\mathcal{F}^{-1}\{A(f_x, f_y)\} = \mathcal{F}^{-1}\{A_0(f_x, f_y)\}*\mathcal{F}^{-1}{H(f_x, f_y)}$$

即：

$$U(x,y) = \iint_{-\infty}^{+\infty}U_0(x_0,y_0)h(x-x_0, y-y_0)\mathrm{d}x_0\mathrm{d}y_0$$

Talbot效应

有一维周期物体，其复振幅透过率为：

$$g_0(x_0) = \sum_{n=-\infty}^{+\infty}c_ne^{ie\pi\frac{n}{d}x_0},\quad n=0,\pm1,\pm2,\cdots$$

对上式作Fourier变换，得物空间的空间频率为：

$$G_0(f_x) = \sum_{n=-\infty}^{+\infty}c_n\delta\left(f_x-\frac{n}{d}\right)$$

由Fresnel衍射传递函数表示式，得：

$$H(f_x) = e^{ikz}e^{-i\pi\lambda zf_x^2}$$

观察平面上得到场分布的频谱为：

$$\begin{align} G(f_x) &= G_0(f_x)H(f_x)\\ &= \sum_{n=-\infty}^{+\infty}c_n\delta\left(f_x-\frac{n}{d}\right)e^{ikz}e^{-i\pi\lambda zf_x^2}\\ &= \sum_{n=-\infty}^{+\infty}c_n\delta\left(f_x-\frac{n}{d}\right)e^{ikz}e^{-i\pi\lambda z\left(\frac{n}{d}\right)^2} \end{align}$$

当\(z\)满足条件：

$$z = \frac{2md^2}{\lambda},\quad m=1,2,3,\cdots$$

则：

$$e^{-i\pi\lambda z\left(\frac{n}{d}\right)^2} =1$$ $$\therefore G(f_x) = \sum_{n=-\infty}^{+\infty}c_n\delta\left(f_x-\frac{n}{d}\right)e^{ikz}$$

对上式进行Fourier逆变换，得到观察平面上场分布为：

$$g(x_0) = g_0(x_0)e^{ikz}$$

其强度分布于物体相同，即：

$$I(x_0) = |g(x_0)|^2 = |g_0(x_0)|^2$$
