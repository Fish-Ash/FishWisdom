渐变折射率分布光纤（GIOF）

GIOF中光线的传播

GIOF中，光线沿曲线传播，光线轨迹取决于光纤折射率分布，由光线方程描述.

柱坐标系中，光线方程的分量形式为：

\(r\)分量：

$$\frac{\mathrm{d}}{\mathrm{d}S}\left(n\frac{\mathrm{d}r}{\mathrm{d}S}\right) - nr\left(\frac{\mathrm{d}\phi}{\mathrm{d}S}\right)^2 = \frac{\mathrm{d}n}{\mathrm{d}r}$$

\(\phi\)分量：

$$m\frac{\mathrm{d}r}{\mathrm{d}S}\frac{\mathrm{d}\phi}{\mathrm{d}S} + \frac{\mathrm{d}}{\mathrm{d}S}\left(nr\frac{\mathrm{d}\phi}{\mathrm{d}r}\right) = 0$$

\(z\)分量：

$$\frac{\mathrm{d}}{\mathrm{d}S}\left(n\frac{\mathrm{d}x}{\mathrm{d}S}\right) = 0$$
  • \(r = \sqrt{x^2 + y^2}\)：光纤轨迹曲线上任一点至纤轴的距离

上式推导中利用了单位矢量\(\hat{\boldsymbol{r}}\)与\(\hat{\boldsymbol{\phi}}\)的关系式：

$$\mathrm{d}\hat{\boldsymbol{r}}/\mathrm{d}\phi = \hat{\boldsymbol{\phi}}$$ $$\mathrm{d}\hat{\boldsymbol{\phi}}/\mathrm{d}\phi = -\hat{\boldsymbol{r}}$$
