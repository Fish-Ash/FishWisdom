严格耦合波分析

严格耦合波分析（RCWA），又称傅里叶模态法（FMM）.

计算过程

前置知识
  • Fourier级数
  • 空间频率

对于周期性的结构，有：

$$\epsilon(x) = \epsilon(x + \Lambda)$$

将其展开为Fourier级数，有：

$$\epsilon(x) = \sum_{n=-\infty}^{\infty} \epsilon_n e^{i n \frac{2\pi}{\Lambda} x}$$

\(G = 2\pi/\Lambda\)称为倒格矢，是波矢.

谐波

频率为基频整数倍的波.

若基频波为\(e^{ikx}\)，则二次、三次谐波分别为\(e^{i2kx}\)和\(e^{i3kx}\).

因此结构的介电常数经过Fourier展开后成为了不同谐波的线性组合.

电场做Floquet展开：

$$\begin{align} E(x,z) &= e^{ik_xx}\\ &= \sum_mE_{0m}(z)e^{i(k_{x0} + mG)x} \end{align}$$ $$\because \nabla\times\boldsymbol{H} = -i\omega\epsilon\boldsymbol{E}$$ $$\begin{align} \epsilon(x)\boldsymbol{E}(x,z) &= \sum_n \epsilon_n e^{inGx}\sum_mE_{0m}(z)e^{i(k_{x0} + mG)x}\\ &= \sum_n\sum_m \epsilon_nE_{0m}(z)e^{i[k_{x0} + (m+n)G]x} \end{align}$$

结构的某个空间周期成分，会让一个场的波矢分量变成另一个波矢分量.

波矢通道

具有某个特定波矢的场分量.

用矩阵逐层连接

  • \(\boldsymbol{a}_1\)：入射侧进入结构的所有正向模式的激发系数
  • \(\boldsymbol{b}_1\)：从结构返回入射侧的所有反向模式的激发系数
  • \(\boldsymbol{a}_n\)：从结构传播到出射侧的所有正向模式的激发系数
  • \(\boldsymbol{b}_n\)：从出射侧反向射入结构的模式系数

[设]已知入射侧初始入射模式\(\boldsymbol{a}_{in}\)，即：

$$\boldsymbol{a}_1 = \boldsymbol{a}_{in}$$

[设]出射侧无额外光源，即：

$$\boldsymbol{b}_n = 0$$ $$\boldsymbol{b}_1 = S_{11}\boldsymbol{a}_1$$ $$\boldsymbol{a}_n = S_{12}\boldsymbol{a}_1$$ $$r_m = \frac{b_{1,m}}{a_{in}}$$ $$t_m = \frac{a_{n,m}}{a_{in}}$$

FDTD

空间划分为离散网格（Yee）

网格三个方向的边长\(\Delta x, \Delta y, \Delta z\)不要求相等.

网格需要足够小，使网格内材料可以近似看作均匀.

只有一套网格.

每个网格中都会有\(E\)和\(H\)，但其分量\(E_x,E_y,E_z\)与\(H_x, H_y, H_z\)放在网格内不同位置.

超表面工程常见工作流

1、适用RCWA扫描单元结构，得到相位、振幅、偏振转换效率与色散数据库

2、构建完整超表面

3、FDTD检查：不同单元间的耦合、边缘效应、实际焦距和焦斑、旁瓣、整体效率、局部近似.

RCWA方法得到的是计算单元无限周期性排列后的电磁响应，不是孤立的单元响应.

RCWA会考虑单元与单元之间的边界条件（周期/Bloch边界条件），但是不会考虑有限超表面的边缘.

Bloch边界条件是周期边界条件的推广.

使用RCWA方法得到的单元数据库，在用于非周期超表面的设计时，还需要考虑一些因素.

Bloch边界条件与周期边界条件值得深挖.

超表面设计方法分类

周期性超表面 RCWA
非周期性超表面 RCWA + 波前设计

超表面可以控制：相位、振幅、频率
