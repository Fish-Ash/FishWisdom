受激布里渊散射

布里渊散射

入射到介质的光波与介质内的弹性声波发生相互作用而产生的光散射现象.

受激布里渊散射（Sitimulated Brillouin Scattering, SBS）

频率为\(\omega\)的强激光束通过某种介质时，会在介质内产生频率为\(\omega_s\)的相干声波（介质在强入射激光作用下产生电致伸缩效应的结果），同时产生频率为\(\omega-\omega_s\)的散射光波.

声波与散射光波沿着特定的方向传播，且仅有入射光强度超过一定值时才能发生上述现象.

这种具有受激发射特性的布里渊散射称为受激布里渊散射.

当强光在介质中传播时，由于电致伸缩效应，会激发出声波，也就是介质的密度波，这个声波又会调制介质的折射率，形成一个会运动的折射率光栅，从而将入射光散射出去.

受激布里渊散射中的散射主要是由运动折射率光栅导致的.

散射就是原来的运动方向改变了.

抑制SBS，归根结底是降低入射激光的谱功率密度，而对入射激光进行线宽展宽可以有效降低谱功率密度.

受激布里渊散射

自发布里渊散射是由入射光在热激发声波上的散射所产生的.

热激发声波

由材料内部热运动自发产生的声波.

[注]受激布里渊散射也可以由吸收效应引起.

当入射激光场的强度足够高时，即使是自发散射光本身也可能变得相当强.

此时，入射光场与散射光场会发生拍频，并通过电致伸缩产生密度与压强起伏.

拍频

两个频率相近的振动叠加后，出现的振幅周期性忽大忽小的现象.

电致伸缩

介质在电场作用下发生机械形变或压力变化的现象.

随后，入射激光场又会在伴随这些密度起伏而出现的折射率变化上发生散射.

散射光将处于斯托克斯频率，并于最初产生该声学扰动的斯托克斯辐射发生相长叠加.

如此一来，声波与斯托克斯波便能相互促进对方增长，且二者均能增长到很大的振幅.

示例

入射光：

  • 振幅：\(E_1\)
  • 角频率：\(\omega_1\)
  • 波矢：\(\mathbf{k}_1\)

声波：

  • 振幅：\(\rho\)
  • 频率：\(\Omega\)
  • 波矢：\(\mathbf{q}\)

入射光在一个后退传播的声波上发生散射：

散射波：

  • 振幅：\(E_2\)
  • 角频率：\(\omega_2\)
  • 波矢：\(\mathbf{k}_2\)
$$\omega_2 = \omega_1 - \Omega_B$$
  • \(\Omega_B\) ：Brillouin频率

Brillouin频率与声学波矢\(\mathbf{q}_B\)的关系由声子色散关系给出：

$$\Omega_B = v |\mathbf{q}_B|$$
  • \(v\)：声速

按照假设，该声波是由激光场与Stokes场的拍频决定，因此声波波矢为：

$$\mathbf{q}_B = \mathbf{k}_1 - \mathbf{k}_2$$

由于光波的波矢与频率满足通常关系，即：

$$|\mathbf{k}_i| = \frac{n\omega_i}{c}$$

由于激光波与Stokes波是反向传播，有：

$$\Omega_B = \frac{n v}{c}(\omega_1 + \omega_2)$$

化简得只用外加场频率\(\omega_1\)表示的Brillouin频率：

$$\Omega_B = \frac{\frac{2 n v}{c}\omega_1}{1 + \frac{n v}{c}}$$
$$\because \omega_2 = \omega_1 - \Omega_B$$ $$\therefore \Omega_B = \frac{2 n v}{c}\omega_1 - \frac{n v}{c}\Omega_B$$ $$\therefore \Omega_B = \frac{\frac{2 n v}{c}\omega_1}{1 + \frac{n v}{c}}$$
$$\because \frac{nv}{c}\ll 1$$ $$\therefore $$
