第一节 极化率的色散特性

极化强度

光在介质中传播时，由于光电场的作用，将产生极化强度.

这里是介质被光电场极化.

一般情况下，极化强度包含线性极化强度与非线性极化强度.

$$\boldsymbol{P} = \boldsymbol{P}_{L} + \boldsymbol{P}_{NL}$$

光电场强度很弱时：可以忽略\(\boldsymbol{P}_{NL}\)，为线性光学问题，此时：

$$\boldsymbol{P} = \boldsymbol{P}_{L} = \boldsymbol{P}^{(1)} = \epsilon_0\chi^{(1)}\boldsymbol{E}$$
  • \(\epsilon_0\)：真空介电常数
  • \(\chi^{(1)}\)：线性极化率

光电场强度较强时：不可忽略\(\boldsymbol{P}_{NL}\)，将其表示为级数形式，有：

$$\begin{align} &\boldsymbol{P}_{L} = \boldsymbol{P}^{(1)}\\ &\boldsymbol{P}_{NL} = \boldsymbol{P}^{(2)} + \boldsymbol{P}^{(3)} + \cdots + \boldsymbol{P}^{(r)} + \cdots \end{align}$$

级数形式即为：\(a_1 + a_2 + \cdots + a_r + \cdots\)或\(a_1 + a_2 + a_3\)的形式

  • \(\boldsymbol{P}^{(r)}\)：\(r\)阶非线性极化强度，与光电场\(\boldsymbol{E}\)的\(r\)次方有关的非线性极化强度.

在无损耗（lossless）、无色散（dispersionless）介质中：

$$\begin{align} \boldsymbol{P} &= \boldsymbol{P}^{(1)} + \boldsymbol{P}^{(2)} + \boldsymbol{P}^{(3)} + \cdots + \boldsymbol{P}^{(r)} + \cdots\\ &= \epsilon_0\chi^{(1)}\boldsymbol{E} + \epsilon_0\chi^{(2)}\boldsymbol{E}^2 + \epsilon_0\chi^{(3)}\boldsymbol{E}^3 + \cdots + \epsilon_0\chi^{(r)}\boldsymbol{E}^r + \cdots \end{align}$$

[注]\(r=1\)时代表线性.

[注]\(\tilde{P}^{(r)}(t) = \epsilon_0\chi^{(r)}\tilde{E}^r(t)\).

[注]这里只考虑电偶极矩近似，完全忽略电四极矩及多极矩的影响.

[注]光电场过强时，上述非极化强度的级数形式将不再适用.

\(\chi\)不一定是常数，但是我们通常将其视作常数张量.

\(\chi^{(r)}\)是\(r\)阶极化率张量.

$$\boldsymbol{P}^{(r)} \propto \boldsymbol{E}^r$$

什么叫“电偶极矩近似”，什么叫“电四极矩及多极矩”？

随时间变化的极化可以作为电磁场新分量的源.

非线性光学介质中的波动方程为：

$$\nabla^2\boldsymbol{E} - \frac{n^2}{c^2}\frac{\partial^2\boldsymbol{E}}{\partial t^2} = \frac{1}{\epsilon_0 c^2}\frac{\partial^2\boldsymbol{P}_{NL}}{\partial t^2}$$
  • \(n\)：线性折射率
  • \(c\)：真空中的光速

这个式子说明\(\boldsymbol{P}_{NL}\)是源项，可能会产生哪些频率的光，由其决定.

将\(\boldsymbol{P}_{NL}(t)\)按时间谐波展开后，其中每一个与\(e^{-i\omega t}\)成正比的分量，都表示可能产生一个频率为\(\omega\)的光.

这个方程与电磁学中的Larmor理论一致，描述了加速运动的电荷会产生电磁辐射.

因果性原理

线性响应函数

光在介质中传播时，\(t\)时刻介质所感应的线性极化强度\(\boldsymbol{P}(t)\)不仅与\(t\)时刻的光电场\(\boldsymbol{E}(t)\)有关，还与\(t\)时刻前所有的光电场有关.

$$\boldsymbol{P}(t) = \int_{-\infty}^t \epsilon_0\boldsymbol{R}(t-\tau)\boldsymbol{E}(\tau)\mathrm{d}\tau$$

设时刻\(t\)前任一时刻\(\tau\)的光电场强度为\(\boldsymbol{E}(\tau)\)，它对\(t\)时刻时的极化强度的贡献为\(\mathrm{d}\boldsymbol{P}(t)\)，且：

$$\mathrm{d}\boldsymbol{P}(t) = \epsilon_0\boldsymbol{R}(t-\tau)\boldsymbol{E}(\tau)\mathrm{d}\tau$$ $$\begin{align}\therefore \boldsymbol{P}(t) &= \int_{-\infty}^t \mathrm{d}\boldsymbol{P}\\ &= \int_{-\infty}^t \epsilon_0\boldsymbol{R}(t-\tau)\boldsymbol{E}(\tau)\mathrm{d}\tau \end{align}$$ $$令\tau' = t - \tau \Rightarrow \tau = t - \tau'$$ $$\tau = -\infty时\rightarrow \tau' = +\infty$$ $$\tau = t时\rightarrow \tau'=0$$ $$\begin{align}\therefore \boldsymbol{P}(t) &= \int_{+\infty}^0\epsilon_0\boldsymbol{R}(\tau')\boldsymbol{E}(t-\tau')\mathrm{d}(t-\tau')\\ &= \int_0^{+\infty}\epsilon_0\boldsymbol{R}(\tau)\boldsymbol{E}(t-\tau)\mathrm{d}\boldsymbol{\tau} \end{align}$$
  • \(\boldsymbol{R}(t-\tau)\)：介质的线性响应函数，是一个二阶张量.

此外，\(t'\gt t\)时的光电场\(\boldsymbol{E}(t')\)对\(\boldsymbol{P}(t)\)是没有贡献的，即：

$$\boldsymbol{R}(t-\tau) = 0,~\tau\gt t$$ $$\therefore \int_{t}^{+\infty}\epsilon_0\boldsymbol{R}(t-\tau)\boldsymbol{E}(\tau)\mathrm{d}\tau = 0$$

亦即：

$$\boldsymbol{P}(t) = \int_{-\infty}^{+\infty}\epsilon_0\boldsymbol{R}(t-\tau)\boldsymbol{E}(\tau)\mathrm{d}\tau$$ $$\boldsymbol{P}(t) = \epsilon_0\boldsymbol{R}*\boldsymbol{E}$$ 响应函数所满足的真实性条件

由于\(\boldsymbol{E}(t)\)与\(\boldsymbol{P}(t)\)均为实函数，故\(\boldsymbol{R}(\tau)\)也必须是实函数，才能保证上式成立.

积分也是线性运算，所以线性响应函数体现了\(\boldsymbol{P}\)与\(\boldsymbol{E}\)之间的线性关系.

非线性响应函数

学到目前为止没明白为什么这节是“介质的色散特性”，“色散”到底是什么？

线性极化率
$$\begin{align} \chi^{(1)}(\omega) &= \int_{-\infty}^{+\infty}\boldsymbol{R}^{(1)}(\tau)e^{i\omega\tau}\mathrm{d}\tau\\ &= \chi'(\omega) + i\chi''(\omega) \end{align}$$
$$\because \boldsymbol{P}(t) = \epsilon_0\boldsymbol{R}(t)*\boldsymbol{E}(t)$$ $$\begin{align} \therefore \boldsymbol{P}(\omega) &= \mathcal{F}[\boldsymbol{P}(t)]\\ &= \epsilon_0\mathcal{F}[\boldsymbol{R}(t)]\boldsymbol{E}(\omega)\\ &= \epsilon_0\chi^{(1)}(\omega)\boldsymbol{E}(\omega) \end{align}$$ $$\therefore \chi^{(1)}(\omega) = \mathcal{F}[\boldsymbol{R}(t)]$$

线性极化率实部与虚部间的关系称为色散关系，由Kramers-Kroning关系给出.

Kramers-Kroning关系

给出了\(\chi^{(1)}(\omega)\)实部与虚部之间的关系.

$$\chi'(\omega) = \frac{1}{\pi}\text{P.V.}\int_{-\infty}^{+\infty}\frac{\chi''(\Omega)}{\Omega-\omega}\mathrm{d}\Omega$$ $$\chi''(\omega) = -\frac{1}{\pi}\text{P.V.}\int_{-\infty}^{+\infty}\frac{\chi'(\Omega)}{\Omega-\omega}\mathrm{d}\Omega$$
  • \(\text{P.V.}\)：柯西主值积分

极化率的单位

  • 宏观介质极化率：\(\chi^{(r)}\)
  • 单个原子极化率：\(\chi^{(r)mic}\)
$$\chi^{(r)} = n\chi^{(r)mic}$$
  • \(n\)：介质的原子数密度
国际单位制（SI） 高斯单位制（c. g. s. /e. s. u.）
$$\chi^{(r)}$$ $$\left(\frac{m}{V}\right)^{r-1}$$ $$\left(\frac{cm^3}{erg}\right)^{(r-1)/2}$$
$$\chi^{(r)mic}$$ $$m^3\left(\frac{m}{V}\right)^{r-1}$$ $$cm^3\left(\frac{cm^3}{erg}\right)^{(r-1)/2}$$

两种单位制中，线性极化率\(\chi^{(1)}\)都是无量纲的，其他非线性极化率张量间的关系为：

$$\frac{\chi^{(r)}(SI)}{\chi^{(r)}(c. g. s.)} = \frac{4\pi}{(3\times 10^4)^{r-1}}$$ $$\frac{\chi^{(r)mic}(SI)}{\chi^{(r)mic}(c. g. s.)} = \frac{4\pi}{10^6(3\times 10^4)^{(r-1)}}$$

第二节 非线性光学极化率的经典描述

振子的非线性响应可以用于描述非线性光学现象.

频率为\(\omega\)的光电场： $$E = E(\omega)e^{-i\omega t} + E^*(\omega)e^{i\omega t}$$ 包含多个频率分量光电场

设光电场包含多个频率分量，用复数表示时，可以写成以下形式：

$$E = \sum_nE(\omega_n)e^{-i\omega_n t}$$
  • \(E(\omega_n)\)：频率为\(\omega_n\)的光场的复振幅.

考虑到光场的真实性，有：

$$E(-\omega_n) = E^*(\omega_n)$$
$$P^{(2)}(t) = \epsilon_0\sum_{m,n}\chi^{(2)}(\omega_m,\omega_n)E(\omega_m)E(\omega_n)e^{-i(\omega_m + \omega_n)t}$$

设光电场包含\(x\)个频率，则：

$$\omega_m, \omega_n \in \{\pm\omega_1, \pm\omega_2, \cdots, \pm\omega_x\}$$

即\(\boldsymbol{P}^{(2)}\)的展开式中存在\(x^2\)项.

\(-\omega\)是为了描述实际电场引入的分量.

色散介质中的极化率

当材料具有色散或损耗时，非线性极化率是一个复数量，它将电场与极化强度的复振幅联系起来.

将电场矢量表示为若干频率分量的离散和，即：

$$\tilde{\boldsymbol{E}}(\boldsymbol{r}, t) = \sum_n'\tilde{\boldsymbol{E}}_n(\boldsymbol{r}, t)$$

其中：

$$\tilde{\boldsymbol{E}}_n(\boldsymbol{r}, t) = \boldsymbol{E}_n(\boldsymbol{r})e^{-i\omega_n t} + c.c.$$ $$P_i(\omega_n+\omega_m) = \epsilon_0\sum_{jk}\sum_{(nm)}\chi_{ijk}^{(2)}(\omega_n+\omega_m, \omega_m, \omega_n)E_j(\omega_n)E_k(\omega_m)$$

有效非线性极化率

约定：

$$d_{ijk} = \frac{1}{2}\chi_{ijk}^{(2)}$$

对于固定的几何构型（即传播方向与偏振方向都确定），可以用如下标量关系表示引起和频的非线性极化：

$$P(\omega_3) = 2\epsilon_0 d_{eff} E(\omega_1)E(\omega_2)$$

类似的，对于二次谐波产生，有：

$$P(2\omega) = 2\epsilon_0 d_{eff}E^2(\omega)$$

其中：

$$E(\omega) = |\boldsymbol{E}(\omega)|$$ $$P(\omega) = |\boldsymbol{P}(\omega)|$$

非线性极化强度表示方法

$$\chi_{\mu\alpha_1\alpha_2\cdots\alpha_r}^{(r)}(\omega_1, \omega_2, \cdots, \omega_r) = \chi_{\mu\alpha_1\alpha_2\cdots\alpha_r}^{(r)}$$

其中，\(\alpha_i\)与\(\omega_i\)一一对应，表示频率为\(\omega_i\)、振动方向为\(\alpha_i\)的光电场分量参与非线性作用；\(\mu\)表示最终产生极化强度的分量方向为\(\mu\).

极化强度表示式

$$\boldsymbol{P}^{(1)} = \sum_n\epsilon_0\boldsymbol{\chi}^{(1)}(\omega_n)\cdot \boldsymbol{E}(\omega_n)e^{-i\omega_nt}$$ $$\boldsymbol{P}^{(2)} = \sum_{m,n}\epsilon_0\boldsymbol{\chi}^{(2)}(\omega_m, \omega_n)\cdot \boldsymbol{E}(\omega_m)\boldsymbol{E}(\omega_n)e^{-i(\omega_m + \omega_n)t}$$ $$\boldsymbol{P}^{(3)} = \sum_{m,n,l}\epsilon_0\boldsymbol{\chi}^{(3)}(\omega_m, \omega_n, \omega_l)\cdot \boldsymbol{E}(\omega_m)\boldsymbol{E}(\omega_n)\boldsymbol{E}(\omega_l)e^{-i(\omega_m + \omega_n + \omega_l)t}$$

\(\boldsymbol{P}^{(r)}\)均为一阶张量，也就是矢量.

\(\cdot, :, \vdots\)为缩并符号，分别表示为：

一重缩并：

$$P_i = \chi\cdot E = \sum_{j} \chi_{ij} E_i$$

二重缩并：

$$P_i = \chi : EE = \sum_{j,k} \chi_{ijk} E_jE_k$$

三重缩并：

$$P_i = \chi \vdots EEE = \sum_{j,k,l} \chi_{ijkl} E_jE_kE_l$$

[注]式中的\(m,n,l\)包含所有的正值与负值.
