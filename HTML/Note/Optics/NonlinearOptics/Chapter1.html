第一节 极化率的色散特性

极化强度

前置知识
  • 电介质的极化

光在介质中传播时，由于光电场的作用，将产生极化强度.

一般情况下，极化强度包含线性极化强度与非线性极化强度.

$$\boldsymbol{P} = \boldsymbol{P}_{L} + \boldsymbol{P}_{NL}$$

光电场强度很弱时：可以忽略\(\boldsymbol{P}_{NL}\)，为线性光学问题，此时：

$$\boldsymbol{P} = \boldsymbol{P}_{L} = \boldsymbol{P}^{(1)} = \varepsilon_0\chi^{(1)}\boldsymbol{E}$$
  • \(\varepsilon_0\)：真空介电常数
  • \(\chi^{(1)}\)：线性极化率

光电场强度较强时：不可忽略\(\boldsymbol{P}_{NL}\)，将其表示为级数形式，有：

$$\begin{align} &\boldsymbol{P}_{L} = \boldsymbol{P}^{(1)}\\ &\boldsymbol{P}_{NL} = \boldsymbol{P}^{(2)} + \boldsymbol{P}^{(3)} + \cdots + \boldsymbol{P}^{(r)} + \cdots \end{align}$$
  • \(\boldsymbol{P}^{(r)}\)：\(r\)阶非线性极化强度，与光电场\(\boldsymbol{E}\)的\(r\)次方有关的非线性极化强度.

在无损耗（lossless）、无色散（dispersionless）介质中：

$$\begin{align} \boldsymbol{P} &= \boldsymbol{P}^{(1)} + \boldsymbol{P}^{(2)} + \boldsymbol{P}^{(3)} + \cdots + \boldsymbol{P}^{(r)} + \cdots\\ &= \varepsilon_0\chi^{(1)}\boldsymbol{E} + \varepsilon_0\chi^{(2)}\boldsymbol{E}^2 + \varepsilon_0\chi^{(3)}\boldsymbol{E}^3 + \cdots + \varepsilon_0\chi^{(r)}\boldsymbol{E}^r + \cdots \end{align}$$
  • \(\chi^{(r)}\)：\(r\)阶极化率张量
  • \(\tilde{P}^{(r)}(t) = \varepsilon_0\chi^{(r)}\tilde{E}^r(t)\)

[注]\(r=1\)时代表线性.

[注]这里只考虑电偶极矩近似，完全忽略电四极矩及多极矩的影响.

[注]光电场过强时，上述非极化强度的级数形式将不再适用.

什么叫“电偶极矩近似”，什么叫“电四极矩及多极矩”？

随时间变化的极化可以作为电磁场新分量的源.

非线性光学介质中的波动方程为：

$$\nabla^2\boldsymbol{E} - \frac{n^2}{c^2}\frac{\partial^2\boldsymbol{E}}{\partial t^2} = \frac{1}{\varepsilon_0 c^2}\frac{\partial^2\boldsymbol{P}_{NL}}{\partial t^2}$$
  • \(n\)：线性折射率
  • \(c\)：真空中的光速

这个式子说明\(\boldsymbol{P}_{NL}\)是源项，可能会产生哪些频率的光，由其决定.

将\(\boldsymbol{P}_{NL}(t)\)按时间谐波展开后，其中每一个与\(e^{-i\omega t}\)成正比的分量，都表示可能产生一个频率为\(\omega\)的光.

这个方程与电磁学中的Larmor理论一致，描述了加速运动的电荷会产生电磁辐射.

介质极化的响应函数

线性响应函数

因果性原理是物理学中的普遍规律.

光在介质中传播时，\(t\)时刻介质所感应的线性极化强度\(\boldsymbol{P}(t)\)不仅与\(t\)时刻的光电场\(\boldsymbol{E}(t)\)有关，还与\(t\)时刻前所有的光电场有关.

$$\boldsymbol{P}(t) = \int_{-\infty}^t \varepsilon_0\boldsymbol{R}(t-\tau)\boldsymbol{E}(\tau)\mathrm{d}\tau$$

设时刻\(t\)前任一时刻\(\tau\)的光电场强度为\(\boldsymbol{E}(\tau)\)，它对\(t\)时刻时的极化强度的贡献为\(\mathrm{d}\boldsymbol{P}(t)\)，且：

$$\mathrm{d}\boldsymbol{P}(t) = \varepsilon_0\boldsymbol{R}(t-\tau)\boldsymbol{E}(\tau)\mathrm{d}\tau$$ $$\begin{align}\therefore \boldsymbol{P}(t) &= \int_{-\infty}^t \mathrm{d}\boldsymbol{P}\\ &= \int_{-\infty}^t \varepsilon_0\boldsymbol{R}(t-\tau)\boldsymbol{E}(\tau)\mathrm{d}\tau \end{align}$$ $$令\tau' = t - \tau \Rightarrow \tau = t - \tau'$$ $$\tau = -\infty时\rightarrow \tau' = +\infty$$ $$\tau = t时\rightarrow \tau'=0$$ $$\begin{align}\therefore \boldsymbol{P}(t) &= \int_{+\infty}^0\varepsilon_0\boldsymbol{R}(\tau')\boldsymbol{E}(t-\tau')\mathrm{d}(t-\tau')\\ &= \int_0^{+\infty}\varepsilon_0\boldsymbol{R}(\tau)\boldsymbol{E}(t-\tau)\mathrm{d}\boldsymbol{\tau} \end{align}$$
  • \(\boldsymbol{R}(t-\tau)\)：介质的线性响应函数，是一个二阶张量.

由于当前及过去时刻的光电场，对此刻极化强度的贡献不是平均的，因此需要引入一个权重因子，能够表征\(\tau\)时刻光电场对当前极化强度的贡献.

这里具有一个假设，即介质具有时间平移不变性，所以对于同样\(t-\tau\)前的时刻，应该具有相同的权重响应.

此外，\(t'\gt t\)时的光电场\(\boldsymbol{E}(t')\)对\(\boldsymbol{P}(t)\)是没有贡献的，即：

$$\boldsymbol{R}(t-\tau) = 0,~\tau\gt t$$ $$\therefore \int_{t}^{+\infty}\varepsilon_0\boldsymbol{R}(t-\tau)\boldsymbol{E}(\tau)\mathrm{d}\tau = 0$$
$$\therefore\boldsymbol{P}(t) = \int_{-\infty}^{+\infty}\varepsilon_0\boldsymbol{R}(\tau)\boldsymbol{E}(t - \tau)\mathrm{d}\tau = \varepsilon_0\boldsymbol{R}*\boldsymbol{E}$$
$$\boldsymbol{P}(t) = \int_{-\infty}^{+\infty}\varepsilon_0\boldsymbol{R}(t-\tau)\boldsymbol{E}(\tau)\mathrm{d}\tau = \varepsilon_0\boldsymbol{R}*\boldsymbol{E}$$

由卷积的交换性质，有：

$$\boldsymbol{P}(t) = \varepsilon_0\boldsymbol{R}*\boldsymbol{E} = \int_{-\infty}^{+\infty}\varepsilon_0\boldsymbol{R}(\tau)\boldsymbol{E}(t - \tau)\mathrm{d}\tau$$
响应函数所满足的真实性条件

由于\(\boldsymbol{E}(t)\)与\(\boldsymbol{P}(t)\)均为实函数，故\(\boldsymbol{R}(\tau)\)也必须是实函数，才能保证上式成立.

非线性响应函数

二阶非线性极化强度

二阶非线性极化强度\(\boldsymbol{P}^{(2)}(t)\)与光电场\(\boldsymbol{E}(t)\)成二次方关系，按因果性原理有：

$$\boldsymbol{P}^{(2)}(t) = \varepsilon_0\int_{-\infty}^{+\infty}\mathrm{d}\tau_1\int_{-\infty}^{+\infty}\mathrm{d}\tau_2\boldsymbol{R}^{(2)}(\tau_1,\tau_2):\boldsymbol{E}(t-\tau_1)\boldsymbol{E}(t-\tau_2)$$
  • \(\boldsymbol{R}^{(2)}(\tau_1, \tau_2)\)：三阶张量，介质的二阶极化响应函数
$$\boldsymbol{P}^{(2)}(t) = \iint_{-\infty}^t\varepsilon_0\boldsymbol{R}(t-\tau_1, t-\tau_2)\boldsymbol{E}(\tau_1)\boldsymbol{E}(\tau_2)\mathrm{d}\tau_1\mathrm{d}\tau_2$$

\(r\)阶非线性极化强度

$$\begin{align} \boldsymbol{P}^{(r)}(t) =&\varepsilon_0\int_{-\infty}^{+\infty}\mathrm{d}\tau_1\int_{-\infty}^{+\infty}\mathrm{d}\tau_2\cdots\int_{-\infty}^{+\infty}\mathrm{d}\tau_r\\ &\times \boldsymbol{R}^{(2)}(\tau_1,\tau_2,\cdots,\tau_r)|\boldsymbol{E}(t-\tau_1)\boldsymbol{E}(t-\tau_2)\cdots\boldsymbol{E}(t-\tau_r) \end{align}$$
  • \(\boldsymbol{R}^{(r)}(\tau_1, \tau_2, \cdots, \tau_r)\)：\(r+1\)阶张量，介质的\(r\)阶极化响应函数

\(\boldsymbol{R}^{(r)}(\tau_1, \tau_2, \cdots, \tau_r)\)与\(\boldsymbol{E}(t-\tau_1)\)间的竖线表示\(r\)个点.

介质极化率的频率色散

上面在时间域内讨论了介质的极化强度与光电场的关系，引入了介质极化的响应函数.

若响应函数已知，原则上可以对介质的光学响应特性给出完整的描述.

但实际上，由于非线性光学经常是在频率域内讨论介质的极化过程，因此通常采用极化率张量表征介质的响应特性.

下面通过Fourier变换，在频率域内引入介质极化率张量，并讨论其色散关系.

线性极化率张量

前置知识
线性极化率
$$\begin{align} \chi^{(1)}(\omega) &= \int_{-\infty}^{+\infty}\boldsymbol{R}^{(1)}(\tau)e^{i\omega\tau}\mathrm{d}\tau\\ &= \chi'(\omega) + i\chi''(\omega) \end{align}$$
$$\because \boldsymbol{P}(t) = \varepsilon_0\boldsymbol{R}(t)*\boldsymbol{E}(t)$$ $$\begin{align} \therefore \boldsymbol{P}(\omega) &= \mathcal{F}[\boldsymbol{P}(t)]\\ &= \varepsilon_0\mathcal{F}[\boldsymbol{R}(t)]\boldsymbol{E}(\omega)\\ &= \varepsilon_0\chi^{(1)}(\omega)\boldsymbol{E}(\omega) \end{align}$$ $$\therefore \chi^{(1)}(\omega) = \mathcal{F}[\boldsymbol{R}(t)] = \int_{-\infty}^{+\infty}\boldsymbol{R}^{(1)}(\tau)e^{i\omega\tau}\mathrm{d}\tau$$

线性极化率实部与虚部间的关系称为色散关系，由Kramers-Kroning关系给出.

Kramers-Kroning关系

给出了\(\chi^{(1)}(\omega)\)实部与虚部之间的关系.

$$\chi'(\omega) = \frac{1}{\pi}\text{P.V.}\int_{-\infty}^{+\infty}\frac{\chi''(\Omega)}{\Omega-\omega}\mathrm{d}\Omega$$ $$\chi''(\omega) = -\frac{1}{\pi}\text{P.V.}\int_{-\infty}^{+\infty}\frac{\chi'(\Omega)}{\Omega-\omega}\mathrm{d}\Omega$$
  • \(\text{P.V.}\)：柯西主值积分

由\(\chi^{(1)}(\omega)\)的色散关系可知，只要我们知道极化率实部或虚部中的任何一个，便可通过色散关系求出另一个，从而获得介质极化的全部知识.

柯西主值积分

非线性极化率张量

二阶极化率张量

$$\chi^{(2)}(\omega_1, \omega_2) = \int_{-\infty}^{+\infty}\mathrm{d}\tau_1\int_{-\infty}^{+\infty}\mathrm{d}\tau_2\boldsymbol{R}^{(2)}(\tau_1, \tau_2)e^{i(\omega_1r_1 + \omega_2r_2)}$$

\(r\)阶极化率张量

$$\chi^{(r)}(\omega_1, \omega_2, \cdots, \omega_r) = \int_{-\infty}^{+\infty}\mathrm{d}\tau_1\int_{-\infty}^{+\infty}\mathrm{d}\tau_2\cdots\int_{-\infty}^{+\infty}\mathrm{d}\tau_r\boldsymbol{R}^{(r)}(\tau_1,\tau_2,\cdots,\tau_r)e^{i(\omega_1r_1 + \omega_2r_2 + \cdots + \omega_rr_r)}$$

介质极化率的空间色散

上面讨论了介质极化率的频率色散特性，并指出：这种频率色散特性起因于极化强度与光电场的时间变化率有关，是时间域内因果性原理的直接结果.

此外，由于介质内给定空间点的极化强度不仅与该点的光电场有关，还与邻近空间点的光电场有关，即与光电场的空间变化率有关，因而导致极化率张量\(\chi\)与光波波矢\(\boldsymbol{k}\)有关，这种\(\chi\)与波矢\(\boldsymbol{k}\)的依赖关系叫做介质极化率的空间色散，其空间色散关系可以通过空间域的Fourier变换得到.

若同时考虑介质极化率的频率色散特性与空间色散特性，介质极化率张量可以表示为\(\chi(\omega, \boldsymbol{k})\).

光频情况下，由于光频辐射波长比电子轨道半径与晶格间的距离大得多，因而在大多数情况下，\(\chi(\omega, \boldsymbol{k})\)的空间色散可以不考虑.

极化率的单位

  • 宏观介质极化率：\(\chi^{(r)}\)
  • 单个原子极化率：\(\chi^{(r)mic}\)
$$\chi^{(r)} = n\chi^{(r)mic}$$
  • \(n\)：介质的原子数密度
国际单位制（SI） 高斯单位制（c. g. s. /e. s. u.）
$$\chi^{(r)}$$ $$\left(\frac{m}{V}\right)^{r-1}$$ $$\left(\frac{cm^3}{erg}\right)^{(r-1)/2}$$
$$\chi^{(r)mic}$$ $$m^3\left(\frac{m}{V}\right)^{r-1}$$ $$cm^3\left(\frac{cm^3}{erg}\right)^{(r-1)/2}$$

两种单位制中，线性极化率\(\chi^{(1)}\)都是无量纲的，其他非线性极化率张量间的关系为：

$$\frac{\chi^{(r)}(SI)}{\chi^{(r)}(c. g. s.)} = \frac{4\pi}{(3\times 10^4)^{r-1}}$$ $$\frac{\chi^{(r)mic}(SI)}{\chi^{(r)mic}(c. g. s.)} = \frac{4\pi}{10^6(3\times 10^4)^{(r-1)}}$$

极化强度表示式

前置知识
  • 张量的点积

若组成光波的各个频率分量是不连续的，则极化强度表示式中的积分应由求和代替：

$$\boldsymbol{P}^{(1)} = \sum_n\varepsilon_0\boldsymbol{\chi}^{(1)}(\omega_n)\cdot \boldsymbol{E}(\omega_n)e^{-i\omega_nt}$$ $$\boldsymbol{P}^{(2)} = \sum_{m,n}\varepsilon_0\boldsymbol{\chi}^{(2)}(\omega_m, \omega_n):\boldsymbol{E}(\omega_m)\boldsymbol{E}(\omega_n)e^{-i(\omega_m + \omega_n)t}$$
$$\boldsymbol{P}^{(3)} = \sum_{m,n,l}\varepsilon_0\boldsymbol{\chi}^{(3)}(\omega_m, \omega_n, \omega_l)\vdots \boldsymbol{E}(\omega_m)\boldsymbol{E}(\omega_n)\boldsymbol{E}(\omega_l)e^{-i(\omega_m + \omega_n + \omega_l)t}$$
$$\vdots$$ $$\boldsymbol{P}^{(r)} = \sum_{\alpha_1,\alpha_2,\cdots,\alpha_r}\varepsilon_0\chi^{(r)}(\omega_{\alpha_1}, \omega_{\alpha_2}, \cdots, \omega_{\alpha_r})|\boldsymbol{E}(\omega_{\alpha_1})\boldsymbol{E}(\alpha_2)\cdots\boldsymbol{E}(\omega_r)e^{-i\mathop{\sum}\limits_{m=1}^r\omega_{\alpha_m}t}$$

[注]式中的\(m,n,l,\alpha_1,\alpha_2,\cdots,\alpha_r\)包含所有的正值与负值.

极化强度矢量的分量表示形式

通常，可以将上面的极化强度矢量关系写成其分量表示形式.

例如，二阶极化强度分量的表示式为：

$$P^{(2)}_\mu(t) = \varepsilon_0\sum_{m,n\\\alpha,\beta}\chi^{(2)}_{\mu\alpha\beta}(\omega_m, \omega_n)E_\alpha(\omega_m)E_\beta(\omega_n)e^{-i(\omega_m+\omega_n)t}$$
  • \(\chi^{(2)}_{\mu\alpha\beta}(\omega_m, \omega_n)\)：二阶极化率张量分量
  • \(\mu,\alpha,\beta = x,y,z\)

考虑Einstein求和规则，可以省略式中对\(\alpha,\beta\)的求和号，即：

$$P^{(2)}_\mu(t) = \varepsilon_0\sum_{m,n}\chi^{(2)}_{\mu\alpha\beta}(\omega_m, \omega_n)E_\alpha(\omega_m)E_\beta(\omega_n)e^{-i(\omega_m+\omega_n)t}$$

该式中的任意一项：

$$\varepsilon_0\chi^{(2)}_{\mu\alpha\beta}(\omega_m, \omega_n)E_\alpha(\omega_m)E_\beta(\omega_n)e^{-i(\omega_m+\omega_n)t}$$

表示：由频率为\(\omega_m\)、振动方向为\(\alpha\)的光电场分量\(E_\alpha(\omega_m, t)\)，与频率为\(\omega_n\)、振动方向为\(\beta\)的光电场分量\(E_\beta(\omega_n, t)\)，通过二阶非线性相互作用产生的、在\(\mu\)方向上振动、频率为\(\omega_m + \omega_n\)的二阶极化强度分量\(P^{(2)}_\mu(\omega_m+\omega_n, t)\).

色散介质中的极化率

当材料具有色散或损耗时，非线性极化率是一个复数量，它将电场与极化强度的复振幅联系起来.

将电场矢量表示为若干频率分量的离散和，即：

$$\tilde{\boldsymbol{E}}(\boldsymbol{r}, t) = \sum_n'\tilde{\boldsymbol{E}}_n(\boldsymbol{r}, t)$$

其中：

$$\tilde{\boldsymbol{E}}_n(\boldsymbol{r}, t) = \boldsymbol{E}_n(\boldsymbol{r})e^{-i\omega_n t} + c.c.$$ $$P_i(\omega_n+\omega_m) = \varepsilon_0\sum_{jk}\sum_{(nm)}\chi_{ijk}^{(2)}(\omega_n+\omega_m, \omega_m, \omega_n)E_j(\omega_n)E_k(\omega_m)$$

有效非线性极化率

约定：

$$d_{ijk} = \frac{1}{2}\chi_{ijk}^{(2)}$$

对于固定的几何构型（即传播方向与偏振方向都确定），可以用如下标量关系表示引起和频的非线性极化：

$$P(\omega_3) = 2\varepsilon_0 d_{eff} E(\omega_1)E(\omega_2)$$

类似的，对于二次谐波产生，有：

$$P(2\omega) = 2\varepsilon_0 d_{eff}E^2(\omega)$$

其中：

$$E(\omega) = |\boldsymbol{E}(\omega)|$$ $$P(\omega) = |\boldsymbol{P}(\omega)|$$

非线性极化强度表示方法

$$\chi_{\mu\alpha_1\alpha_2\cdots\alpha_r}^{(r)}(\omega_1, \omega_2, \cdots, \omega_r) = \chi_{\mu\alpha_1\alpha_2\cdots\alpha_r}^{(r)}$$

其中，\(\alpha_i\)与\(\omega_i\)一一对应，表示频率为\(\omega_i\)、振动方向为\(\alpha_i\)的光电场分量参与非线性作用；\(\mu\)表示最终产生极化强度的分量方向为\(\mu\).
