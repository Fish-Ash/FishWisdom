假设

1、介质：无反演对称.

2、所讨论的效应都远离共振区\(\rightarrow \chi^{(1)},\chi^{(2)}\)均为实数，具有完全对易对称性与时间反演对称性.

$$\boldsymbol{P}^{(2)} = \epsilon_0\chi^{(2)}\boldsymbol{E}^2$$ $$\therefore \boldsymbol{P}^{(2)} \propto \boldsymbol{E}^2$$ $$\boldsymbol{E} = E_0\cos(\omega t - \boldsymbol{k}\cdot\boldsymbol{r} + \phi_0)$$ $$\begin{align} \boldsymbol{E}^2 &= E_0^2\cos^2(\omega t - \boldsymbol{k}\cdot\boldsymbol{r} + \phi_0)\\ &= \frac{E_0^2}{2}[1 + \cos(2\omega t - 2\boldsymbol{k}\cdot\boldsymbol{r} + 2\phi_0)] \end{align}$$ $$\therefore \boldsymbol{P}^{(2)} \propto C + \cos(2\omega t - 2\boldsymbol{k}\cdot\boldsymbol{r} + 2\phi_0)$$

之所以说\(\boldsymbol{P}^{(2)} \propto C + \cos(2\omega t - 2\boldsymbol{k}\cdot\boldsymbol{r} + 2\phi_0)\)就产生了一个频率为\(2\omega\)的光波，是因为\(\boldsymbol{P}\)是Maxwell方程中的源项，其振荡频率为\(2\omega\)，因此会辐射出频率为\(2\omega\)的电磁波.

二阶非线性极化强度的一般形式为：

$$\boldsymbol{P}^{(2)} = \epsilon_0\chi^{(2)}:\boldsymbol{E}_1\boldsymbol{E}_2$$

故考虑二阶非线性时，最多考虑两个电场矢量的相互作用.

这里需要考虑的是：并矢与双点积

当仅存在一个电场矢量时，才会有：

$$\boldsymbol{P}^{(2)} = \epsilon_0\chi^{(2)}\boldsymbol{E}^2$$ $$\boldsymbol{P}^{(2)}\propto \boldsymbol{E}_1\boldsymbol{E}_2$$ $$\boldsymbol{E}_1\boldsymbol{E}_2 = \boldsymbol{E}_{01}\boldsymbol{E}_{02}\cos(\omega_1 t - \boldsymbol{k}_1\cdot\boldsymbol{r} + \phi_{01})\cos(\omega_2 t - \boldsymbol{k}_2\cdot\boldsymbol{r} + \phi_{02})$$ $$\boldsymbol{P}^{(2)}\propto \boldsymbol{E}_{01}\boldsymbol{E}_{02}\cos(\omega_1 t - \boldsymbol{k}_1\cdot\boldsymbol{r} + \phi_{01})\cos(\omega_2 t - \boldsymbol{k}_2\cdot\boldsymbol{r} + \phi_{02})$$ $$\boldsymbol{P}^{(2)}\propto \cos[(\omega_1 + \omega_2) t - (\boldsymbol{k}_1 + \boldsymbol{k}_2)\cdot\boldsymbol{r} + (\phi_{01} + \phi_{02})] + \cos[(\omega_1 - \omega_2) t - (\boldsymbol{k}_1 - \boldsymbol{k}_2)\cdot\boldsymbol{r} + (\phi_{01} - \phi_{02})]$$

前者为和频，后者为差频.

此处没有非线性电光效应与光整流效应，是因为为考虑DC项.

当我们希望某束光在某特定介质中以某固定角频率传播时，其波矢量是确定的（\(\boldsymbol{k} = \frac{\omega}{c}n(\omega)\)），所以只有当入射光的波矢量满足相位匹配条件时，才能实现有效的非线性光学过程.

第一节 线性电光效应

预备知识
  • 折射率椭球
线性电光效应（Pockler效应）

当没有反演中心的晶体受到直流电场或低频电场作用时，其折射率发生与外加电场成线性关系的变化.

[注]此处所指“低频电场”是相较于光频而言，故微波频率也包含在内.

线性电光效应发生时，变化的本质对象是折射率椭球，因此晶体的主轴方向可能改变，主折射率也可能变化.

反演中心

反演中心是晶体中的一种对称中心.

介质在光电场、低频电场或直流电场 两个电场的作用下，产生二阶非线性极化.

低频电场或直流电场引起介质折射率的线性变化，进而影响光电场的传播.

设直流电场为\(\boldsymbol{E}_0\)，光电场为\(\boldsymbol{E}\exp{(-i\omega)t} + c.c.\)，则根据极化强度的一般表示式，有：

$$\boldsymbol{P}^{(1)}(t) = \epsilon_0 \chi^{(1)}(0)\cdot \boldsymbol{E}_0 + \epsilon_0[\chi^{(1)}(\omega)\cdot \boldsymbol{E}e^{-i\omega t} + c.c.]$$

第二节 光整流效应

光整流效应

一个高强度单色激光通过非线性介质，由于二阶非线性差频过程产生一个直流极化场\(\boldsymbol{P}_0\)，并在介质中建立一个直流电场的现象.

曼利-罗关系

进行三波混频的光波所携带的总能量通量在介质内处处相等，光场与介质间无能量交换.

$$S_{\omega_1} + S_{\omega_2} + S_{\omega_3} = C$$
$$\begin{align} &\frac{k_1}{\omega_1}E^*_1\frac{\mathrm{d}E_1}{\mathrm{d}z} + \frac{k_2}{\omega_2}E^*_2\frac{\mathrm{d}E_2}{\mathrm{d}z} + \frac{k_3}{\omega_3}E_3\frac{\mathrm{d}E^*_3}{\mathrm{d}z}\\ =& \frac{i}{c^2}\chi_{eff}^{(2)}(\omega_1E_1^*E_2^*E_3e^{-i\Delta kz} + \omega_2 E_1^*E_2^*E_3e^{-i\Delta kz} - \omega_3E_1^*E_2^*E_3e^{-i\Delta kz})\\ =& 0 \end{align}$$

对上式取复共轭并相加，因为：

$$x^*\frac{\mathrm{d}x}{\mathrm{d}t} + x\frac{\mathrm{d}x^*}{\mathrm{d}t} = \frac{\mathrm{d}}{\mathrm{d}t}(x\cdot x^*) = \frac{\mathrm{d}|x|^2}{\mathrm{d}t}$$

故有：

$$\frac{k_1}{\omega_1}\frac{\mathrm{d}|E_1|^2}{\mathrm{d}z} + \frac{k_2}{\omega_2}\frac{\mathrm{d}|E_2|^2}{\mathrm{d}z} + \frac{k_3}{\omega_3}\frac{\mathrm{d}|E_3|^2}{\mathrm{d}z} = 0$$

积分得：

$$\frac{k_1}{\omega_1}|E_1|^2 + \frac{k_2}{\omega_2}|E_2|^2 + \frac{k_3}{\omega_3}|E_3|^2 = C$$

由能流密度表达式：

$$S = \frac{1}{2}\epsilon|2E|^2v = \frac{2}{\mu_0}\frac{k}{\omega}|E|^2$$

故：

$$S_{\omega_1} + S_{\omega_2} + S_{\omega_3} = C$$
曼利-罗关系 $$\frac{S_{\omega_1}}{\omega_1} - \frac{S_{\omega_2}}{\omega_2} = C_1$$ $$\frac{S_{\omega_1}}{\omega_1} + \frac{S_{\omega_3}}{\omega_3} = C_2$$ $$\frac{S_{\omega_2}}{\omega_3} + \frac{S_{\omega_3}}{\omega_3} = C_3$$

和频产生

假设非线性介质中，开始时并无频率为\(\omega_3\)的光波分量，该分量是由入射频率为\(\omega_1\)和\(\omega_2\)的光波混合产生的.

因此，称\(\omega_1\)和\(\omega_2\)光波为泵浦光，称\(\omega_3\)为信号光.

为确定所产生的频率为\(\omega_3\)的信号光波电场的变化规律，需要在给定入射光电场\(E(\omega_1, 0)\)和\(E(\omega_2, 0)\)的条件下，求解基本耦合波方程组.

有两种可供选择的求解方法：小信号近似理论与大信号理论.

小信号近似理论

认为在光混频过程中，频率\(\omega_1\)和\(\omega_2\)的泵浦光波强度改变很小，故可认为其强度在光波耦合过程中是不变的，此时将基本耦合波方程组中的\(E(\omega_1, z)\)与\(E(\omega_2, z)\)视为常数，只需求解\(E(\omega_3, z)\)式.

在满足相位匹配的条件下，即\(\Delta k=0\)时，方程

$$\frac{\mathrm{d}E(\omega_3, z)}{\mathrm{d}z} = \frac{i\omega_3^2}{k_3c^2}\chi_{eff}^{(2)}E(\omega_1, z)E^*(\omega_2, z)e^{i\Delta kz}$$

的解为：

$$E(\omega_3, z) = \frac{i\omega_3^2}{k_3c^2}\chi_{eff}^{(2)}E(\omega_1,0)E(\omega_2,0)z$$

什么是相位匹配，什么是相位匹配条件，为什么要相位匹配？

大信号理论

认为在光混频过程中，需考虑泵浦抽空效应，\(\omega_1\)、\(\omega_2\)和\(\omega_3\)的光波强度都在变化，需要同时求解基本耦合波方程组中的三个方程.

泵浦抽空效应

在三波混频（或二阶非线性）过程中，泵浦光因强度向信号光与闲置光转换能量而显著减弱的现象.

谐波的产生

一个频率为\(\omega_1\)的入射波产生谐波的过程：

1、产生频率为\(2\omega_1\)的二次谐波的极化波.

2、能量从极化波转移到频率为\(2\nu_1\)的电磁波.
