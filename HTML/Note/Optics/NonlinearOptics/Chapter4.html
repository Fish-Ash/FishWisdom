假设

1、介质：无反演对称.

2、所讨论的效应都远离共振区\(\rightarrow \chi^{(1)},\chi^{(2)}\)均为实数，具有完全对易对称性与时间反演对称性.

$$\boldsymbol{P}^{(2)} = \epsilon_0\chi^{(2)}\boldsymbol{E}^2$$ $$\therefore \boldsymbol{P}^{(2)} \propto \boldsymbol{E}^2$$ $$\boldsymbol{E} = E_0\cos(\omega t - \boldsymbol{k}\cdot\boldsymbol{r} + \phi_0)$$ $$\begin{align} \boldsymbol{E}^2 &= E_0^2\cos^2(\omega t - \boldsymbol{k}\cdot\boldsymbol{r} + \phi_0)\\ &= \frac{E_0^2}{2}[1 + \cos(2\omega t - 2\boldsymbol{k}\cdot\boldsymbol{r} + 2\phi_0)] \end{align}$$ $$\therefore \boldsymbol{P}^{(2)} \propto C + \cos(2\omega t - 2\boldsymbol{k}\cdot\boldsymbol{r} + 2\phi_0)$$

之所以说\(\boldsymbol{P}^{(2)} \propto C + \cos(2\omega t - 2\boldsymbol{k}\cdot\boldsymbol{r} + 2\phi_0)\)就产生了一个频率为\(2\omega\)的光波，是因为\(\boldsymbol{P}\)是Maxwell方程中的源项，其振荡频率为\(2\omega\)，因此会辐射出频率为\(2\omega\)的电磁波.

二阶非线性极化强度的一般形式为：

$$\boldsymbol{P}^{(2)} = \epsilon_0\chi^{(2)}:\boldsymbol{E}_1\boldsymbol{E}_2$$

故考虑二阶非线性时，最多考虑两个电场矢量的相互作用.

这里需要考虑的是：并矢与双点积

当仅存在一个电场矢量时，才会有：

$$\boldsymbol{P}^{(2)} = \epsilon_0\chi^{(2)}\boldsymbol{E}^2$$ $$\boldsymbol{P}^{(2)}\propto \boldsymbol{E}_1\boldsymbol{E}_2$$ $$\boldsymbol{E}_1\boldsymbol{E}_2 = \boldsymbol{E}_{01}\boldsymbol{E}_{02}\cos(\omega_1 t - \boldsymbol{k}_1\cdot\boldsymbol{r} + \phi_{01})\cos(\omega_2 t - \boldsymbol{k}_2\cdot\boldsymbol{r} + \phi_{02})$$ $$\boldsymbol{P}^{(2)}\propto \boldsymbol{E}_{01}\boldsymbol{E}_{02}\cos(\omega_1 t - \boldsymbol{k}_1\cdot\boldsymbol{r} + \phi_{01})\cos(\omega_2 t - \boldsymbol{k}_2\cdot\boldsymbol{r} + \phi_{02})$$ $$\boldsymbol{P}^{(2)}\propto \cos[(\omega_1 + \omega_2) t - (\boldsymbol{k}_1 + \boldsymbol{k}_2)\cdot\boldsymbol{r} + (\phi_{01} + \phi_{02})] + \cos[(\omega_1 - \omega_2) t - (\boldsymbol{k}_1 - \boldsymbol{k}_2)\cdot\boldsymbol{r} + (\phi_{01} - \phi_{02})]$$

前者为和频，后者为差频.

此处没有非线性电光效应与光整流效应，是因为为考虑DC项.

当我们希望某束光在某特定介质中以某固定角频率传播时，其波矢量是确定的（\(\boldsymbol{k} = \frac{\omega}{c}n(\omega)\)），所以只有当入射光的波矢量满足相位匹配条件时，才能实现有效的非线性光学过程.

第一节 线性电光效应

预备知识
  • 折射率椭球
线性电光效应（Pockler效应）

当没有反演中心的晶体受到直流电场或低频电场作用时，其折射率发生与外加电场成线性关系的变化.

[注]此处所指“低频电场”是相较于光频而言，故微波频率也包含在内.

线性电光效应发生时，变化的本质对象是折射率椭球，因此晶体的主轴方向可能改变，主折射率也可能变化.

反演中心

反演中心是晶体中的一种对称中心.

介质在光电场、低频电场或直流电场 两个电场的作用下，产生二阶非线性极化.

低频电场或直流电场引起介质折射率的线性变化，进而影响光电场的传播.

设直流电场为\(\boldsymbol{E}_0\)，光电场为\(\boldsymbol{E}\exp{(-i\omega)t} + c.c.\)，则根据极化强度的一般表示式，有：

$$\boldsymbol{P}^{(1)}(t) = \epsilon_0 \chi^{(1)}(0)\cdot \boldsymbol{E}_0 + \epsilon_0[\chi^{(1)}(\omega)\cdot \boldsymbol{E}e^{-i\omega t} + c.c.]$$

第二节 光整流效应

光整流效应

一个高强度单色激光通过非线性介质，由于二阶非线性差频过程产生一个直流极化场\(\boldsymbol{P}_0\)，并在介质中建立一个直流电场的现象.

谐波的产生

一个频率为\(\omega_1\)的入射波产生谐波的过程：

1、产生频率为\(2\omega_1\)的二次谐波的极化波.

2、能量从极化波转移到频率为\(2\nu_1\)的电磁波.

参量转换

参量转换其实就是一种特殊的和频产生或差频产生.

参量转换的分类

  • 参量上转换：对应于和频过程，由频率较低的信号辐射转换为频率较高的辐射
  • 参量下转换：对应于差频过程，由频率较高的信号辐射转换为频率较低的辐射

参量转换的理论分析

[设]泵浦光频率为\(\omega_1\).

实际过程中，参与频率转换作用的强光波（泵浦光）通常比弱光波（信号光）强得多，因此在频率转换过程中，泵浦光所损失或得到的功率与其总功率相比很小，可忽略其强度的变化，认为是常数，即：

$$\frac{\mathrm{d}E_1}{\mathrm{d}z}\approx 0$$

这种近似不仅适用于小的\(z\)值，对所有的\(z\)值都适用.

在这种近似下，仅需求解三波混频耦合波方程中的\(\frac{\mathrm{d}E_2}{\mathrm{d}z}\)式与\(\frac{\mathrm{d}E_3}{\mathrm{d}z}\)式.

$$\frac{\mathrm{d}E_2}{\mathrm{d}z} = \frac{i\omega_2^2}{k_2c^2}\chi_{\text{eff}}^{(2)}E_3E_1^*e^{-i\Delta kz}$$ $$\frac{\mathrm{d}E_3}{\mathrm{d}z} = \frac{i\omega_3^2}{k_3c^2}\chi_{\text{eff}}^{(2)}E_1E_2e^{i\Delta kz}$$

可以得到\(E_2\)满足的二阶微分方程

$$\frac{\mathrm{d}^2E_2}{\mathrm{d}z^2} + i\Delta k\frac{\mathrm{d}E_2}{\mathrm{d}z} + \frac{1}{l_M^2}E_2 = 0$$
$$\frac{\mathrm{d}^2E_2}{\mathrm{d}z^2} = \frac{i\omega_2^2}{k_2c^2}\chi_{\text{eff}}^{(2)}E_1^*\left(\frac{\mathrm{d}E_3}{\mathrm{d}z} - i\Delta kE_3\right)e^{-i\Delta k z}$$ $$E_3 = \frac{k_2c^2}{i\omega_2^2\chi_{\text{eff}^{(2)}}E_1^*}\frac{\mathrm{d}E_2}{\mathrm{d}z}e^{i\Delta kz}$$ $$\begin{align} \frac{\mathrm{d}^2E_2}{\mathrm{d}z^2} &= \frac{i\omega_2^2}{k_2c^2}\chi_{\text{eff}}^{(2)}E_1^*\left(\frac{\mathrm{d}E_3}{\mathrm{d}z} - i\Delta kE_3\right)e^{-i\Delta k z}\\ &= \frac{i\omega_2^2}{k_2c^2}\chi_{\text{eff}}^{(2)}E_1^*\left(\frac{i\omega_3^2}{k_3c^2}\chi_{\text{eff}}^{(2)}E_1E_2 - i\Delta k\cdot\frac{k_2c^2}{i\omega_2^2\chi_{\text{eff}^{(2)}}E_1^*}\cdot \frac{\mathrm{d}E_2}{\mathrm{d}z}\right)\\ &= -i\Delta k\frac{\mathrm{d}E_2}{\mathrm{d}z} - \frac{1}{c^4}\frac{\omega_2^2\omega_3^2}{k_2k_3}\left(\chi_{\text{eff}}^{(2)}\right)^2E_1^*E_1E_2 \end{align}$$
特征长度\(l_M\) $$l_M = \left[\frac{1}{2c^2}\left(\frac{\omega_2^2\omega_3^2}{k_2k_3}\right)^{1/2}\left\lvert\chi_{\text{eff}}^{(2)}\right\rvert E_0(\omega_1, 0)\right]^{-1}$$

1、去探究一下\(l_M\)的定义式

对于参量下转换过程

起始条件为：

$$E(\omega_2, z)\rvert_{z=0} = E(\omega_2, 0) = 0$$

由三波混频耦合波方程：

$$\left.\frac{\mathrm{d}E(\omega_2, z)}{\mathrm{d}z}\right\rvert_{z=0} = \frac{i\omega_2^2}{k_2c^2}E(\omega_3, 0)E^*(\omega_1, 0)$$

在这种条件下求解微分方程，结果为：

$$E(\omega_2, z) = \frac{i\omega_2^2}{k_2c^2}\chi_{\text{eff}}^{(2)}E(\omega_3, 0)E^*(\omega_1, 0)\frac{e^{-i\frac{\Delta kz}{2}}}{\left[\frac{1}{l_M^2} + \left(\frac{\Delta k}{2}\right)^2\right]^{1/2}}\sin\left\{\left[\frac{1}{l_M^2} + \left(\frac{\Delta k}{2}\right)^2\right]^{1/2}z\right\}$$ $$N_2(z) = \frac{N_3(0)}{l_M^2}\frac{1}{\frac{1}{l_M^2} + \left(\frac{\Delta k}{2}\right)^2}\sin^2\left\{\left[\frac{1}{l_M^2} + \left(\frac{\Delta k}{2}\right)^2\right]^{1/2}z\right\}$$

微分方程的求解过程

由Manley-Rowe关系，得：

$$N_2 + N_3 = N_3(0)$$
$$N_2 + N_3 = N_2(0) + N_3(0) = C$$ $$\because E_2(z) = 0$$ $$\therefore N_2(0) = 0$$ $$\therefore N_2 + N_3 = N_3(0)$$
$$\therefore N_3(z) = N_3(0)\frac{1 + \left(\frac{\Delta k L_M}{2}\right)^2 - \sin^2\left\{\left[\frac{1}{l_M^2} + \left(\frac{\Delta k}{2}\right)^2\right]^{1/2}z\right\}}{1 + \left(\frac{\Delta k L_M}{2}\right)^2}$$
$$\begin{align}\because N_2(z) &= \frac{N_3(0)}{l_M^2}\frac{1}{\frac{1}{l_M^2} + \left(\frac{\Delta k}{2}\right)^2}\sin^2\left\{\left[\frac{1}{l_M^2} + \left(\frac{\Delta k}{2}\right)^2\right]^{1/2}z\right\}\\ &= N_3(0)\frac{\sin^2\left\{\left[\frac{1}{l_M^2} + \left(\frac{\Delta k}{2}\right)^2\right]^{1/2}z\right\}}{1 + \left(\frac{\Delta k L_M}{2}\right)^2} \end{align}$$ $$\begin{align}\therefore N_3(z) &= N_3(0) - N_2\\ &= N_3(0)\frac{1 + \left(\frac{\Delta k L_M}{2}\right)^2 - \sin^2\left\{\left[\frac{1}{l_M^2} + \left(\frac{\Delta k}{2}\right)^2\right]^{1/2}z\right\}}{1 + \left(\frac{\Delta k L_M}{2}\right)^2} \end{align}$$

\(N_2(z)\)与\(N_3(z)\)两式，就是参量下转换过程中，\(\omega_2\)与\(\omega_3\)光波光子通量随距离\(z\)变化的关系式.

对于参量上转换过程

对于参量上转换过程，光子通量随距离\(z\)变化的关系式可以直接从参量下转换的\(N_2(z)\)与\(N_3(z)\)两式中得出，知识需要交换式中的频率\(\omega_2\)与\(\omega_3\).

$$N_3(z) = \frac{N_2(0)}{l_M^2}\frac{1}{\frac{1}{l_M^2} + \left(\frac{\Delta k}{2}\right)^2}\sin^2\left\{\left[\frac{1}{l_M^2} + \left(\frac{\Delta k}{2}\right)^2\right]^{1/2}z\right\}$$ $$N_2(z) = N_2(0)\frac{1 + \left(\frac{\Delta k L_M}{2}\right)^2 - \sin^2\left\{\left[\frac{1}{l_M^2} + \left(\frac{\Delta k}{2}\right)^2\right]^{1/2}z\right\}}{1 + \left(\frac{\Delta k L_M}{2}\right)^2}$$

参量上转换

研究参量上转换的实际意义在于：可以利用这种频率上转换过程，实现红外信号及红外图像的探测.

将红外波段很弱的信号或很弱的图像上转换到可见光范围，虽然上转换效率很低，但因在可见光区域有较灵敏的探测器和拾像器件，所以可以通过提高可见光区域的探测能力补偿上转换效率的不足.

应当明确指出的是：图像上转换之所以可能，是相位匹配条件满足及上转换强度与信号强度之间成线性关系这两者共同作用的结果.

只有这样，在参量上转换过程中，图像才不失真.
