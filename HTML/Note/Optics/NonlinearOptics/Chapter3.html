光在非线性介质中传播时的波动方程

[注]波浪号\(\sim\)表示随时间快速变化的量.

Maxwell方程祖为：

$$\begin{align} \nabla \cdot \tilde{\boldsymbol{D}} &= \tilde{\rho}\\ \nabla \cdot \tilde{\boldsymbol{B}} &= 0\\ \nabla \times \tilde{\boldsymbol{E}} &= -\frac{\partial \tilde{\boldsymbol{B}}}{\partial t}\\ \nabla \times \tilde{\boldsymbol{H}} &= \frac{\partial \tilde{\boldsymbol{D}}}{\partial t} + \tilde{\boldsymbol{J}} \end{align}$$

我们只关注其在无自由电荷区域内的解，因此：

$$\tilde{\rho} = 0$$

且其中不包含自由电流，因此：

$$\tilde{\boldsymbol{J}} = 0$$

假设介质是非磁性的，因此：

$$\tilde{\boldsymbol{B}} = \mu_0 \tilde{\boldsymbol{H}}$$

允许材料在满足以下条件时是非线性的：

$$\tilde{\boldsymbol{D}} = \epsilon_0\tilde{\boldsymbol{E}} + \tilde{\boldsymbol{P}}$$

其中，一般来说，极化强度矢量\(\tilde{\boldsymbol{P}}\)以非线性方式依赖于局域电场强度\(\tilde{\boldsymbol{E}}\).

这句话的意思是，\(P = f(E)\)

$$\begin{align} \because \nabla\times\tilde{\boldsymbol{E}} &= -\frac{\partial \tilde{\boldsymbol{B}}}{\partial t}\\ &= -\mu_0\frac{\partial \tilde{\boldsymbol{H}}}{\partial t} \end{align}$$ $$\begin{align} \therefore \nabla\times\nabla\times\tilde{\boldsymbol{E}} &= -\mu_0\frac{\partial}{\partial t}(\nabla\times\tilde{\boldsymbol{H}})\\ &= -\mu_0\frac{\partial}{\partial t}\left(\frac{\partial \tilde{\boldsymbol{D}}}{\partial t}\right)\\ &= -\mu_0\frac{\partial^2\tilde{\boldsymbol{D}}}{\partial t^2} \end{align}$$ $$\therefore\nabla\times\nabla\times\tilde{\boldsymbol{E}} + \mu_0\frac{\partial^2\tilde{\boldsymbol{D}}}{\partial t^2} = 0$$ $$\because\tilde{\boldsymbol{D}} = \epsilon_0\tilde{\boldsymbol{E}} + \tilde{\boldsymbol{P}}$$ $$\therefore\nabla\times\nabla\times\tilde{\boldsymbol{E}} + \epsilon_0\mu_0\frac{\partial^2\tilde{\boldsymbol{E}}}{\partial t^2} +\mu_0\frac{\partial^2\tilde{\boldsymbol{P}}}{\partial t^2} = 0$$ $$\because c = 1/\sqrt{\epsilon_0\mu_0}$$ $$\therefore\nabla\times\nabla\times\tilde{\boldsymbol{E}} + \frac{1}{c^2}\frac{\partial^2\tilde{\boldsymbol{E}}}{\partial t^2} = -\frac{1}{\epsilon_0 c^2}\frac{\partial^2\tilde{\boldsymbol{P}}}{\partial t^2}$$

这是非线性光学中最普遍形式的波动方程.

在特定条件下该方程可以进一步简化，例如使用矢量分析（vector calculus）中的恒等式，有：

$$\nabla\times\nabla\times\tilde{\boldsymbol{E}} = \nabla(\nabla\cdot\tilde{\boldsymbol{E}}) - \nabla^2\tilde{\boldsymbol{E}}$$

在线性光学的各向同性无源介质中，有：

$$\because \nabla\cdot\tilde{\boldsymbol{D}} = 0$$ $$\therefore \nabla\cdot\tilde{\boldsymbol{E}} = 0$$

在非线性光学：

$$\because\tilde{\boldsymbol{D}} = \epsilon_0\tilde{\boldsymbol{E}} + \tilde{\boldsymbol{P}}$$ $$\therefore \nabla\cdot\tilde{\boldsymbol{E}} \neq 0$$

但对于通常关心的情形，例如\(\tilde{\boldsymbol{E}}\)具有横向无限平面波的形式，则：

$$\nabla \cdot \tilde{\boldsymbol{E}} = 0$$

更一般地，即使其不为零，也常可以证明其很小，尤其是在缓变振幅近似（slowly varying amplitude approximation）成立的情况下.

因此，在非线性光学中，波动方程通常可以简化为：

$$\nabla^2\tilde{\boldsymbol{E}} - \frac{1}{c^2}\frac{\partial^2\tilde{\boldsymbol{E}}}{\partial t^2} = \frac{1}{\epsilon_0 c^2}\frac{\partial^2\tilde{\boldsymbol{P}}}{\partial t^2}$$

亦即（\(\tilde{\boldsymbol{D}} = \epsilon_0\tilde{\boldsymbol{E}} + \tilde{\boldsymbol{P}}\)）：

$$\nabla^2\tilde{\boldsymbol{E}} - \frac{1}{\epsilon_0 c^2}\frac{\partial^2\tilde{\boldsymbol{D}}}{\partial t^2} = 0$$

区分线性部分与非线性部分

$$\because \tilde{\boldsymbol{P}} = \tilde{\boldsymbol{P}}^{(1)} + \tilde{\boldsymbol{P}}_{NL}$$ $$\begin{align} \therefore \tilde{\boldsymbol{D}} &= \epsilon_0\tilde{\boldsymbol{E}} + \tilde{\boldsymbol{P}}^{(1)} + \tilde{\boldsymbol{P}}_{NL}\\ &= \tilde{\boldsymbol{D}}^{(1)} + \tilde{\boldsymbol{P}}_{NL} \end{align}$$

其中\(\tilde{\boldsymbol{D}}^{(1)}\)为\(\tilde{\boldsymbol{D}}\)的线性部分.

$$\therefore \nabla^2\tilde{\boldsymbol{E}} - \frac{1}{\epsilon_0c^2}\frac{\partial^2\tilde{\boldsymbol{D}}^{(1)}}{\partial t^2} = \frac{1}{\epsilon_0 c^2}\frac{\partial^2\tilde{\boldsymbol{P}}_{NL}}{\partial t^2}$$

无损、无色散介质的情况

考虑无损、无色散介质的情况：

$$\tilde{\boldsymbol{D}}^{(1)} = \epsilon_0\boldsymbol{\epsilon}^{(1)}\cdot\tilde{\boldsymbol{E}}$$
  • \(\boldsymbol{\epsilon}^{(1)}\)：实的、与频率无关的介电常数张量

对于各向同性材料，上述关系可以进一步简化为：

$$\tilde{\boldsymbol{D}}^{(1)} = \epsilon_0\epsilon^{(1)}\tilde{\boldsymbol{E}}$$
  • \(\epsilon_0 = 8.854 \times 10^{-12}\text{F/m}\)：真空介电常数
  • \(\epsilon^{(1)}\)：相对介电常数，无量纲标量，其值与介质种类有关

波动方程进一步简化为：

$$\nabla^2\tilde{\boldsymbol{E}} - \frac{\epsilon^{(1)}}{c^2}\frac{\partial^2\tilde{\boldsymbol{E}}}{\partial t^2} = \frac{1}{\epsilon_0 c^2}\frac{\partial^2\tilde{\boldsymbol{P}}_{NL}}{\partial t^2}$$
$$L[\boldsymbol{E}] = \nabla^2\tilde{\boldsymbol{E}} - \frac{\epsilon^{(1)}}{c^2}\frac{\partial^2\tilde{\boldsymbol{E}}}{\partial t^2}$$

具有这种形式的方程被称为驱动波动方程.

$$L[\boldsymbol{E}] = S$$

\(S\)被称为源项

这个方程具有受驱动波动方程（driven wave equation）（非齐次）的形式.

介质的非线性响应作为源项出现在方程的右侧，若无这个源项，上式的解就是以速度\(c/n\)传播的自由波.

其中：

$$n = \sqrt{\epsilon^{(1)}}$$

色散介质的情况

对于色散介质，必须分别考虑每个频率分量：

$$\tilde{\boldsymbol{E}}(\boldsymbol{r}, t) = \sum_n' \tilde{\boldsymbol{E}}_n(\boldsymbol{r}, t)$$ $$\tilde{\boldsymbol{P}}_{NL}(\boldsymbol{r}, t) = \sum_n' \tilde{\boldsymbol{P}}_{NL, n}(\boldsymbol{r}, t)$$ $$\tilde{\boldsymbol{D}}^{(1)}(\boldsymbol{r}, t) = \sum_n' \tilde{\boldsymbol{D}}_n^{(1)}(\boldsymbol{r}, t)$$

其中，每一个\(n\)对应一个频率分量.

求和仅对正的场分量进行

就是不考虑\(-\omega\)的情况.

每一个频率分量可以写成复振幅的形式：

$$\tilde{\boldsymbol{E}}_n(\boldsymbol{r}, t) = \boldsymbol{E}_n(\boldsymbol{r})e^{-i\omega_n t} + c.c.$$ $$\tilde{\boldsymbol{P}}_{NL, n}(\boldsymbol{r}, t) = \boldsymbol{P}_{NL, n}(\boldsymbol{r})e^{-i\omega_n t} + c.c.$$ $$\tilde{\boldsymbol{D}}_n^{(1)}(\boldsymbol{r}, t) = \boldsymbol{D}_n^{(1)}(\boldsymbol{r})e^{-i\omega_n t} + c.c.$$

若损耗（dissipation）可以忽略，则：

$$\boldsymbol{D}_n^{(1)}(\boldsymbol{r}) = \epsilon_0\boldsymbol{\epsilon}^{(1)}(\omega_n)\cdot\tilde{\boldsymbol{E}}_n(\boldsymbol{r}, t)$$
  • \(\boldsymbol{\epsilon}^{(1)}(\omega_n)\)：实的、频率相关的介电张量
$$\therefore \nabla^2\tilde{\boldsymbol{E}}_n - \frac{\boldsymbol{\epsilon}^{(1)}(\omega_n)}{c^2}\frac{\partial^2\tilde{\boldsymbol{E}}_n}{\partial t^2} = \frac{1}{\epsilon_0 c^2}\frac{\partial^2\tilde{\boldsymbol{P}}_{NL,n}}{\partial t^2}$$

该方程对各个频率分量均成立.
