Einstein求和约定

哑标（dummy index）

出现且仅出现两次的下标.

哑标可以省略求和符号.

自由标（free index）

仅出现一次的下标.

$$\begin{align} &x_1y_1 + x_2y_2 + \cdots + x_ny_n\\ =& \sum_{i=1}^n x_iy_i\\ =& x_iy_i \end{align}$$

其中\(i\)为哑标，可以省略求和符号.

$$\begin{align} &x_{11}y_n + x_{22}y_n + \cdots + x_{kk}y_n\\ =& \sum_{m=1}^k x_{mm}y_n\\ =& x_{mm}y_n \end{align}$$

其中\(m\)为哑标，可以省略求和符号；\(n\)为自由标，保持不变.

$$\begin{align} &x_1y_1z_1 + x_2y_2z_2 + \cdots + x_ny_nz_n\\ =& \sum_{i=1}^n x_iy_iz_i\\ \end{align}$$

不存在哑标，不可省略求和符号.

$$\begin{align} &x_{ij}y_i\\ =& \sum_{i=1}^n x_{ij}y_i\\ =& x_{1j}y_1 + x_{2j}y_2 + \cdots + x_{nj}y_n \end{align}$$

其中\(i\)为哑标，需要加上求和符号；\(j\)为自由标，保持不变.
