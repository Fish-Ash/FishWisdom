非线性极化率的性质

  • 真实性条件
  • 本征对易对称性
  • 完全对易对称性
  • 空间对称性

考虑频率为\(\omega_1\)、\(\omega_2\)与\(\omega_3 = \omega_1 + \omega_2\)三个光波在无损二阶非线性介质中的相互作用.

极化率张量的真实性条件 $$[\chi^{(r)}(\omega_1 , \omega_2, \cdots, \omega_r)]^* = \chi^{(r)}(-\omega_1^*, -\omega_2^*, \cdots, -\omega_r^*)$$

\(^*\)是取复共轭的意思.

$$-\omega^* = -(\omega^*)$$

当频率为实数时：

$$[\chi^{(r)}(\omega_1 , \omega_2, \cdots, \omega_r)]^* = \chi^{(r)}(-\omega_1, -\omega_2, \cdots, -\omega_r)$$

一般来说频率都是实数.

本征对易对称性

$$\chi^{(2)}(\omega_1, \omega_2) = \chi^{(2)}(\omega_2, \omega_1)$$

由一维振子的二阶非线性极化率表达式：

$$\chi^2(\omega_1, \omega_2) = -A\frac{ne^3}{\epsilon_0m^2}F(\omega_1 + \omega_2)F(\omega_1)F(\omega_2)$$

可得：

$$\chi^{(2)}(\omega_1, \omega_2) = \chi^{(2)}(\omega_2, \omega_1)$$

对于三阶非线性极化率张量，下示6个式子是相等的：

$$\chi_{\mu\alpha\beta\gamma}^{(3)}(\omega_1, \omega_2, \omega_3)$$ $$\chi_{\mu\alpha\gamma\beta}^{(3)}(\omega_1, \omega_3, \omega_2)$$
$$\chi_{\mu\beta\alpha\gamma}^{(3)}(\omega_2, \omega_1, \omega_3)$$ $$\chi_{\mu\beta\gamma\alpha}^{(3)}(\omega_2, \omega_3, \omega_1)$$
$$\chi_{\mu\gamma\alpha\beta}^{(3)}(\omega_3, \omega_1, \omega_2)$$ $$\chi_{\mu\gamma\beta\alpha}^{(3)}(\omega_3, \omega_2, \omega_1)$$
完全对易对称性

在\(\chi^{(1)}(\omega)\)的表达式中，用\(-\omega\)代替\(\omega\)时，其值不变，即：

$$\chi^{(1)}(-\omega) = \chi^{(1)}(\omega)$$

在\(\chi^{(2)}(\omega_1, \omega_2)\)的表达式中，用\(-(\omega_1 + \omega_2)\)代替\(\omega_1\)或\(\omega_2\)时，其值不变，即：

$$\chi^{(2)}[-(\omega_1 + \omega_2), \omega_2] = \chi^{(2)}[\omega_1, -(\omega_1 + \omega_2)] = \chi^{(2)}(\omega_1, \omega_2)$$

在\(\chi^{(3)}(\omega_1, \omega_2, \omega_3)\)的表达式中，用\(-(\omega_1 + \omega_2 + \omega_3)\)代替\(\omega_1\)或\(\omega_2\)或\(\omega_3\)时，其值不变，即：

$$\begin{align} &\chi^{(3)}[-(\omega_1 + \omega_2 + \omega_3), \omega_2, \omega_3]\\ =&\chi^{(3)}[\omega_1, -(\omega_1 + \omega_2 + \omega_3), \omega_3]\\ =&\chi^{(3)}[\omega_1, \omega_2, -(\omega_1 + \omega_2 + \omega_3)]\\ =&\chi^{(3)}(\omega_1, \omega_2, \omega_3) \end{align}$$
空间对称性

三维空间中，介质的极化率是张量.

线性极化率\(\chi^{(1)}\)是二阶张量，一般有9个元素；

二阶极化率\(\chi^{(2)}\)是三阶张量，一般有27个元素；

三阶极化率\(\chi^{(3)}\)是四阶张量，一般有91个元素；

……

\(r\)阶极化率\(\chi^{(r)}\)是\(r+1\)阶张量.

晶体的对称性越高，极化率张量中的非零元素、独立元素数目越少.

Kleinman对称性

很多情况下，非线性相互作用所涉及的光波频率\(\omega_i\)都远小于材料系统的最低共振频率.

材料系统的最低共振频率

材料出现明显共振吸收或强响应的最低频率.

这种条件下，非线性极化率基本与频率无关.

此外，在低频激发条件下，系统对外场的响应基本上是瞬时的，在这种条件下，非线性极化可以在时域中写成：

$$\tilde{P}(t) = \epsilon_0\chi^{(2)}\tilde{E}(t)$$

其中，\(\chi^{(2)}\)可以看作是常数.

当外加场频率\(\omega_i\)远小于共振频率\(\omega_0\)时，介质必然是无损的.
