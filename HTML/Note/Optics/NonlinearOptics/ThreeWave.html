三波混频

三波混频现象

两个频率不同的单色光同时入射到非线性介质中，产生和频与差频的效应.

在非线性介质中，同时入射两束强光电场，由于介质存在二阶非线性极化，介质内部会产生一个随时间振荡的新的极化源.

介质中的极化，本质上是正负电荷发生相对位移，当极化随时间振荡时，意味着电荷在加速运动.

加速运动的电荷会辐射出电磁波.

由二阶非线性极化强度的一般表示式，可以得到三波混频中任何一对光波所感应的非线性极化强度复振幅：

$$\boldsymbol{P}^{(2)}(\omega_1) = 2\epsilon_0\chi^{(2)}(\omega_3, -\omega_2):\boldsymbol{E}(\omega_3, z)\boldsymbol{E}^*(\omega_2, z)$$ $$\boldsymbol{P}^{(2)}(\omega_2) = 2\epsilon_0\chi^{(2)}(\omega_3, -\omega_1):\boldsymbol{E}(\omega_3, z)\boldsymbol{E}^*(\omega_1, z)$$ $$\boldsymbol{P}^{(2)}(\omega_3) = 2\epsilon_0\chi^{(2)}(\omega_1, \omega_2):\boldsymbol{E}(\omega_1, z)\boldsymbol{E}(\omega_2, z)$$

考虑到\(\omega_3 = \omega_1 + \omega_2\)，因此仅计算：

$$\begin{cases} \omega_m, \omega_n = \omega_1, \omega_2\\ \omega_m, \omega_n = \omega_2, \omega_1\\ \end{cases}$$

两项.

$$\begin{align} P^{(2)}(t) &= \epsilon_0\sum_{m,n}\chi^{(2)}(\omega_m,\omega_n)E(\omega_m)E(\omega_n)e^{-i(\omega_m + \omega_n)t}\\ &= \epsilon_0\chi^{(2)}(\omega_1,\omega_2)E(\omega_1)E(\omega_2)e^{-i\omega_3t} + \epsilon_0\chi^{(2)}(\omega_2,\omega_1)E(\omega_2)E(\omega_1)e^{-i\omega_3t} \end{align}$$

考虑到二阶极化率的本征对易对称性，有：

$$\chi^{(2)}(\omega_1, \omega_2) = \chi^{(2)}(\omega_2, \omega_1)$$ $$\therefore P^{(2)}(t) = 2\epsilon_0\chi^{(2)}(\omega_1,\omega_2)E(\omega_1)E(\omega_2)e^{-i\omega_3t}$$

省略时间相位因子，得到非线性极化强度复振幅为：

$$P^{(2)}(\omega_3) = 2\epsilon_0\chi^{(2)}(\omega_1,\omega_2)E(\omega_1)E(\omega_2)$$

考虑张量形式，才会引入并联式双点积，得到：

$$\boldsymbol{P}^{(2)}(\omega_3) = 2\epsilon_0\chi^{(2)}(\omega_1, \omega_2):\boldsymbol{E}(\omega_1, z)\boldsymbol{E}(\omega_2, z)$$

光波的角频率由时间相位因子的\(\omega\)决定，当只关注频率为\(\omega_n\)的光波时，就只用计算能构成\(\omega_n\)的频率的排列组合即可.

在推导特定频率（如ω₁）的耦合方程时，只考虑能产生该频率极化的频率组合项。对于ω₁ = ω₃ - ω₂的过程，仅此项满足频率匹配条件并对P⁽²⁾(ω₁)有贡献，其他项不参与该相互作用，故忽略.

非线性介质中，三波（\(\omega_1, \omega_2, \omega_3 = \omega_1 + \omega_2\)）混频的基本耦合波方程组：

$$\frac{\mathrm{d}E(\omega_1, z)}{\mathrm{d}z} = \frac{i\omega_1^2}{k_1c^2}\chi_{eff}^{(2)}E(\omega_3, z)E^*(\omega_2, z)e^{-i\Delta kz}$$ $$\frac{\mathrm{d}E(\omega_2, z)}{\mathrm{d}z} = \frac{i\omega_2^2}{k_2c^2}\chi_{eff}^{(2)}E(\omega_3, z)E^*(\omega_1, z)e^{-i\Delta kz}$$ $$\frac{\mathrm{d}E(\omega_3, z)}{\mathrm{d}z} = \frac{i\omega_3^2}{k_3c^2}\chi_{eff}^{(2)}E(\omega_1, z)E^*(\omega_2, z)e^{i\Delta kz}$$
  • \(\chi_{eff}^{(2)}\in \mathbb{R}\)：有效非线性极化率，标量.
仿真 $$y = u + iv$$ $$\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\mathrm{d}u}{\mathrm{d}x} + i\frac{\mathrm{d}v}{\mathrm{d}x}$$ $$\frac{\mathrm{d} \text{Re}(y)}{\mathrm{d}x} = \frac{\mathrm{d}u}{\mathrm{d}x} = \text{Re}(\frac{\mathrm{d}y}{\mathrm{d}x})$$ $$\frac{\mathrm{d} \Im(y)}{\mathrm{d}x} = \frac{\mathrm{d}v}{\mathrm{d}x} = \Im(\frac{\mathrm{d}y}{\mathrm{d}x})$$

求解该方程组，代入的数值是\(E_n(\omega_n, 0)\)，求解的是\(E_n(\omega_n, z)\)

这三个方程描述的是同一个非线性过程的不同投影.

方程左边指复振幅随z的变化.

方程右边如果都是复振幅，那就是正比于；如果存在复振幅的复共轭，类似于反比的味道，比如说w_1 = w_3 - w_2，复共轭体现的就是那个“-”.
