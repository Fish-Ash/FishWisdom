三波混频

三波混频

本节讨论由二阶非线性极化引起的三波混频现象.

三波混频现象

两个频率不同的单色光同时入射到非线性介质中，产生和频与差频的效应.

在非线性介质中，同时入射两束强光电场，由于介质存在二阶非线性极化，介质内部会产生一个随时间振荡的新的极化源.

介质中的极化，本质上是正负电荷发生相对位移，当极化随时间振荡时，意味着电荷在加速运动.

加速运动的电荷会辐射出电磁波.

和频产生过程

当入射光为\(\omega_1\)和\(\omega_2\)时，由于二阶非线性作用，将产生频率为\(\omega_3 = \omega_1 + \omega_2\)的非线性极化强度，进而由这个非线性极化强度产生频率为\(\omega_3\)的光场.

[注]倍频过程是和频产生过程\(\omega_2 = \omega_1\)的特殊情形.

差频产生过程

当入射光为\(\omega_1\)和\(\omega_3\)时，由于二阶非线性作用，将产生频率为\(\omega_2 = \omega_3 - \omega_1\)的非线性极化强度，进而由这个非线性极化强度产生频率为\(\omega_1\)的光场.

要想在非线性介质的众多非线性光学过程中保证和频或差频产生，必须使这些过程满足相位匹配条件：

$$\boldsymbol{k}_1 + \boldsymbol{k}_2 - \boldsymbol{k}_3 = 0$$

相位匹配条件可以十分普遍地用来将我们需要的过程从所有可能产生的过程中分离出来.

若满足\(\boldsymbol{k}_1 + \boldsymbol{k}_2 - \boldsymbol{k}_3 = 0\)的相位匹配条件，我们就可以只考虑\(\omega_1\)、\(\omega_2\)与\(\omega_3 = \omega_1 + \omega_2\)这三个频率的光波耦合，而完全不考虑这三个频率的光波与所有其他频率光波的任何耦合.

这三个频率光波在非线性介质中的耦合，使得其中任何一对光波一起感应一个极化强度，这个极化强度的振荡频率就是相应的第三束光波的频率.

三波混频耦合波方程组

由二阶非线性极化强度的一般表示式，可以得到三波混频中任何一对光波所感应的非线性极化强度复振幅：

$$\boldsymbol{P}^{(2)}(\omega_1) = 2\epsilon_0\chi^{(2)}(\omega_3, -\omega_2):\boldsymbol{E}(\omega_3, z)\boldsymbol{E}^*(\omega_2, z)$$ $$\boldsymbol{P}^{(2)}(\omega_2) = 2\epsilon_0\chi^{(2)}(\omega_3, -\omega_1):\boldsymbol{E}(\omega_3, z)\boldsymbol{E}^*(\omega_1, z)$$
$$\boldsymbol{P}^{(2)}(\omega_3) = 2\epsilon_0\chi^{(2)}(\omega_1, \omega_2):\boldsymbol{E}(\omega_1, z)\boldsymbol{E}(\omega_2, z)$$

考虑到\(\omega_3 = \omega_1 + \omega_2\)，因此仅计算：

$$\begin{cases} \omega_m, \omega_n = \omega_1, \omega_2\\ \omega_m, \omega_n = \omega_2, \omega_1\\ \end{cases}$$

两项.

$$\begin{align} P^{(2)}(t) &= \epsilon_0\sum_{m,n}\chi^{(2)}(\omega_m,\omega_n)E(\omega_m)E(\omega_n)e^{-i(\omega_m + \omega_n)t}\\ &= \epsilon_0\chi^{(2)}(\omega_1,\omega_2)E(\omega_1)E(\omega_2)e^{-i\omega_3t} + \epsilon_0\chi^{(2)}(\omega_2,\omega_1)E(\omega_2)E(\omega_1)e^{-i\omega_3t} \end{align}$$

考虑到二阶极化率的本征对易对称性，有：

$$\chi^{(2)}(\omega_1, \omega_2) = \chi^{(2)}(\omega_2, \omega_1)$$ $$\therefore P^{(2)}(t) = 2\epsilon_0\chi^{(2)}(\omega_1,\omega_2)E(\omega_1)E(\omega_2)e^{-i\omega_3t}$$

省略时间相位因子，得到非线性极化强度复振幅为：

$$P^{(2)}(\omega_3) = 2\epsilon_0\chi^{(2)}(\omega_1,\omega_2)E(\omega_1)E(\omega_2)$$

考虑张量形式，才会引入并联式双点积，得到：

$$\boldsymbol{P}^{(2)}(\omega_3) = 2\epsilon_0\chi^{(2)}(\omega_1, \omega_2):\boldsymbol{E}(\omega_1, z)\boldsymbol{E}(\omega_2, z)$$

光波的角频率由时间相位因子的\(\omega\)决定，当只关注频率为\(\omega_n\)的光波时，就只用计算能构成\(\omega_n\)的频率的排列组合即可.

在推导特定频率（如ω₁）的耦合方程时，只考虑能产生该频率极化的频率组合项。对于ω₁ = ω₃ - ω₂的过程，仅此项满足频率匹配条件并对P⁽²⁾(ω₁)有贡献，其他项不参与该相互作用，故忽略.

根据单色平面光波在稳态条件下的非线性耦合波方程，\(\omega_1,~\omega_2,~\omega_3\)的光电场标量复振幅\(E(\omega_1, z),~E(\omega_2, z),~E(\omega_3, z)\)满足的微分方程为：

$$\frac{\mathrm{d}E(\omega_1, z)}{\mathrm{d}z} = \frac{i\mu_0\omega_1^2}{2k_1}\boldsymbol{a}(\omega_1)\cdot\boldsymbol{P}_{\text{NL}}'(\omega_1, z)e^{-ik_1z}$$ $$\frac{\mathrm{d}E(\omega_2, z)}{\mathrm{d}z} = \frac{i\mu_0\omega_2^2}{2k_2}\boldsymbol{a}(\omega_2)\cdot\boldsymbol{P}_{\text{NL}}'(\omega_2, z)e^{-ik_2z}$$ $$\frac{\mathrm{d}E(\omega_3, z)}{\mathrm{d}z} = \frac{i\mu_0\omega_3^2}{2k_3}\boldsymbol{a}(\omega_3)\cdot\boldsymbol{P}_{\text{NL}}'(\omega_3, z)e^{-ik_3z}$$

式中：

$$\boldsymbol{P}_{\text{NL}}'(\omega_1, z) = 2\varepsilon_0\chi^{(2)}(\omega_3, -\omega_2):\boldsymbol{a}(\omega_3)\boldsymbol{a}(\omega_2)E(\omega_3, z)E^*(\omega_2, z)e^{i(k_3-k_2)z}$$ $$\boldsymbol{P}_{\text{NL}}'(\omega_2, z) = 2\varepsilon_0\chi^{(2)}(\omega_3, -\omega_1):\boldsymbol{a}(\omega_3)\boldsymbol{a}(\omega_1)E(\omega_3, z)E^*(\omega_1, z)e^{i(k_3-k_1)z}$$ $$\boldsymbol{P}_{\text{NL}}'(\omega_3, z) = 2\varepsilon_0\chi^{(2)}(\omega_1, \omega_2):\boldsymbol{a}(\omega_1)\boldsymbol{a}(\omega_2)E(\omega_1, z)E(\omega_2, z)e^{i(k_1+k_2)z}$$

[令]\(\Delta k = k_1 + k_2 - k_3\)，有：

$$\frac{\mathrm{d}E(\omega_1, z)}{\mathrm{d}z} = \frac{i\omega_1^2}{k_1c^2}[\chi^{(2)}(\omega_3, -\omega_2)\vdots\boldsymbol{a}(\omega_1)\boldsymbol{a}(\omega_3)\boldsymbol{a}(\omega_2)]E(\omega_3, z)E^*(\omega_2, z)e^{-i\Delta kz}$$ $$\frac{\mathrm{d}E(\omega_2, z)}{\mathrm{d}z} = \frac{i\omega_2^2}{k_2c^2}[\chi^{(2)}(\omega_3, -\omega_1)\vdots\boldsymbol{a}(\omega_2)\boldsymbol{a}(\omega_3)\boldsymbol{a}(\omega_1)]E(\omega_3, z)E^*(\omega_1, z)e^{-i\Delta kz}$$ $$\frac{\mathrm{d}E(\omega_3, z)}{\mathrm{d}z} = \frac{i\omega_3^2}{k_3c^2}[\chi^{(2)}(\omega_1, \omega_2)\vdots\boldsymbol{a}(\omega_3)\boldsymbol{a}(\omega_1)\boldsymbol{a}(\omega_2)]E(\omega_1, z)E(\omega_2, z)e^{i\Delta kz}$$

上面三式方括号中标量乘的定义为：

$$\chi^{(2)}\vdots\boldsymbol{a}\boldsymbol{b}\boldsymbol{c} = \sum_{\alpha,\beta,\gamma = x,y,z}\chi_{\alpha\beta\gamma}^{(2)}a_\alpha b_\beta c_\gamma$$

若介质对频率为\(\omega_1,~\omega_2,~\omega_3\)的光波都是无耗的，即\(\omega_1,~\omega_2,~\omega_3\)远离共振区，则上面方程中的\(\chi^{(2)}(\omega_3, -\omega_2),~\chi^{(2)}(\omega_3, -\omega_1),~\chi^{(2)}(\omega_1, \omega_2)\)都是实数.

考虑完全对易对称性，不难证明上式中的方括号都相等.

引入一个实数\(\chi^{(2)}_{\text{eff}}\)表示它们：

有效非线性极化率\(\chi^{(2)}_\text{eff}\) $$\begin{align} \chi^{(2)}_{\text{eff}} &= \chi^{(2)}(\omega_1, \omega_2)\vdots \boldsymbol{a}(\omega_3)\boldsymbol{a}(\omega_1)\boldsymbol{a}(\omega_2)\\ &= \chi^{(2)}(\omega_3, -\omega_2)\vdots \boldsymbol{a}(\omega_1)\boldsymbol{a}(\omega_3)\boldsymbol{a}(\omega_2)\\ &= \chi^{(2)}(\omega_3, -\omega_1)\vdots \boldsymbol{a}(\omega_2)\boldsymbol{a}(\omega_3)\boldsymbol{a}(\omega_1)\\ \end{align}$$

补充：张量点积的互换性？

非线性介质中，三波（\(\omega_1, \omega_2, \omega_3 = \omega_1 + \omega_2\)）混频的基本耦合波方程组：

三波混频基本耦合波方程 $$\frac{\mathrm{d}E(\omega_1, z)}{\mathrm{d}z} = \frac{i\omega_1^2}{k_1c^2}\chi_{eff}^{(2)}E(\omega_3, z)E^*(\omega_2, z)e^{-i\Delta kz}$$ $$\frac{\mathrm{d}E(\omega_2, z)}{\mathrm{d}z} = \frac{i\omega_2^2}{k_2c^2}\chi_{eff}^{(2)}E(\omega_3, z)E^*(\omega_1, z)e^{-i\Delta kz}$$ $$\frac{\mathrm{d}E(\omega_3, z)}{\mathrm{d}z} = \frac{i\omega_3^2}{k_3c^2}\chi_{eff}^{(2)}E(\omega_1, z)E(\omega_2, z)e^{i\Delta kz}$$
  • \(\chi_{eff}^{(2)}\in \mathbb{R}\)：有效非线性极化率，标量.
仿真 $$y = u + iv$$ $$\frac{\mathrm{d}y}{\mathrm{d}x} = \frac{\mathrm{d}u}{\mathrm{d}x} + i\frac{\mathrm{d}v}{\mathrm{d}x}$$ $$\frac{\mathrm{d} \text{Re}(y)}{\mathrm{d}x} = \frac{\mathrm{d}u}{\mathrm{d}x} = \text{Re}(\frac{\mathrm{d}y}{\mathrm{d}x})$$ $$\frac{\mathrm{d} \text{Im}(y)}{\mathrm{d}x} = \frac{\mathrm{d}v}{\mathrm{d}x} = \text{Im}(\frac{\mathrm{d}y}{\mathrm{d}x})$$

求解该方程组，代入的数值是\(E_n(\omega_n, 0)\)，求解的是\(E_n(\omega_n, z)\)

这三个方程描述的是同一个非线性过程的不同投影.

方程左边指复振幅随z的变化.

方程右边如果都是复振幅，那就是正比于；如果存在复振幅的复共轭，类似于反比的味道，比如说w_1 = w_3 - w_2，复共轭体现的就是那个“-”.
