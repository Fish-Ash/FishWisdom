非线性光学晶体

非线性介质中的三波和四波相互作用

非线性光学晶体的折射率\(n\)式光波电场强度矢量\(\boldsymbol{E}\)的函数.

$$n(\boldsymbol{E}) = n_0 + n_1\boldsymbol{E} + n_2\boldsymbol{E}^2 + \cdots$$
  • n_0是没有电场时的折射率（常用于传统的线性光学）.

介质的折射率会随电场而改变.

物理光学等学科研究的是弱光问题，通常将折射率近似为\(n_0\).

对于极化率：

$$\chi^{(1)} = \frac{1}{4\pi}(\epsilon_0 - 1) = \frac{1}{4\pi}(n_0^2 - 1)$$ $$\chi^{(2)} \approx \frac{1}{2\pi}n_0n_1$$ $$\chi^{(3)} \approx \frac{1}{2\pi}n_0n_2$$
  • \(\epsilon_0\)：无电场情况下的介电常数.

二阶非线性仅存在于非中心对称的晶体中（\(\chi^{(2)} = 0\)），即在不具有对称中心的晶体中存在.

在具有对称中心及各向同性的介质中：\(\chi^{(2)} \equiv 0\).

三阶非线性存在于所有晶体于各向同性介质中.

具有频率为\(\omega_1\)和\(\omega_2\)的两束单色波在具有二阶非线性的晶体中传播会产生具有\(\omega_3 = \omega_1 + \omega_2\)（和频）与\(\omega_4 = \omega_1 - \omega_2\)（差频）频率的混频波.

\(\omega_1 = \omega_2\)的情况下，将得到：

二次谐波发生（SHG）为和频发生（SFG）的特例，\(\omega_3 = 2\omega_1\).

光学整流（OR）为差频发生（DFG）的特例，\(\omega_4 = 0\).

相位匹配条件

通常情况下，所有光学介质的非线性都是弱的，即：

$$\chi^{(3)}\boldsymbol{E}^2 \ll \chi^{(1)}\boldsymbol{E} \ll \chi^{(0)}$$

只有当光波满足相位匹配条件,在相当长的晶体中传播时才能观察到显著的非线性效应.

$$\boldsymbol{k}_3 = \boldsymbol{k}_2 + \boldsymbol{k}_1$$ $$\boldsymbol{k}_4 = \boldsymbol{k}_2 - \boldsymbol{k}_1$$

假设晶体长度为\(L\)，将其分成无数个薄片，每个薄片都产生一个微弱的非线性信号光

如果相位匹配条件不满足，则每个薄片产生的非线性信号光与前一个薄片产生的信号光相位不同，导致它们相互干涉，最终使得总的非线性信号光强度较弱.

满足相位匹配的条件时，会产生相长干涉.

在所有波矢方向一致的情况下，矢量相位匹配可以简化为标量相位匹配.

单轴晶体的相位匹配类型

在三频率相互作用中，必须要利用不同偏振的光波才能满足相位匹配.

SFG：

若两束混合波具有相同的偏振性，和频处的辐射将会在其垂直的方向上偏振.

这种情况下，可以实现Ⅰ类相位匹配.

负单轴晶体中：

$$\boldsymbol{k}_{o1} + \boldsymbol{k}_{o2} = \boldsymbol{k}_3^e(\theta)$$

这被称为“ooe”相位匹配或“ooe”相互作用或\(Ⅰ^{(-)}\)类相位匹配.

正单轴晶体中：

$$\boldsymbol{k}_1^e(\theta) + \boldsymbol{k}_2^e(\theta) = \boldsymbol{k}_{o3}$$

这被称为“eeo”相位匹配或“eeo”相互作用或\(Ⅰ^{(+)}\)类相位匹配.

[注]对于SFG，“ooe”等符号的含义为：第一个字母代表较低频率的波，第三个字母代表较高频率的波.

若两束混合的波是正交偏振的，将产生Ⅱ类相位匹配.

负单轴晶体中相应于e光的SF波：

$$\boldsymbol{k}_{o1} + \boldsymbol{k}_2^e(\theta) = \boldsymbol{k}_3^e(\theta)$$

这被称为“oee”相位匹配或“oee”相互作用或\(Ⅱ^{(-)}\)类相位匹配.

或：

$$\boldsymbol{k}_1^e(\theta) + \boldsymbol{k}_{o2} = \boldsymbol{k}_3^e(\theta)$$

这被称为“eoe”相位匹配或“eoe”相互作用或\(Ⅱ^{(-)}\)类相位匹配.

对于正单轴晶体内的o光：

$$\boldsymbol{k}_{o1}(\theta) + \boldsymbol{k}_2^e(\theta) = \boldsymbol{k}_{o3}$$

这被称为“oeo”相位匹配或“oeo”相互作用或\(Ⅱ^{(+)}\)类相位匹配.

或：

$$\boldsymbol{k}_1^e(\theta) + \boldsymbol{k}_{o2} = \boldsymbol{k}_{o3}$$

这被称为“eoo”相位匹配或“eoo”相互作用或\(Ⅱ^{(+)}\)类相位匹配.

单轴晶体的相位匹配角

单轴非线性晶体的色散特性仅由极角\(\theta\)决定.

双轴晶体的相位匹配类型

双轴晶体中，仅能实现三种普遍类型的相位匹配：

Ⅰ类相位匹配 ss-f
Ⅱ类相位匹配 sf-f
fs-f

[注]第三个符号表示较高的频率\(\omega_3\).

SHG（\(\omega_3 = 2\omega_1\)）情况下

双轴晶体所有主平面内，仅能实现两类共线相位匹配：

Ⅰ类相位匹配（ss-f） $$n_s(\omega_1) = n_{s1} = n_f(\omega_3) = n_{f3}$$ Ⅱ类相位匹配（sf-f） $$n_{s1} + n_{f1} = 2n_{f3}$$
