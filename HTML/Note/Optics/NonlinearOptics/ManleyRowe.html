Manley-Rowe关系

能量守恒关系式
$$S_{\omega_1} + S_{\omega_2} + S_{\omega_3} = C$$

三波混频耦合波方程组\(\omega_1,~\omega_2,~\omega_3\)式分别左乘\(\frac{k_1}{\omega_1}E_1^*,~\frac{k_2}{\omega_2}E_2^*,~\frac{k_3}{\omega_3}E_3\)后相加，得：

$$\begin{align} &\frac{k_1}{\omega_1}E^*_1\frac{\mathrm{d}E_1}{\mathrm{d}z} + \frac{k_2}{\omega_2}E^*_2\frac{\mathrm{d}E_2}{\mathrm{d}z} + \frac{k_3}{\omega_3}E_3\frac{\mathrm{d}E^*_3}{\mathrm{d}z}\\ =& \frac{i}{c^2}\chi_{eff}^{(2)}(\omega_1E_1^*E_2^*E_3e^{-i\Delta kz} + \omega_2 E_1^*E_2^*E_3e^{-i\Delta kz} - \omega_3E_1^*E_2^*E_3e^{-i\Delta kz})\\ =& \frac{i}{c^2}\chi_{eff}^{(2)}(\omega_1 + \omega_2 - \omega_3)E_1^*E_2^*E_3e^{-i\Delta kz}\\ =& 0 \end{align}$$

对上式取复共轭并相加，因为：

$$x^*\frac{\mathrm{d}x}{\mathrm{d}t} + x\frac{\mathrm{d}x^*}{\mathrm{d}t} = \frac{\mathrm{d}}{\mathrm{d}t}(x\cdot x^*) = \frac{\mathrm{d}|x|^2}{\mathrm{d}t}$$ $$\therefore \frac{k_1}{\omega_1}\frac{\mathrm{d}|E_1|^2}{\mathrm{d}z} + \frac{k_2}{\omega_2}\frac{\mathrm{d}|E_2|^2}{\mathrm{d}z} + \frac{k_3}{\omega_3}\frac{\mathrm{d}|E_3|^2}{\mathrm{d}z} = 0$$

积分得：

$$\frac{k_1}{\omega_1}|E_1|^2 + \frac{k_2}{\omega_2}|E_2|^2 + \frac{k_3}{\omega_3}|E_3|^2 = C$$

由能流密度表达式：

$$S = \frac{1}{2}\epsilon|2E|^2v = \frac{2}{\mu_0}\frac{k}{\omega}|E|^2$$ $$\therefore S_{\omega_1} + S_{\omega_2} + S_{\omega_3} = C$$

该式表明：进行三波混频的光波所携带的总能量通量在介质内处处相等，光场与介质间无能量交换.

实际上，这正是我们上面假定这三束耦合光波的频率远离共振区、极化率张量具有完全对易对称性的必然结果.

因此，我们在此再一次看到极化率张量为实数是与介质无损耗相联系着的.

什么叫频率远离共振区？

Manley-Rowe关系
$$\frac{S_{\omega_1}}{\omega_1} - \frac{S_{\omega_2}}{\omega_2} = C_1$$

三波混频耦合波方程组\(\omega_1,~\omega_2\)式分别左乘\(\frac{k_1}{\omega_1^2},~\frac{k_2}{\omega_2^2}\)后相除，得：

$$\left(\frac{k_1}{\omega_1^2}\frac{\mathrm{d}E_1}{\mathrm{d}z}\right)/\left(\frac{k_2}{\omega_2^2}\frac{\mathrm{d}E_2}{\mathrm{d}z}\right) = E_2^*/E_1^*$$ $$\therefore \frac{k_1}{\omega_1^2}E_1^*\frac{\mathrm{d}E_1}{\mathrm{d}z} - \frac{k_2}{\omega_2^2}E_2^*\frac{\mathrm{d}E_2}{\mathrm{d}z} = 0$$

取上式复共轭，并与之相加，积分后得：

$$\frac{k_1}{\omega_1^2}|E_1|^2 - \frac{k_2}{\omega_2^2}|E_2|^2 = C_1$$

利用能量密度\(S_\omega\)表示式，上式变为：

$$\frac{S_{\omega_1}}{\omega_1} - \frac{S_{\omega_2}}{\omega_2} = C_1$$
$$\frac{S_{\omega_1}}{\omega_1} + \frac{S_{\omega_3}}{\omega_3} = C_2$$ $$\frac{S_{\omega_2}}{\omega_3} + \frac{S_{\omega_3}}{\omega_3} = C_3$$

利用上述任意两式，都可以确定第三个式子.

同时，上述三个关系式一起便可以得到能量守恒关系式.

Manley-Rowe关系的光子通量表示

由于\(S_\omega/\hbar\omega\)表示光场中频率为\(\omega\)的光子平均通量，所以Manley-Rowe关系式又可表示为：

$$N_{\omega_1} - N_{\omega_2} = C_1$$ $$N_{\omega_1} + N_{\omega_3} = C_2$$ $$N_{\omega_2} + N_{\omega_3} = C_3$$

同时，能量守恒关系式可以表示为：

$$\omega_1N_{\omega_1} + \omega_2N_{\omega_2} + \omega_3N_{\omega_3} = C$$

由这些关系可以说明：因为光场与介质间无任何能量交换，因此频率为\(\omega_1\)和\(\omega_2\)的光子只能同时产生或同时消失，而与此同时就有一个频率为\(\omega_3\)的光子消失或产生.

另一种形式的Manley-Rowe关系

光强：

$$I_i = 2nc\epsilon_0E_iE_i^*$$ $$\therefore \frac{\mathrm{d}I_i}{\mathrm{d}z} = 2nc\epsilon_0\left(E_i^*\frac{\mathrm{d}E_i}{\mathrm{d}z} + c.c.\right)$$ 由三波混频耦合波方程： $$\frac{\mathrm{d}E_1}{\mathrm{d}z} = \frac{i\omega_1^2}{k_1c^2}\chi_{\text{eff}}^{(2)}E_3E_2^*e^{-i\Delta kz}$$ $$\frac{\mathrm{d}E_2}{\mathrm{d}z} = \frac{i\omega_2^2}{k_3c^2}\chi_{\text{eff}}^{(2)}E_3E_1^*e^{-i\Delta kz}$$ $$\frac{\mathrm{d}E_3}{\mathrm{d}z} = \frac{i\omega_1^2}{k_1c^2}\chi_{\text{eff}}^{(2)}E_1E_2e^{i\Delta kz}$$ $$\begin{align}\therefore \frac{\mathrm{d}I_1}{\mathrm{d}z} &= 2n_1c\varepsilon_0\left[E_1^*\frac{i\omega_1^2}{k_1c^2}\chi_{\text{eff}}^{(2)}E_3E_2^*e^{-i\Delta kz} + c.c.\right]\\ &= \frac{2n_1c\varepsilon_0\omega_1^2\chi_{\text{eff}}^{(2)}}{k_1c^2}(iE_1^*E_2^*E_3e^{-i\Delta kz} + c.c.) \end{align}$$ $$\because d_{\text{eff}} = \frac{1}{2}\chi_{\text{eff}}^{(2)}$$ $$k_1 = \frac{2\pi}{\lambda_1} = \frac{\omega_1 T_1}{\lambda_0/n_1} = \frac{n_1\omega_1}{c}$$ $$\therefore \frac{\mathrm{d}I_1}{\mathrm{d}z} = 4\varepsilon_0\omega_1d_{\text{eff}}(iE_1^*E_2^*E_3e^{-i\Delta kz} + c.c.)$$

同理：

$$\frac{\mathrm{d}I_2}{\mathrm{d}z} = 4\varepsilon_0\omega_2d_{\text{eff}}(iE_1^*E_2^*E_3e^{-i\Delta kz} + c.c.)$$ $$\begin{align} \frac{\mathrm{d}I_3}{\mathrm{d}z} &= 4\varepsilon_0\omega_3d_{\text{eff}}(iE_1E_2E_3^*e^{i\Delta kz} + c.c.)\\ &= -4\varepsilon_0\omega_3d_{\text{eff}}(iE_1^*E_2^*E_3e^{-i\Delta kz} + c.c.) \end{align}$$ $$\therefore \frac{\mathrm{d}I_1}{\mathrm{d}z} + \frac{\mathrm{d}I_2}{\mathrm{d}z} + \frac{\mathrm{d}I_3}{\mathrm{d}z} = 4\varepsilon_0(\omega_1 + \omega_2 - \omega_3)d_{\text{eff}}(iE_1^*E_2^*E_3e^{-i\Delta kz} + c.c.)$$ $$\because I = I_1 + I_2 + I_3,\quad \omega_1 + \omega_2 = \omega_3$$ $$\therefore \frac{\mathrm{d}I}{\mathrm{d}z} = 0$$
