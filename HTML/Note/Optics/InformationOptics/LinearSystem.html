线性系统

系统

从数学上看，很多线性都可以抽象为：使函数\(f\)经过一定的变换，形成函数\(g\)的运算过程.

这种实现函数变换的运算过程称为系统.

这种意义下的系统，即可以是特定功能的元器件的组合，例如电子线路、光学透镜组等；也可以是与实际元件无关的物理现象，例如光波通过自由空间的传播过程等.

这样定义的系统的作用可由算符\(L\{\}\)表征，即：

$$g = L\{f\}$$

二维形式为：

$$g(x_2, y_2) = L\{f(x_1, y_1)\}$$
  • \(f\)：系统的输入函数
  • \(g\)：系统的输出函数

[注]在应用问题中，两个函数宗量的意义与量纲可以不同.

线性系统

[设]

$$g_1(x_2, y_2) = L\{f_1(x_1, y_1)\}$$ $$g_2(x_2, y_2) = L\{f_2(x_1, y_1)\}$$ 叠加性 $$L\{f_1(x_1, y_1) + f_2(x_1, y_1)\} = L\{f_1(x_1, y_1)\} + L\{f_2(x_1, y_1)\} = g_1(x_2, y_2) + g_2(x_2, y_2)$$ 均匀性 $$L\{af_1(x_1, y_1)\} = aL\{f_1(x_1, y_1)\} = ag_1(x_2, y_2),\quad a\in\mathbb{C}$$
线性系统

同时具有叠加性与均匀性的系统，即：

$$\begin{align} L\{a_1f_1(x_1, y_1) + a_2f_2(x_1, y_1)\} &= a_1L\{f_1(x_1, y_1)\} + a_2L\{f_2(x_1, y_1)\}\\ &= a_1g_1(x_2, y_2) + a_2g_2(x_2, y_2) \end{align}$$

上式表明，当输入函数是多个函数的线性组合时，该系统的输出函数，等于输入函数中各个函数单独输入时各对应输出函数的线性组合.

基元函数

在光学中，常用的基元函数基本上有两种：

  • 点基元函数（\(\delta\)函数）
  • 指数基元函数

点基元函数对应发光点，对应空域.

指数基元函数对应平面波，对应频域.

下面以点基元函数为例说明线性系统的分解与综合的过程.

任何输入函数\(f(x_1, y_1)\)可以很方便地分解成\(\delta\)函数的线性组合.

应用\(\delta\)函数的卷积性质，\(f(x_1, y_1)\)可以用\(delta\)函数表示为：

$$f(x_1, y_1) = \iint_{-\infty}^{+\infty} f(\alpha, \beta)\delta(x_1 - \alpha, y_1 - \beta)\mathrm{d}\alpha\mathrm{d}\beta$$

这个积分式可以看作是一种特殊的线性叠加：

当\(\alpha, \beta\)在整个物平面上取值时，上式是无穷多个不同位置的\(\delta\)函数\(\delta(x_1-\alpha, y_1-\beta)\)以\(f(\alpha,\beta)\mathrm{d}\alpha\mathrm{d}\beta\)为系数（权重）的线性叠加.

$$\begin{align}\therefore g(x_2, y_2) &= L\{f(x_1, y_1)\}\\ &= L\left\{\iint_{-\infty}^{+\infty}f(\alpha, \beta)\delta(x_1-\alpha, y_1-\beta)\mathrm{d}\alpha\mathrm{d}\beta\right\}\\ &= \iint_{-\infty}^{+\infty}f(\alpha, \beta)L\left\{\delta(x_1-\alpha, y_1-\beta)\right\}\mathrm{d}\alpha\mathrm{d}\beta\\ \end{align}$$

\(L\{\delta(x_1-\alpha, y_1-\beta)\}\)的物理意义为：

当物平面上位于\((x_1 = \alpha, y_1=\beta)\)点的单位脉冲（点光源）通过系统后在像面得到的分布.

称为脉冲响应函数或点扩散函数.

对于给定的光学系统，点扩散函数既与输入点脉冲的位置\(\alpha, \beta\)的位置有关，又与像点的位置\(x_2, y_2\)有关，因此其一般表示为：

$$h(x_2, y_2;\alpha, \beta) = L\{\delta(x_1-\alpha, y_1-\beta)\}$$ $$\therefore g(x_2, y_2) = \iint_{-\infty}^{+\infty}f(\alpha, \beta)h(x_2, y_2;\alpha, \beta)\mathrm{d}\alpha\mathrm{d}\beta$$

这个表达式称为叠加积分.

该式表明，线性系统的性质完全由它的脉冲响应\(h(x_2, y_2;\alpha,\beta)\)所表征.

对于一个脉冲响应已知的线性系统，任何输入函数对应的输出函数均可由叠加积分求得.

线性平移不变系统

[设]

一个系统与输入函数\(f(x_1, y_1)\)对应的输出函数为\(g(x_2, y_2)\).

当系统输入函数发生一个平移，即\(f(x_1, y_1)\to f(x_1-x_0, y_1-y_0)\)时，若系统相应的输出函数也只是平移，即\(g(x_2, y_2)\to g(x_2-Mx_0, y_2-My_0)\)，则称该系统具有平移不变性.

这里是针对空间平移说的，因此也称为空间平移不变性.

式中\(M\)为光学系统的垂轴放大率.

线性空间平移不变系统

既具有线性又具有空间平移不变性的系统.

简称线性平移不变系统或线性不变系统.

线性不变系统中的叠加积分写为：

$$g(x_2, y_2) = \iint_{-\infty}^{+\infty}f(\alpha, \beta)h(x_2-M\alpha, y_2-M\beta)\mathrm{d}\alpha\mathrm{d}\beta$$

若物平面与像平面的空间坐标取合适的标度，不难做到\(M=1\)，则：

$$\begin{align} g(x_2, y_2) &= \iint_{-\infty}^{+\infty}f(\alpha, \beta)h(x_2-\alpha, y_2-\beta)\mathrm{d}\alpha\mathrm{d}\beta\\ &= f(x_2, y_2)*g(x_2, y_2) \end{align}$$

为了在数学上为这种系统建立统一模型，对具有平移不变性的系统，还要求其输入函数与输出函数具有相同的宗量，即：

$$x=x_1,\quad y=y_1$$

从而对它们无需区分，统一用\((x,y)\)表示，对这种系统来说：

$$L\{f(x,y)\} = g(x,y)$$ $$L\{f(x-x_0, y-y_0)\} = g(x-x_0, y-y_0)$$ $$\begin{align}\therefore g(x,y) &= \iint_{-\infty}^{+\infty}f(\alpha)h(x-\alpha, y-\beta)\mathrm{d}\alpha\mathrm{d}\beta\\ &= f(x,y)*h(x,y) \end{align}$$

线性平移不变系统的传递函数

在应用问题中，一个系统的输入是空间函数\(f(x,y)\).

若\(f(x,y)\)的Fourier变换存在，且为：

$$F(\xi, \eta) = \iint_{-\infty}^{+\infty}f(x,y)\exp[-i2\pi(\xi x + \eta y)]\mathrm{d}x\mathrm{d}y$$
  • \(\xi,\eta\)：具有长度倒数的量纲，即具有空间频率的意义，即单位长度内变化的周数

上式的Fourier变换将空间函数\(f(x,y)\)转换为空间频谱函数\(F(\xi,\eta)\)，或者说空域与频域通过Fourier变换联系起来.

确定了\(\xi,\eta\)的频率意义后，再考察上式的Fourier逆变换：

$$f(x,y) = \iint_{-\infty}^{+\infty}F(\xi,\eta)\exp[i2\pi(\xi x + \eta y)]\mathrm{d}\xi\mathrm{d}\eta$$

上式表明：空间信号\(f(x,y)\)可以分解为具有不同空间频率\(\xi, \eta\)的基元函数\(e^{i2\pi(\xi x + \eta y)}\)的线性组合，\(F(\xi,\eta)\mathrm{d}\xi\mathrm{d}\eta\)就是这一线性组合中对应的基元函数的权重因子.

这就是除\(\delta\)函数外的第二种基元函数.

这里以\(e^{i2\pi(\xi x + \eta y)}\)为基元函数，意味着将一个空间信号分解成具有不同空间频率的周期函数的线性组合，各周期信号的权重为\(F(\xi,\eta)\mathrm{d}\xi\mathrm{d}\eta\).

显然，\(F(\xi,\eta)\)描述了空间信号\(f(x,y)\)中不同频率的基元函数的组成情况.

这里将频谱函数\(F(\xi,\eta)\)称为频谱密度（谱密度）.

对\(f(x,y),g(x,y),h(x,y)\)作Fourier变换，求出相应的频谱函数\(F(\xi,\eta),G(\xi,\eta),H(\xi,\eta)\)，利用Fourier变换的卷积定理，有：

$$G(\xi,\eta) = H(\xi,\eta)F(\xi,\eta)$$
$$\because g(x,y) = f(x,y)*h(x,y)$$ $$\therefore \mathcal{F}\{g(x,y)\} = \mathcal{F}\{f(x,y)*h(x,y)\}$$ $$\therefore G(\xi,\eta) = F(\xi,\eta)H(\xi,\eta)$$

上式与\(g(x,y) = f(x,y)*h(x,y)\)式一样，描述了系统对输入函数的变换作用，一个在频域，一个在空域.

当然，频域中的这种描述，仅对线性空不变系统成立.

由此可见，对于线性平移不变系统，可采用两种方法研究：

  • 在空域通过输入函数与脉冲响应函数的卷积直接求得输出函数.
  • 在空间频率域求输入函数与脉冲响应函数两者各自频谱密度的乘积，再对该乘积取Fourier逆变换求得输出函数.

从表面看，后一种方式包括正反两个变换与一个乘积运算，似乎比前一周方式更加复杂；然而通过利用Fourier变换性质与Fourier变换对偶表，或利用快速Fourier变换，常可以使Fourier变换、求积、Fourier逆变换这一运算过程远比卷积运算方便.

因此，从频域考察线性平移不变系统，不仅具有重要的理论意义，而且具有很高的实用价值.

传递函数

对系统作频谱分析，就是考察系统对输入函数中不同频率基元函数\(e^{i2\pi(\xi x + \eta y)}\)的作用.

这种作用应该表现为输出函数与输入函数中同一频率基元成分的权重的相对变化.

因此，用输出函数与输入函数两者频谱密度的比例\(G(\xi,\eta)/F(\xi,\eta)\)来表征系统的频率响应特性是合理的.

由上述分析可知，该比值恰为系统的原点脉冲响应的频谱密度\(H(\xi,\eta)\)，即：

$$H(\xi,\eta) = \frac{G(\xi,\eta)}{F(\xi,\eta)}$$

也就是说，原点脉冲响应的频谱密度可以表征系统对输入函数中不同频率的基元成分的传递能力.

因此,\(H(\xi,\eta)\)称为线性平移不变系统的传递函数.
