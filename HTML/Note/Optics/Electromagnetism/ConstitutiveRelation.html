本构关系

最简单的本构关系

Maxwell方程组定义了物质中的电荷与电流产生的场，但是它并不能描述这些电荷与电流是如何产生的.

为了求得电磁场的自洽解，必须用一些描述物质在场作用下特性的物质方程来补充Maxwell方程组.

这些物质方程（material equations）被称为本构关系（constitutive relations）.

物质方程

[设]一般情况下

$$\boldsymbol{D} = \epsilon_0\boldsymbol{E} + \boldsymbol{P}$$ $$\boldsymbol{B} = \mu_0(\boldsymbol{H} + \boldsymbol{M})$$ $$\boldsymbol{j} = \sigma\boldsymbol{E}$$

[设]无色散、线性、各向同性介质.

$$\boldsymbol{D} = \epsilon_0\epsilon_r\boldsymbol{E},\quad(\boldsymbol{P} = \epsilon_0\chi_e\boldsymbol{E})$$
$$\begin{align} \boldsymbol{D} &= \epsilon_0\boldsymbol{E} + \boldsymbol{P}\\ &= \epsilon_0\boldsymbol{E} + \epsilon_0\chi_e\boldsymbol{E}\\ &= \epsilon_0(1 + \chi_e)\boldsymbol{E} \end{align}$$

[令]

$$\epsilon_r = 1 + \chi_e$$ $$\therefore \boldsymbol{D} = \epsilon_0\epsilon_r\boldsymbol{E}$$
$$\boldsymbol{B} = \mu_0\mu_r\boldsymbol{H},\quad(\boldsymbol{M} = \chi_m\boldsymbol{H})$$
$$\begin{align} \boldsymbol{B} &= \mu_0(\boldsymbol{H} + \boldsymbol{M})\\ &= \mu_0(\boldsymbol{H} + \chi_m\boldsymbol{H})\\ &= \mu_0(1 + \chi_m)\boldsymbol{H} \end{align}$$

[令]

$$\mu_r = 1 + \chi_m$$ $$\therefore \boldsymbol{B} = \mu_0\mu_r\boldsymbol{H}$$
$$\boldsymbol{j}_c = \sigma\boldsymbol{E}$$
  • \(\boldsymbol{P}\)：极化强度
  • \(\boldsymbol{M}\)：磁化强度
  • \(\sigma\)：介质的电导率，各向同性均匀介质中\(\sigma = 0\)
  • \(\epsilon_0\)：真空介电常数
  • \(\mu_0\)：真空磁导率
