孤立导体的电容

孤立导体

附近无其他导体或带电体的导体.

$$C = \frac{q}{U}$$

C是与导体的尺寸与形状有关，与q、U无关的常量，称为孤立导体的电容.

其物理意义是使导体每升高单位电势所需的电荷量.

国际单位制中，电容的单位为法拉(法)，\(F = C/V\).

常用单位有：

$$1\mu F = 10^{-6}F$$ $$1pF = 10^{-12}F$$

平行板电容器

实际常用的绝大多数电容器可看作：两块彼此靠得很近的平行金属极板组成的平行板电容器.

设两块金属极板面积为\(S\)，内表面间距为\(d\).

在极板面的线度远大于其间距离（\(S\gg d^2\)）的情况下，除边缘部分外，情况与两极板为无限大时差不多.

此时两极板内表面均带电，极板间的电场是均匀的.

设两极板A、B的电荷量分别是\(\pm q\)，则电荷面密度分别为\(\pm\sigma_e = \pm q/S\)，故电场强度为\(E = \sigma_e/\epsilon_0\)，电势差为：

$$U_{AB} = \int_A^B \mathbf{E}\cdot\mathrm{d}\mathbf{l} = Ed = \frac{\sigma_ed}{\epsilon_0} = \frac{qd}{\epsilon_0S}$$ $$\therefore C_{AB} = \frac{q}{U_{AB}} = \frac{\epsilon_0S}{d}$$

对于电容器的电容，常略去下标AB不写，即：

$$C = \frac{\epsilon_0S}{d}$$

电容器的串并联

电容器的性能规格有两个主要指标：

  • 电容量
  • 耐压能力

使用电容器时，两极板所加电压不能超过所规定的耐压值，否则电容器内的电介质有被击穿的风险，即电介质失去绝缘作用，电容器损坏.

实际工作中，当遇到单独一个电容器在电容的数值或耐压能力方面不满足要求时，可以通过串联或并联多个电容器来达到所需的性能.

并联

电容器并联时，总电容等于各电容器电容之和.

$$C = C_1 + C_2 + \cdots + C_n$$

串联

电容器串联时，总电容的倒数等于各电容器电容的倒数之和.

$$\frac{1}{C} = \frac{1}{C_1} + \frac{1}{C_2} + \cdots + \frac{1}{C_n}$$
