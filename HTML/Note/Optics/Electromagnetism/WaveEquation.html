波动方程

非齐次波动方程

前置知识
  • Maxwell方程组
$$\nabla\times\nabla\times\boldsymbol{E} + \frac{1}{c^2}\frac{\partial^2 \boldsymbol{E}}{\partial t^2} = -\mu_0\frac{\partial}{\partial t}\left(\frac{\partial\boldsymbol{P}}{\partial t} + \boldsymbol{j} + \nabla\times\boldsymbol{M}\right)$$
$$\nabla\times\nabla\times\boldsymbol{E} = -\frac{\partial(\nabla\times\boldsymbol{B})}{\partial t}$$ $$\because\boldsymbol{B} = \mu_0(\boldsymbol{H} + \boldsymbol{M})$$ $$\begin{align} \nabla\times\nabla\times\boldsymbol{E} &= -\mu_0\frac{\partial}{\partial t}\left(\nabla\times\boldsymbol{H} + \nabla\times\boldsymbol{M}\right)\\ &= -\mu_0\frac{\partial}{\partial t}\left(\frac{\partial\boldsymbol{D}}{\partial t} + \boldsymbol{j} + \nabla\times\boldsymbol{M}\right)\\ &= -\mu_0\frac{\partial}{\partial t}\left(\epsilon_0\frac{\partial\boldsymbol{E}}{\partial t} + \frac{\partial\boldsymbol{P}}{\partial t} + \boldsymbol{j} + \nabla\times\boldsymbol{M}\right)\\ &= -\mu_0\frac{\partial}{\partial t}\left(\frac{\partial\boldsymbol{P}}{\partial t} + \boldsymbol{j} + \nabla\times\boldsymbol{M}\right) - \mu_0\epsilon_0\frac{\partial^2\boldsymbol{E}}{\partial t^2} \end{align}$$ $$\therefore \nabla\times\nabla\times\boldsymbol{E} + \mu_0\epsilon_0\frac{\partial^2\boldsymbol{E}}{\partial t^2} = -\mu_0\frac{\partial}{\partial t}\left(\frac{\partial\boldsymbol{P}}{\partial t} + \boldsymbol{j} + \nabla\times\boldsymbol{M}\right)$$
$$\nabla\times\nabla\times\boldsymbol{B} + \frac{1}{c^2}\frac{\partial^2\boldsymbol{B}}{\partial t^2} = \mu_0\nabla\times\left(\frac{\partial\boldsymbol{P}}{\partial t} + \boldsymbol{j} + \nabla\times\boldsymbol{M}\right)$$
$$\because\boldsymbol{B} = \mu_0(\boldsymbol{H} + \boldsymbol{M})$$ $$\begin{align} \nabla\times\nabla\times\boldsymbol{B} &= \mu_0\nabla\times\left(\nabla\times\boldsymbol{H} + \nabla\times\boldsymbol{M}\right)\\ &= \mu_0\nabla\times\left(\frac{\partial\boldsymbol{D}}{\partial t} + \boldsymbol{j} + \nabla\times\boldsymbol{M}\right)\\ &= \mu_0\nabla\times\left(\epsilon_0\frac{\partial\boldsymbol{E}}{\partial t} + \frac{\partial\boldsymbol{P}}{\partial t} + \boldsymbol{j} + \nabla\times\boldsymbol{M}\right)\\ &= \mu_0\nabla\times\left(\frac{\partial\boldsymbol{P}}{\partial t} + \boldsymbol{j} + \nabla\times\boldsymbol{M}\right) + \epsilon_0\mu_0\frac{\partial(\nabla\times\boldsymbol{E})}{\partial t}\\ \end{align}$$ $$\therefore \nabla\times\nabla\times\boldsymbol{B} + \frac{1}{c^2}\frac{\partial^2\boldsymbol{B}}{\partial t^2} = \mu_0\nabla\times\left(\frac{\partial\boldsymbol{P}}{\partial t} + \boldsymbol{j} + \nabla\times\boldsymbol{M}\right)$$

[令]

$$\boldsymbol{j} = \boldsymbol{j}_s + \boldsymbol{j}_c$$ $$\boldsymbol{j}_{tot} = \boldsymbol{j}_s + \boldsymbol{j}_c + \frac{\partial\boldsymbol{P}}{\partial t} + \nabla\times\boldsymbol{M}$$
  • \(\boldsymbol{j}_{tot}\)：总电流密度
  • \(\boldsymbol{j}_s\)：源电流密度
  • \(\boldsymbol{j}_c\)：感生传导电流密度
  • \(\frac{\partial\boldsymbol{P}}{\partial t}\)：极化电流密度
  • \(\nabla\times\boldsymbol{M}\)：磁化电流密度

波动方程

$$\nabla^2\boldsymbol{E} - \frac{1}{v^2}\frac{\partial\boldsymbol{E}}{\partial t} = 0$$ $$\nabla^2\boldsymbol{B} - \frac{1}{v^2}\frac{\partial\boldsymbol{B}}{\partial t} = 0$$

用单一的一个标量波动方程就可以概括\(\boldsymbol{E}\)和\(\boldsymbol{H}\)中所有分量的行为：

$$\nabla^2u(Q, t) - \frac{n^2}{c^2}\frac{\partial^2 u(Q, t)}{\partial t^2} = 0$$
  • \(\nabla^2\)：Laplace算子
  • \(u(Q, t)\)：任何标量场分量
  • \(Q\)：空间位置
  • \(t\)：时间
