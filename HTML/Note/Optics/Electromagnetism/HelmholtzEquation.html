Helmholtz方程

Helmholtz方程就是波动方程在“单频简谐场”条件下的频域形式.

$$\nabla^2 \boldsymbol{E} + k^2n^2\boldsymbol{E} + \nabla\left(\boldsymbol{E} \cdot \frac{\nabla\epsilon}{\epsilon}\right) = 0$$ $$\nabla^2 \boldsymbol{H} + k^2n^2\boldsymbol{H} + \frac{\nabla\epsilon}{\epsilon}\times(\nabla\times\boldsymbol{H}) = 0$$

单色光波场中任一点\(P\)的光振动\(u\)应满足标量波动方程：

$$\nabla^2u - \frac{1}{c^2}\frac{\partial^2 u}{\partial t^2} = 0$$
  • \(\nabla^2\)：拉普拉斯算子

实扰动\(u\)又可以表示为：

$$u(P, t) = \text{Re}\{U(P)e^{i2\pi\nu t}\}$$

将其代入上式，可得不含时间的方程：

$$(\nabla^2 + k^2)U(P) = 0$$
  • \(k\)：波数

上式即为Helmholtz方程，可以将其视作自由空间传播的单色光扰动的复振幅必须满足的波动方程.

对于单色光场来说，标量波动方程与Helmholtz方程是等价的.

标量波动方程同时存在时间与空间变量，而Helmholtz方程只包含空间变量，因此在求解单色光场的空间分布时，Helmholtz方程更为方便.

$$(\nabla^2 + k_i^2)\boldsymbol{E}_i = -i\omega\mu_0\mu_i\boldsymbol{j}_i + \frac{\nabla\rho_i}{\epsilon_0\epsilon_i}$$ $$(\nabla^2 + k_i^2)\boldsymbol{H}_i = -\nabla\times\boldsymbol{j}_i$$
变系数Helmholtz方程 $$\nabla^2\boldsymbol{E} + k_0^2n^2(\boldsymbol{r})\boldsymbol{E} = 0$$ $$\nabla^2\boldsymbol{H} + k_0^2n^2(\boldsymbol{r})\boldsymbol{H} = 0$$
