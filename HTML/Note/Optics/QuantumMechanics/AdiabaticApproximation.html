绝热近似

绝热定理

绝热近似最基本的内容可以表述为绝热定理.

绝热定理

[设]Hamiltonian量由初值\(H^i\)逐渐变化到终值\(H^f\).

[设]从\(H^i\)到\(H^f\)的演化过程中谱是分立的且不简并，这样态的次序就不会混淆.

若粒子开始时处于\(H^i\)的第\(n\)阶本征态，它将按Scrödinger方程演化\(H^f\)的第\(n\)阶本征态.

第\(n\)阶本征态就是指能量为\(E_n\)的那个本征态.

演化就是指变化到.

绝热定理的证明

Hamiltonian量不依赖时间的情况

此时，在开始时满足：

$$H\psi_n = E_n\psi_n$$
$$H\Psi = E_n\Psi$$ $$H\psi\phi = E_n\psi\phi$$ $$\because \phi = e^{-iEt/\hbar}$$ $$\therefore H\psi_n = E_n\psi_n$$

第\(n\)本征态\(\psi_n\)的一个粒子以后将仍处在第\(n\)本征态，只是具有了一个相因子：

$$\Psi_n(t) = \psi_n e^{-iE_nt/h}$$
这个相因子是在任何一个n阶本征态都存在的.

Hamiltonian量随时间变化的情况

此时，本征函数与本征值也随时间变化：

$$H(t)\psi_n(t) = E_n(t)\psi_n(t)$$

这里的\(\psi_n(t)\)并不包含\(\phi(t)\)，它是另一种形式的随时间变化.

但它们在任何瞬间仍构成正交归一集：

$$\left\langle\psi_n(t)\middle|\psi_m(t)\right\rangle = \delta_{mn}$$

且它们是完备的，因此含时Scrödinger方程：

$$i\hbar\frac{\partial}{\partial t}\Psi(t) = H(t)\Psi(t)$$

的一般解可以表示为它们的线性叠加：

$$\Psi(t) = \sum_n c_n(t)\psi_n(t)e^{i\theta_n(t)}$$

式中：

$$\theta_n(t) = -\frac{1}{\hbar}\int_0^t E_n(t')\mathrm{d}t'$$

这是将标准含时相位因子推广到\(E_n\)随时间变化的情况.

通常这个因子可以包含在\(c_n(t)\)中，但由于它在Hamiltonian量不含时时也同样存在，因此单独写出.

将

$$\Psi(t) = \sum_n c_n(t)\psi_n(t)e^{i\theta_n(t)}$$

代入到

$$i\hbar\frac{\partial}{\partial t}\Psi(t) = H(t)\Psi(t)$$ $$\therefore i\hbar\sum_n\left(\frac{\partial c_n}{\partial t}\psi_ne^{i\theta_n} + \frac{\partial \psi_n}{\partial t}c_ne^{i\theta_n} + \frac{\mathrm{d}\theta_n}{\mathrm{d}t}ic_n\psi_ne^{i\theta_n}\right) = \sum_n c_n H\psi_n e^{i\theta_n}$$

由积分上限函数：

$$\because\theta_n(t) = -\frac{1}{\hbar}\int_0^t E_n(t')\mathrm{d}t'$$ $$\frac{\mathrm{d}\theta_n}{\mathrm{d}t} = -\frac{1}{\hbar}E_n(t)$$ $$\because H(t)\psi_n(t) = E_n(t)\psi_n(t)$$ $$\therefore i\hbar\sum_n\left(\frac{\partial c_n}{\partial t}\psi_n + \frac{\partial \psi_n}{\partial t}c_n\right)e^{i\theta_n} + \sum_nE_nc_n\psi_ne^{i\theta_n} = \sum_n c_n E_n\psi_n e^{i\theta_n}$$ $$\therefore \sum_n\frac{\partial c_n}{\partial t}\psi_ne^{i\theta_n} = -\sum_n\frac{\partial\psi_n}{\partial t}c_ne^{i\theta_n}$$

对\(\psi_n\)取与\(\psi_m\)的内积：

$$\sum_n\frac{\partial c_n}{\partial t}\left\langle\psi_m\middle|\psi_n\right\rangle e^{i\theta_n} = -\sum_n\left\langle\psi_m\middle|\frac{\partial\psi_n}{\partial t}\right\rangle c_ne^{i\theta_n}$$ $$\because \left\langle\psi_m\middle|\psi_n\right\rangle = \delta_{mn}$$ $$\therefore\sum_n\frac{\partial c_n}{\partial t}\delta_{mn}e^{i\theta_n} = -\sum_n\left\langle\psi_m\middle|\frac{\partial\psi_n}{\partial t}\right\rangle c_ne^{i\theta_n}$$ $$\because\sum_n\frac{\partial c_n}{\partial t}\delta_{mn}e^{i\theta_n} = \frac{\partial c_m}{\partial t}e^{i\theta_m}$$ $$\therefore\frac{\partial c_m}{\partial t}e^{i\theta_m} = -\sum_n\left\langle\psi_m\middle|\frac{\partial\psi_n}{\partial t}\right\rangle c_ne^{i\theta_n}$$ $$\therefore\frac{\partial c_m}{\partial t} = -\sum_n\left\langle\psi_m\middle|\frac{\partial\psi_n}{\partial t}\right\rangle c_ne^{i(\theta_n-\theta_m)}$$

将

$$H(t)\psi_n(t) = E_n(t)\psi_n(t)$$

对时间求微分：

$$\frac{\partial H}{\partial t}\psi_n + \frac{\partial \psi_n}{\partial t}H = \frac{\partial E_n}{\partial t}\psi_n + \frac{\partial \psi_n}{\partial t}E_n$$

取与\(\psi_m\)的内积：

$$\left\langle\psi_m\middle|\frac{\partial H}{\partial t}\middle|\psi_n\right\rangle + \left\langle\psi_m\middle|H\middle|\frac{\partial \psi_n}{\partial t}\right\rangle = \frac{\partial E_n}{\partial t}\delta_{mn} + E_n\left\langle\psi_n\middle|\psi_m\right\rangle$$

利用\(H\)的Hermitian性：

$$\left\langle\psi_m\middle|H\middle|\frac{\partial\phi_n}{\partial t}\right\rangle = E_m\left\langle\phi_m\middle|\frac{\partial\psi_n}{\partial t}\right\rangle$$

在\(n\neq m\)时：

$$\left\langle\psi_m\middle|\frac{\partial H}{\partial t}\middle|\psi_n\right\rangle = (E_n-E_m)\left\langle\psi_n\middle|\psi_m\right\rangle$$

设能级不能简并，将上式代入到：

$$\frac{\partial c_m}{\partial t} = -\sum_n\left\langle\psi_m\middle|\frac{\partial\psi_n}{\partial t}\right\rangle c_ne^{i(\theta_n-\theta_m)}$$ $$\therefore\frac{\partial c_m}{\partial t} = -c_m\left\langle\psi_m\middle|\frac{\partial\phi_m}{\partial t}\right\rangle -\sum_{n\neq m}\frac{\left\langle\psi_m\middle|\frac{\partial H}{\partial t}\middle|\psi_n\right\rangle}{E_n-E_m}e^{(-i/\hbar)\int_0^t[E_n(t')-E_m(t')]\mathrm{d}t'}$$

这个结果是精确的.

回到绝热近似：设\(\frac{\partial H}{\partial t}\)非常小，舍弃上式第二项（这步的严格证明非常复杂）：

$$\therefore\frac{\partial c_m}{\partial t} = -c_m\left\langle\psi_m\middle|\frac{\partial\phi_m}{\partial t}\right\rangle$$

解得：

$$c_m(t) = c_m(0)e^{i\gamma_m(t)}$$

其中：

$$\gamma_m(t)\equiv i\int_0^t\left\langle\psi_m(t')\middle|\frac{\partial}{\partial t'}\psi_m(t')\right\rangle\mathrm{d}t'$$

特别地，若粒子开始时处于第\(n\)本征态，即：

$$c_n(0) = 1, c_m(0) = 0, m\neq n$$

则：

$$\begin{align} \Psi(t) &= \sum_n c_n(t)\psi_n(t)e^{i\theta_n(t)}\\ &= e^{i\theta_n(t)t}e^{i\gamma_n(t)}\psi_n(t) \end{align}$$

因此它仍处于演化Hamiltonian量的第n本征态，仅仅添加了一对相因子.
