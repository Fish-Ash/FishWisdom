自旋

自旋

经典力学中，一个刚性物体具有两种角动量：

  • 轨道角动量\(\boldsymbol{L} = \boldsymbol{r}\times\boldsymbol{p}\)：物体质心相对原点的运动
  • 自旋\(\boldsymbol{S} = I\boldsymbol{\omega}\)：物体绕质心的运动

自旋的代数理论与轨道角动量的极其相似，由基本对易关系：

$$\left[\hat S_x, \hat S_y\right] = i\hbar\hat S_z$$ $$\left[\hat S_y, \hat S_z\right] = i\hbar\hat S_x$$ $$\left[\hat S_z, \hat S_x\right] = i\hbar\hat S_y$$

自旋与轨道角动量的代数理论相似性就体现在它们都满足角动量基本对易关系.

自旋的基本对易关系不好证明，一般是通过轨道角动量的基本对易关系建立的.

  • \(s\)：自旋（角量子数）
  • \(m\)：（自旋）磁量子数

可以得出\(S^2\)与\(S_z\)的本征矢满足：

$$\hat S^2\left|s,m\right\rangle = \hbar^2 s(s+1)\left|s,m\right\rangle$$ $$\hat S_z\left|s,m\right\rangle = \hbar m\left|s,m\right\rangle$$

[注]由于自旋的本征态不是函数，因此使用右矢\(\left\lvert s,m\right\rangle\)标记.

本征态不一定用函数表示，也可以用向量表示.

[令]

$$S_\pm = S_x\pm iS_y$$ $$\hat S_\pm\left|s,m\right\rangle = \hbar\sqrt{s(s+1)-m(m\pm1)}\left|s,m\pm1\right\rangle$$

\(m\)所有可能的取值为：

$$m = -s, -s+1, \cdots, s-1, s$$
自旋\(s\)

每一种基本粒子都有一个特定的永远不变的\(s\)，称为该种粒子的自旋.

粒子 自旋\(s\)
\(\pi\)介子 0
质子、电子、中子、夸克、轻子 1/2
光子 1
\(\Delta\)粒子 3/2
引力子 2

自旋1/2

\(s = 1/2\)是构成普通物质的例子（质子、中子和电子）的自旋，以及所有夸克和所有轻子的自旋.

掌握自旋1/2更容易理解高自旋.

对于\(s=1/2\)，\(\hat S^2\)与\(\hat S_z\)仅有两个本征态：

  • 上自旋态\(\uparrow\)：\(\left|\frac{1}{2}, \frac{1}{2}\right\rangle\)
  • 下自旋态\(\downarrow\)：\(\left|\frac{1}{2}, -\frac{1}{2}\right\rangle\)

利用这两个基矢量，一个自旋\(1/2\)粒子的一般态可以表示为一个二元列矩阵或旋量：

一般态指系统所有可能的量子态中的任意一个状态.

$$\chi = \left(\begin{matrix}a\\b\end{matrix}\right) = a\chi_+ + b\chi_-$$
  • \(\chi_+ = \left(\begin{matrix}1\\0\end{matrix}\right)\)：代表上自旋
  • \(\chi_- = \left(\begin{matrix}0\\1\end{matrix}\right)\)：代表下自旋
  • \(|a|^2\)：上自旋的概率
  • \(|b|^2\)：下自旋的概率

自旋1/2的本征态在\(S_z\)表象下一定是一个2x1矩阵.

因此自旋算符一定是2x2矩阵.

自旋算符成为\(2\times2\)矩阵，具体表示可由它们对\(\chi_+\)和\(\chi_-\)作用的结果写出.

$$\begin{align} \boldsymbol{S}^2\chi_+ = \frac{3}{4}\hbar^2\chi_+\\ \boldsymbol{S}^2\chi_- = \frac{3}{4}\hbar^2\chi_- \end{align}\Rightarrow \boldsymbol{S}^2 = \frac{3}{4}\hbar^2\left(\begin{matrix}1&0\\0&1\end{matrix}\right)$$

将\(\boldsymbol{S}^2\)写成矩阵元待定的矩阵：

$$\boldsymbol{S}^2 = \left(\begin{matrix}c&d\\e&f\end{matrix}\right)$$ $$\because\boldsymbol{S}^2\chi_+ = \frac{3}{4}\hbar^2\chi_+$$ $$\therefore \left(\begin{matrix}c&d\\e&f\end{matrix}\right)\left(\begin{matrix}1\\0\end{matrix}\right) = \frac{3}{4}\hbar^2\left(\begin{matrix}1\\0\end{matrix}\right)$$ $$\therefore \left(\begin{matrix}c\\e\end{matrix}\right) = \left(\begin{matrix}\frac{3}{4}\hbar^2\\0\end{matrix}\right)$$ $$\because\boldsymbol{S}^2\chi_- = \frac{3}{4}\hbar^2\chi_-$$ $$\therefore \left(\begin{matrix}c&d\\e&f\end{matrix}\right)\left(\begin{matrix}0\\1\end{matrix}\right) = \frac{3}{4}\hbar^2\left(\begin{matrix}0\\1\end{matrix}\right)$$ $$\therefore \left(\begin{matrix}d\\f\end{matrix}\right) = \left(\begin{matrix}0\\\frac{3}{4}\hbar^2\end{matrix}\right)$$ $$\therefore \boldsymbol{S}^2 = \frac{3}{4}\hbar^2\left(\begin{matrix}1&0\\0&1\end{matrix}\right)$$
$$\begin{align} \boldsymbol{S}_z\chi_+ = \frac{1}{2}\hbar\chi_+\\ \boldsymbol{S}_z\chi_- = \frac{1}{2}\hbar\chi_- \end{align}\Rightarrow \boldsymbol{S}_z = \frac{1}{2}\hbar^2\left(\begin{matrix}1&0\\0&-1\end{matrix}\right)$$
$$\begin{align} &\boldsymbol{S}_+\chi_+ = 0\\ &\boldsymbol{S}_+\chi_- = \hbar\chi_+ \end{align}\Rightarrow \boldsymbol{S}_+ = \hbar\left(\begin{matrix}0&1\\0&0\end{matrix}\right)$$
$$\sqrt{s(s+1) - m(m+1)}\rvert_{s=1/2, m=1/2} = 0$$ $$\sqrt{s(s+1) - m(m+1)}\rvert_{s=1/2, m=-1/2} = 1$$
$$\begin{align} &\boldsymbol{S}_-\chi_- = 0\\ &\boldsymbol{S}_-\chi_+ = \hbar\chi_+ \end{align}\Rightarrow \boldsymbol{S}_- = \hbar\left(\begin{matrix}0&0\\1&0\end{matrix}\right) $$ $$\because S_\pm = S_x\pm iS_y$$ $$\therefore S_x = \frac{1}{2}(S_++S_-),\quad S_y = -\frac{i}{2}(S_+-S_-)$$ $$\boldsymbol{S}_x = \frac{1}{2}\hbar\left(\begin{matrix}0&1\\1&0\end{matrix}\right)$$ $$\boldsymbol{S}_y = \frac{1}{2}\hbar\left(\begin{matrix}0&-i\\i&0\end{matrix}\right)$$

\(\boldsymbol{S}\)可以更简洁地表示为：

$$\boldsymbol{S} = \frac{\hbar}{2}\boldsymbol{\sigma}$$

其中：

$$\sigma_x\equiv \left(\begin{matrix}0&1\\1&0\end{matrix}\right),\quad \sigma_y\equiv \left(\begin{matrix}0&-i\\i&0\end{matrix}\right),\quad \sigma_x\equiv \left(\begin{matrix}1&0\\0&-1\end{matrix}\right)$$

这就是Pauli自旋矩阵.

\(\boldsymbol{S}_x,\boldsymbol{S}_y,\boldsymbol{S}_z,\boldsymbol{S}^2\)是厄密矩阵（因为它们都是可观测量）.

\(\boldsymbol{S}_+\boldsymbol{S}_-\)是非厄密的（都是不可观测量）.
