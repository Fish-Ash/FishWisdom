自旋

自旋

经典力学中，一个刚性物体具有两种角动量：

  • 轨道角动量\(\boldsymbol{L} = \boldsymbol{r}\times\boldsymbol{p}\)：物体质心相对原点的运动
  • 自旋\(\boldsymbol{S} = I\boldsymbol{\omega}\)：物体绕质心的运动

自旋的代数理论与轨道角动量的极其相似，由基本对易关系：

$$\left[S_x, S_y\right] = i\hbar S_z$$ $$\left[S_y, S_z\right] = i\hbar S_x$$ $$\left[S_z, S_x\right] = i\hbar S_y$$

自旋与轨道角动量的代数理论相似性就体现在它们都满足角动量基本对易关系.

这个基本对易关系同样也是由量子力学得出的内容.

可以得出\(S^2\)与\(S_z\)的本征矢满足：

$$S^2\left|s,m\right\rangle = \hbar^2 s(s+1)\left|s,m\right\rangle$$ $$S_z\left|s,m\right\rangle = \hbar m\left|s,m\right\rangle$$

及：

$$S_\pm\left|s,m\right\rangle = \hbar\sqrt{s(s+1)-m(m\pm1)}\left|s,m\pm1\right\rangle$$
自旋\(s\)

每一种基本粒子都有一个特定的永远不变的\(s\)，称为该种粒子的自旋.

粒子 自旋\(s\)
\(\pi\)介子 0
质子、电子、中子、夸克、轻子 1/2
光子 1
\(\Delta\)粒子 3/2
引力子 2

自旋1/2

\(s = 1/2\)是构成普通物质的例子（质子、中子和电子）的自旋，以及所有夸克和所有轻子的自旋.

掌握自旋1/2更容易理解高自旋.

对于\(s=1/2\)，\(S^2\)与\(S_z\)仅有两个本征态：

\(S^2\)与\(S_z\)都是矢量算符.

  • 上自旋态\(\uparrow\)：\(\left|\frac{1}{2}, \frac{1}{2}\right\rangle\)
  • 下自旋态\(\downarrow\)：\(\left|\frac{1}{2}, \frac{1}{2}\right\rangle\)

下自旋态应该是\(\left|\frac{1}{2}, -\frac{1}{2}\right\rangle\)，这里应该是笔误.

利用这两个基矢量，一个自旋\(1/2\)粒子的一般态可以表示为一个二元列矩阵或旋量：

一般态指系统所有可能的量子态中的任意一个状态.

$$\chi = \left(\begin{matrix}a\\b\end{matrix}\right) = a\chi_+ + b\chi_-$$
  • \(\chi_+ = \left(\begin{matrix}1\\0\end{matrix}\right)\)：代表上自旋
  • \(\chi_- = \left(\begin{matrix}0\\1\end{matrix}\right)\)：代表下自旋
