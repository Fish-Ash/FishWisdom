Hermitian算符

Hermitian算符

一个可观测量\(Q(x,p)\)的期望可以用内积符号简洁表示：

$$\langle Q\rangle = \int\psi^*\hat Q\psi\mathrm{d}x = \langle\psi\lvert\hat{Q}\psi\rangle,\quad Q\in\mathbb{R}\Rightarrow \langle Q\rangle\in\mathbb{R}$$ 性质
$$\langle\psi\lvert\hat{Q}\psi\rangle = \langle\hat{Q}\psi\lvert\psi\rangle$$
$$\because \langle Q\rangle \in \mathbb{R}$$ $$\therefore \langle Q\rangle = \langle Q\rangle ^*$$ $$\therefore \langle\psi\lvert\hat{Q}\psi\rangle = \langle\psi\lvert\hat{Q}\psi\rangle ^*$$ $$\because \langle g\lvert f\rangle = \langle f\lvert g\rangle ^*$$ $$\therefore \langle\psi\lvert\hat{Q}\psi\rangle = \langle\psi\lvert\hat{Q}\psi\rangle ^* = \langle\hat{Q}\psi\lvert\psi\rangle$$

上式对任意波函数成立，因此表示可观测量的算符具有特殊的性质：

$$\langle f\lvert\hat{Q}f\rangle = \langle\hat{Q}f\lvert f\rangle$$

对任意\(f(x)\)成立.

[延伸]

$$\langle f\lvert\hat{Q}g\rangle = \langle\hat{Q}f\lvert g\rangle$$

对任意\(f(x)\)与\(g(x)\)成立.

Hermitian算符指满足上述条件的\(\hat Q\).

可观测量的算符一定是Hermitian算符.

Hermitian算符不一定都是可观测量的算符.

定值态（determinate State）

量子力学中的不确定性

当对全同体系组成的系综测量一个可观测量Q，每个体系都处于相同的状态\(\Psi\)，每次测量并不能得到相同的结果.

“全同体系”通常指由全同粒子组成的量子系统，也就是这些粒子具有完全相同的内禀属性，例如质量、电荷和自旋，并且在量子力学中原则上不可相互区分.

具有这样性质的量子系统在宏观体系上不一定是完全相同的.

可观测量Q的定值态

可以使每次观测Q都得到相同值q的态.

Hamiltonian的定态是定值态：

测量一个粒子处于定态\(\Psi_n\)时的总能量，测得值总是\(E_n\)

定值态下\(Q\)的标准差总为0：

$$\sigma^2 = \left\langle\left(\hat{Q} - \langle Q\rangle\right)^2\right\rangle = \left\langle\Psi\middle|\left(\hat{Q} - q\right)^2\Psi\right\rangle = \left\langle\left(\hat{Q} - q\right)\Psi\middle|\left(\hat{Q} - q\right)\Psi\right\rangle = 0$$ 算符\(\hat{Q}\)的本征值方程

$$\hat{Q}\Psi = q\Psi$$

  • \(\Psi\)：\(\hat{Q}\)的一个本征函数
  • \(q\)：相应的本征值，是一个数

定值态是\(\hat{Q}\)的本征函数.

在定值态上测量\(Q\)一定能得到本征值\(q\).

任何本征函数乘一个常数，依旧是一个具有相同本征值的本征函数.

[注]0不可作本征函数（否则由\(\hat Q 0 = q0\)，任何\(q\)都将成为本征值），但可做本征值.

谱

一个算符的所有本征值的集合称为这个算符的谱.

谱的简并

两个或多个线性独立的本征函数具有相同的本征值的情况.

总能量的定值态是Hamiltonian算符的本征函数（定态Schrödinger方程）：

$$\hat H\psi = E\psi$$
  • \(E\)：本征值
  • \(\psi\)：本征函数
$$\hat H\psi e^{-iEt/\hbar} = E\psi e^{-iEt/\hbar}\Rightarrow \hat H\Psi = E\Psi$$

仍是\(H\)的本征函数.

Hermitian算符的本征函数

Hermitian算符的本征函数就是物理上可观测的定值态.

分成两种情况讨论：

  • 分立谱
  • 连续谱

分立谱

本征值是分开的，则本征函数处于Hilbert空间中，且构成物理上可实现的态.

数学上，Hermitian算符可归一化的本征函数具有两个重要性质：

性质1

其本征值为实数.

[设]

$$\hat{Q}f = qf$$
  • \(\hat{Q}\)：Hermitian算符
  • \(q\)：\(\hat{Q}\)的本征值
  • \(f(x)\)：\(\hat{Q}\)的本征函数

由于\(\hat{Q}\)为Hermitian算符，故：

$$\langle f\lvert\hat{Q}f\rangle = \langle \hat{Q}f\lvert f\rangle$$

假定本征函数位于Hilbert空间内，否则内积不可能存在.

为什么是假定？

$$\therefore \int f^*qf\mathrm{d}x = \int q^*f^*f\mathrm{d}x$$

\(q\)与\(q^*\)是常数，因此可以移出积分外.

$$\therefore q\langle f|f\rangle = q^*\langle f|f\rangle$$ $$\because \langle f|f\rangle\neq 0$$

因为\(f(x) = 0\)不是正当的本征函数.

$$\therefore q = q^*$$ $$\therefore q\in\mathbb{R}$$

[注]这个结果表明，如果对粒子的一个定值态测量一个可观测值，至少会得到一个实数.

为什么是“至少”？

性质2

属于不同本征值的本征函数是正交的

[设]

$$\hat{Q}f = q_1f$$ $$\hat{Q}g = q_2g$$ $$\because \left\langle f\middle|\hat{Q}g\right\rangle = \left\langle \hat{Q}f\middle|g\right\rangle$$ $$\therefore \int f^*q_1g\mathrm{d}x = \int q_2^*f^*g\mathrm{d}x$$ $$\therefore q_1\left\langle f\middle|g\right\rangle = q_2^*\left\langle f\middle|g\right\rangle$$

（内积的存在是因为假定本征函数位于Hilbert空间内）

$$\because q_1\neq q_2$$ $$\therefore \left\langle f\middle|g\right\rangle = 0$$

连续谱

本征值充满一个范围，则本征函数是不可归一化的，且它们不能代表可能的波函数.

广义统计诠释

若测量一个处于\(\Psi(x,t)\)态的可观测量\(Q(x,p)\)，那么其结果一定是Hermitian算符\(\hat{Q}(x,-i\mathrm{d}\hbar/\mathrm{d}x)\)的一个本征值.

若\(\hat{Q}\)的谱是分立的，得到与正交归一本征函数\(f_n(x)\)相应的本征值\(q_n\)的几率是：

$$|c_n|^2,\quad c_n = \left\langle f_n\middle|\Psi\right\rangle$$
