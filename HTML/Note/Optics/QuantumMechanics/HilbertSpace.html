Hilbert空间

Hilbert空间简介及一些运算

Hilbert空间

所有在特定区域的平方可积函数的集合构成的一个非常小的矢量空间.

$$\left\{f(x)\middle|\int_a^b|f(x)|^2\mathrm{d}x \lt \infty\right\}$$

数学上，称此矢量空间为\(L_2(a,b)\).

通常情况下，\(a = -\infty\)，\(b = +\infty\).

Hilbert空间中的矢量并不一定都是量子态，但所有物理上可实现的量子纯态，都对应与Hilbert空间中的某个向量.

从抽象的代数意义上看，任何一个函数都可以表示为向量（高等代数、泛函分析）

一个完整的矢量空间缺乏内积.

N维空间中，可以简单地用对应于N个正交归一基矢的分量\(\{a_n\}\)的一个N行列矩阵表示一个矢量\(\lvert\alpha\rangle\)：

$$\lvert\alpha\rangle \rightarrow \boldsymbol{a} = \left[\begin{matrix}a_1\\a_2\\\vdots\\a_N\end{matrix}\right]$$

\(\lvert\alpha\rangle\)：抽象矢量，选定一组基后，可以将其表示为\(\boldsymbol{a}\)的形式.

量子态在数学情景下用抽象矢量表示，这就是引入Hilbert空间的意义.

矢量内积

两个矢量的内积（三维空间标量积的推广）\(\langle\alpha\lvert\beta\rangle\)为一个复数：

$$\langle\alpha\lvert\beta\rangle = a_1^*b_1 + a_2^*b_2 + \cdots + a_N^*b_N$$

量子力学中，波函数是处于Hilbert空间中的.

线性变换

线性变换\(T\)用矩阵（相应指定的基矢）表示，通过普通的矩阵乘法规则作用于矢量上，得到新矢量：

$$\lvert\beta\rangle = T\lvert\alpha\rangle \rightarrow\boldsymbol{b} = \boldsymbol{T}\boldsymbol{a} = \left[\begin{matrix}t_{11}&t_{12}&\cdots&t_{1N}\\t_{21}&t_{22}&\cdots&t_{2N}\\\vdots&\vdots&&\vdots\\t_{N1}&t_{N2}&\cdots&t_{NN}\end{matrix}\right]\left[\begin{matrix}a_1\\a_2\\\vdots\\a_N\end{matrix}\right]$$

函数内积

定义两个函数\(f(x)\)与\(g(x)\)的内积为：

$$\langle f\lvert g\rangle = \int_a^bf^*(x)g(x)\mathrm{d}x$$

若两个函数都是平方可积的（即两个函数均存在于Hilbert空间中），则其内积必定存在（上式中的积分收敛于一有限值）.

这一结论可由Schwarz不等式推出.

性质 $$\langle g\lvert f\rangle = \langle f\lvert g\rangle^*$$

绝大多数情况下，在量子力学中我们遇到的矢量是函数，它们存在于无穷维空间中.

对于它们，用\(N\)行列矩阵/矩阵的方法有些笨拙，以及在有限维下很好行为的矩阵乘法可能存在问题.

比如，对于内积，有限求和总是存在的，但无限求和或积分可能不收敛，这种情况下内积将不存在，那么涉及到内积的任何论述都将出现问题.

Hilbert空间下函数的关系

归一化函数

若一个函数与其自身内积为1，称之为归一化的.

正交函数

若两个函数内积为0，称其为正交的.

正交归一函数

若一组函数之间是正交的，本身又是归一化的，称其为正交归一的.

$$\left\langle f_m\middle|f_n\right\rangle = \delta_{mn}$$

完备函数

若存在一组函数，Hilbert空间中的任意其他函数都可以表示为这组函数的线性叠加，称这组函数为完备的.

$$f(x) = \sum_{n=1}^\infty c_nf_n(x)$$
