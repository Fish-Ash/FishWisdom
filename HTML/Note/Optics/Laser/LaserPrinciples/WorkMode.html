连续与脉冲工作方式

激光器按器泵浦方式，可分为连续（CW）激光器与脉冲激光器.

激光器的工作方式主要由泵浦速率的时间决定：

  • 连续方式：时间无限延伸时泵浦速率原则上均不为0.
  • 脉冲方式：泵浦速率仅在某一（些）时段取非0值.
    • 单脉冲方式：泵浦速率仅在某一时段取非0值.
    • 相同周期重复频率：取非0值的时段周期性重复.

什么叫“泵浦速率”？

泵浦速率

单位时间内，泵浦过程把多少粒子从低能级激发到高能级.

连续激光器与脉冲激光器的区别

以三能级红宝石系统的激励过程为例，说明连续激光器与脉冲激光器的本质区别.

考虑一种简化情况：粒子数密度为\(n\)的红宝石被一个矩形脉冲激励光照射时，基态E1上的粒子被抽运到E3能级的激励概率\(W_{13}(t)\)如图所示：

$$W_{13}(t) = \begin{cases} W_{13} & 0 \lt t \leq t_0 \\ 0 & t > t_0 \end{cases}$$

由此得出的结论对其他情况也是适用的.

对于\(t_0\rightarrow\infty\)的情况，为CW工作.

\(W_{13}\)非0时段为\(t_i\lt t\lt t_i+T\)时，为重复频率工作.

典型的三能级系统，\(E_3\)近似为空能级：

$$n_3\approx 0$$ $$\frac{\mathrm{d}n_3}{\mathrm{d}t}\approx 0$$

假定激光器工作在阈值附近，则受激辐射很弱，则：

$$\frac{\mathrm{d}n_2}{\mathrm{d}t} = -(\tau_2^{-1}+\eta_1W_{13})n_2+\eta_1nW_{13}$$

上式为一阶非齐次常微分方程，相应齐次方程的解为：

$$n_{20} = Ce^{-(\tau_2^{-1} + \eta_1W_{13})t}$$

此处\(C\)为常数，可用常数变易法求出.

$$C(t) = \frac{\eta_1W_{13}n}{\tau_2^{-1} + \eta_1W_{13}}[e^{(\tau_2^{-1} + \eta_1W_{13})t} - 1]$$

解得：

$$n_2(t) = \frac{\eta_1W_{13}n}{\tau_2^{-1} + \eta_1W_{13}}[1 - e^{(\tau_2^{-1} + \eta_1W_{13})t}],\quad t\in[0,t_0]$$

即在\(t\in[0,t_0]\)范围内，激光上能级粒子数随时间增加而增加，并在\(t=t_0\)时达到最大值.

连续激光器讨论

对于连续激光器，激光工作物质在连续泵浦时间内，各能级粒子数密度及腔内光子数密度保持稳定，即：

$$\mathrm{d}n_i/\mathrm{d}t = 0$$ $$\mathrm{d}N/\mathrm{d}t = 0$$

这种情况下，各能级粒子数密度即光子数密度速率方程由微分方程简化为代数方程来求得稳态解.

长脉冲激光器

脉冲泵浦持续时间远大于受激辐射跃迁上能级寿命（\(t_0\gg \tau_2\)）的激光器.

由于脉冲泵浦持续时间足够长，长脉冲激光器也达到稳定状态，因此长脉冲激光器也可以看成一个连续激光器，使用连续激光器的理论进行处理.

准连续波激光器是长脉冲激光器的一种.

脉冲激光器讨论

在脉冲激光器中，由于泵浦时间较短，在泵浦持续时间内，各能级粒子数密度及光子数密度均处于剧烈的变化中，在尚未达到平衡状态前，泵浦作用就已终止，整个激光系统处于非稳态.

因此，用速率方程讨论脉冲激光器的特性就比较复杂，但可在适当近似条件下得到速率方程的瞬态解，对脉冲激光与介质的相互作用及脉冲激光器的输出特性作出定性的解释.

短脉冲运转

短脉冲运转指：\(t_0\lt\tau_2\)

  • \(\tau_2 = \frac{1}{A_{21} + S_{21}}\)：激光上能级的寿命

整个抽运期间，\(t\lt\tau_2\)

弛豫振荡

设\(t_0 = 0\)时，泵浦脉冲开始.

第一阶段（\(t_0\sim t_1\)）

工作物质在泵浦脉冲的抽运下，激光上能级粒子数不断增加，\(t=t_1\)时，达到阈值反转粒子数密度\(\Delta n_t\).

第二阶段（\(t_1\sim t_2\)）

由于\(\Delta n\gt \Delta n_t\)，腔内开始有激光产生.

光子数密度因受激辐射急剧增加，同时反转粒子数密度\(\Delta n\)因抽运而增加，又因受激辐射而减少.

由于光不是很强，泵浦激励作用使\(\Delta n\)增加的速率大于受激辐射使\(\Delta n\)减少的速率，\(\Delta n\)处于上升阶段，继续增加.

随着腔内光子数密度\(N\)的增大，受激辐射增强，受激辐射\(\Delta n\)减少的速率增大.

到\(t = t_2\)时，受激辐射使\(\Delta n\)减少的速率恰等于泵浦激励使\(\Delta n\)增加的速率，此时\(\Delta n\)达到极大值.

第三阶段（\(t_2\sim t_3\)）

光子数密度\(N\)通过消耗反转粒子而迅速增加.

受激辐射使\(\Delta n\)减少的速率大于泵浦激励使\(\Delta n\)增加的速率，\(\Delta n\)逐渐减少.

重复频率：每秒激光发出的脉冲数

脉宽：每个脉冲的持续时间

峰值功率：脉冲的最大功率

平均功率：脉冲的平均功率
