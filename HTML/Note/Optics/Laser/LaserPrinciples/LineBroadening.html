谱线加宽与线型函数

  • 谱线加宽概述（线型函数、线宽）

引言

本节首先介绍光谱线的线型函数与线宽，然后讨论引起谱线加宽的几种原因及相应的线型函数，最后对实际激光工作物质的光谱线加宽特性进行简要讨论.

谱线加宽概述

实际上，自发辐射所释放的光谱线并非严格的单色光（即单一频率），而是具有一定的频率宽度.

由于种种因素的影响，该自发辐射的功率（或光强）分布在以其跃迁波尔频率\(\nu = \frac{E_2-E_1}{h}\)为中心的小频率范围内，\(\nu_0\)称为中心频率.

可以用单色辐射功率\(P(\nu)\)来描述这一分布规律.

单色辐射功率\(P(\nu)\)

发光粒子在频率\(\nu\)处，单位频率间隔内的自发辐射功率.

在中心频率\(\nu_0\)处，单色辐射功率最大；偏离中心频率时，单色辐射功率便按一定规律衰减.

为定量描述光谱线的加宽特性，引入线型函数与线宽的概念.

光谱线的线型函数与线宽对激光器输出激光的相干性及增益、模式、功率等均有影响.

线型函数

若自发辐射的总功率为\(P\)，则频率分布在\(\nu\sim\nu + \mathrm{d}\nu\)内的功率为\(P(\nu)\mathrm{d}\nu\)，且：

$$P = \int_{-\infty}^{+\infty}P(\nu)\mathrm{d}\nu$$

则光谱线的线型函数定义为：

$$g(\nu,\nu_0) = \frac{P(\nu)}{P}$$

其量纲为秒.

显然，线型函数是归一化的，即：

$$\int_{-\infty}^{+\infty}g(\nu,\nu_0)\mathrm{d}\nu = 1$$

如图所示，线型函数曲线是以中心频率\(\nu_0\)为中心的对称曲线，\(\nu = \nu_0\)处线型函数值\(g(\nu, \nu_0)\)最大.

线型函数可理解为自发辐射跃迁概率按频率\(\nu\)的分布函数，线型函数曲线包含所有可能的自发辐射谱线（频率）的光谱线的轮廓形状.

由归一化条件可知，线型函数曲线与横轴所围的面积等于1.

线宽/半幅线宽（FWHM, Full Width at Half Maximum）

线型函数半极值点对应的频率宽度.

[设]在\(\nu = \nu_1\)与\(\nu = \nu_2\)处，线型函数的值降至最大值的一半，即：

$$g(\nu_1, \nu_0) = g(\nu_2, \nu_0) = \frac{1}{2}g(\nu_0, \nu_0)$$

则线宽为：

$$\Delta\nu = \nu_2 - \nu_1$$

谱线加宽的机理

引起谱线加宽的物理原因：

  • 自然加宽
  • 碰撞加宽
  • 多普勒加宽

自然加宽

自然加宽

由于发光粒子的激发态能级具有有限寿命引起的自发辐射谱线加宽.

自然加宽线型函数与线宽分别用\(g_N(\nu, \nu_0)\)与\(\Delta \nu_N\)表示.

[注]自然加宽无法避免.

经典理论解释

按照经典的电磁理论，一个原子可以看作是一个由正、负电荷组成的电偶极子，如图所示：

当原子的正、负电荷中心相对做频率为\(\nu_0\)的简谐运动时，该原子就会发射频率为\(\nu_0\)的光波.

但由于电子在发射光波过程中不断损耗能量，它振动的振幅也就不断衰减，辐射的电磁波亦随之减弱.

如图所示为电磁场振幅\(E\)随时间\(t\)变化的示意图：

通常这一衰减电磁场可以写成复数形式：

$$E(t) = E_0e^{-\gamma/2t}e^{i2\pi\nu_0 t}$$
  • \(\gamma\)：振幅衰减因子

按照Fourier分析，这一衰减的光波不再是单一频率\(\nu_0\)的振动，而是包含多个频率的光波，即谱线加宽了.

由于原子在发光中的能量衰减是必然的，因此这种加宽机制称为自然加宽.

由经典物理模型可证明，自然加宽的线型函数可表示为：

$$g_N(\nu, \nu_0) = \frac{\gamma}{\left(\frac{\gamma}{2}\right)^2 + 4\pi^2(\nu - \nu_0)^2} = \frac{1/\tau_s}{\left(\frac{1}{2\tau_s}\right)^2 + 4\pi^2(\nu - \nu_0)^2}$$
  • \(\tau_s = 1/\gamma\)：原子在激光上能级\(E_2\)的平均寿命

由上式可知：

1、\(\nu = \nu_0\)时，\(g_N(\nu_0, \nu_0)\)为极大值\(g_m\)，有：

$$g_m = g_N(\nu_0, \nu_0) = 4\tau_s$$

2、\(\nu_1 = \nu_0 - \frac{1}{4\pi\tau_s},~\nu_2 = \nu_0 + \frac{1}{4\pi\tau_s}\)时，有：

$$g_N(\nu_1, \nu_0) = g_N(\nu_2, \nu_0) = \frac{1}{2}g_m = 2\tau_s$$

故谱线宽度为：

$$\Delta_N = \nu_2 - \nu_1 = \frac{1}{2\pi\tau_s}$$
洛伦兹型函数 $$g(\nu, \nu_0) = \frac{\frac{\Delta \nu}{2\pi}}{(\nu-\nu_0)^2 + \left(\frac{\Delta\nu}{2}\right)^2}$$

具有上述表达式的线型函数称为洛伦兹型函数，相应的光谱曲线称为洛伦兹型曲线.

自然加宽的线型函数为洛伦兹型函数，即：

$$g_N(\nu, \nu_0) = \frac{\frac{\Delta \nu_N}{2\pi}}{(\nu-\nu_0)^2 + \left(\frac{\Delta\nu_N}{2}\right)^2}$$

量子理论解释

碰撞加宽

引起光谱线加宽的另一个原因是：原子之间、原子与器壁间会发生无规则碰撞.

气体激光器中，大量气体原子处于无规则热运动状态，原子与原子之间、原子与气体放电管壁之间会发生频繁的碰撞.

除了直接碰撞外，当两个原子之间的距离足够近时，它们之间的相互作用足以改变原本的能量状态，也可以认为是发生碰撞.

经典振子模型认为碰撞会使原子发光中断或光波相位发生突变，如图所示.

其效果均相当于原子在激光上能级\(E_2\)的寿命缩短.

与图：原子自发辐射的电磁场中的自然衰减波的粒子相比，偏离简谐波的程度更大，因而使谱线进一步加宽.

从量子力学观点看，处于激发态的原子，在碰撞过程中，失掉内能通过非辐射跃迁的形式回到基态，使原子在激发态上的平均寿命缩短了，从而导致光谱线在自然加宽的基础上被进一步加宽.

碰撞加宽

碰撞引起的光谱线加宽.

其线型函数与线宽分别用\(g_L(\nu, \nu_0)\)与\(\Delta nu_L\)表示.

尽管自然加宽与碰撞加宽产生的机理不同，但都可以归结为等效能级寿命问题.

因此，碰撞加宽可以采用洛伦兹型函数描述：

$$g_L(\nu, \nu_0) = \frac{\frac{\Delta \nu_L}{2\pi}}{(\nu-\nu_0)^2 + \left(\frac{\Delta\nu_L}{2}\right)^2}$$
  • \(\Delta_L = 1/2\pi\tau_L\)
  • \(\tau_s\)：平均碰撞时间，即任一原子与其他原子发生碰撞的平均时间间隔；用于描述碰撞的频繁程度，即由于碰撞而导致发光粒子处在激光上能级的寿命

为什么等效能级寿命问题就可以采用洛伦兹型函数描述？

由于碰撞的发生是随机的，因此只能了解\(\tau_s\)的统计特性.

Doppler加宽

光谱线的Doppler加宽是由粒子的热运动引发光频率的改变（即Doppler频移）造成的.

光学Doppler效应

如图所示，假定接受器固定在实验室坐标系中，设一发光原子（光源）相对于光接收器静止时，测得的光波中心频率为\(\nu_0\)；当发光原子相对于接收器沿\(z\)方向以\(v_z\)速度运动时，接收器测得的光波频率中心变为\(\nu_0'\)，即：

$$\nu_0' = \nu_0\sqrt{\left(1 + \frac{v_c}{c}\right)/\left(1 - \frac{v_c}{c}\right)}$$

这就是光学Doppler效应.

简单来讲就是，相对于同一个静止的观察者而言，静止的光源与运动的光源发出的光的频率不同.

当原子运动速度远小于光速，即\(v_z/c\ll 1\)时，可取一级近似，即：

$$\nu_0' = \nu_0\left(1 + \frac{\nu_z}{c}\right)$$

均匀加宽

自然加宽与碰撞加宽的共同特点

引起加宽的物理因素对每个粒子都是等同的，自然加宽机制中大量粒子中的每一个都有相同的平均寿命；碰撞加宽中，大量粒子中的每一个都有相同的受到其他粒子碰撞的机会.

光源中每个发光粒子由于某种物理因素的影响而使光谱线加宽，但中心频率保持不变，且所有发光粒子的谱线加宽完全一样.

这样，整个光源的光谱线中心频率仍与单个发光粒子的中心频率一致，而且整个光源的光谱线的线型函数和线宽与单个发光粒子的线型函数和线宽相同.

二者都是光辐射偏离简谐波，这种偏离引起了谱线的加宽.

在自然加宽机制中，粒子发射电磁波的振幅不断衰减而偏离简谐波；在碰撞加宽机制中，粒子间的碰撞使得粒子的发射电磁波突然中断，从而偏离简谐波.

在这类加宽中，每一粒子的一次发光对谱线内的所有频率均有贡献.

在均匀加宽中，不能将某一特定发光粒子与\(g(\nu,\nu_0)\)中某一频率联系起来.

光谱线

用于描述相对光强在不同频率上的分布.

设某条光谱线总光强为\(I_0\)，频率\(\nu\)附近单位频率间隔\(\mathrm{d}\nu\)内的光强为\(I(\nu)\).

则在频率\(\nu\)附近单位频率间隔\(\mathrm{d}\nu\)内的相对光强为：

$$f(\nu) = I(\nu)/I_0$$

\(f(\nu)\)表示某一谱线在单位频率间隔内的相对光强分布，称为光谱线的线型函数.

光谱的线型和宽度与光的时间相干性直接相关.

光谱的线型和宽度对许多激光器的输出特性（激光的增益、模式、功率等）都有影响.

原子发光是有限波列的单频光，因此仍有一定的频带宽度.

有限波列\(\Rightarrow\)有一定带宽

这意味着原子发射的不是恰好为某一频率\(\nu_0\)（满足\(h\nu_0 = E_2 - E_1\)）的光，而是发射频率在\(\nu_0\)附近某段范围内的光.

判定同一条谱线：

同一对能级上发生的辐射跃迁辐射出的光对应同一条谱线

e.g.从\(E_x\)自发辐射与受激辐射到\(E_n\)所发出的光对应同一谱线.

不同谱线的带宽不一定相同.

对于同一个谱线而言，不同频率对应的光强相对强度不一样.

光谱线的性质

线型函数的归一化条件 $$\int_{0}^{+\infty}I(\nu)\mathrm{d}\nu = I_0$$ $$\int_{0}^{+\infty}f(\nu)\mathrm{d}\nu = 1$$ 光谱线宽度（光谱线半宽度、光谱线半值宽度）

线型函数在\(\nu_0\)处达到最大值，而在\(\nu_1\)及\(\nu_2\)处，有：

$$f(\nu_1) = f(\nu_2) = \frac{1}{2}f(\nu_0)$$

定义\(\Delta\nu = \nu_2 - \nu_1\)，即相对光强为最大值\(1/2\)处的频率间隔，为光谱线半宽度.
