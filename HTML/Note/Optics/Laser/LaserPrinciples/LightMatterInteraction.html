以上三种过程是同时存在的.

二能级系统模型

考虑原子的两个能级\(E_2 \gt E_1\)，且满足：

  • \(E_1\)：低能级（基态）
  • \(E_2\)：高能级（激发态）
$$E_2 - E_1 = h\nu$$

单位体积内处于两能级的原子数密度分别为\(n_1\)和\(n_2\).

自发辐射跃迁

自发辐射跃迁

处于高能级的原子，自发向低能级跃迁，并辐射出一个能量为\(h\nu\)的光子的过程.

自发辐射光

由自发辐射跃迁产生的光波.

自发辐射光是非相干光.

自发跃迁概率 $$A_{21} = \left(\frac{\mathrm{d}n_{21}}{\mathrm{d}t}\right)_{sp}\frac{1}{n_2}$$
  • \(\left(\frac{\mathrm{d}n_{21}}{\mathrm{d}t}\right)_{sp}\)：单位体积内在\(\mathrm{d}t\)时间中由于自发辐射跃迁引起的由\(E_2\)向\(E_1\)跃迁的原子数.

受激辐射跃迁

受激辐射跃迁

处于高能级的原子，在频率为\(\nu\)的辐射场作用下，向低能级跃迁，并辐射出一个能量为\(h\nu\)的光子的过程.

受激辐射光

由受激辐射跃迁产生的光波.

受激辐射概率 $$W_{21} = \left(\frac{\mathrm{d}n_{21}}{\mathrm{d}t}\right)_{st}\frac{1}{n_2}$$
  • \(\left(\frac{\mathrm{d}n_{21}}{\mathrm{d}t}\right)_{st}\)：单位体积内在\(\mathrm{d}t\)时间中由于受激辐射跃迁引起的由\(E_2\)向\(E_1\)跃迁的原子数.

受激吸收跃迁

受激吸收跃迁

处于低能态的原子，在频率为\(\nu\)的辐射场作用下，吸收一个能量为\(h\nu\)的光子，并向高能级跃迁的过程.

受激吸收跃迁概率 $$W_{12} = \left(\frac{\mathrm{d}n_{12}}{\mathrm{d}t}\right)_{st}\frac{1}{n_1}$$
  • \(\left(\frac{\mathrm{d}n_{12}}{\mathrm{d}t}\right)_{st}\)：单位体积内在\(\mathrm{d}t\)时间中由于受激吸收跃迁引起的由\(E_1\)向\(E_2\)跃迁的原子数.

爱因斯坦系数的相互关系

腔内物质原子数按能级分布应服从热平衡状态下的玻尔兹曼分布：

$$\frac{n_2}{n_1} = \frac{g_2}{g_1}\exp{\left(-\frac{E_2-E_1}{kT}\right)}$$

式中，\(g_1\)和\(g_2\)分别为能级\(E_1\)和\(E_2\)的统计权重.

能量密度：

$$\rho_v = \frac{8\pi h\nu^3}{c^3}\frac{1}{\exp{\left(\frac{h\nu}{kT}\right) - 1}}$$

热平衡状态下，各能级上的粒子数应该保持动态平衡，即：

$$A_{21}n_2 + W_{21}n_2 = W_{12}n_1$$ $$A_{21}n_2 + B_{21}\rho_vn_2 = B_{12}\rho_vn_1$$

上三式对于\(T\rightarrow \infty\)的情况也应成立，则：

$$\lim\limits_{T\rightarrow \infty}\frac{n_2}{n_1} = \frac{g_2}{g_1}$$ $$\lim\limits_{T\rightarrow \infty}\rho_v = \infty$$ $$\because A_{21}n_2 + B_{21}\rho_vn_2 = B_{12}\rho_vn_1$$ $$\therefore \frac{1}{\rho_1}A_{21}\frac{n_2}{n_1} + B_{21}\frac{n_2}{n_1} = B_{12}$$ $$\therefore B_{21}\frac{g_2}{g_1} = B_{12}$$ $$\therefore \frac{B_{12}}{B_{21}} = \frac{g_2}{g_1}$$ $$\therefore \frac{W_{12}}{W_{21}} = \frac{g_2}{g_1}$$
$$\frac{A_{21}}{B_{21}} = \frac{8\pi h\nu^3}{c^3}$$ $$\because A_{21}n_2 + B_{21}\rho_vn_2 = B_{12}\rho_vn_1$$ $$\frac{n_2}{n_1} = \frac{g_2}{g_1}\exp{\left(-\frac{E_2-E_1}{kT}\right)}$$ $$\therefore (A_{21} + B_{21}\rho_\nu)\cdot\frac{g_2}{g_1}e^{−\frac{E_2−E_1}{kT}} = B_{12}\rho_\nu$$

由此可得光场的单色辐射能量密度为：

$$\rho_\nu = \frac{g_2A_{21}}{g_1B_{12}e^{h\nu/k_bT} - g_2B_{21}}$$ $$\because g_1B_{12} = g_2B_{21}$$ $$\therefore \rho_\nu = \frac{g_2A_{21}}{g_2B_{21}(e^{h\nu/k_bT} - 1)}$$

根据黑体辐射的普朗克公式，热平衡状态下黑体单色辐射能量密度为：

$$\rho_\nu = \frac{8\pi h\nu^3}{c^3}\frac{1}{e^{h\nu/k_bT} - 1}$$ $$\therefore \frac{A_{21}}{B_{21}} = \frac{8\pi h\nu^3}{c^3}$$
