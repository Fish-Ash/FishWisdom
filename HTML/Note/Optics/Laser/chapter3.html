普通光源在红外和可见光波段是非相干光源.

光放大物质的增益系数与增益曲线

工作物质/激活物质/激光介质/增益介质

处于集居数反转状态的物质.

一段工作物质就是一个光放大器.

增益系数（\(g\)）

光通过单位长度的工作物质后光强增长的百分数.

$$g = \frac{\mathrm{d}I(z)}{\mathrm{d}z}\frac{1}{I(z)}$$

\(\mathrm{d}I(z)\)正比于单位体积激活物质的净受激辐射光子数：

$$\mathrm{d}I(z)\propto [W_{21}n_2 - W_{12}n_1]h\nu\mathrm{d}z$$

这里不考虑自发辐射也是因为非相干吗？

为什么单位体积用dz？

当\(g_1 = g_2\)时，由爱因斯坦相对系数关系，可得：

$$B_{21} = B_{12}$$ $$\therefore \mathrm{d}I(z) \propto B_{21}h\nu\rho(z)[n_2(z)-n_1(z)]\mathrm{d}z$$ $$\therefore \mathrm{d}I(z) \propto B_{21}h\nu I(z)[n_2(z)-n_1(z)]\mathrm{d}z$$

\(I(z)\)与\(\rho(z)\)有什么关系？

$$\therefore g\propto B_{21}h\nu[n_2(z) - n_1(z)]$$

若\(n_2-n_1\)不随\(z\)变化，则增益系数\(g\)为一常数\(g^0\).

此时有：

$$I(z) = I_0e^{g^0z}$$

由增益系数的定义：

$$g^0 = \frac{\mathrm{d}I(z)}{\mathrm{d}z}\frac{1}{I(z)}$$ $$\therefore \int_0^z g^0\mathrm{d}z = \int_0^z \frac{1}{I(z)}\mathrm{d}z$$ $$\therefore g^0z = \ln\frac{I(z)}{I(0)}$$ $$\therefore I(z) = I_0e^{g^0z}$$
  • \(I_0\)：\(z=0\)处的初始光强.
增益饱和效应

实际上光强\(I\)的增加正是由于高能级原子向低能级受激跃迁的结果，或者说光放大正是以单位体积内集居数差值\(n_2(z) - n_1(z)\)的减小为代价的.

并且，光强\(I\)越大，\(n_2(z) - n_1(z)\)减少得越多.

所以实际上\(n_2(z) - n_1(z)\)随\(z\)的增大而减少，增益系数\(g\)也随\(z\)的增加而减小，这一现象就称为增益饱和效应.

$$n_2 - n_1 = \frac{n_2^0 - n_1^0}{1 + \frac{I}{I_s}}$$
  • \(I_s\)：饱和光强
  • \(n_2^0 - n_1^0\)：光强为\(I=0\)时单位体积内的初始集居数差值.

该式的推导见3.5节.

$$g(I) \propto B_{21}h\nu\frac{n_2^0 - n_1^0}{1 + \frac{I}{I_s}}$$ $$g(I) = \frac{g^0}{1 + \frac{I}{I_s}}$$

若放大器中光强始终满足\(I\ll I_s\)，则\(g(I) \approx g^0\).

光的自激振荡

在光放大的同时，通常还存在着光的损耗.

损耗系数（\(\alpha\)） $$\alpha = -\frac{\mathrm{d}I(z)}{\mathrm{d}z}\frac{1}{I(z)}$$

光通过单位距离后光强衰减的百分数.

同时考虑增益与损耗，则：

$$\mathrm{d}I(z) = [g(I) - \alpha]I(z)\mathrm{d}z$$

假设有初始光强为\(I_0\)的微弱光进入一无限长放大器：

1、光强\(I(z)\)按小信号放大规律\(I(z) = I_0e^{(g^0-\alpha)z}\)增长.

2、随着\(I(z)\)的增加，\(g(I)\)将由饱和效应按\(g(I) = \frac{g^0}{1 + \frac{I}{I_s}}\)减小，因而\(I(z)\)的增长变得缓慢.

3、当\(g(I) = \alpha\)时，\(I(z)\)不再增加并达到一个稳定的极限值\(I_m\).

根据条件\(g(I) = \alpha\)可得：

$$I_m = I_s(\frac{g^0}{\alpha} - 1)$$
激光器的振荡条件 $$g^0 \geq \alpha$$

阈值增益系数

设光强\(I_0\)在腔内往返一周后变为\(I\)，则：

$$I = I_0e^{2(G^0l-\delta)}$$
  • \(l\)：激光工作物质的长度
  • \(\delta\)：单程损耗因子

显然，若要形成激光，必有\(I\neq I_0\)，即：

$$2(G_0l - \delta)\neq 0$$ $$G^0 \neq \frac{\delta}{l}$$

这便是形成激光的阈值条件.

阈值增益系数 $$G_t = \frac{\delta}{t}$$

一旦激光器中的损耗系数确定，则该激光器的增益系数也随之确定为一常数.

若谐振腔中某模式的小信号增益系数大于或等于阈值增益系数，则该模式就可以起振从而形成激光；反之则不能.

不同纵模具有相同的单程损耗\(\delta\)，因而具有相同的阈值增益系数\(G_1\).

不同横模因具有不同的横向光场分布，因此具有不同的单程衍射损耗，从而有不同的阈值增益系数.

高阶横模的衍射损耗大，阈值增益系数便比低阶模大.

阈值反转集居数密度

增益系数和反转集居数密度间的关系为：

$$G(\nu) = \Delta n\sigma_{21}(\nu, \nu_0)$$
阈值反转集居数密度 $$\Delta n_t = \frac{G_t}{\sigma_{21}(\nu, \nu_0)} = \frac{\delta}{\sigma_{21}(\nu, \nu_0)l}$$
