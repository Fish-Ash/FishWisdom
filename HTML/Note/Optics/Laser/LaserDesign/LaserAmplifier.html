激光放大器

本章将讨论激光束通过光学激活材料时产生的能量增益.

在设计高能量、高亮度的光源时，以激光作为脉冲放大器是非常重要的.

高能量脉冲的产生基于主振荡器和多级功率放大器的共同作用.

振荡器-放大器系统中：

  • 脉宽、光束发散角和光谱宽度取决于谐振腔.
  • 脉冲能量与功率由放大器决定.

设计激光放大器时，考虑以下因素：

  • 增益与提取的能量
  • 放大器引起的波前畸变与脉冲形状畸变
  • 放大器系统中光学元件的能量与功率密度
  • 放大器内引起超辐射或前激射的反馈

设计放大器时，主要考虑从放大器中所能获得的增益和提取的能量，放大器中棒的长度主要取决于所需的增益.

而考虑到损耗阈值，棒的直径主要取决于所需要的输出能量.

在已泵浦到一定反转粒子数级别的放大器中，增益主要取决于输入脉冲的强度与持续时间.

脉冲放大

设放大器的运行时间比泵浦速率\(W_p\)和自发发射时间\(\tau_f\)快，则有：

$$t_p\ll \tau_f, W_p^{-1}$$

\(t_p\)是通过放大介质脉冲的脉宽.

\(W_p\)是速率，每秒几次；\(W_p^{-1}\)是每次用时.

信号脉冲：待放大脉冲

\(t_p\ll \tau_f\)：脉宽远小于荧光寿命\(\Rightarrow\)信号放大的作用时间极短\(\Rightarrow\)上能级的自发辐射损失可以忽略不计.

\(t_p\ll W_p^{-1}\)：极短时间内泵浦源来不及泵浦新的能量

因此，放大过程是以输入信号到达之前就存储于激光上能级的能量为基础的.

这句话的意思是：在待放大的激光束进入放大器之前，就需要给放大器中增益介质的激光上能级注入能量.

当输入脉冲通过放大器时，原子受到激励释放出存储的能量.

原子是指放大器增益介质中的原子，激励是来自信号激光的激励.

泵浦源的作用是预先在工作物质中存储能量，信号脉冲则用于激发这些存储的能量.

放大过程可以用速率方程：

$$\frac{\partial n}{\partial t} = -\gamma n\phi_\sigma c - \frac{n + n_{tot}(\gamma - 1)}{\tau_f} + W_p(n_{tot} - n)$$ $$\frac{\partial \phi}{\partial t} = c\phi_\sigma n - \frac{\phi}{\tau_c} + S$$

若忽略荧光与泵浦再脉冲持续时间内的影响，则反转粒子数为：

$$\frac{\partial n}{\partial t} = -\gamma nc\sigma\phi$$

当脉冲通过具有反转粒子数的介质时，可以用下述与时间有关的非线性光子传输方程描述其增大.

$$\frac{\partial\phi}{\partial t} = cn\sigma\phi - \frac{\partial\phi}{\partial x}c$$

该方程也解释了辐射对激活介质的影响，反之亦然.

小体积介质中，光子密度的变化量等于受激发射过程产生的光子数和从该体积射出的光子通量之差.

考察单色光入射到长度为\(L\)的放大器棒前表面的一维情况.

将光束射入增益介质的点定为参考点，即\(x=0\).

为得出反转电子数\(n\)与光子通量\(\phi\)，必须求解上述两个方程.

若输入到放大器中的是矩形脉冲，持续时间为\(t_p\)，初始光子密度为\(phi_0\)，则光子密度的解为：

$$\frac{\phi(x,t)}{\phi_0} = \left[1 - (1-e^{-\sigma nx})e^{-\gamma\sigma\phi_0(ct-x)}\right]^{-1}$$
  • \(n\)：反转粒子数密度

设：\(t=0\)时，材料内\(n\)是均匀的.

当光束通过长度为\(x=l\)的放大器时，能量增益为：

$$G = \frac{1}{\phi_0 t_p}\int_{-\infty}^{+\infty}\phi(l,t)\mathrm{d}t$$
$$G = \frac{1}{c\gamma\sigma\phi_0t_p}\ln[1+(e^{\gamma\sigma\phi_0\tau_0c}-1)e^{n\sigma l}]$$
$$G = \frac{1}{\phi_0 t_p}\int_{-\infty}^{+\infty}\phi(l,t)\mathrm{d}t$$ $$\frac{\phi(x,t)}{\phi_0} = \left[1 - (1-e^{-\sigma nx})e^{-\gamma\sigma\phi_0(ct-x)}\right]^{-1}$$

积分得：

$$G = \frac{1}{c\gamma\sigma\phi_0t_p}\ln[1+(e^{\gamma\sigma\phi_0\tau_0c}-1)e^{n\sigma l}]$$
单位面积输入能量 $$E_{in} = c\phi_0 t_p h\nu$$
饱和能量密度\(E_s\) $$E_s = \frac{h\nu}{\gamma\sigma} = \frac{E_{st}}{\gamma g_0}$$
  • \(E_{st} = h\nu n\)：单位体积存储的能量
  • \(g_0 = n\sigma\)：小信号增益系数
Frantz-Nodvik公式
$$G = \frac{E_s}{E_{in}}\ln\left[1 + \left(e^{E_{in}/E_s} - 1\right)G_0\right]$$
$$G = \frac{1}{c\gamma\sigma\phi_0t_p}\ln[1+(e^{\gamma\sigma\phi_0\tau_0c}-1)e^{n\sigma l}]$$ $$E_{in} = c\phi_0 t_p h\nu$$ $$E_s = \frac{h\nu}{\gamma\sigma} = \frac{E_{st}}{\gamma g_0}$$ $$\frac{E_s}{E_{in}} = \frac{1}{c\gamma\sigma\phi_0t_p}$$ $$\frac{E_{in}}{E_s} = c\gamma\sigma\phi_0t_p$$

\(t_p\)和\(\tau_0\)间的关系是什么？

$$G_0 = e^{g_0l} = e^{n\sigma l}$$ $$\therefore G = \frac{E_s}{E_{in}}\ln\left[1 + \left(e^{E_{in}/E_s} - 1\right)G_0\right]$$
  • \(G\)：增益
  • \(E_{in}\)：输入脉冲的能量密度
  • \(E_s\)：饱和能量密度
  • \(G_0 = e^{g_0l}\)：小信号单程增益

双程放大器内的输出能量密度\(E_2\)为：

$$E_2 = E_s\ln\left[1 + \left(e^{E_1/E_s} -1\right)e^{g_0'l}\right]$$
  • \(g_0' = (1-\eta_1)g_0\)

增益极限与放大器的稳定性

放大器其实就是一种激光器，其放大效率主要取决于反转粒子数，但是存在一个过程ASE会减少反转粒子数，因此需要抑制它.

设计放大器或多级放大系统的考虑因素：在期望的工作条件下获得稳定的运行.

在一个作为放大器或Q开关振荡器的激光器中，激活材料起着储能元件的作用，其效用很大程度上取决于所获得的反转粒子数.

放大器本质上也是一个激光器.

Q开关振荡器：包含了Q开关的激光系统.

当激活材料中反转粒子数增加时，很多机理上使上能级的粒子数开始减少.

放大的受激发射（ASE）能引起粒子数的减少，ASE有时也称为超荧光.

这里的减少特指激光上能级的反转粒子数减少，因此使得放大器的损耗增加.

使光源发出的辐射进入激光跃迁波长、或延长增益介质中的光路径、或增大内部与外部反射，都可增强这一受激发射.

若由于放大器内光学表面的反馈而存在充分的反馈，放大器就会在信号脉冲达到之前开始发射激光.

若在垂直于光束方向的表面发生反射，放大器将仅仅成为振荡器，并在Q开关开始作用前或信号脉冲到达前出现前激射.

包括棒的圆柱表面反射在内的总反射，将导致寄生模的产生，它们的传播方向与激光器光轴成一定角度.

前激射与寄生振荡是反转粒子数材料与高反射环境相互作用的结果，且容易受到设计变化的影响.

放大的自发发射

在放大器中获得的反转粒子数，通常受放大的自发发射引起粒子数减少的损耗的影响.

强ASE的有利条件是：工作物质中存在高增益与长路径.

在这些条件下，在激光棒的一个端面附近出现的自发衰变，能够在经过激活材料的另一端面前被放大.

ASE不存在阈值，荧光发射功率随增益而快速增大，因此当泵浦功率增大时，ASE成为激光放大器中的主要衰变机理.

就这点来说，可以从棒的每个截面观测到工作物质轴线周围立体角\(\Omega\)范围内存在的强发射.

$$\Omega = A/L^2$$
  • \(A\)：棒的截面
  • \(L\)：棒的长度

由于端面存在反射，所以棒的几何孔径角度增大\(n^2\).

前激射

放大器泵浦期间发生的激光作用，是由光路径中不同界面的残余反馈引起的.

通过对长度为\(L\)、泵浦到某反转级别的放大器棒的增益的研究，可以导出稳定的工作条件.

反转级别用单位长度的增益系数\(g\)表示.

令棒端面的反射率分别为\(r_1\)与\(r_2\)，则棒中任何位置发射的自发发射都将沿垂直于棒端面的方向传播.

在一个往返后，表现出约\(r_1r_2e^{2gL}\)的回路增益.

当回路增益大于1时，将形成振荡，直到耗尽棒的有效储能.

因此，对于放大器有如下要求：

$$r_1r_2e^{2gL}\lt 1$$

此条件决定了棒的长度上限.

寄生模

工作物质边缘的内反射会显著增大ASE，当这些反射导致产生封闭路径，即光线自身存在反射时更是如此.

在此条件下得到强的反馈机理，且当工作物质内的增益一超过反射损耗，就建立起寄生振荡.

e.g. 侧面抛光的棒中，内部模完全包含在内反射中.

一种成为耳语模的内部模向四周传播，且无纵向分量.

该模进入棒内的最大距离达到\(r = R/n\)，其中\(n\)为折射率.

另一种成为光管模的内部模沿棒以z形传播.

在浸没式棒中，特别是在折射率匹配的液体中，或在具有粗糙表面、构纹、镀有增透膜层的棒，都明显增大了内辐射模引起的增益极限.

若棒表面有光劈或增透膜，则会抑制纵模.

防止或降低放大器内反馈的技术

为使前激射最小化，在棒的端面切出一个与棒轴成一定角度的倾角，通常为布儒斯特角，或镀上增透膜.

将棒浸在反射率匹配的液体中，或给棒的圆柱侧打毛，能使圆柱棒表面引起的利州自发发射的反射降到最小.

若需要多级放大，则各级都需要使用下述的一种或几种方法退耦和：

  • 尽可能扩大放大器间距.
  • 由于ASE出现在相对较大的光束角中，则放大器间的大距离将非常有效地减少各级间的反馈，而使用空间滤波片可能更有效.
  • 若多级放大器的小信号增益很高（30dB及以上），就在放大器间插入基于法拉第效应的光学振荡器.
