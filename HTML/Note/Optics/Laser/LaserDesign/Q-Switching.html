调Q技术

激光调Q技术

用调节谐振腔的Q值获得激光巨脉冲的技术.

将激光能量压缩到宽度极窄的脉冲中发射，从而使光源的峰值功率可以提高几个数量级的技术.

巨脉冲

高峰值功率的窄脉冲.

Q值（品质因数） $$Q = 2\pi\frac{W}{\Delta W} = \frac{2\pi\nu\eta L}{\delta c}$$
  • \(W\)：谐振腔内储存的能量
  • \(\Delta W\)：每振荡周期损耗的能量
  • \(\nu\)：激光振荡频率
  • \(\eta\)：介质折射率
  • \(L\)：谐振腔腔长
  • \(\delta\)：光在腔内传播的单程损耗
  • \(c\)：光速

Q值越高，腔内损耗越小；Q值越低，腔内损耗越大.

普通激光器峰值功率不高的原因

脉冲自由运转激光器输出的光脉冲不是单一的光滑脉冲，而是由若干小尖峰脉冲构成的序列.

每个小尖峰脉冲均产生于阈值附近，而脉宽又非常短（仅微秒量级）.

激光器输出的能量分散在这样一串脉冲中，因而不能具有很高的峰值功率，增大泵浦能量仅能使尖峰脉冲的数目增多，而不能提高峰值功率.

一般情况下，激光器谐振腔的阈值始终保持不变，当光泵浦使反转粒子数达到或略超过阈值时，激光器便开始振荡.

于是激光上能级粒子数因受激辐射减少，致使上能级无法积累很大的反转粒子数，只能限制在阈值反转粒子数附近.

提高激光器峰值功率的方法

当激光器泵浦初期，将其振荡阈值调至很高，抑制激光振荡的产生，使激光上能级的反转粒子数大量积累.

当反转粒子数积累到最大时，突然将阈值调至很低，此时积累在上能级的粒子便雪崩式跃迁至低能级，在极短时间内将能量释放出来，获得巨脉冲.

改变激光器阈值的方法

激光器振荡的反转集居数密度为：

$$\Delta n_t = \frac{\delta}{\sigma_{21}l}$$
  • \(l\)：激光工作物质的长度
$$\Delta n_t = \frac{2\pi\nu\eta L}{\sigma_{21}lc}\cdot\frac{1}{Q}$$

即\(\Delta n_t\)反比于\(Q\)值.

由此可见，要改变激光器的阈值，可以通过突变谐振腔的Q值（或损耗\(\delta\)）实现.

调Q原理

采用某种办法使谐振腔在泵浦开始时处于高损耗低Q值的状态，此时激光振荡的阈值很高，粒子密度反转数即使积累到很高水平也不会产生振荡；

当粒子密度反转数达到其峰值时，突然使腔的Q值增大，导致激光介质的增益大大超过阈值，及其快速地产生振荡；

此时储存在亚稳态上的粒子所具有的能量会很快转换为光子的能量，光子像雪崩一样以极高的速率增长，激光器便可输出一个峰值功率高、宽度窄的激光巨脉冲.

电光调Q

利用晶体的普克尔效应实现Q值突变的方法.

利用晶体的电光效应作为Q开关的元件.

以磷酸二氘钾（KD*P）为例：

KD*P晶体是最常用的电光晶体之一.

在激光谐振腔中插入起振片作为Q开关的KD*P晶体.

什么是晶体的电光效应？

当向晶体施加电场时，其折射率椭球的形状与方位会发生改变，导致沿特定方向传播的光的折射率n发生变化.

什么是起振片？

一种只允许特定振动方向的光通过的光学元件.

当在晶体上加半波电压后，往返通过晶体的线偏振光，其振动方向相对改变90°.

对于未加电压的晶体，往返通过晶体的线偏振光振动方向不变.

当晶体在z轴方向加电压后，由于感应双折射，沿x方向振动的偏振光进入晶体后将分解为沿x'方向和y'方向振动的二线偏振光.

适当调整电压大小，使通过晶体后的两者相位差为\(\pi/2\)（相应电压大小为\(V_{\pi/2}\)），因而合成光为圆偏振光.

再次经过反射镜反射，圆偏振光再次通过晶体，相位差再次增加\(\pi/2\)，则出射光又成一线偏振光，但其振动方向为y方向，恰遇原入射偏振光的振动方向x垂直.

声光调Q

利用声光器件的衍射效应控制谐振腔损耗以实现Q值突变的方法.

声光衍射效应

激光通过介质中的超声场时发生衍射，从而造成光束偏折.

声光调Q适合高重复频率

当声波频率较高，声光作用长度\(L\)足够大，满足\(2\pi L\lambda/(n\lambda_s^2)\gg 1\)时（\(\lambda\)为光波波长，\(\lambda_s\)为声波波长），根据体光栅衍射的Bragg定律，光束以\(\theta_i\)角入射介质产生衍射极值应满足Bragg方程：

$$2\lambda_s\sin\theta_B = \frac{\lambda}{\eta_0}$$
  • \(\eta_0\)：超声介质的折射率

此时入射角\(\theta_i\)等于衍射角等于Bragg角\(\theta_B\)，即：

$$\sin\theta_i = \sin\theta_B = \frac{\lambda}{2\eta_0\lambda_s}$$

尝试将声光调Q与声光效应结合起来

在此条件下，透射光束分裂为0级与+1级（或-1级）（视入射光方向而定）衍射光，+1级（或-1级）衍射光与声波波面的夹角为\(\theta_B\)，这种现象称为Bragg衍射.

一级衍射光强\(I_1\)（或\(I_{-1}\)）与入射光强\(I_i\)之比为：

$$\frac{I_1}{I_i} = \sin^2\left(\frac{\Delta \phi}{2}\right)$$
  • \(\Delta \phi\)：经过长度为\(d\)的位相位光栅后光波相位变化的幅度.

\(I_1/I_i\)为衍射效率，其值越大，说明越多的入射光集中到+1级（或-1级）衍射极上，使入射光束的能量得到充分利用.

$$\Delta\phi = \frac{2\pi}{\lambda}\Delta\eta d = \frac{\pi}{\lambda}\sqrt{2\frac{d}{H}MP}$$
  • \(\Delta\eta\)：介质折射率变化的幅值
  • \(d\)：换能器的长度
  • \(H\)：换能器的宽度
  • \(M\)：声光介质的品质因数
  • \(P\)：超声驱动功率

提高超声驱动功率可得到较高的衍射效率.

换能器：产生声波的器件.

声光Q开关由一块对激光波长透明的声光介质及换能器（即超声波发生器）组成，换能器用一个高频振荡电源来驱动，以产生相应的机械振动，从那个人产生超声波耦合到声光介质中去.

声光器件在腔内按Bragg条件放置.

当加上超声波时，光束按Bragg条件决定的方向发生偏折，由于一级衍射光偏离谐振腔轴向而导致损耗增加.

此时腔的损耗严重，Q值很低，不能形成激光振荡.

在此阶段，增益介质在光泵激励下，激光高能级大量积累离子.

若此时突然撤除超声波，则衍射效应立即消失，光束顺利地通过均匀的声光介质，不发生偏折，腔的损耗突然下降，Q值升高，从而形成一个强的巨脉冲输出.

声光调Q开关时间一般小于脉冲建立时间，属于快开关类型.

由于开关的调制电压很低（\(\lt 200V\)），所以可以用于增益较低的连续激光器，对连续器件获得高重复率的脉冲输出.

但由于声光调Q开关对高能量激光器的开关能力差，不宜用于高能调Q激光器.
