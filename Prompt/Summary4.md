# 用户学习与任务执行习惯画像（新增与修正部分）

## 一、身份背景


* 当前学习目标更加明确：先建立能够理解 Berry 相位的最小量子力学知识体系，再连接到光学中的 Pancharatnam–Berry 相位。
* 不以完整掌握量子力学课程为目标，而是以格里菲斯《量子力学概论》为参考主线，按实际理解需求选择章节。
* 对教材顺序不盲从：当发现教材或原学习路径存在知识跨度时，会主动要求重构路线。

  * 图片引用；

  * `\lvert`、`\rangle`

  * Dirac bra-ket 符号

## 三、掌握技能情况

## 1. Python 与编程

原画像基本不变，新增观察如下：

* 本轮未继续推进 Python 或 Agent 编程。
* 具备较强的**结构化笔记编写能力**，能够使用 HTML 和 LaTeX 组织较长的知识内容。

* 会主动要求检查：

  * 公式是否写错；

* 对 B1 二维复向量与矩阵阶段的处理表明，用户更偏好 **just-in-time learning（即时按需学习）**，而不是脱离当前问题系统补完全部数学。

## 2. 量子力学与 Berry 相位基础

### 已形成初步理解的内容

* 波函数与含时 Schrödinger 方程；
* Born 统计诠释；
* 波函数归一化与平方可积；
* 可观测量、算符与期待值；
* Heisenberg 不确定原理的基本含义；
* 量子态不是单纯描述“粒子空间分布”，而是描述系统各种可观测量的统计规律；
* 定态与定态 Schrödinger 方程；
* Hamiltonian 本征态与能量本征值；
* 一维无限深方势阱中的：

  * 边界条件；
  * 离散能级；
  * 基态与激发态；
  * 节点；
  * 正交归一；
  * 完备性；
  * 一般态的本征态展开；
  * (|c_n|^2) 的能量测量概率意义；
* Hilbert 空间的入门理解；
* 抽象态矢量与选定基后的坐标表示之间的区别；
* Hermitian 算符、伴随算符及本征值为实数；
* 广义统计诠释；
* Dirac notation / bra–ket notation；
* 位置基、动量基和能量本征基；
* 波函数作为抽象态矢量在某组基下的展开系数：
  [
  \Psi(x,t)=\langle x|\psi(t)\rangle;
  ]
* 自旋角动量的基础符号：

  * (\mathbf S)
  * (\hat S^2)
  * (\hat S_z)
  * (s)
  * (m_s)
* 自旋 (1/2) 粒子的一般态：
  [
  |\chi\rangle=a|+\rangle+b|-\rangle.
  ]

### 尚未稳定掌握或决定按需学习的内容

* 二维复向量和 (2\times2) 矩阵本征问题的系统方法；
* Pauli 矩阵；
* 角动量对易关系的完整理论背景；
* 自旋 (1/2) 的完整矩阵表征；
* 磁场中的自旋 Hamiltonian；
* 参数依赖 Hamiltonian；
* 参数空间与瞬时本征态；
* 绝热定理的准确条件；
* 动力学相位、整体相位和相对相位的系统区分；
* Berry 相位的数学表达和几何图像；
* Berry 相位与光学 PB 相位的正式对应。

### 学习路径修正

原路径中从 Dirac 符号直接进入自旋阶段跨度过大，已经重新规划为：

[
\text{相位}
\rightarrow
\text{二能级态}
\rightarrow
\text{按需补矩阵工具}
\rightarrow
\text{自旋 }1/2
\rightarrow
\hat H(\mathbf B)
\rightarrow
\text{参数空间}
\rightarrow
\text{绝热演化}
\rightarrow
\text{Berry 相位}
\rightarrow
\text{光学 PB 相位}.
]

其中矩阵工具不再作为必须先完整学完的独立阶段，而作为后续按需调用的工具。

## 四、学习习惯

## 1. 总体学习习惯

在原画像基础上，以下特征得到进一步确认：

* **高度依赖阶段性交付标准**：每完成一部分，会明确询问“是否可交付”“能否进入下一阶段”。
* 喜欢将每个阶段转化为可归档笔记，而不是只进行口头理解。
* 会主动提交完整笔记片段，要求 AI 进行：

  * 逐项校验；
  * 查错；
  * 修正符号；
  * 判断是否达到交付标准。
* 对错误极其敏感，尤其关注：

  * 教材笔误；
  * 翻译笔误；
  * 分母、正负号、变量名；
  * ket、波函数和本征函数符号混用；
  * 公式左、右两侧对象是否一致。
* 不会因为教材这样写就直接接受，会检查公式上下文是否自洽。
* 当学习路线不适配时，会要求重新规划，而不是强行继续。
* 偏好“当前真正缺什么就补什么”，不接受为了形式完整而加入大量暂时无用内容。
* 对抽象概念需要反复确认不同层次的表述：

  * 它是什么；
  * 它表示什么；
  * 为什么要引入；
  * 它是否客观存在；
  * 它与具体物理图像的关系是什么。
* 容易在“数学对象”和“物理对象”之间产生疑问，因此后续回答应明确区分：
  [
  \text{物理系统}
  \leftrightarrow
  \text{抽象量子态}
  \leftrightarrow
  \text{选定基后的数学表示}.
  ]

## 2. 编程学习习惯

新增或修正如下：

* 更偏好将代码、公式和说明直接整理为最终可用笔记。
* 在给出 HTML 或 LaTeX 内容时，AI 应优先：

  1. 检查物理含义；
  2. 检查公式；
  3. 检查符号一致性；
  4. 指出必须修改的位置；
  5. 再判断是否可交付。
* 不需要每次完整重写全部 HTML；除非内容错误较多，否则列出局部修正更符合需求。
* 对缺乏系统教材支撑的工具学习接受度较低。
* 更适合：

  * 在实际物理问题中引入矩阵；
  * 当场学习需要的线性代数操作；
  * 立即将工具用于当前公式。
* 不适合：

  * 脱离物理目标单独铺开完整矩阵理论；
  * 一开始要求掌握大量抽象数学定义。

## 3. 物理学习习惯

本轮最显著的新特征如下：

### 强烈需要区分物理图像与数学表示

用户会持续追问：

* 量子态描述什么；
* 量子系统在物理上是什么；
* 一个空间中是否包含许多粒子；
* 波函数是否就是粒子分布；
* 抽象态矢量为什么存在；
* 基矢量为何也是抽象矢量；
* 本征态是否客观存在。

因此后续解释新概念时，最好按以下顺序：

1. **研究对象是什么**；
2. **物理上要描述什么**；
3. **使用什么数学对象描述**；
4. **选定基后如何写成具体形式**；
5. **哪些量可以测量，哪些只是表示方式**。

### 不满足于形式公式

仅给出公式通常不足以完成理解。例如看到

[
\sigma_x\sigma_p\geq\frac{\hbar}{2}
]

用户会继续追问“不确定”的物理含义；看到

[
|\psi\rangle
]

会继续追问它是什么、为什么要引入、是不是任意矢量。

因此后续公式说明应至少包含一句：

> 这个公式在描述什么物理关系。

### 喜欢从具体模型建立抽象概念

一维无限深方势阱对用户帮助较大，因为它能够建立：

[
\text{边界条件}
\rightarrow
\text{允许波长}
\rightarrow
\text{离散能量}
\rightarrow
\text{本征态}.
]

后续讲解自旋、绝热演化和 Berry 相位时，应优先选取：

* 二能级系统；
* 自旋 (1/2)；
* 缓慢转动的磁场；

而不是直接从一般 Hilbert 空间和微分几何开始。

### 对符号角色要求严格

回答时应主动区分：

* 大写或带帽符号：算符；
* 小写量子数：本征值标签；
* ket：抽象态；
* 波函数：特定基下的展开系数；
* 列向量：选定有限维基后的坐标；
* (\hat Q^\dagger)：伴随；
* (\hat Q^*)：复共轭，不等同于伴随。


## 4. 英语翻译与术语学习习惯

新增总结如下：

* 用户更常提出“某术语英文是什么”，而不是要求整段翻译。
* 推荐回答格式进一步简化为：

```markdown
中文：一维无限深方势阱  
英文：one-dimensional infinite square well  
常见替代：one-dimensional infinite potential well  
教材常用：infinite square well
```

* 对英文术语应说明：

  * 标准表达；
  * 是否有常见替代；
  * 哪种在教材或论文中更常见。
* 不需要扩展词源或长篇语言说明，除非用户继续追问。
* 专业术语翻译必须与符号和物理对象一致，避免把：

  * state
  * eigenstate
  * stationary state
  * wave function
  * state vector
    混为同一概念。

## 五、后续 AI 服务建议

* 每次默认只推进一个最小知识节点。
* 用户询问概念时，优先执行其既定规则：一句话解释，必要时扩展为一段。
* 在开始新阶段前明确：

  * 阅读范围；
  * 当前核心问题；
  * 必须掌握内容；
  * 暂不要求内容；
  * 交付标准。
* 用户提交笔记后，优先判断：

  * 核心结论是否正确；
  * 是否存在笔误或符号错误；
  * 是否达到当前阶段 MVP；
  * 是否能够进入下一阶段。
* 遇到抽象概念时，必须明确区分：
  [
  \text{物理对象、量子态、抽象矢量、基、展开系数、测量结果}.
  ]
* Berry 相位后续学习应继续沿以下最小路线推进：
  [
  \text{整体相位与相对相位}
  \rightarrow
  \text{动力学相位}
  \rightarrow
  \text{二能级系统}
  \rightarrow
  \text{自旋 }1/2
  \rightarrow
  \text{磁场参数}
  \rightarrow
  \text{绝热演化}
  \rightarrow
  \text{Berry 相位}.
  ]
