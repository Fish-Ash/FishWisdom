#### 已完成：初步衍射级次分析

对于 XZ 平面内的 45°斜入射，曾利用光栅衍射条件讨论基底中可能出现的传播级次：

[
n_{\mathrm{sub}}\sin\theta_m
============================

\sin45^\circ+m\frac{\lambda}{P}
]

其中假设入射介质为空气。

当熔融石英在 351 nm 附近的折射率近似为 1.48 时，曾得到关闭基底 X 向负一级传播透射通道的条件：

[
P<\frac{351\ \mathrm{nm}}{1.48+\sin45^\circ}
\approx160.5\ \mathrm{nm}
]

这表明在 (P=190) nm 或 (250) nm 时，不能默认基底中只有零级透射。

注意：

* 这是衍射通道的初步判断，不是最佳反射周期。
* 对二维正方晶格，应进一步检查二维倒格矢对应的所有传播衍射级次。
* 尚未正式完成各衍射级次的功率分解。

### 项目 2：介质超表面高反射机制研究

#### 背景

用户希望从物理机制而非单纯参数优化出发，理解周期介质结构如何形成高反射。

重点涉及：

* Guided-Mode Resonance（GMR）。
* Mie 模态。
* 周期阵列中的散射与集体耦合。
* 衍射级次与辐射通道。
* Huygens 型超表面。
* 导模有效折射率与模式约束。

#### 当前状态

已经讨论过上述概念，但尚未对当前纳米柱结构完成明确的模态识别。

特别是当前纳米柱与基底使用同一种 SiO₂ 材料，不能直接套用具有高折射率导波层的传统 GMR 结构模型。

#### 已完成

* 将 GMR 确定为一个值得探索的候选机制。
* 讨论折射率对比度对模态约束的影响。
* 讨论斜入射时的平行动量和衍射通道。
* 认识到高反射峰需要进一步通过场分布和模态分析解释。
* 已初步把相关论文引入研究设计。

#### 已做出的决定

优先根据能够实际运行的电磁仿真结果判断物理机制，不直接把文献中的机制归属于当前不同几何结构。

#### 下一步

获得可信光谱之后：

* 检查共振峰位置和带宽。
* 观察近场分布。
* 扫描周期和入射角。
* 研究模态与辐射通道。
* 必要时使用本征模或相关数值方法。
* 判断是否符合传统 GMR 条件，或者属于其他共振或散射机制。

#### 需要注意

典型的匹配 Huygens 条件可能对应反射抑制及透射相位调控，不能简单宣称“电磁偶极匹配就能产生高反射”。

同样，45°斜入射并不天然优于正入射。

这些规则在原始迁移档案末尾的用户 Prompt 中有更加明确的文字。新 AI 应以用户亲自提供的原文为准。

### 2. 代码检查规则

当用户提供 Lumerical Script 时，应分别判断：

| 判断层级  | 需要检查的内容              |
| ----- | -------------------- |
| 语法    | 命令及表达式是否符合脚本语言要求     |
| 对象属性  | 软件版本是否支持对应属性和取值      |
| 仿真设置  | 光源、边界条件、Monitor 是否正确 |
| 运行状态  | 求解器是否实际完成            |
| 数据处理  | R、T、频率和波长提取是否正确      |
| 数值可信度 | 网格、时间、PML 等是否收敛      |
| 物理可信度 | 结果是否支持所声称的共振机制       |

**不要用“代码基本正确”代替上述判断。**

发现明确错误时，应指出具体位置并给出最小修改代码。

如果仅仅是计算效率或收敛性的改进建议，必须标注为建议，不应把它描述成语法错误。

### 3. 仿真结论的表达规则

严格区分：

| 层级   | 合适的表达            |
| ---- | ---------------- |
| 理论猜测 | 可能存在某类共振         |
| 初步仿真 | 当前参数下计算得到某个结果    |
| 收敛仿真 | 经过数值收敛检查后结果稳定    |
| 机制确认 | 场分布、模态或色散分析支持该机制 |
| 实验验证 | 已有对应实验测量数据支持     |

不能跳过数值和物理验证过程。

### 4. 材料与 LIDT 研究规则

讨论高激光损伤阈值时，应同时关注：

* 材料在目标波长的吸收。
* 局域电场增强。
* 电场热点位置。
* 表面粗糙度与制造缺陷。
* 激光脉宽。
* 重复频率。
* 单脉冲或多脉冲条件。
* 损伤定义和实验检测方法。

不能简单依据材料带隙或某种薄膜的损伤实验结果，就判断相应纳米柱结构一定具有更高 LIDT。

### 5. BFAST 和 Bloch 的使用规则

* BFAST 是当前研究固定角度宽带斜入射的一条技术路线。
* 普通 Bloch 单频仿真可作为低成本的基础测试方案。
* 普通 Bloch 宽带仿真不应自动等同于固定 45°宽带仿真。
* 减少 Monitor 频率采样点不等于同比例减少 FDTD 计算时间。
* 求解时间主要需要结合网格数量、仿真时间步数、算法和计算资源分析。

### 6. 关于 AI 技术判断的规则

任何未经用户确认或未经软件实际运行验证的 AI 技术建议，都不能自动视为已经达成的共识。

特别是在涉及软件具体属性、边界条件及算法性能时，应区分官方文档支持的事实、AI 推断与实测结果。

### 1. 自定义材料名称

用户曾经修改过早期脚本中重复设置几何属性的问题。

不应在新脚本已修复的情况下，继续重复讨论该错误。

每次应以当前最新代码为判断依据。

### 3. 对全 SiO₂ 结构的 GMR 假设

此前 AI 曾不够严谨地认为，同材料基底与图案化层可以直接形成传统导模共振。

正确处理方式是：

判断是否存在导模，需要考虑实际折射率分布、模式有效折射率和约束条件。

如果图案化层缺乏相对于基底的有效折射率优势，就不能直接套用传统高折射率波导层的 GMR 解释。

### 4. Huygens 超表面与高反射的关系

此前 AI 曾过于简单地把电、磁偶极匹配与高反射联系起来。

正确处理方式：

典型匹配 Huygens 条件常与低反射和透射相位调控有关。

高反射需要具体分析散射系数和干涉条件。

### 5. 45°斜入射不一定更有利

不能认为 45°入射天然比正入射更容易产生有用的 GMR。

入射角改变平行动量、辐射通道和模态耦合条件，但不存在普遍适用的最佳角度。

### 6. 不同论文结构不能混淆

必须区分：

* 一维无限延伸圆柱阵列。
* 二维有限高度纳米柱阵列。
* 图案化光子晶体薄板。
* 有基底和无基底结构。

不同结构可能具有不同的模态、对称性和辐射通道。

不能仅因为结构中都有介质柱，就认为文献理论能够直接迁移。

### 7. 对代码正确性判断不够严格

历史中 AI 曾多次回答“没有明确错误”，之后又补充新问题或修改建议。

这使代码可靠性判断变得不够清晰。

以后需要把：

**语法正确、软件兼容、能够运行、物理合理、数值收敛**

分别判断。

### 8. 对计算耗时的解释必须基于证据

本次讨论中，AI 认为 45° BFAST 的额外开销可能是主要耗时因素。

但用户的具体运行日志尚未检查，因此不能确定 BFAST 是唯一原因。

尤其需要避免把性能参考数据当作用户电脑的实测结果。

给出关键公式、适用条件以及当前结构是否满足这些条件。

**仿真结果问题：**

先解释实际得到的物理量，再判断是否足以支持用户的结论，最后提出最有价值的验证方法。

**性能问题：**

先区分算法本身计算量较大、运行资源不足和求解器异常，不要未经诊断就归因于某一个因素。

### 5. 如何判断用户是否理解论文

只有用户主动追问、分析、归纳、应用或明确确认的内容，才能记录为已经理解。

以下情形不能算作用户掌握：

* AI 翻译过论文。
* AI 解释过相关公式。
* AI 总结过论文。
* AI 展示过图表。
* AI 推荐过论文但用户没有进一步讨论。

如果用户重新上传论文，应当以新提供的原文为依据，不要根据迁移档案猜测正文细节。

### 6. 最适合的当前接续方式

如果用户提出“继续之前的 FDTD 仿真”，应当优先围绕求解器性能和可靠性开展工作。

当前真正需要解决的是：

**为什么简单的 250 nm 周期单元在 45° BFAST 宽带仿真下耗时异常，以及如何建立能够稳定运行的参考仿真。**

不应该立即跳到大规模参数扫描，也不应该在结果还不可靠时给出所谓的最优几何参数。

### 7. 关于本档案的优先级

本档案前文的“偏好”“共识”“研究状态”和“协作规则”，包含历史转接材料及 AI 对已有交流的整理。

它们不应与用户本人明确填写的 Prompt 视为相同层级。

**如果用户在档案绝对末尾填写的【最高优先级用户 Prompt】与前文存在冲突，应以末尾用户亲自填写的原文为准。**

不应自行折中、淡化、改写或重新解释用户最终明确提出的要求。

这里的“最高优先级”仅指这份迁移档案所承载的用户上下文内部的优先级，实际执行仍需遵守新对话环境中的系统级和开发者级指令。
