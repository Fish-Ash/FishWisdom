### 2. 初步评估了项目难度

结论：

> 项目原理上可实现，但工程难度偏高；作为第一版仿真任务可做，作为高效率实物器件较难，作为高功率 351 nm 工程器件很难。

主要难点：

* 351 nm 属于紫外波段，对材料和加工要求高；
* 351、526.5、1053 nm 跨度大；
* 同一 meta-atom 需要对多个波长产生不同响应；
* 高效率和低串扰难以同时满足；
* 实物加工和高功率激光损伤风险较高。

---

### 3. 理解并确认了相位梯度

已确认：

[
\frac{d\phi}{dx}=k_0\sin\theta
]

其中：

[
k_0=\frac{2\pi}{\lambda}
]

并明确：

* (x) 是超表面平面内的横向方向；
* 相位梯度为 0 表示不主动偏转；
* 351 nm 若直通，则目标相位梯度可设为 0；
* 相位梯度单位可以是 rad/nm 或 rad/μm，但需要和波长单位保持一致。

---

### 4. 得到了目标相位梯度

假设偏转角为 (10^\circ)，得到：

| 波长       |     相位梯度 (\mathrm{d}\phi/\mathrm{d}x) |
| -------- | ------------------------------------: |
| 351 nm   |                  (0\ \mathrm{rad/nm}) |
| 526.5 nm | (+2.07\times10^{-3}\ \mathrm{rad/nm}) |
| 1053 nm  | (-1.04\times10^{-3}\ \mathrm{rad/nm}) |

符号含义：

* 正号表示向 (+x) 方向偏转；
* 负号表示向 (-x) 方向偏转。

---

### 5. 得到了相位周期

公式：

[
\Lambda=\frac{2\pi}{\left|\frac{d\phi}{dx}\right|}
]

也等价于：

[
\Lambda=\frac{\lambda}{\sin\theta}
]

在 (\theta=10^\circ) 下：

| 波长       |                相位周期 |
| -------- | ------------------: |
| 351 nm   |            (\infty) |
| 526.5 nm | (3032\ \mathrm{nm}) |
| 1053 nm  | (6064\ \mathrm{nm}) |

说明：

* 351 nm 相位梯度为 0，因此没有有限横向相位周期；
* (\Lambda) 是横向相位从 0 变化到 (2\pi) 的长度，不是光的波长 (\lambda)。

---

### 6. 确定了第一版单元周期 (p)

暂定：

[
p=200\ \mathrm{nm}
]

理由：

* 小于最短波长 351 nm 在介质中的尺度约束；
* 可作为第一版 MVP 初值；
* 后续可扫描优化。

---

### 7. 完成相位周期离散化

计算：

[
N=\frac{\Lambda}{p}
]

得到：

| 波长       | 连续 (N) | 离散后 (N) |              实际相位周期 |
| -------- | -----: | ------: | ------------------: |
| 526.5 nm |  15.16 |      15 | (3000\ \mathrm{nm}) |
| 1053 nm  |  30.32 |      30 | (6000\ \mathrm{nm}) |

说明：

> 连续设计给出理论相位周期，实际结构只能放整数个 meta-atom，因此需要离散化。

---

### 8. 计算了相位步进

公式：

[
\Delta\phi=\frac{2\pi}{N}
]

得到：

| 波长       | (N) |              相位步进 |
| -------- | --: | ----------------: |
| 526.5 nm |  15 | (\frac{2\pi}{15}) |
| 1053 nm  |  30 |  (\frac{\pi}{15}) |

---

### 9. 建立了公共超胞概念

因为：

[
N_{526.5}=15
]

[
N_{1053}=30
]

公共超胞取：

[
N_{\text{supercell}}=30
]

也就是用 30 个 meta-atom 作为公共周期。

在 30 个 meta-atom 内：

* 526.5 nm 相位循环两次；
* 1053 nm 相位循环一次。

---

### 10. 得到了 30 个 meta-atom 的目标相位表

当前交付版本：

| 编号 (m) |                         526.5 nm 目标相位 |        1053 nm 目标相位 |
| -----: | ------------------------------------: | ------------------: |
|      0 |                                   (0) |                 (0) |
|      1 |                     (\frac{2\pi}{15}) |   (-\frac{\pi}{15}) |
|      2 |                     (\frac{4\pi}{15}) |  (-\frac{2\pi}{15}) |
|    ... |                                   ... |                 ... |
|     14 |                    (\frac{28\pi}{15}) | (-\frac{14\pi}{15}) |
|    ... |                                   ... |                 ... |
|     29 | (\frac{58\pi}{15} = \frac{28\pi}{15}) | (-\frac{29\pi}{15}) |

存疑点：

> 关于相位是否需要按 (2\pi) 取模，以及取模对实际设计有什么影响，用户暂时不理解，要求先记录，暂不展开。
